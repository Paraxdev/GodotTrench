# TrenchDot { #trenchdot }

![TrenchDot, um editor de níveis para o Godot](assets/brand/itch-banner-960x300.png)

O TrenchDot é um editor de níveis baseado em brushes para o Godot, no espírito do TrenchBroom e do Hammer.
Suporta I/O, malhas próprias (Hammer, Quake, Blockbench) e mais!

O TrenchDot tira muita inspiração do TrenchBroom e segue o próprio caminho em torno do Godot. Ele não tem vínculo com o
projeto TrenchBroom.

![O editor TrenchDot](screenshots/editor.png)

## Download { #download }

O TrenchDot tem uma [beta contínua no GitHub](https://github.com/Paraxdev/TrenchDot/releases/tag/beta), ou seja, ela é
sempre a versão mais nova que você pode conseguir.
Por estar numa fase muito inicial, nenhuma versão LTS está planejada no momento. Quando ele se firmar como um software
útil, será feita uma versão completa.

Como alternativa, ele também está disponível no [itch.io](https://paraxdev.itch.io/trenchdot).

Para compilá-lo a partir do código-fonte, veja [Desenvolvimento](development.md).
