# TrenchDot { #trenchdot }

![TrenchDot, ein Level-Editor für Godot](assets/brand/itch-banner-960x300.png)

TrenchDot ist ein Brush-basierter Level-Editor für Godot, im Geist von TrenchBroom und Hammer.
Unterstützt I/O, eigene Meshes (Hammer, Quake, Blockbench) und mehr!

TrenchDot holt sich viel Inspiration von TrenchBroom und geht rund um Godot seinen eigenen Weg. Es steht in keiner Verbindung zum
TrenchBroom-Projekt.

![Der TrenchDot-Editor](screenshots/editor.png)

## Download { #download }

TrenchDot hat eine [laufende Beta auf GitHub](https://github.com/Paraxdev/TrenchDot/releases/tag/beta), das heißt, sie ist
immer die neueste Version, die du bekommen kannst.
Weil das Projekt noch ganz am Anfang steht, ist derzeit keine LTS-Version geplant. Sobald daraus nützliche Software wird,
folgt ein vollständiges Release.

Alternativ gibt es TrenchDot auch auf [itch.io](https://paraxdev.itch.io/trenchdot).

Wie du es aus dem Quellcode baust, steht unter [Entwicklung](development.md).
