# 几何体 { #geometry }

## 笔刷 { #brush }

一个凸的实体，存成它精确的角点，加上一份索引这些角点的面列表，所以你不必求平面相交就能得到角点。面的平面在加载时重新计算。

| 键 | 类型 | 含义 |
| --- | --- | --- |
| `vertices` | `[x, y, z]` 数组 | 以地图单位表示的角点 |
| `faces` | 面的数组 | 每个面一个多边形 |

每个面：

| 键 | 类型 | 默认值 | 含义 |
| --- | --- | --- | --- |
| `indices` | 整数数组 | 必填 | `vertices` 的索引，至少三个，从外面看是逆时针 |
| `material` | 字符串 | `""` | 总是写入。纹理名称，例如 `base/wall` |
| `uv` | 对象 | 轴向对齐 | 总是写入。纹理怎样铺在这个面上，见[纹理投影](#texture-projection) |
| `props` | 字符串到字符串的对象 | 省略 | 自由格式的面属性，比如下面的混合键 |
| `disp` | 对象 | 省略 | 把这个面变成[置换](#displacement) |
| `colors` | `[r, g, b, a]` 数组 | 省略 | [顶点绘制](../editor/texturing.md#vertex-paint)，每个索引一种颜色 |

Godot 构建时会跳过顶点数或面数少于四个的笔刷，因为任何封闭的实体都不会比这更少。

一个面还可以在两种材质之间混合。面属性 `blend_material`、`blend_detile`、`blend_uv_scale` 和 `blend_detile_sharpen` 负责设置它，之后顶点颜色的 alpha 会让整个面从 `material` 向 `blend_material` 渐变。

## 纹理投影 { #texture-projection }

`uv` 是 Valve 220 风格的投影，带显式的轴：两个世界方向说明纹理在面上朝哪个方向延伸，再用偏移和缩放把它放好。

| 键 | 类型 | 含义 |
| --- | --- | --- |
| `u_axis`、`v_axis` | `[x, y, z]` | 纹理 u 和 v 的世界方向 |
| `offset` | `[u, v]` | 以纹素计的位移 |
| `scale` | `[u, v]` | 每纹素的地图单位数 |
| `rotation` | 数字 | 可选，仅供参考，轴里已经包含了旋转 |

点 `p` 落在纹素 `dot(p, u_axis) / scale.x + offset.x` 上，v 同理。要得到最终的 UV，再把它除以纹理尺寸。材质有 `texture_size` 时用它，见[材质](../godot/materials.md)，否则用图像的像素尺寸。

缺少 `uv` 时，等于 `u_axis = [1, 0, 0]`、`v_axis = [0, 0, 1]`、缩放为 1。有 `uv` 时，除 `rotation` 外每个键都是必填的。

## 纹理设置 { #texture-settings }

顶层的 `textures` 对象存放每个带材质的面共用的设置，以材质名为键。只写入和默认值不同的设置，没有任何设置的材质会被省略。

| 键 | 类型 | 默认值 | 含义 |
| --- | --- | --- | --- |
| `bake` | 布尔 | `true` | 这些面在光照贴图里占一块位置。关掉后，Godot 给它们的是烘焙光的平均值 |
| `casts` | 布尔 | `true` | 这些面在烘焙中会挡光 |
| `texel_scale` | 数字 | `1` | 把这些面上光照贴图的纹素大小乘以这个值，范围 0.125 到 16 |
| `size` | `[w, h]` | 无 | 一次重复覆盖多少地图单位，用来代替上面的纹理尺寸 |
| `projection` | 字符串 | `"face"` | `"world"` 会忽略每个笔刷面的 `uv`，改用按它法线重置的投影，偏移 0、缩放 1 |

`world` 只作用于笔刷面，网格的面保留自己的投影。

## 置换 { #displacement }

一个四边形的面可以带 Hammer 风格的置换，也就是一个顶点网格，每个顶点都沿面的法线被推出去。

| 键 | 类型 | 默认值 | 含义 |
| --- | --- | --- | --- |
| `power` | 整数 | 必填 | 1 到 4。网格每边有 `2^power + 1` 个顶点 |
| `heights` | 数字数组 | 必填 | 每个网格顶点沿法线被推出多远 |
| `alphas` | 数字数组 | 省略 | 每个网格顶点的混合权重，0 显示这个面的材质 |

两个数组都按行优先排列，各有 `(2^power + 1)^2` 项。行从面的第一个角朝第四个角方向，列从第一个角朝第二个角方向。

## 网格 { #mesh }

可编辑的多边形网格。和笔刷不同，它可以是凹的、开放的，或者带不平的面。

| 键 | 类型 | 默认值 | 含义 |
| --- | --- | --- | --- |
| `vertices` | `[x, y, z]` 数组 | 必填 | 以地图单位表示的角点 |
| `faces` | 面的数组 | 必填 | 键和笔刷的面一样，另加 `uvs` |
| `smooth_angle` | 数字 | `0`，省略 | 夹角小于这个度数的相交面共用法线，着色平滑。0 是平直着色 |
| `decal` | 布尔 | `false`，省略 | 把这个网格标记为[贴花](../editor/decals.md) |

平滑时，会把每个面角和它顶点周围的每个面做比较。一个网格如果每个角需要超过 64 次比较，或者总共超过 262,144 次，就改用平直着色。只有被几百个面共用的顶点才会到这一步，比如超过大约 650 条边的圆锥的尖端。

网格面的 `uvs` 是 `[u, v]` 的数组，每个索引一项，以纹理宽度计。有它时它会替代 `uv`，数量和 `indices` 对不上时，编辑器会拒绝这张地图。
