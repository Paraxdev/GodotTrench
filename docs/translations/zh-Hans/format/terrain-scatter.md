# 地形与散布 { #terrain-and-scatter }

## 地形 { #terrain }

规则网格上的高度图，每个网格顶点一个高度，最多用四个纹理图层绘制。大块数据在 JSON 里是 base64 文本，在[二进制容器](container.md#value-encoding)里是原始字节。

| 键 | 类型 | 默认值 | 含义 |
| --- | --- | --- | --- |
| `origin` | `[x, y, z]` | 必填 | 第一个顶点的世界位置 |
| `resolution` | `[nx, nz]` | 必填 | 沿 X 和 Z 的顶点数，各至少为 2 |
| `cell_size` | 数字 | 必填 | 相邻顶点之间的地图单位数 |
| `heights` | base64 | 必填 | 小端序 32 位浮点数，每个顶点一个高度 |
| `layers` | 数组 | 必填 | 最多四个纹理图层，见下 |
| `splat` | base64 | 省略 | 每个顶点四个权重字节，每个图层一个，表示每个图层在那里显示多少 |
| `holes` | base64 | 省略 | 每个格子一个字节，非零表示把这个格子从地形里挖掉 |
| `chunk_cells` | 整数 | `32` | 总是写入。每个分块边上的格子数。渲染和碰撞时，地形会按这个大小切成分块 |

顶点 `(i, j)` 位于 `origin + (i * cell_size, heights[j * nx + i], j * cell_size)`。`splat` 用同样的顺序，读取时会把权重归一化，全为零的条目表示图层 0。`holes` 按同样的顺序覆盖 `(nx - 1) * (nz - 1)` 个格子。

每个图层：

| 键 | 类型 | 默认值 | 含义 |
| --- | --- | --- | --- |
| `material` | 字符串 | 必填 | 这个图层绘制的材质 |
| `tile` | 数字 | `256` | 纹理每重复一次占多少地图单位 |
| `detile` | 数字 | `0` | 0 到 1，重复被打散的强度，用来让网格般的图案不再显现 |
| `detile_sharpen` | 数字 | `0.5` | 0 到 1，去平铺后的结果保持多清晰 |

这些设置在实际中是什么样，见[地形图层](../editor/terrain-layers.md)。

地形始终与坐标轴对齐。实例会用它完整的变换，包括旋转，来移动地形的中心，但永远不会旋转网格本身。

## 散布 { #scatter }

一个散布集合把少数几种模型的许多副本放在同一个节点里，比如绘制到表面上的树、石头或草。编辑器一侧见[散布](../editor/scatter.md)。除 `targets` 和 `material` 外，每个键都总是写入。

| 键 | 类型 | 默认值 | 含义 |
| --- | --- | --- | --- |
| `name` | 字符串 | 必填 | 编辑器里显示的名称 |
| `kind` | 字符串 | `props` | Godot 构建什么。`props` 保留脚本和碰撞，`foliage` 是不带碰撞的 MultiMesh |
| `targets` | 节点 id 数组 | 省略 | 这个集合绘制在其上的表面 |
| `items` | 数组 | 必填 | 它散布的模型，见下 |
| `collision` | 字符串 | foliage 为 `none`，其余为 `convex` | 每个实例的碰撞形状：`none`、`box`、`convex`、`decomposition` 或 `trimesh` |
| `cast_shadows` | 布尔 | `true` | 实例是否投射阴影 |
| `visibility_range` | 数字 | `0` | 超过这个距离就隐藏实例，0 表示永不隐藏 |
| `chunk_size` | 数字 | `0` | 把集合切成这个大小的格子，让 Godot 能剔除屏幕外的部分，0 表示只有一个格子。新建的集合用 2048 |
| `static_props_multimesh` | 布尔 | `false` | 带脚本的道具场景也用 MultiMesh 绘制。道具多时更省，但它们的脚本会被丢掉 |
| `material` | 字符串 | 省略 | 整个集合的材质覆盖 |
| `instances` | 数组 | 空 | 已放置的实例，见下 |

把一个集合和它指向的表面一起复制，副本会指向复制出来的表面。

每个条目是集合可以放置的一种模型：

| 键 | 类型 | 默认值 | 含义 |
| --- | --- | --- | --- |
| `source` | 字符串 | 必填 | `res://` 模型或场景 |
| `weight` | 数字 | `1` | 这个条目被选中的相对几率 |
| `scale` | `[min, max]` | `[0.8, 1.2]` | 随机等比缩放的范围 |
| `spacing` | 数字 | `48` | 到其他每个实例的最小距离 |
| `align` | 数字 | `0` | 0 表示直立，1 表示顺着表面法线，中间的值表示倾斜一部分 |
| `random_yaw` | 布尔 | `true` | 把每个实例转向随机的朝向 |
| `tilt` | 数字 | `0` | 随机倾斜的最大角度，单位是度 |
| `sink` | 数字 | `0` | 压进表面的地图单位数，这样树根和岩石底部不会悬空 |
| `material` | 字符串 | 省略 | 这个条目的材质覆盖，优先于集合的 |
| `enabled` | 布尔 | `true`，省略 | 画刷是否绘制这个条目。已经放下的实例会保留 |

每个实例是一个扁平数组 `[item, x, y, z, pitch, yaw, roll, scale]`，其中 `item` 是 `items` 的索引，角度单位是度，按 YXZ 顺序。保存时位置四舍五入到 0.01，角度到 0.1，缩放到 0.001，这样容器就能把它们存成[整数列](container.md#value-encoding)。
