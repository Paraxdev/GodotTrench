# 逻辑图 { #the-logic-graph }

**逻辑**面板把地图的实体 I/O 显示成一张图。每个接了线的实体和每个逻辑实体都是一个节点，每条连接都是一根线，从一个节点右侧的输出引脚连到另一个节点左侧的输入引脚。

图里显示的是检查器编辑的同一批输出，所以在一边的改动会立刻显示在另一边。无论你用不用这张图，地图、Godot 构建和游戏的工作方式都完全一样。

## 打开它 { #opening-it }

选择*视图 > 面板 > 逻辑*。

![视图菜单，面板已展开，悬停在逻辑上](../assets/logic-graph/menu-panels-logic.png)

它会在视图下方的材质旁边打开，并把那个停靠区扩大到窗口中间部分的一半左右，因为图需要空间。拖动分隔线或标签页可以改变它。

![夜间街区演示地图的逻辑面板：按钮连到门、一个触发器和一个计时器，标题按类别着色，一个叫“大厅灯光”的框围着一个带延迟打开三盏灯的触发器](../assets/logic-graph/graph.png)

## 读懂这张图 { #reading-the-graph }

| 你看到的 | 它的含义 |
| --- | --- |
| 节点标题 | 实体的 targetname，没有则是它用*重命名*起的名字，再没有就是它的类名。下面是类别和类名 |
| 标题下的灰色文字 | 与实体默认值不同的设置，比如 `max 3`、`wait 2 s` 或 `once`，截成两行短文字。没有这些文字的节点用的都是默认值。检查器会显示全部设置 |
| 标题颜色 | 类别：取定义的分组，没有则取类名的第一个词，所以 `logic_relay` 是 *logic*。见[颜色](#colors) |
| 引脚 | 输入在左，输出在右，来自[实体定义](entities/README.md)，再加上地图已经在那个实体上用过的名字。实心引脚表示接了线。悬停在引脚上可以看到它的类型和它传递的值 |
| 黄色的引脚名 | 这个名字不在实体的定义里，问题面板也会对它发出警告 |
| 连线标签 | 设置了的话，会显示延迟、`once` 或可触发的次数，以及参数。悬停在连线上可以看到完整的输出、目标、输入和延迟 |
| 蓝色节点和连线 | 只有运行中的游戏才会解析的[目标](parameters.md#targets)，比如 `!player`、`@enemies`、节点路径或像 `door_*` 这样的通配符 |
| 红色节点，红色虚线 | 没有任何实体拥有的 targetname，通常是打错了 |

只有接了线的实体，以及逻辑和数学实体，才会有节点。选中任何其他实体，无论是在视图里还是在大纲里，它也会显示出来，随时可以接线。

## 颜色 { #colors }

颜色帮助你扫视一张大图，但每种颜色同时也配有名称或形状，而且这些配色对常见的几种色盲也保持可区分。

| 类别 | 颜色 |
| --- | --- |
| logic | 蓝色 |
| math | 橙色 |
| trigger | 蓝绿色 |
| func、门、按钮和移动体 | 朱红色 |
| light | 黄色 |
| env | 青色 |
| game | 天蓝色 |
| prop | 粉色 |
| npc | 红紫色 |
| info | 灰色 |

| 引脚类型 | 颜色 |
| --- | --- |
| pulse，不带值的事件 | 白色 |
| bool | 朱红色 |
| int | 天蓝色 |
| float | 蓝绿色 |
| string | 粉色 |
| vector3 | 黄色 |
| color | 红紫色 |
| node，比如激活者 | 蓝色 |
| variant，任意值 | 灰色 |

传递值的引脚是圆形，pulse 是三角形。连线采用它起点那个输出的颜色。你用定义的 `group` 设置的自定义类别，也会得到自己的颜色。

## 接线 { #wiring }

从输出引脚拖到输入引脚。拖动时，连线能接上的引脚会出现一个圆环，而它将落到的那个引脚会被填上。松手后，这条连接就会添加到源实体的输出里。

![从 button_1 的 released 输出拖出一根线，连到 hall_light 的 turn_off 输入，它能接上的引脚显示着圆环](../assets/logic-graph/wire-drag.gif)

pulse 可以接任何引脚，值则可以接同类型的引脚，所以 `activator` 节点接不上 `int` 输入。（int 也可以接 float 或 bool 引脚，反过来也一样，variant 可以接任何类型。）任何引脚仍然都会接受这根线，实体 I/O 里的名字只会在游戏运行时检查。

没有 targetname 的目标会在同一步里得到一个：用你在大纲里通过*重命名*给它起的名字，所以你叫它 `lamp` 的灯会成为目标 `lamp`，否则就是一个空闲的名字，比如 `door_2`。如果别的实体已经有这个名字，就会在后面加上数字。

你也可以把线放在别的地方：

* 放在节点的标题上，从它所有的输入里挑选，或者输入任何名字。
* 放在空白处，在那里添加一个逻辑实体，它已经接上了你拖出线的那个引脚。

### 添加逻辑实体 { #adding-logic-entities }

在空白处右键，或者按面板左上角的**添加**，就可以不带连线地添加一个逻辑实体。

![添加列表：一个搜索框，下面是 logic 分组，logic_animate 高亮，接着是 logic_auto、logic_branch 等](../assets/logic-graph/add-menu.png)

不搜索时，列表按类别分组，先是 logic 和 math，然后是其他有输入或输出的实体。输入文字可以在所有类里搜索：名称以这段文字开头或包含它的类排在前面，然后是类别或描述符合的类。上下方向键移动高亮，Enter 添加那个类。

新实体都是点实体，而 Godot 构建会为每个实体生成一个节点，所以它们需要在地图里有个位置。它们会放在名为 *Logic* 的图层上，挨着和它们接线的实体，或者放在 3D 视图相机的前方。每个实体会立刻得到一个空闲的 targetname，比如 `relay_2`，它就是节点的标题。请在检查器里修改它，因为*重命名*只会设置大纲里的名字。

> [!NOTE]
> 没有玩法实体包就没有可添加的逻辑实体。这时添加菜单会提示你安装它。

### 编辑一条连接 { #editing-a-connection }

点一根线，图右上角的一个框就能让你编辑它的输出、目标、输入、参数、延迟和次数。它的**删除**按钮，或者指针在图上时按 Delete 键，可以删除它。

![选中了从 button_1 到 hall_light 的连线，右上角是“来自 button_1 的连接”框，输出 released，目标 hall_light，输入 turn_off，延迟 0.00 秒，次数每次，以及删除按钮](../assets/logic-graph/connection-box.png)

在连线上的任意位置右键，不只是在它的标签上，就能看到**编辑连接**和**删除连接**。每一次改动都是*历史*里的一步，所以撤销和别处一样好用。

### 节点菜单 { #the-node-menu }

右键点一个节点，可以看到能对它的实体做什么。

![hall_light 节点的右键菜单：在视图中聚焦、重命名、复制一份、选择相连节点、断开全部、删除实体，以及带有 switched 输出的模拟](../assets/logic-graph/node-menu.png)

| 项目 | 作用 |
| --- | --- |
| 在视图中聚焦 | 选中它并把视图移到它那里，和双击一样 |
| 重命名 | 在大纲里重命名实体。有 targetname 时节点以 targetname 为标题，所以这个名字只会显示在没有 targetname 的实体上 |
| 复制一份 | 把实体复制到旁边一个网格步长的位置，从它出发的连线也一起复制 |
| 选择相连节点 | 选中这个节点，以及与它有线相连的每个节点 |
| 断开全部 | 一步删除进出这个节点的每一根线。实体保留 |
| 删除实体 | 把实体从地图里移除，见[复制、粘贴和删除](#copy-paste-and-delete) |
| 模拟 | 在纸面上触发它的一个输出，见[模拟](#simulate) |

选中了多个节点时，右键点其中一个已选中的节点，复制一份和删除会作用于所有选中的节点。

## 复制、粘贴和删除 { #copy-paste-and-delete }

图里显示的是地图的实体，所以指针在图上时，这些按键作用于所选的实体，笔刷也包括在内。

| 按键 | 作用 |
| --- | --- |
| Ctrl+C、Ctrl+V | 复制和粘贴。副本会落在离原件一个网格步长的地方，连线也一起带上，因为指针下没有视图可以放它。指针在某个视图上时粘贴，就会把它放在那里 |
| Ctrl+D | 复制一份，同样落在离原件一个网格步长的地方 |
| Delete | 删除所选的连线或框。没有选中它们时，会把所选**实体从地图里**删除，而不只是删掉它们的节点。从其他实体连到被删实体的线会变红。撤销能把一切恢复 |
| Ctrl+A | 选中地图里的所有东西，而不只是显示出来的节点 |

## 四处移动 { #moving-around }

| 想要 | 做法 |
| --- | --- |
| 缩放 | 滚动滚轮 |
| 平移 | 用中键或右键拖动。不移动的右键点击会打开一个菜单，所以手抖的平移可能会把它弹出来，按 Escape 关闭 |
| 选择 | 点一个节点，Shift 或 Ctrl 点击是追加，在空白处拖动是框选。实体会在视图和大纲里同时被选中，反过来也一样 |
| 在视图中聚焦 | 双击一个节点 |
| 移动 | 拖动节点。它们的位置会保存在地图里 |
| 整理 | **排列**按信号流向布置所选的节点。选中不到两个时，每个节点都会回到自动布局 |
| 看到全部 | **适应**，或者指针在图上时按 Home |
| 看到所选内容 | 指针在图上时按 F，会把所选节点取景 |

没人动过的节点会遵循自动布局，按信号流向从左到右排列，视图会缩放到适合面板，直到你自己缩放或平移。一旦你在图里移动了节点或接了线，其他节点就保持原位，新节点会出现在它所连接的东西旁边。蓝色和红色的标记节点不是实体，所以你不能移动它们。它们就放在以它们为目标的节点旁边。

## 框 { #frames }

框是一组节点后面带标题的方框，用来让一张大图保持有条理：一栋建筑的门、一个谜题、一段过场。选中节点后在图上按 **C**，或者按面板工具栏里的**聚焦**，然后输入它的标题。顶部那张图里的*大厅灯光*框就是一个。

| 想要 | 做法 |
| --- | --- |
| 把框连同里面的内容一起移动 | 拖动它的标题 |
| 调整它的大小 | 拖动它右下角的角 |
| 重命名 | 双击它的标题，或者选中它后按 F2 |
| 改变颜色或删除 | 右键点它的标题。删除框会保留它里面的节点 |

框作为编辑器数据保存在地图里，Godot 构建会忽略它们。

## 模拟 { #simulate }

选中一个实体，按**模拟**并选它的一个输出，或者右键点一个节点。图会用黄色给这个输出会触发的每根线编号，图下方的列表按节点标题显示每一步，按各步到达的顺序排列，并给出经过延迟后的秒数。**清除**会结束预览。点一步可以选中它的连线。

![在 button_2 上模拟：通往 garage_door 以及再通往 garage_beacon 的连线是黄色的，编号为 1 到 3，图下方的列表写出了每一步](../assets/logic-graph/simulate.png)

它遵循运行时的规则：目标按 targetname 查找，继电器、计时器、计数器、门控、门和其他常见实体会把链传下去。像 `!player` 这样的运行时目标会显示出来，但不会继续跟踪。

触发几个输出之一的实体，会显示它可能触发的每一根线。这些步骤以及它们之后的一切，在列表里以 `(maybe)` 结尾，在连线的编号上以 `?` 结尾，悬停在上面会说明它在等什么。由 `add` 或 `subtract` 驱动的计数器就是这样继续到 `hit_max` 和 `hit_min` 的，因为预览不会计算按了几次：这一步就在那里，当计数器达到它的 `max` 或 `min` 时才会发生。`logic_sequence` 按它的 `interval`、`times` 和 `steps` 属性给出的时间触发它的各步，所以过场读起来就像一条时间线。

模拟是在纸面上进行的，不需要 Godot。游戏里实际会发生什么，见[调试接线](debugging.md)。
