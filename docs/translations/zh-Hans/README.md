# TrenchDot { #trenchdot }

![TrenchDot，一款面向 Godot 的关卡编辑器](assets/brand/itch-banner-960x300.png)

TrenchDot 是一款面向 Godot 的基于笔刷的关卡编辑器，秉承 TrenchBroom 和 Hammer 的精神。
支持 I/O、自定义网格（Hammer、Quake、Blockbench）等更多功能！

TrenchDot 从 TrenchBroom 那里汲取了很多灵感，同时围绕 Godot 走出了自己的路。它与 TrenchBroom 项目没有任何关联。

![TrenchDot 编辑器](screenshots/editor.png)

## 下载 { #download }

TrenchDot 在 GitHub 上有[滚动更新的 beta 版](https://github.com/Paraxdev/TrenchDot/releases/tag/beta)，也就是说它始终是你能拿到的最新版本。
由于项目还处在非常早期的阶段，目前没有推出 LTS 版本的计划。等它成长为真正有用的软件，会发布正式版。

你也可以在 [itch.io](https://paraxdev.itch.io/trenchdot) 上获取它。

想从源代码构建，请访问[开发](development.md)。
