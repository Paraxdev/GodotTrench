# 贴花 { #decals }

贴花用来在表面上添加污渍、水渍、裂缝、海报和招牌。它们被画在比身后的墙稍微靠近相机一点的位置，并混合叠加在墙上，所以不会相对于墙或者彼此闪烁。

## 放置贴花 { #placing-a-decal }

1. 找到材质

    在材质面板里查找它，面板左上角的搜索框会有帮助。

2. 按住 Alt，把它拖到面上

    光标旁边的卡片会提醒你，Alt 放下的是贴花。

    ![把 night/shop_sign 拖到砖墙上，光标旁边的卡片写着：放到面上，Shift 覆盖整个笔刷，Alt 放下贴花](../assets/decals/decal-alt-drop.png)

3. 松开

    你应该会看到贴花落在你放下的位置，是一个一米见方、32 乘 32 个单位的方块，朝向面的外侧。

    ![砖墙上的店铺招牌贴花](../assets/decals/decal-on-wall.png)

贴花是一个普通的网格，所以可以像移动、旋转和缩放网格一样处理它。选中它后，检查器里会显示已勾选的 **贴花（混合，双面）**，以及用来精确摆放它的位置和尺寸字段。

![选中了贴花的检查器，勾选了贴花（混合，双面），尺寸为 32 乘 32](../assets/decals/decal-inspector.png)

同一个复选框可以把任何薄网格变成贴花，用于有自定义轮廓的情况。

柔和的边缘会保持柔和。如果想要硬边切口，请使用 Alpha 裁剪模式的材质，参见[透明度](../godot/materials.md#transparency)。

## 为什么不用薄笔刷 { #why-not-a-thin-brush }

> [!WARNING]
> 不要用离墙几毫米的薄笔刷或薄网格来伪造贴花。它们会闪烁。

凑近看，薄笔刷看起来没问题。一退远，它就会开始透过墙闪烁，形成条纹，并且随着你移动而蠕动。这叫做深度冲突。

GPU 通过比较各个表面的深度，来判断每个像素处哪个表面最近，而它存储深度的级数是有限的。表面越远，或者你沿着它看得越平，这些级数就越粗。在几米之外，笔刷和墙会被舍入到同一级，于是每个像素几乎是随机地选中其中一个，而且每次相机移动，选择都会变。把笔刷离墙更远，只会把闪烁推到更远的地方，而且在近处它会明显地悬浮在墙前面。

贴花没有这个问题。Godot 构建地图时，会把每个贴花朝相机拉近它距离的 0.05%，也就是 1 米处半毫米，100 米处 5 厘米，所以在任何距离它都保持在墙的前面。这个拉近沿着你的视线进行，所以贴花在屏幕上不会移位。它自己也不写入深度，所以重叠的贴花是互相混合，而不是互相冲突。

薄网格只要勾选上 **贴花（混合，双面）** 就没问题了，那会让它成为真正的贴花。

## 投影贴花 { #projected-decals }

普通贴花是平的。对于要包裹住台阶、管道或者凹凸地面的污渍，请改用投影贴花。它是一个实体，会把材质照到它方框内的一切东西上，包括道具。它的绘制开销更大，所以在平整的表面上还是用普通贴花。

它随玩法实体包一起提供，名为 `infodecal`。[投影贴花](projected-decals.md)会告诉你如何设置它、如何放置它，以及需要注意什么。
