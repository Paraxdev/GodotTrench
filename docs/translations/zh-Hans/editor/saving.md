# 保存与恢复 { #saving-and-recovery }

按 Ctrl+S 保存，按 Ctrl+Shift+S 则是*另存为…*。文件对话框会从当前地图所在的文件夹开始，从没保存过的地图则从 Godot 项目开始，因为插件是按 `res://` 路径加载地图的。如果你只想快速打开某张地图，*文件 > 项目中的地图*会列出项目里的所有地图。

## 备份与自动保存 { #backups-and-autosave }

编辑器会在你的地图旁边保留两种备用副本：

| 文件 | 写入时机 |
| --- | --- |
| `<map>.tdm.bak` | 每次保存时，写入上一个版本的副本。把它改名为 `.tdm` 就能回到上一次保存 |
| `<map>.tdm.autosave` | 每三分钟一次，针对每个有未保存更改的标签页 |

想改变自动保存的频率，去*文件 > 偏好设置*，设置**自动保存（分钟，0 = 关闭）**。

![偏好设置里的自动保存（分钟，0 = 关闭）字段，设为 3](../assets/saving/prefs-autosave.png)

自动保存使用 Godot 不会导入的扩展名，所以做到一半的地图不会出现在你的游戏里。保存地图会删除它的自动保存。

## 恢复地图 { #recovering-a-map }

如果编辑器在你保存之前关掉了，就打开自动保存：

1. 选择*文件 > 打开地图…*。
2. 选**自动保存（恢复地图）**这个文件类型，打开 `.tdm.autosave` 文件。状态栏应该会提示已从自动保存恢复了地图。
3. 保存。这会重新写出真正的 `.tdm`。

从没保存过的地图会改为自动保存到一个临时文件。你可以在*文件 > 打开最近*里找到它们，在*自动保存的无标题地图*下面。

![文件 > 打开最近，顶部是没有最近的地图，下面是自动保存的无标题地图列表](../assets/saving/open-recent-autosaves.png)

## 损坏的文件 { #damaged-files }

磁盘上损坏的地图文件仍然能打开。编辑器会读取每个完好的部分，把图层、分组或实体已经丢失的对象放进一个名为*Recovered*的图层，并在状态栏里说明哪些内容无法读取。保存时会把损坏的原文件保留为 `<map>.tdm.bak`，所以你仍然可以从版本控制里还原它。
