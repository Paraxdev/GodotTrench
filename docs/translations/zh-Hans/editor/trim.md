# 饰条 { #trim }

*笔刷 > 添加饰条…* 会沿着面的边缘铺设一条条笔刷，从面上凸出来。沿着墙的底部是踢脚线，沿着顶部是顶角线，围着地板是边框，围着水池是池沿。下面是一个普通房间点击一次前后的样子：

![一个抹了灰泥的房间，有一个门洞，墙被选中，还没有饰条](../assets/trim/room-before.png)

![同一个房间，沿着墙的底部有深色踢脚线，一直延伸到门洞](../assets/trim/room-after.png)

1. （可选）选择饰条的材质

    按 Escape 让所有东西都不被选中，然后在材质面板里点击那个材质。它会成为当前材质，而不会改变地图。

2. 选中墙

    所选笔刷的每个竖直面都会得到饰条。如果只想给单个面加，改为 Shift+点击它们，Ctrl+Shift+点击可以添加或移除更多。

3. 打开对话框

    选择 *笔刷 > 添加饰条…*。它一开始使用当前材质，之后可以用 **用当前** 再切换回来。底部会显示它找到了多少个面。

4. 设置条带

    选择哪些 **边** 要加：底部、顶部、两侧或全部。**高度** 是条带沿着面延伸的距离，**深度** 是它凸出多远，**内缩** 会在边缘和条带之间留出间隙。

    ![添加饰条对话框，边设为底部，高度 6 u，深度 2 u，内缩 0 u，材质为 showcase/planks_dark，勾选了仅边下方有地面处，碰撞关闭，选中了 20 个面](../assets/trim/add-trim-dialog.png)

5. 点击 **添加饰条**

    状态栏会显示它做了多少条。

当 **碰撞** 关闭（默认）时，这些条带会放进一个 `func_detail_illusionary` 里，这样玩家不会被它们绊住。勾选它，或者使用没有这个实体的游戏，它们就会放进一个普通的编组。

两个加了饰条的面相接的地方，一条延伸进拐角，另一条在拐角处停下，所以拐角能闭合，两条也不会重叠。在独立的墙端或门洞周围，条带会绕过去。如果一条会落在另一个笔刷内部，比如两段墙之间过梁的两端，就会被省略。

**仅边下方有地面处** 会让底部饰条只加在站在某个东西上的边，所以门洞上方过梁的底面不会得到踢脚线。

> [!TIP]
> 饰条就是普通的笔刷。之后可以像其他笔刷一样，对单个条带重新贴图、删除或改变形状。

## MCP { #mcp }

`trim` 工具接受 `faces`，格式为 `[[brush, face], ...]`，或者笔刷 `ids`，或者当前选区，另外还有 `edges`、`height`、`depth`、`inset`、`material`、`on_floor` 和 `collision`。它返回新建的编组或实体，以及它做了多少条。
