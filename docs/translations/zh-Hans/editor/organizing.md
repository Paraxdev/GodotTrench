# 整理地图 { #organizing-a-map }

地图一大，你就会想把它分成几个部分，方便再找到东西，也把会重复用的部件放在一处。这些大多从大纲开始，它是左边的那个面板。

## 图层 { #layers }

大纲把地图显示成一棵由图层、组和对象组成的树。图层让你把地图分成几部分，比如每栋建筑一个图层，这样你处理其余部分时，就可以隐藏或锁定其中一部分。

点击大纲顶部的**添加图层**新建一个，它会立刻成为当前图层。新对象会放进当前图层，也就是标着*(当前)*的那个，点击某个图层就让它成为当前图层。行前面的眼睛用来隐藏它，锁则让它无法被选中或编辑。

鼠标停在一行上，可以看到它的材质、尺寸和边界。这个对象会同时在每个视图里描出轮廓，这样你就能看出 `brush7` 是哪面墙。

![大纲里 House 图层已展开，鼠标停在 brush7 这一行上，提示显示它的材质、尺寸和边界，同时 3D 视图和前视图里描出了后墙的轮廓](../assets/organizing/outliner-hover.png)

笔刷和网格按种类和编号列出，比如 `brush12` 或 `mesh40`，这样挖空或减去之后留下的墙就能区分开。对象移动时、跨越多次保存，编号都不会变。

### 给东西起名 { #naming-things }

选中一个对象并按 F2，或者在大纲或某个视图里右键点它，选*重命名*。这一行会变成一个文本框。按 Enter 保留名字，按 Escape 取消，名字留空则恢复默认名字。

![大纲里的一行笔刷变成了文本框，里面输入着“front wall”](../assets/organizing/outliner-rename.png)

名字会随地图一起保存。实体的 `targetname` 和这个名字是分开的，所以重命名永远不会改变输出指向的目标。裁切、CSG 操作或转换后留下的各个部分会保留这个名字，给链接组里的对象起名，则会在每个副本里都起上这个名字。

（图层、组和散布集合永远保留一个名字，所以对它们来说，留空什么都不会改变。重命名散布集合时，也会重命名散布工具为它建的那个图层。）

### 在大纲里选对象 { #picking-objects-in-the-outliner }

Ctrl+点击一行，把它加进选择或从选择里去掉。Shift+点击会选中你上次点击的那一行到这一行之间的每一行，Ctrl+Shift+点击则把这个范围加到已选中的内容里。对于藏在其他东西后面、在视图里很难选的对象，用大纲往往更容易。

### 让图层不进入 Godot { #keeping-a-layer-out-of-godot }

对于永远不该进入游戏的参考几何体，右键点它的图层，选*切换导出时省略*。这个图层的名字后面就会显示*[已省略]*。光是隐藏不够，Godot 仍然会构建隐藏的对象。

![Blockout 参考图层的右键菜单，鼠标停在切换导出时省略上](../assets/organizing/layer-menu-omit.png)

## 组 { #groups }

组把对象放在一起，让它们作为一个整体被选中和移动，比如一张桌子的几个笔刷。和组有关的一切都在*编辑 > 组*下面。

![编辑菜单里组已展开，鼠标停在链接复制上](../assets/organizing/menu-groups.png)

| 输入 | 结果 |
| --- | --- |
| Ctrl+G、Ctrl+Shift+G | 把选中的内容编组、取消编组 |
| 点击 | 选中组内的对象 |
| 双击 | 选中整个组 |

**链接复制**（Ctrl+Shift+D）会做出一个与原件保持同步的副本，所以修好一个窗框，就修好了所有窗框。链接的副本在大纲里显示*(已链接)*，点击其中一个会选中整个组，因为它的副本是作为一个整体编辑的。当某个副本必须不同时，*编辑 > 组 > 解除组链接*会断开链接。

## 预制体 { #prefabs }

对于要跨地图复用的部件，选中它们，再选*编辑 > 预制体 > 从选择创建…*。这会把选中的内容存成它自己的 `.tdm`，并在原处放一个实例。预制体文件一变，每个实例都会更新。

![编辑菜单里预制体已展开，鼠标停在从选择创建上](../assets/organizing/menu-prefabs.png)

> [!NOTE]
> 创建预制体之前先保存一次地图。预制体路径是相对于地图存储的，所以在地图有文件之前，编辑器会拒绝创建。

对于粘贴一次之后再自由塑形的部件，请改用[预制体库](prefab-library.md)。

把一个预制体放两次，会得到两个 targetname 相同的实体。实例的 fixup 能解决这个问题：fixup 为 `p1` 时，里面的每个名字都会加上这个前缀，于是 `door` 变成 `p1-door`，每个副本的接线就各自独立。地图文件和 Godot 构建都认识 fixup，但编辑器还没有可以设置它的字段。

## 隔离框 { #cordon }

隔离框会把编辑器缩小到一张大地图的某一部分。

1. 选中你想处理的内容。
2. 选择*视图 > 隔离框 > 用选择设置隔离框*，或者在检查器里点击**隔离框**。

    ![视图菜单里隔离框已展开，鼠标停在用选择设置隔离框上](../assets/organizing/menu-cordon.png)

3. 凡是没有碰到你选中内容周围那个黄色框的东西，现在都被隐藏，也无法被选中，状态栏会显示*隔离框*。

    ![之前：整张地图，有房子、草坪、一堵花园墙、一根柱子和一个高大的参考方块。之后：只剩黄色框里的房子和与它相接的草坪](../assets/organizing/cordon-before-after.png)

*视图 > 隔离框 > 启用隔离框*可以把它关掉再打开，*清除隔离框*则把它移除。隔离框会随地图一起保存。

它只改变编辑器显示的内容，Godot 仍然会构建整张地图。想把某个区域交给另一个工具，*文件 > 导出 > .map，仅隔离框…*只会写出它里面的对象。

## 问题 { #issues }

问题面板是大纲和历史旁边的那个标签页，它会在你工作时检查地图。它列出会在 Godot 里出错或看起来不对的问题，比如没有体积的笔刷、没有材质的面，或者指向没有任何东西使用的 targetname 的输出。

![问题面板里有一条缺少目标的错误、三条警告（重复的笔刷、没有定义的实体、两个会深度冲突的面）和一条空组的提示，大多数带有修复按钮](../assets/organizing/issues-panel.png)

点击一个问题就会选中并框出那个对象。很多问题带有**修复**按钮，标题栏里的**全部修复**会修复所有能修的。

如果警告说某个面与另一个笔刷在同一平面上的面重叠，就表示这两个面在 Godot 里会闪烁。把其中一个面移出这个平面，或者修掉重叠的部分。

如果警告说某个模型不存在，就表示某个道具的 `model` 指向了一个不在那里的文件，所以这个道具构建出来没有网格。当存在同名但扩展名不同的文件时，比如模型写的是 `chair.glb` 而存在的是 `chair.gltf`，警告会点出它的名字。

如果警告说有东西会从地图里运行 GDScript，就表示地图带着它自己的代码，一旦场景在 Godot 里播放，这些代码就会运行。每个带 `source` 或 `expression` 的 `logic_script`、每个能递给它代码的输出或 `logic_call`（比如把 `source` 发给它的输出），以及每个包含其中任何一种的预制体，都会各给出一条。玩别人做的地图之前先读一读它们。

以“Godot”开头的警告来自 Godot 里最近一次构建，也就是保存之后或*在 Godot 中构建*之后：包括缺少定义而被构建出来的类，以及那次构建的其他警告。参见[什么都不做的实体](../godot/entities-troubleshooting.md)。

## 历史 { #history }

历史面板列出每一次编辑，最新的在最上面。点击较早的一条，就会撤销回到它，包括那一条。被撤销的编辑会变暗，留在*当前*上方，点击其中一条就会重做到它。

![历史面板里重命名和编组变暗地排在当前标记上方，鼠标停在挖空这一条上](../assets/organizing/history-panel.png)

## MCP { #mcp }

通过 [MCP 服务器](../mcp.md)驱动编辑器的代理或脚本，用 `validate_map` 工具运行与问题面板相同的检查，它按代号称呼它们，比如 `coplanar_faces` 和 `missing_model`。`run_action` 的 `insert_prefab` 动作带有 `fixup`，所以代理放置实例时，可以顺便给它设置 fixup。
