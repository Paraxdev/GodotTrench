# 笔刷与 CSG { #brushes-and-csg }

笔刷是你搭建关卡时用得最多的东西。它们画起来很快，能整齐地吸附到网格上，在 Godot 里会变成带有匹配碰撞的网格。除非某一节指明了别的工具，这里的一切都使用 **选择** 工具（Q）。

## 绘制与移动 { #draw-and-move }

在选区之外的任意位置、任意视图里拖动，就会有一个方盒跟着鼠标。2D 视图会在它旁边标出尺寸。在 3D 视图里，它从光标下的表面开始，厚度是一个网格步长。在 2D 视图里，它的深度取你上一个画的笔刷的深度，第一个笔刷则是 128 个单位。

![在 3D 中画方盒时的四个视图，新方盒是 144 乘 144 个单位，厚度为一个网格步长，即 16 个单位](../assets/brushes/draw-box-3d.png)

选中笔刷之后，你可以移动它：

| 输入 | 结果 |
| --- | --- |
| 拖动选区 | 移动它，Shift 会锁定到主轴 |
| Ctrl+拖动选区 | 移动一份副本，原件保持不动 |
| Alt+拖动选区（3D） | 垂直移动。如果不是从选区上开始，Alt+拖动会环绕相机 |
| 方向键、Page Up、Page Down | 微调一个网格步长 |
| `[` 和 `]` | 把网格减半和加倍 |

在 3D 里，选区还会出现移动、旋转和缩放的小工具。旋转吸附到 15°，按住 Shift 则是 1°。如果它碍事，可以在 *视图 > 变换小工具* 下把它关掉。

## 精确的位置和尺寸 { #exact-position-and-size }

有时你需要精确的数字，比如一个和墙一样深的门洞切割体。选中笔刷，把数字输入到右侧的 **检查器** 里。

![选中了一个笔刷的检查器，显示它的位置和尺寸字段](../assets/brushes/inspector-position-size.png)

位置是最低的角，也就是 X、Y、Z 最小的那个角，通常也是落在网格上的那个角。新的尺寸会让选区从这个角向外增长，所以位置保持不变。开启吸附时，拖动字段会按网格步进，输入的值则会被精确保留。网格、笔刷实体以及多个对象的选区也会显示同样的字段。

## 改变形状 { #reshape }

不离开选择工具，你就可以改变所选笔刷的形状：

| 输入 | 结果 |
| --- | --- |
| Shift+拖动所选的面（3D） | 推或拉那个面 |
| Ctrl+Shift+拖动所选的面（3D） | 从它上面挤出一个新笔刷 |
| 拖动选区的边（2D） | 调整大小。边会亮成黄色，光标会在拖动可以调整大小的地方改变形状 |

![在 3D 视图中 Shift+拖动所选方盒的侧面，方盒按网格步长拉伸](../assets/brushes/push-face.gif)

对于斜坡、坡道和倾斜的墙，按 C 使用 **裁切** 工具：

1. 沿着切线点击两到三个点。它们会吸附到网格，在 3D 里则落在你点击的表面上。
2. 按 Tab 选择要保留的部分：前半、后半或者两半都留。视图底部的文字会告诉你当前选的是哪一个。
3. 按 Enter 切开。如果点错了，Backspace 会删掉最后一个点。

![裁切工具，在前视图中沿着方盒的上角放了两个点，切割线在 3D 视图中也能看到](../assets/brushes/clip-points.png)

要拖动单个角，按 V 使用 **顶点** 工具，或者在选中笔刷时按 Tab。它会在角上显示手柄，在边的中点和面的中心显示小蓝点。点击一个点就能选中它，或者把它从笔刷上拖开，在那里添加一个角。Delete 会删除所选的顶点。

![裁切过的方盒上的顶点工具，黄色的角手柄，边和面上有蓝色的点](../assets/brushes/vertex-handles.png)

> [!NOTE]
> 笔刷不能有凹陷，所以会造成凹陷的移动会被拒绝。你会在它将要落下的位置看到一个红色的幽灵，状态栏里也有一行提示。改为把那个点向外拉，或者把笔刷转换成[网格](meshes.md)来做凹陷和悬挑。

## 旋转、缩放与测量 { #rotate-scale-and-measure }

| 工具 | 输入 | 结果 |
| --- | --- | --- |
| **旋转**（R） | 拖动选区周围的圆环 | 以 15° 步进旋转，按住 Shift 则是 1° 步进。2D 视图只有一个圆环，绕着它所看向的那条轴 |
| **缩放**（T） | 拖动选区边界上的手柄 | 按网格调整大小，按住 Alt 则两侧同时变化，中心保持不动。3D 视图每一侧都有一个手柄 |
| **测量**（M） | 拖动，或者点击两个点 | 显示以单位和米为单位的距离，并在视图底部显示它的 X、Y、Z 和水平分量 |

![3D 视图中的测量工具，一条标着 230.76 u (7.21 m) 的线，底部是 X、Y 和 Z 分量](../assets/brushes/measure.png)

## 形状生成器 { #shape-generator }

圆柱、拱门、楼梯、屋顶以及其他需要手绘很多笔刷的形状，可以用形状生成器来做。

1. 在形状应该放的位置画一个方盒，并保持选中。
2. 打开 *笔刷 > 形状生成器…*（Ctrl+Shift+B）。
3. 选择 **形状** 和它的选项。对话框会告诉你它填充的范围，以及它会替换当前选区。
4. 点击 **创建**。

![形状生成器对话框设为圆柱体，16 条边，轴为 Y，填充一个 128 x 192 x 128 的选区](../assets/brushes/shape-generator.png)

![左边是被选中的方盒，右边是替换它的 16 边圆柱体](../assets/brushes/shape-generator-box-to-cylinder.png)

圆柱和圆锥默认是竖直站立的。在 **轴** 下选择 **X** 或 **Z**，就能在同一个方盒里把它放倒，用来做管道、原木或横梁，而不用事后再旋转。圆环、拱墙、人字屋顶、尖塔和网格总是生成为[网格](meshes.md)。圆柱、圆锥和球体用 **创建为可编辑网格** 也可以成为网格，然后 **平滑着色** 会把它们磨圆。**文本** 形状用笔刷搭出块状字母，用于招牌和地面文字。

## CSG { #csg }

CSG 操作在 *笔刷 > CSG* 下，这里也有它们的两个设置。

![笔刷菜单中展开了 CSG 子菜单，列出带快捷键的减去、凸合并、相交和挖空，以及“切出的面保留目标的材质”复选框和墙厚字段](../assets/brushes/menu-brush-csg.png)

这四个操作在工具栏里也各有一个按钮，位于吸附和 UV 锁定按钮的右边。

![工具栏中的四个 CSG 按钮，鼠标悬停在凸合并上并显示它的工具提示](../assets/brushes/toolbar-csg.png)

| 操作 | 按键 | 结果 |
| --- | --- | --- |
| 减去 | Ctrl+K | 从它接触到的每个笔刷中切掉选区，然后删除选区。如果选区没有接触任何其他笔刷，就会保留，状态栏会这样提示 |
| 挖空 | Ctrl+Shift+K | 把一个笔刷变成围绕它原来体积的墙，厚度为 16 个单位，除非你在同一个菜单里改了 *墙厚*。太薄放不下两面墙的笔刷会保持原样 |
| 凸合并 | Ctrl+M | 把选区融合成一个把它们包起来的凸笔刷 |
| 相交 | Ctrl+L | 只保留所选笔刷重叠的部分 |

要开一个门洞或窗户，在洞应该在的位置放一个笔刷，然后用减去，[入门](../getting-started.md)里会带你做一遍。切割打开的面会采用切割体的材质，除非你在同一个菜单里勾选 *切出的面保留目标的材质*。

## 置换 { #displacements }

对于笔刷关卡里不平整的地面，比如碎石坡，你可以把一个面变成置换并对它雕刻。

1. Shift+点击一个四边形的面，或者选中笔刷以使用它的顶面。
2. 打开 *笔刷 > 置换*，选择其中一个 **创建** 条目。幂次越高，网格越精细。
3. **雕刻** 工具（G）会自动切换到位，在面上拖动来塑形。

![笔刷菜单中展开了置换子菜单，有创建，幂次 2 (5x5)、创建，幂次 3 (9x9) 和创建，幂次 4 (17x17)，然后是缝合置换和移除置换](../assets/brushes/menu-brush-displacement.png)

对于更大的户外区域，[地形](terrain.md)更合适。
