# 地形绘制 { #terrain-painting }

**混合**工具（Shift+G）用来绘制地形的[图层](terrain-layers.md)，比如沿海滩刷沙子，或在悬崖上刷岩石。和雕刻一样，它作用于选中的地形，什么都没选时则作用于所有地形。

## 混合工具 { #the-blend-tool }

1. 选择工具

    按 Shift+G，或者使用 *地形 > 混合 > 混合工具*。它的选项会显示在左上角的工具选项栏里。

    ![坡度模式下的混合工具选项：模式、衰减、图层、半径、强度和坡度范围](../assets/terrain-painting/blend-toolbar.png)

2. 选择模式

    栏里的第一个菜单决定笔刷绘制什么，模式列在下面。

    ![混合工具的模式菜单已展开，鼠标停在坡度上](../assets/terrain-painting/blend-modes.png)

3. 选好图层并绘制

    把**图层**（0 到 3）设为你想要的那一层，然后在地形上拖动。轻轻多刷几遍，边缘会比一遍用力刷更柔和。

    ![在绘制模式下用图层 2 沿岛屿向上刷出一条泥土小路](../assets/terrain-painting/blend-paint-path.gif)

| 模式 | 绘制什么 |
| --- | --- |
| 绘制 | 在笔刷下添加选定的图层 |
| 擦除 | 向图层 0，也就是基础地面刷回去 |
| 平滑 | 柔化图层之间的边界 |
| 锐化 | 让最强的图层胜出，得到清晰的边界 |
| 噪声 | 只刷在给定**大小**的云状斑块里，适合苔藓、干草或砂砾 |
| 坡度 | 只刷在地面处于两个角度之间的地方。`30` 到 `90` 会把比 30° 更陡的地方都刷成岩石 |
| 高度 | 只刷在两个世界高度之间，适合水线处的沙子或林木线以上的雪 |

坡度和高度让超大笔刷也很安全，在坡度模式下用一把山丘那么大的笔刷，只会把悬崖变成岩石。

栏里的第二个菜单是衰减，也就是强度如何从笔刷中心淡化到边缘。

| 衰减 | 形状 |
| --- | --- |
| 平滑 | 柔和的淡化，通常的选择 |
| 线性 | 从中心到边缘均匀淡化 |
| 恒定 | 整个圆盘强度相同，得到生硬的边缘 |
| 喷洒 | 随机的斑点，适合卵石和花朵 |

Shift 会把绘制、噪声、坡度和高度变成擦除，Ctrl 则是平滑。Ctrl+滚轮调整笔刷大小。

（注意：栏里更靠右的**设置混合材质**、**重复**、**去平铺**、**锐化**和**应用平铺**是用来混合笔刷面的，地形的这些设置来自它的图层。）

## 自动绘制 { #auto-paint }

自动绘制会根据地形的形状重新刷一遍，在你动手绘制之前是个快速的初稿。

1. 选中地形

    自动绘制只会动选中的地形。

2. 运行它

    选 *地形 > 混合 > 自动绘制图层*，或者点击检查器里的**自动绘制**。

    ![地形 > 混合菜单，鼠标停在自动绘制图层上，并且在 y 0 处勾选了从海平面分带](../assets/terrain-painting/menu-auto-paint.png)

| 图层 | 刷在 |
| --- | --- |
| 1 | 比约 50° 更陡的坡面 |
| 2 | 高度范围的最高 20% |
| 3 | 高度范围的最低 8% |

图层 0 覆盖其余的一切。图层较少的地形，会把缺少的分带放进它的最后一层。

范围从最低点开始算，在岛上那就是海底。勾选**从海平面分带**，就改为从你给的高度开始量，比如上面 y 0 处的水线。

![自动绘制之前的海岛，全是草地](../assets/terrain-painting/auto-paint-before.jpg)

![自动绘制之后的同一座岛：悬崖上是岩石，山顶是泥土，沿海滩是沙子](../assets/terrain-painting/auto-paint-after.jpg)

> [!WARNING]
> 自动绘制会替换所有已绘制的内容，所以先雕刻，再自动绘制，最后才手工绘制。

## 最窄能画多窄 { #how-narrow-you-can-paint }

绘制的内容存在顶点上，所以一笔需要大约两个单元的半径，才能得到干净的一条带。小于一个单元时，它会变成阶梯状。要画窄的小径，就用更小的单元，或者在上面铺一个网格或[贴花](decals.md)。

![半径 40、96 和 160 的笔画，在 64 单位的单元上，旁边是存放绘制内容的顶点网格](../assets/terrain-painting/brush-width-grid.jpg)
