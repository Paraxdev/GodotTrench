# 地形 { #terrain }

地形是一大片高度网格，你可以像捏黏土一样雕刻它，上面最多能刷四种纹理。丘陵、海滩和山谷这类开阔的地面适合用它，靠手工一块块做笔刷会慢得没完。

这一页讲怎样创建地形，以及怎样用雕刻工具（G）塑形。给它贴纹理见[地形图层](terrain-layers.md)和[地形绘制](terrain-painting.md)。

## 创建地形 { #creating-a-terrain }

1. 打开对话框

    在菜单栏里选 *地形 > 创建地形…*。

    ![地形菜单已展开，鼠标停在创建地形…上](../assets/terrain/menu-create-terrain.png)

2. 选一个大小

    **分辨率**和**单元大小**决定它有多大，它们下面的**大小**一行会以单位和米显示结果。默认的 129 x 129 个顶点配 64 单位的单元，得到 8192 单位，也就是 256 米。参见下面的[选择单元大小](#picking-the-cell-size)。

    ![创建地形对话框，保持默认值：129 x 129，64 u 的单元，丘陵，以及四个图层字段](../assets/terrain/create-terrain-dialog.png)

3. （可选）选一个起始形状

    **形状**是你出发的地面。默认是丘陵，其他有平直、山、岛屿、山谷和山脊。**导入 PNG…** 则改为读取一张灰度高度图，越亮的像素越高。这两项只能在创建时用。

4. （可选）选好图层

    **基础图层**、**坡面图层**、**峰顶图层**和**低地图层**是地形的四种纹理，**用当前**会填入你最近点击的材质。勾选**按坡度和高度绘制图层**后，它们会立刻被刷上，参见[自动绘制](terrain-painting.md#auto-paint)。

5. 点击底部的**创建**

    地形会以 3D 光标为中心，或者在取消勾选 **3D 光标**后，以你输入的**居中**为中心，那个高度就成为地形的零点。你应该会看到新地形被选中，雕刻工具已经处于激活状态。

## 选择单元大小 { #picking-the-cell-size }

| 设置 | 含义 |
| --- | --- |
| 分辨率 | 每条边上有多少个顶点，从 33 到 1025。顶点越多能容纳的细节越多，但绘制和雕刻的开销也越大 |
| 单元大小 | 相邻两个顶点之间的距离，以地图单位计 |

例如 257 个顶点配 64 单位的单元，得到 16384 单位，也就是 512 米。

两个顶点之间什么都没有，所以单元大小就是地形能容纳的最细的细节。山脉要用大单元，花园则用小的。

选错了？选中地形，在检查器里打开**重采样**。它会按较长一边的 65、129、257 或 513 个顶点重建网格，并保留高度、绘制内容和洞。地形的大小不变，所以顶点越多，单元就越小。

![地形的检查器，重采样菜单已展开，鼠标停在 257 个顶点上](../assets/terrain/inspector-resample.png)

**区块单元数**（默认 32）会把地形切成方形的小块，用于绘制和碰撞。区块越小，雕刻时重建得越快，区块越大，Godot 里的节点就越少。

## 雕刻 { #sculpting }

按 G，在左上角的工具选项栏里选一个模式，然后在地形上拖动。它作用于选中的地形，什么都没选时则作用于所有地形。

![雕刻工具的模式菜单在工具选项栏里展开，旁边是半径和强度输入框](../assets/terrain/sculpt-modes.png)

一直按住鼠标键，地面就会在笔刷下不断升高。

![按住抬升并使用 900 单位的笔刷，从岛上堆出一座小山](../assets/terrain/sculpt-raise.gif)

| 模式 | 作用 |
| --- | --- |
| 抬升、降低 | 只要按着按钮，就不断把高度堆高或挖低。点一下会做出一个小凸起 |
| 平滑 | 让每个顶点向它的邻居放松，用来柔化疙瘩和尖锐的山脊 |
| 压平 | 把地面拉到笔画开始处的高度，用来做平台、道路和高地 |
| 噪声 | 加上细小的随机起伏，让平地看起来没那么人工 |
| 梯田 | 把高度吸附到每 **步长** 单位一级的台阶上，适合稻田或阶梯状的悬崖。这个输入框会出现在模式旁边 |
| 绘制 Alpha、擦除 Alpha、绘制图层 | 用来绘制而不是塑形。Alpha 模式是给置换用的，绘制图层则绘制模式旁边设置的地形图层。在地形上，[混合工具](terrain-painting.md)能更精细地控制这件事 |
| 挖洞、填洞 | 整格整格地挖掉或补回，碰撞也一起处理。适合做洞穴或掩体的入口 |

Ctrl+滚轮调整笔刷大小，Shift 对调抬升和降低，按住 Ctrl 则不论什么模式都变成平滑。

**强度**决定笔刷干活的速度。抬升和降低每点强度每秒移动笔刷中心 8 单位，与半径无关，所以默认的 4 每秒堆高 32 单位。做丘陵和岛屿时，把强度调高，不要按住一分钟。

笔刷半径要大于地形的单元大小，更小的笔刷只会推动它下面的那一个顶点（出现这种情况时状态栏会告诉你）。

想重新开始，用 *地形 > 雕刻 > 压平*，或者检查器里的**压平**，把整个选中的地形重设回它的零点高度。

> [!TIP]
> 用大笔刷塑形，每粗糙地走一遍就平滑一次。小笔刷会留下疙瘩。

## 在 Godot 里 { #in-godot }

每个地形都会变成一个 `TrenchDotTerrain` 节点，它是一个 `StaticBody3D`（Godot 里用于永远不会移动的实心地面的节点），碰撞与它绘制出来的样子一致。在游戏代码里，`height_at(x, z)` 会返回某个局部位置的地面高度，在运行时把东西放到地面上很方便。

## MCP { #mcp }

`terrain_edit` 工具的 `sculpt` 操作会施加一次点按，它的强度就是这一下把中心移动多远，同样与半径无关。以强度 4 持续一秒的笔画，相当于一次强度 32 的点按。
