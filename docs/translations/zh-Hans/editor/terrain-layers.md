# 地形图层 { #terrain-layers }

地形有一到四个图层，每个图层是一种材质，加上几项控制它如何重复的设置。选中地形，你就能在检查器里找到它们。各个图层共同分摊地面，所以在草地上刷沙子，会夺走草的权重。

![一个有四个图层的地形的检查器，每个图层都有材质、平铺、去平铺和锐化](../assets/terrain-layers/layers-inspector.png)

| 想做的事 | 这样做 |
| --- | --- |
| 添加一个图层 | 点击图层下面的 **+ 层（当前材质）**，它使用你最近在材质面板里点击的材质。地形不足四层时才会显示 |
| 移除最后一个图层 | **- 最后一层** |
| 更换图层的材质 | 在图层的输入框里输入材质名，或者把材质从材质面板拖到地形上。检查器底部的那一行会说明拖放会落到哪一层，启用混合工具时，它就是该工具正在绘制的那一层 |

**图层 0 是基础地面。**没有刷过的地面显示图层 0，擦除也会刷回它，所以把你最常见的地面放在那里，通常是草地。

新地形会得到*创建地形*对话框里指定的图层，默认是四个。为地形还没有的图层拖放材质，会把它添加成下一个图层。

## 平铺与去平铺 { #tile-and-de-tiling }

任何一张在大片区域上重复的纹理，从远处看都会露出网格图案。这些设置是在近看的清晰度和隐藏这种图案之间做取舍。

| 设置 | 含义 |
| --- | --- |
| 平铺 | 纹理重复一次覆盖多少地图单位。对于你会走在上面的地面，128 到 384 比较合适 |
| 去平铺 | 0 到 1。把每次重复随机旋转并错位，让网格不再显现 |
| 锐化 | 0 到 1，去平铺大于 0 之后才会出现。0 把错位的各次重复均匀混合，看起来偏软。1 只沿它们的接缝混合，纹理保持清脆 |

小的平铺近看清晰，但从远处能看到明显的重复，大的平铺则会让脚下变模糊。去平铺不用更大的平铺也能藏起重复，但会多花纹理读取，所以重复不明显的地方就保持 0。

![平铺 256，左边去平铺为 0，右边为 0.7](../assets/terrain-painting/detile-compare.jpg)

> [!NOTE]
> 材质的 `metadata/texture_size` 对地形不起作用，只有**平铺**起作用。

## 在 Godot 里的样子 { #how-it-looks-in-godot }

每个图层都从上方和侧面投影，所以悬崖显示的是岩石而不是一团糊，也与你在编辑器里看到的一致。每个图层使用它材质的颜色纹理、法线贴图、粗糙度和自发光。环境光遮蔽在它位于粗糙度纹理里时会被使用，比如 ORM 纹理，或者图层没有粗糙度纹理时。
