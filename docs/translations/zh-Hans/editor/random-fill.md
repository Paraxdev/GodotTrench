# 随机填充 { #random-fill }

*笔刷 > 随机填充…* 会用[预制体库](prefab-library.md)里的部件铺满一个单元格网格，每个格子里放哪个部件按权重来挑。先做一小套部件，比如办公室房间、走廊、柱阵和开阔的地面，填充就能用它们排出一整层的平面布局。每个种子给出不同的布局，同一个种子则总是给出同一个。

1. 做好你的部件

    把每个部件做成一个格子宽（默认 128 单位），以原点为中心。墙不要贴着格子的边界，这样相邻的部件总能连通。

    然后把它加进库里：选中它，展开预制体标签页顶部的**添加所选内容**，勾选**保持位置**，起个名字，点击**添加**（参见[你自己的部件](prefab-library.md#your-own-pieces)）。

    ![预制体标签页，添加所选内容已展开且勾选了保持位置，它的提示写着保持地图原点作为部件的原点，就像给随机填充用的套件](../assets/random-fill/prefabs-keep-position.png)

2. 打开对话框

    选 *笔刷 > 随机填充…*。

    ![笔刷菜单，鼠标停在随机填充…上](../assets/random-fill/menu-random-fill.png)

3. 添加部件

    从**添加部件…**里挑出每个部件，并给它一个**权重**：权重 6 的部件填满的格子，大约是权重 3 的部件的两倍。**旋转**让部件可以随机旋转 90 度的整数倍。

    ![随机填充对话框，有三个部件、它们的权重、空白权重 4、一个 12 乘 8 的网格，以及彩色的预览](../assets/random-fill/random-fill-dialog.png)

4. （可选）留出一些空格

    **空白权重**的作用就像一个什么都不放的部件。

5. 摆好网格

    选中地面并点击**适应所选内容**，或者自己设置**单元格**大小、**单元格数**和**角点**。

6. （可选）让部件聚集

    **聚集度**会把每种部件聚成大约**片区大小**个格子的片区，这样一翼办公室会挨着一个柱厅，而不是所有东西均匀混在一起。

7. 填充

    彩色网格会预览布局，每个部件一种颜色。点击**填充**，**重新随机**会用下一个种子替换上一次的填充。

    ![一块地面被方柱、圆柱和成堆的箱子填满，有些格子留空](../assets/random-fill/random-fill-result.jpg)

填充的结果是一组普通拷贝，所以它的烘焙和构建和你手工放的东西一样，之后也可以编辑任何一个格子。每份拷贝的实体名都有自己的前缀 `rf<seed>_<n>-`，所以带有连线实体的部件，比如按定时器闪烁的灯，在每个格子里都能各自正常工作。

> [!TIP]
> 把不同种类的细节分成对同一个网格的几次填充，比如一次填墙，一次填天花板灯，各有自己的权重，例如在正常工作的灯里混几盏坏掉或闪烁的灯。

## MCP { #mcp }

`random_fill` 工具接受 `pieces`，形如 `[{name, weight, rotate}]`，还有 `empty`、`min`、`cell`、`cells`、`seed`、`cluster` 和 `cluster_size`。`preview: true` 只把布局以草图形式返回，`replace` 会先移除之前的填充。
