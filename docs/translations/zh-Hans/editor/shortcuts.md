# 快捷键 { #shortcuts }

这些是默认按键，也就是 TrenchBroom 预设。

想用别的按键？*帮助 > 键盘快捷键…*会列出每一个绑定。在过滤框里输入就能找到某一个，按**设置**，再按新的快捷键。那个窗口顶部的**预设**，或者*文件 > 偏好设置 > 快捷键预设*，可以切换到 Hammer 或 Blender，参见[其他预设](#other-presets)。

![键盘快捷键窗口，已按 csg 过滤，带有预设下拉框、重置自定义，以及每一行上的设置和清除按钮](../assets/shortcuts/keyboard-shortcuts-window.png)

你在输入框里打字或者菜单打开时，快捷键会暂停。当指针停在浮动窗口上，比如形状生成器，只有保存、撤销和重做能用，这样原本给窗口的按键，就永远不会删除或改动你的地图。

## 工具 { #tools }

再按一次工具的按键就回到选择。Esc 会取消一次拖动或笔触，否则它会回到选择，而在选择工具里它会清空选择。

| 按键 | 工具 |
| --- | --- |
| Q | 选择，绘制笔刷和移动东西 |
| C | 裁切，沿一个平面切开笔刷 |
| V | 顶点，拖动笔刷的角点 |
| R | 旋转 |
| T | 缩放 |
| Tab | 就地编辑选中的内容：网格在网格工具里，笔刷在顶点工具里。它从不转换笔刷，转换由*网格 > 编辑网格*来做 |
| Shift+T | 纹理，在面上对齐纹理 |
| P | 绘制，把顶点颜色画到面上 |
| G | 雕刻地形和置换 |
| Shift+G | 混合地形图层 |
| B | 散布 |
| Shift+E | 体积，拖出一个触发体积 |
| Shift+P | 路径，放置一串 `path_corner` 实体 |
| M | 测量距离 |

## 视图里的鼠标 { #mouse-in-the-views }

| 输入 | 结果 |
| --- | --- |
| 在选择之外拖动 | 绘制笔刷 |
| 拖动选择 | 移动。Ctrl 复制，Shift 锁定轴，Alt 在 3D 里垂直移动 |
| 点击、双击 | 选中、选中整个组 |
| 很快在同一处再点一次，或者 Alt+点击（2D） | 选中光标下的下一个对象，比如在顶视图里选中天花板下面的墙 |
| Ctrl+点击 | 加入选择或从选择里去掉，在视图和大纲里都可以 |
| 在大纲里 Shift+点击 | 选中从上次点击的那一行开始的各行 |
| Shift+点击、Ctrl+Shift+点击 | 选中一个面、添加或去掉一个面 |
| Shift+拖动选中的面（3D） | 推或拉它 |
| Ctrl+Shift+拖动选中的面（3D） | 挤出一个新笔刷 |
| 右键拖动（3D） | 环顾四周。按住它再用 WASD 飞行，Q 和 E 下降和上升 |
| 中键拖动 | 平移 |
| Alt+左键拖动（3D） | 环绕。在选择工具里，从选择或它的控件上开始的拖动，会改为垂直移动它 |
| Ctrl+滚轮（雕刻、混合、绘制、散布） | 调整笔刷大小 |

## 编辑 { #editing }

| 按键 | 操作 |
| --- | --- |
| Ctrl+Z、Ctrl+Shift+Z 或 Ctrl+Y | 撤销、重做 |
| Ctrl+X、Ctrl+C、Ctrl+V | 剪切、复制、粘贴到鼠标位置 |
| Ctrl+D、Ctrl+Shift+D | 复制、链接复制 |
| F2 | 在大纲里重命名选中的对象 |
| Ctrl+R | 重复上一次旋转、翻转、微移或复制。在网格编辑里，它会做一次环切 |
| Delete 或 Backspace | 删除 |
| Ctrl+A、Esc、Ctrl+I | 全选、取消选择、反向选择 |
| Ctrl+T、Ctrl+Shift+T | 把选中的笔刷当作模板，选中它们接触到的内容，或者位于它们内部的内容。模板笔刷会被删除 |
| Ctrl+G、Ctrl+Shift+G | 编组、取消编组 |
| Ctrl+H、Ctrl+J、Ctrl+Shift+H | 隐藏选中的内容，隐藏其他所有内容来孤立它，显示全部 |
| 方向键、Page Up、Page Down | 按一个网格步长微移 |

## 笔刷、网格和纹理 { #brushes-meshes-and-textures }

| 按键 | 操作 |
| --- | --- |
| Ctrl+K、Ctrl+M、Ctrl+L | CSG 减去（把选中的内容从它接触的东西里挖掉）、凸包合并、求交 |
| Ctrl+Shift+K | 挖空，把实心笔刷变成带墙的房间 |
| Ctrl+Shift+B | 形状生成器，用来做拱门、圆柱、楼梯和其他现成的形状 |
| Ctrl+Shift+E、Ctrl+Shift+J | 把笔刷转为网格、合并网格 |
| Ctrl+Shift+W | 把笔刷移到世界，从它们的实体里取出来，让它们变成普通的关卡几何体 |
| Ctrl+Shift+U | 切换 UV 锁定，笔刷移动时让纹理跟着它 |
| Alt+H | 热点适配，把选中的面适配到饰条图集里最匹配的矩形 |

## 视图和文件 { #view-and-files }

| 按键 | 操作 |
| --- | --- |
| F 或 Ctrl+U | 框出选中的内容，或者整张地图 |
| `[` 和 `]`，或 `-` 和 `=` | 网格减半或加倍 |
| F4、F3 | 循环切换着色（带纹理、平面、光照、线框），切换光照预览 |
| Shift+Space | 最大化指针下方的视图 |
| Ctrl+Shift+1 到 9、Ctrl+1 到 9 | 保存、调用相机书签 |
| Ctrl+=、Ctrl+-、Ctrl+0 | 界面缩放放大、缩小、重置 |
| F1 | 在指针下方的工具、面板标签页、菜单项或检查器分区处打开[手册](interface.md#help-and-the-manual)，其他任何地方则打开命令面板 |
| Ctrl+点击工具栏里的工具，macOS 上是 Cmd+点击 | 在手册里打开它的页面 |
| Ctrl+Shift+P | 命令面板 |
| Ctrl+N、Ctrl+O | 新建地图、打开地图 |
| Ctrl+S、Ctrl+Shift+S | 保存、另存为 |
| Ctrl+Shift+N、Ctrl+Tab、Ctrl+W | 新建标签页、下一个标签页、关闭标签页 |
| F5 | 运行 Godot 项目 |

> [!NOTE]
> F2 以前是循环切换着色。现在它用来重命名，和 Godot、Blender 以及大多数文件管理器一样，着色则移到了 F4。你自己在快捷键窗口里设置的绑定保持原样。

## 其他预设 { #other-presets }

预设只会改变下面这些按键，其他一切都和上面一样。你自己的绑定叠在任何预设之上，快捷键窗口里的**重置自定义**会清除它们。

| 按键 | Hammer 预设 |
| --- | --- |
| Shift+S、Shift+X、Shift+V、Shift+A | 选择、裁切、顶点、纹理工具 |
| H、Ctrl+H、U | 隐藏、孤立、显示全部 |
| Ctrl+W | 把笔刷移到世界 |
| Ctrl+M | 形状生成器 |
| Ctrl+L | 绕竖直轴旋转 90° |
| Ctrl+Shift+M、Ctrl+Shift+L | CSG 凸包合并、求交 |
| Ctrl+F4 | 关闭标签页 |

| 按键 | Blender 预设 |
| --- | --- |
| A、Alt+A | 全选、取消选择 |
| X | 删除 |
| Shift+D、Alt+D | 复制、链接复制 |
| S | 缩放工具 |
| H、Alt+H、/ | 隐藏、显示全部、孤立 |
| Ctrl+J | 合并网格 |
| Z | 循环切换着色 |
| Shift+A | 形状生成器 |
| F3 | 命令面板 |
| F4 | 光照预览 |
| Alt+Shift+H | 热点适配 |
