# UV 编辑器 { #uv-editor }

UV 编辑器会把所选的笔刷面和网格面平铺画在它们的平铺纹理上，这样你就能看到每个面显示的是纹理的哪一部分。它负责[纹理工具](texturing.md#the-texture-tool)在 3D 视图里做不到的事，比如把网格的 UV 精确放到像素。

## 打开它 { #opening-it }

UV 编辑器是右侧面板里的一个标签页，挨着检查器，*纹理 > UV 编辑器* 也可以把它调出来。然后选中面：在视图里 Shift+点击一个面，或者使用纹理工具。最上面一行会写出材质名和你选中的面数。

![UV 编辑器里选中了一个墙面，在平铺的 showcase/plaster 纹理上画成一个橙色矩形](../assets/uv-editor/uv-editor-face.png)

> [!TIP]
> 只要 UV 编辑器是面板里当前显示的标签页，Ctrl+点击笔刷或网格就会选中它的所有面，这样每一侧都能一次贴上纹理。已经选中的笔刷和网格也会变成它们的面。如果选择里还有别的东西，比如地形或实体，Ctrl+点击就照常添加和移除对象。

笔刷面通常用一组偏移、缩放和旋转来决定纹理。带有**显式 UV** 的面则为每个角各存一个纹理位置，网格需要的正是这种方式。UV 编辑器把这类面画成蓝色，你可以逐个选取它们的角。橙色的面没有显式 UV，只能整体移动。

## 操作 { #controls }

顶部那一行末尾的 **?** 也会在编辑器里显示这些内容。

| 输入 | 结果 |
| --- | --- |
| 拖动空白处 | 移动纹理，面带有显式 UV 时则移动整个面 |
| 滚轮、右键拖动 | 缩放、旋转 |
| 点击一个角 | 把它连同与它缝合的相邻面的角一起选中 |
| Shift+点击、Ctrl+点击 | 添加、移除 |
| Alt+点击 | 只选中该面的这个角，用来拆开缝合 |
| 在空白处 Shift 或 Ctrl+拖动 | 框选，添加或移除 |
| 拖动已选中的角 | 移动整个选择 |
| 双击一个角 | 出现只沿 U 或 V 移动的操纵轴，按 Escape 隐藏 |
| 中键拖动、Ctrl+滚轮 | 平移、缩放画布 |

选中角之后，滚轮和右键拖动会围绕它们的中心缩放和旋转。画布下方的 U 和 V 输入框可以把选择精确放到像素。

菜单后面那些小按钮用来切换像素吸附、显示纹理的热点、让普通拖动变成框选、显示操纵轴、切换 UV 锁定，以及重新框住这些面。把鼠标停在上面就能看到各自的作用。

## 网格 UV 投影 { #mesh-uv-projections }

选中网格面后，**投影**菜单会为你排好显式 UV。它采用相同纹理的笔刷面会得到的纹素密度，所以网格和周围的笔刷能对得上。把鼠标停在某一项上会看到一行说明。

![UV 编辑器的投影菜单已展开，鼠标停在圆柱 Y 上并显示提示：绕穿过这些面中心的这条世界轴包裹，u 沿它环绕](../assets/uv-editor/projection-menu.png)

| 命令 | 结果 |
| --- | --- |
| *平面*、*平面 X*、*Y*、*Z* | 沿面大致朝向的方向，或沿某一条世界轴投影，让它们保持为一整块 |
| *方盒* | 每个面从离它最近的世界轴投影，适合方方正正的形状 |
| *圆柱 X*、*Y*、*Z*、*球体* | 把纹理包裹在面上，适合管道、柱子和穹顶 |
| *视图* | 沿 3D 摄像机的方向直接投影 |
| *展开* | 沿边把这些面一个接一个铺平，让条带和网格保持连续 |
| *重置为世界* | 刚重置的笔刷面所用的投影 |
| *烘焙平面* | 把平面纹理变成可编辑的角 UV，在有些面还没有角 UV 时显示 |
| *清除 UV* | 再次丢弃显式 UV |
| *归一化* | 把 UV 一次性缩放到刚好适合纹理 |
| *打包* | 以同一个纹素密度把各个孤岛打包进纹理 |

这里一根 12 边的柱子用了*圆柱 Y*，它的侧面现在并排成一条绕着纹理的连续条带：

![对一根 12 边的网格柱子使用圆柱 Y 之后的 UV 编辑器，它的侧面排成一条连续的条带](../assets/uv-editor/uv-editor-cylinder.png)

**UV** 菜单可以翻转、旋转、适配、对齐、拉直并吸附到像素。**热点**菜单可以适配到热点矩形，参见[热点](texturing.md#hotspots)。
