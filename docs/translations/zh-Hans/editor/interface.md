# 界面与导航 { #interface-and-navigation }

TrenchDot 参考了 TrenchBroom 和 Hammer，所以如果你用过其中任何一个，大多数习惯都能直接沿用。如果没用过，这一页会带你熟悉一下，[从 Unity 或 Blender 转过来](coming-from-unity-blender.md)则会把你已经知道的概念对应过来。

## 窗口 { #the-window }

![编辑器中的一个小房间：左侧是大纲，中间是 3D、顶、前和侧视图，右侧是检查器，底部是材质面板](../assets/interface/window.png)

菜单在最上方。命令放在它所改动的对象类型之下，所以 CSG 在 *笔刷* 下，地形雕刻在 *地形* 下。

找不到某个功能？按 Ctrl+Shift+P（或 F1）打开命令面板，输入它的名字。名字带行话的命令，比如 *挖空* 或 *UV 锁定*，把鼠标悬停上去就会自己解释，命令面板也会在列表下方显示同样的一行。按 Escape 或点击面板外面，就能关闭它而不运行任何命令。

![命令面板中输入了 hollow，选中了带快捷键的“笔刷：挖空”，下方是解释它的那一行](../assets/interface/command-palette.png)

工具栏正下方是 **工具选项栏**。它显示当前工具的设置，如果这个工具没有设置，就显示一行如何使用它的说明。把鼠标悬停在那里的工具名上，或者工具栏里的对应按钮上，可以看到简短的描述。

![悬停在“选择工具”上的工具选项栏，提示描述了这个工具，末尾是 F1：手册](../assets/interface/tool-options-tooltip.png)

### 空地图卡片 { #the-empty-map-card }

在新建的空地图上，3D 视图里有一张卡片告诉你从哪里开始：在顶视图中拖动来画出第一个方盒，顶视图会用一个黄色标签标出位置。卡片下方还解释了 3D 相机的用法，并链接到[入门指南](../getting-started.md)。如果当前打开的项目里有地图，**打开此项目中的地图** 会把它们列出来，这样你就可以改为打开一张做好的地图。

![3D 视图中的空地图卡片，带有入门指南、打开此项目中的地图和隐藏提示，旁边是顶视图中的黄色标签](../assets/interface/empty-map-card.png)

地图里一有内容，这张卡片就会消失。**隐藏提示** 会关闭这些提示，在 *文件 > 偏好设置* 里勾选 *空地图时的提示* 可以把它们再打开。

### 面板 { #panels }

| 面板 | 停靠位置 | 用途 |
| --- | --- | --- |
| 大纲 | 左侧 | 把地图显示为由[图层、编组](organizing.md)和对象组成的树 |
| 历史 | 左侧 | 每一次编辑。点击其中一条会撤销它和之后的所有操作，点击一条变暗的记录会重做到它为止 |
| 问题 | 左侧 | 你工作时发现的问题，比如没有材质的面。点击一条会选中对应对象，大多数问题都提供修复 |
| 检查器 | 右侧 | 所选对象的属性，比如实体的键，或者笔刷的精确位置和尺寸 |
| 实体 | 右侧 | 可以拖进视图的实体类 |
| UV 编辑器 | 右侧 | [精确的纹理摆放](uv-editor.md) |
| 散布 | 右侧 | [散布](scatter.md)工具所绘制的模型 |
| 材质 | 底部 | 你项目里的纹理 |
| 模型 | 底部 | 可以放置的[模型文件](models.md) |
| 预制体 | 底部 | 来自[预制体库](prefab-library.md)、可以粘贴的现成部件 |
| 逻辑 | 默认关闭 | 以图的形式显示的[实体连线](../gameplay/logic-graph.md)，用来连接实体并预览某个输出会触发什么 |
| 参考 | 默认关闭 | 在你的脚本中使用某个实体类的代码 |

不小心关掉了某个面板？从 *视图 > 面板* 重新打开。同一个菜单底部的 *重置布局* 会把一切放回最初的位置。

![视图菜单中展开了面板，已显示的面板打了勾，底部是重置布局](../assets/interface/view-panels-menu.png)

## 帮助与手册 { #help-and-the-manual }

工具提示会解释按钮、标签页和设置。想了解更多，把鼠标指向一个工具、一个面板标签页、一个菜单项或者检查器的某个分区，再按 **F1**，就会打开本手册中对应的页面。在工具栏里按住 Ctrl 点击一个工具（macOS 上是 Cmd+点击）效果相同。末尾写着 *F1：手册* 的提示背后有一个页面，除此之外，F1 打开的是命令面板。

*帮助 > 手册* 会打开手册的开头。

![帮助菜单，鼠标悬停在手册上](../assets/interface/help-menu.png)

等你熟悉之后，可以在 *文件 > 偏好设置* 中取消勾选 *帮助文字*，隐藏工具选项栏和各面板里的简短指引行。它们的工具提示仍然保留。

（注意：链接会在你的网页浏览器中打开。如果没有浏览器打开，状态栏会提示，同时链接会被复制到剪贴板。）

## 视图 { #views }

视图有 3D、顶视图、前视图和侧视图。2D 视图沿着一条轴直直地看过去，这让对齐更容易。选中某个东西后，它们会在上方标出宽度，在旁边标出高度。

![前视图，选中了一个方盒笔刷，上方标着 96，旁边标着 48](../assets/interface/front-view-size-labels.png)

在 2D 视图里点击，会选中沿视线方向最近的对象，所以在顶视图里，天花板会遮住它下面的墙。在同一位置一秒半之内再点一次，或者随时按住 Alt 点击，就会切换到光标下的下一个对象。

| 操作 | 效果 |
| --- | --- |
| 拖动分隔线的交叉点 | 同时调整四个视图的大小 |
| Shift+空格 | 最大化指针所在的视图，再按一次恢复 |
| *视图 > 视图* | 在一个、两个和四个视图之间切换，或者把关掉的视图找回来。单视图会保留你最后使用的视图，一开始是 3D 视图，而且在只显示一个视图时，选另一个视图的名字就会切换过去 |

![视图菜单中展开了视图：四个视图打了勾，还有单视图、双视图、四视图，以及快捷键为 Shift+空格的最大化视图](../assets/interface/view-views-menu.png)

## 标签页 { #tabs }

每张打开的地图都有一个标签页，打开两张之后，标签栏会出现在工具选项栏下方。Ctrl+Shift+N（或 **+** 按钮）新建标签页，Ctrl+Tab 切换，Ctrl+W 关闭。

![标签栏中打开了 room.tdm 和 untitled.tdm，鼠标悬停在 + 按钮上，显示新建标签页](../assets/interface/map-tabs.png)

当前地图有未保存的改动时，*新建地图* 和导入都会在新标签页中打开。关闭已修改的标签页时会询问保存、放弃还是取消，退出时会列出所有未保存的地图。

## 相机 { #camera }

| 输入 | 3D 视图 | 2D 视图 |
| --- | --- | --- |
| 右键拖动 | 环顾四周。WASD 移动，Q 和 E 下降和上升，Shift 速度变为三倍 | 平移 |
| 中键拖动 | 平移 | 平移 |
| 滚轮 | 前进和后退，正前方的表面越远，速度越快 | 朝光标处缩放 |
| Alt+左键拖动 | 环绕，除非拖动从所选对象上开始，那样会让它垂直移动 | |

WASD 只有在你按住右键时才会飞行，否则这几个键是快捷键。忘了操作方式？把鼠标悬停在视图的标签上就行。在你第一次环顾四周之前，鼠标指针位于 3D 视图上时，视图还会在名字下面显示这些操作（空地图卡片上的 **隐藏提示** 可以把它关掉）。

**F** 会在所有视图中聚焦所选对象，没有选中任何东西时则聚焦整张地图。滚轮每滚一格，2D 视图的缩放倍数在任何缩放级别下都一样，所以从整片大地形缩到一个房间大约要滚 20 格，在房间上按 **F** 更快。

Ctrl+Shift+1 到 9 会把 3D 相机存为书签，Ctrl+1 到 9 跳回去。书签保存在地图里，撤销不会影响它们。

## 着色 { #shading }

F4 会让 3D 视图依次切换带纹理、平直、光照预览和线框，视图会在左上角显示当前模式。地图有了[烘焙](light-baking.md)之后，**烘焙光照** 排在光照预览之后。F3 会直接跳到 **光照预览**，再按一次回到带纹理，不会经过其他模式。

![3D 视图依次切换带纹理、平直、光照和线框着色](../assets/interface/shading-cycle.gif)

光照预览会显示地图的灯光、太阳阴影、天空和雾，不需要在 Godot 里构建。它只绘制最强的 64 个点光源和聚光灯，所以灯光多得多的地图在这里可能比在 Godot 里更暗。

## 主题 { #theme }

TrenchDot 有深色和浅色两种外观。新安装时默认是深色。

1. 打开 **文件 > 偏好设置**。**主题** 是第一行，在窗口顶部。
2. 点击下拉菜单，选择 **深色**、**浅色** 或 **系统**。

    ![偏好设置中的主题下拉菜单，展开后有深色、浅色和系统](../assets/interface/preferences-theme.png)

3. 整个编辑器会在下一帧改变，不需要重启。你的选择会和其他偏好设置一起保存。

    ![浅色主题下的编辑器，带有菜单栏、大纲、3D 视图和顶视图](../assets/interface/theme-light-window.png)

**系统** 会跟随你操作系统的浅色或深色应用模式，并随它一起变化。选中它时，下拉菜单会显示 *系统（浅色）* 或 *系统（深色）*，这样你能看到系统给出了什么。如果系统没有报告模式，编辑器就保持深色。

你也可以在 **视图 > 主题** 里选，它就在 *界面缩放* 下面，或者在命令面板里用 *视图：主题：深色*、*浅色* 或 *系统*。默认没有绑定按键，但你可以在快捷键编辑器里给每一项设一个键。

在浅色下，2D 视图（顶视图、前视图和侧视图）会变成纸张的样子，浅灰色背景配深色网格线和笔刷边缘，这样你画的线条依然一眼就能看清。3D 视图在两种主题下都保持深色的周围，UV 编辑器和热点编辑器的纹理画布也是如此。纹理在任一主题下看起来都一样，浅色的周围会改变你对颜色的判断。

<div class="td-mcp" markdown>

通过 [MCP 服务器](../mcp.md)，带 `"theme": "light"` 的 `set_editor` 会切换主题。可用的值是 `dark`、`light` 和 `system`，未知的值会报错，并且不会改变任何东西。`get_state` 会把你的选择报告为 `ui.theme`，把屏幕上实际显示的报告为 `ui.theme_active`。

</div>

## 语言 { #language }

菜单、面板、工具提示和状态消息有英语、德语、法语、西班牙语、葡萄牙语、俄语、简体中文和日语版本。新安装时默认是英语。

1. 打开 **文件 > 偏好设置**。**语言** 是第二行，就在 **主题** 下面。
2. 点击下拉菜单，选择你的语言。每种语言都用它自己的名字列出，所以即使编辑器用的是你看不懂的语言，你也能找到自己的语言。

    ![偏好设置中的语言下拉菜单，展开后有 English、Deutsch、Français、Español、Português、Русский、简体中文 和 日本語](../assets/interface/preferences-language.png)

3. 整个编辑器会立刻切换，不需要重启。你的选择会和其他偏好设置一起保存。

    ![德语的文件菜单](../assets/interface/language-file-menu-de.png)

当使用英语以外的语言时，这一行会显示成例如 *语言 (Language)*，这样你总能找到回去的路。你也可以在命令面板里选择语言，比如 *视图：语言：Deutsch*，同一个命令在每种语言下都能用，因为命令面板也会搜索英文名称。默认没有绑定按键，但你可以在快捷键编辑器里给每种语言设一个键。

这些翻译由 AI 撰写，还没有母语者校对过，这一行下面的说明也这样写着。还没有翻译的文字会显示英文，这个版本不认识的语言也一样。如果某处翻译读起来不对，你可以在[该语言的语言文件](https://github.com/Paraxdev/TrenchDot/tree/main/crates/td_editor/locales)里修改，参见[翻译](../development.md#translations)。

> [!NOTE]
> 手册会跟随编辑器的语言。选了某种语言之后，在工具、面板或菜单上按 **F1**，以及 **帮助** 菜单里的条目，都会打开手册中你所用语言的对应页面。手册页眉里的语言按钮可以切换这里的语言。还没有翻译的页面，或者翻译之后又有改动的页面，会以英文显示，并在顶部带一条说明。截图显示的是英文编辑器，所以请在你的语言里找同一个条目，或者把英文名称输入命令面板。实体类名、地图键、文件格式、日志和 [MCP 服务器](../mcp.md)在每种语言下都保持英文。

<div class="td-mcp" markdown>

通过 [MCP 服务器](../mcp.md)，带 `"language": "de"` 的 `set_editor` 会切换语言。可用的值是 `en`、`de`、`fr`、`es`、`pt`、`ru`、`zh-Hans` 和 `ja`，大小写不限，未知的值会报错，错误信息列出所有可用值，并且不会改变任何东西。`get_state` 会把你的选择报告为 `ui.language`。工具名、回复和错误在每种语言下都保持英文。用 `--default-prefs` 启动的编辑器是英语，e2e 测试依赖这一点。

</div>

## 界面缩放 { #interface-scale }

Ctrl+= 和 Ctrl+- 缩放界面，Ctrl+0 重置。你也可以在 *文件 > 偏好设置* 顶部找到同样的 *界面缩放*。如果显示器报告了错误的显示缩放，取消勾选它正下方的 *跟随显示器*。

![偏好设置窗口的顶部：主题设为深色，语言设为 English，界面缩放为 100%，显示缩放中勾选了跟随显示器，下面是空地图时的提示和帮助文字](../assets/interface/preferences-scale-and-tips.png)
