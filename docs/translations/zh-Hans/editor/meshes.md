# 网格 { #meshes }

和笔刷不同，网格可以有凹陷、孔洞和弯曲的面，所以可以用来做岩石、管道、光滑的拱门，以及其他笔刷做不出来的形状。

## 编辑网格 { #editing-a-mesh }

选中想要改变形状的笔刷，选择 *网格 > 编辑网格*。它会把它们转换成网格，并立刻开始编辑。

![网格菜单，鼠标悬停在编辑网格上，下面依次是笔刷转网格（Ctrl+Shift+E）、网格转笔刷、合并网格（Ctrl+Shift+J），以及拓扑、组件、法线与着色和变换子菜单](../assets/meshes/menu-edit-mesh.png)

选中网格时，**Tab** 的效果相同，再按一次 Tab 就回到对象。对笔刷按 Tab 打开的是顶点工具，所以误按一个键绝不会把笔刷变成网格。工具栏里的网格工具按钮会开始编辑，而不做任何转换。Ctrl+Shift+E 只做转换，Ctrl+Shift+J 把多个网格合并成一个。

编辑时，顶部的工具选项栏会在 **顶点**、**边** 和 **面** 之间切换，并带有常用操作的按钮。

![网格工具的工具选项栏，有顶点、边和面，然后是细分、合并、填充、删除、平滑和平直](../assets/meshes/mesh-tool-options.png)

## 按键 { #keys }

按键遵循 Blender。例如，按 3，点击方盒的顶面，按 E，然后向上移动鼠标并点击，就能把它挤出来：

![面模式下的网格方盒，它的顶面按网格步长向上挤出](../assets/meshes/extrude-face.gif)

| 按键 | 操作 |
| --- | --- |
| 1、2、3 | 操作顶点、边或面 |
| A、Alt+A | 全选、取消选择 |
| Alt+点击、Ctrl+Alt+点击 | 选中穿过所点边的边环，或者横跨它的环带 |
| Ctrl+L | 选中与所选内容相连的一切 |
| G、R、S | 移动、旋转、缩放 |
| E | 从选区向外挤出新的几何体 |
| I | 内插，在每个所选面内部生成一个更小的面 |
| Ctrl+B、Ctrl+Shift+B | 给边或顶点倒角，把角切掉 |
| Ctrl+R | 环切，在网格上横跨生成一圈新的边。滚轮或 + 和 - 设置切割的数量 |
| K | 刀，点击两个点，沿着这条线切开 |
| M | 把所选顶点合并到它们的中心 |
| F | 填充，在所选顶点之间生成一个新的面 |
| X 或 Delete | 删除 |
| Shift+D | 复制并移动 |
| P | 把选区分离成一个新网格 |
| Alt+F | 翻转法线，用于从错误一侧显示的面 |

移动、旋转或缩放时，按 X、Y 或 Z 锁定到那条轴，或者按 Shift 加字母把它排除在外。输入数字可以得到精确的量。点击或 Enter 确认，右键点击或 Escape 取消。视图底部的提示行会在你操作时列出这些按键。

## 小工具 { #gizmo }

双击一个元素，会在它上面放一个移动、旋转和缩放的小工具。这是让顶点沿某一条轴滑动的干净做法，在 2D 视图里也能用。Escape 会隐藏它并保留选区。

其余的功能在 *网格* 菜单里，比如细分、三角化、实体化、镜像和平滑着色。
