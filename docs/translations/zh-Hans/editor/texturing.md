# 贴图 { #texturing }

## 应用材质 { #applying-materials }

你的纹理都在 **材质** 面板里，它位于窗口底部、视图下方。左上角的搜索框按名称筛选，**地图中使用** 和 **收藏** 可以缩小列表，滑块用来设置缩略图的大小。

![材质面板，有搜索框、文件夹列表、地图中使用、收藏和大小滑块，下面是材质缩略图，鼠标悬停在 dev/blue 上，显示它的名称和尺寸](../assets/texturing/materials-panel.png)

| 操作 | 结果 |
| --- | --- |
| 点击缩略图 | 应用到选区，并用于新的笔刷 |
| 把缩略图拖到面上 | 应用到那个面 |
| 放下时按住 Shift | 应用到整个笔刷或网格 |
| 放下时按住 Alt | 作为[贴花](decals.md)放置 |

拖动时，光标旁边有一张小卡片提醒你各个修饰键，你一松手面就会改变。

![把 withered/mossy_plaster 拖到砖墙的正面，然后是同一面墙，只有正面贴上了灰泥](../assets/texturing/drop-on-face.png)

想不拖动就给一个面贴图，先在视图里 Shift+点击它，再点击缩略图。Ctrl+Shift+点击可以添加或移除更多的面。

右键点击缩略图还有更多操作：把它加入收藏、选中使用它的面、在整张地图里用它替换当前材质、打开热点编辑器，或者用 *在文件管理器中显示* 打开它的纹理所在的文件夹并选中文件，比如为了编辑它。

![缩略图的右键菜单，有应用到选择、添加到收藏、选择使用它的面、在地图中用它替换 showcase/red_bricks、热点编辑器、复制名称和在文件管理器中显示](../assets/texturing/material-context-menu.png)

把材质放到地形上会设置地形图层，参见[地形图层](terrain-layers.md)。

UV 锁定（Ctrl+Shift+U）默认是开启的，所以移动笔刷时纹理会一直贴在它上面。

## 内置颜色 { #built-in-colors }

材质面板里始终提供 `dev/grey`、`dev/dark`、`dev/orange`、`dev/blue` 和 `dev/green`，这些网格纹理用来在关卡有美术资源之前搭灰盒。用它们给房间做颜色编码，在构建之后依然有效，因为插件自带同样的网格，项目里没有同名纹理时 Godot 就会使用它们。你自己的纹理，比如 `res://textures/dev/grey.png`，会替换其中一个。

## 工具纹理 { #tool-textures }

编辑器会把工具纹理画成带条纹的透明样子，Godot 构建则不给它们生成可见的网格。`special/`、`tools/` 或 `td/` 文件夹里的每一张纹理都算，以下列出的任何一种工具命名的纹理也算，比如 `common/caulk`。

![一个 dev/dark 方块，它前面是一堵透明的紫色 special/clip 墙，还有一个带橙色条纹的 special/trigger 方盒](../assets/texturing/tool-textures.png)

| 纹理 | 在 Godot 中 |
| --- | --- |
| `special/clip`、`playerclip`、`nodraw`、`caulk`、`trigger`、`sky` 以及其他任何工具 | 有碰撞但什么都不画。触发器会保留它的触发体形状 |
| `special/skip`、`origin`、`hint`、`hintskip`、`null`、`areaportal` | 什么都不构建。只有这些面的笔刷没有碰撞 |
| `special/occluder` | 什么都不画，也不会遮住相邻的东西，但会加进会构建遮挡体的实体（比如 `func_geo`）的遮挡体里 |

地图设置里指定了裁切、跳过、原点和天空纹理，默认分别是 `special/clip` 等等。原点笔刷只有使用地图设置里指定的那张纹理时，才会设置它所属实体的原点。

## 纹理工具 { #the-texture-tool }

面的对齐方式指的是纹理在它上面的位置：偏移、缩放和旋转。按 **Shift+T** 使用纹理工具，它可以就地编辑这些，就像 Hammer 的面编辑模式。点击一个面来选中它。它会染成红色，并显示一个蓝色方框框住纹理的一次重复，另外还有两条短线表示 U 和 V 方向。光标下的面会有黄色轮廓。

![纹理工具，选中了砖墙的正面，一个蓝色方框标出纹理的一次重复](../assets/texturing/texture-tool-face.png)

| 输入 | 结果 |
| --- | --- |
| 点击、Ctrl+点击 | 点击选中一个面，Ctrl+点击添加或移除一个 |
| 拖动所选的面 | 滑动纹理，光标下的像素始终留在光标下 |
| 方向键 | 按网格大小的像素数滑动，按住 Shift 则滑动一个像素 |
| Ctrl+滚轮 | 以 2 倍缩放，按住 Shift 则是精细步进 |
| Alt+滚轮 | 以 15° 旋转，按住 Shift 则是 1° |
| Alt+点击 | 拾取一个面的材质和对齐方式 |
| 右键点击 | 应用当前材质 |
| Ctrl+右键点击 | 应用并重置对齐方式 |
| Shift+右键点击 | 粘贴拾取的材质和对齐方式 |
| Alt+右键点击 | 应用当前材质，并把所选面的对齐方式越过边继续延伸 |

Alt+右键点击能让饰条或一排砖这样的纹理干净地绕过拐角。

顶部的工具选项栏里有 **对齐** 按钮。**左**、**右**、**顶**、**底** 和 **居中** 会把纹理推到面的那一侧，**适应** 会把它拉伸铺满整个面，**适应宽** 和 **适应高** 只横向或只纵向拉伸。勾选 **视为整体** 后，它们会把所有选中的面当作一个区域处理，所以一张纹理会铺满所有面。**对齐视图** 会沿着 3D 相机的方向投射纹理。

![纹理工具的工具选项栏，有对齐的左、右、顶、底、居中、适应、适应宽、适应高、视为整体、对齐视图和热点适配](../assets/texturing/texture-tool-options.png)

如果你更喜欢数字，**检查器** 会在 **对齐方式** 下显示同一个面，有偏移、缩放和旋转字段，还有用来翻转、转动和重置的按钮。它下面的 **纹理工具** 用来设置纹素密度，以及在面与面之间复制对齐方式。

![选中了一个面的检查器，有带偏移、缩放和旋转的对齐方式分区、对齐按钮和纹理工具分区](../assets/texturing/inspector-alignment.png)

对于有显式 UV 的面，以及网格，请使用 [UV 编辑器](uv-editor.md)。

## 纹理缩放 { #texture-scale }

默认情况下，一个纹理像素覆盖一个地图单位，所以 64 像素的纹理每两米重复一次。这适合低分辨率的纹理，但一张 1024 像素的照片会拉伸到 32 米。把材质上的 `metadata/texture_size` 设为一次重复应该覆盖的世界尺寸，参见[纹理尺寸](../godot/materials.md#texture-size)。材质名称下面的检查器那一行会告诉你一个面得到了什么，比如“1024 x 1024 px, 64 x 64 units a repeat”。

如果只想为一张地图设置，或者让一张纹理无缝地铺过每一个面，请使用检查器里的[纹理设置](light-baking.md#texture-settings)。它的重复尺寸优先于材质的。

## 热点 { #hotspots }

热点让一张饰条图集可以给很多形状各异的面贴图。你只需标记一次它的矩形，然后 TrenchDot 会为每个面挑选合适的那个。

1. 在材质面板里右键点击饰条图集，选择 **热点编辑器**。*纹理 > 热点编辑器…* 也能打开它，针对所选面的材质，没有选中面时则针对当前材质。

    ![纹理菜单，鼠标悬停在热点编辑器… 上，底部是热点适配（Alt+H）](../assets/texturing/menu-texture.png)

2. 在纹理上拖动来画一个矩形，或者设置一个网格并点击 **拆分为栅格**。拖动矩形可以移动它，拖它的角手柄可以调整大小，右键点击会删除它。
3. 点击 **保存**。这些矩形会存进纹理文件旁边的 `<texture>.hotspots.json`。
4. 选中这些面，使用 *纹理 > 热点适配*（Alt+H），或者在编辑器里点击 **应用到选择**。

![热点编辑器中的 withered/concrete_panels，拆分成 4 乘 4 的网格，16 个矩形，未保存](../assets/texturing/hotspot-editor.png)

热点适配会给每个面分配形状与它最接近的矩形，并优先选择能让纹理保持接近正常比例的那个。

## 顶点绘制 { #vertex-paint }

**绘制** 工具（P）把顶点颜色画到笔刷的面上，用于污渍、色调和伪造的光照。在工具选项栏里，笔刷半径和强度旁边选择颜色，然后在面上拖动。它会绘制所选的笔刷，没有选中任何东西时则绘制每个笔刷。Ctrl+滚轮调整笔刷大小。

![绘制工具的工具选项栏，有颜色色块、半径 48 u 和强度 4.0](../assets/texturing/paint-tool-options.png)
