# 预制体库 { #prefab-library }

底部、挨着材质和模型的**预制体**标签页，存放着可以直接粘贴进地图的现成部件：楼梯、门洞、柱子、小房间和各种细节。可以把它想成 TrenchBroom 制图者常常复制取用的预制体合集，只不过直接内置在编辑器里。

![预制体标签页，有搜索预制体、分类列表、卡片大小滑块，以及每个内置部件一张卡片，鼠标停在折返楼梯上并显示提示：楼梯/折返楼梯，192 × 128 × 352 单位，内置](../assets/prefab-library/prefabs-panel.png)

每张卡片都从最能看清部件的那一面来画它：楼梯这类平面布局从上往下看，门洞这类墙体从正面看。越亮表示离得越近。

## 粘贴一个部件 { #pasting-a-piece }

1. 指向那个位置

    在视图里把鼠标停在部件应该放的位置，这会设置 3D 光标。

2. 点击卡片

    在*搜索预制体*里输入，或者选一个分类来找到它，然后点击。部件会以那个位置为中心粘贴进来，并吸附到网格，和 Ctrl+V 一样。

    ![折返楼梯被粘贴进一个小房间，台阶用的是灰色的 dev 材质](../assets/prefab-library/pasted-switchback-stair.png)

只有平面布局上的位置会跟随光标。高度保持部件保存时的样子，所以在上层楼里，粘贴之后要再把它抬起来。

粘贴就是一份普通的拷贝，与库之间没有链接，所以随便重塑或重新贴图都可以。内置部件用的是每个项目都有的 `dev/` 材质，可以在材质标签页里给它们重新贴图。

右键点击卡片会有*粘贴*和*复制*。复制会把部件放进剪贴板，可以粘贴到别的地图，或者以文本形式分享。

要用随机挑选的部件铺满一整片区域，请用[随机填充](random-fill.md)。

> [!TIP]
> 部件一旦粘贴，就是普通的地图内容。如果想让某样东西在用到的每个地方都保持同步，比如在整栋建筑里重复出现的窗框，就改用[预制体实例](organizing.md#prefabs)。

## 你自己的部件 { #your-own-pieces }

1. 选中对象

    在打开了 Godot 项目的情况下，选中想要变成部件的东西。

2. 添加所选内容

    展开预制体标签页顶部的**添加所选内容**，给部件起个名字和分类，然后点击**添加**。

    ![添加所选内容已展开，名称是 Grand stair，分类是楼梯，保持位置未勾选，以及添加的提示：把所选内容保存为 res://prefab_library 里的 .tdm，底部中心放在原点](../assets/prefab-library/add-the-selection.png)

3. 找到新卡片

    它会排在最前面，带一个蓝色的边框。右键点击它会有*打开编辑*，把部件当作地图打开，还有*在文件管理器中显示*。内置部件不能编辑。

    ![Grand stair 卡片的右键菜单，有粘贴、复制、打开编辑（鼠标停在上面）和在文件管理器中显示](../assets/prefab-library/card-menu.png)

部件会保存为 `res://prefab_library/<category>/` 里的一个 `.tdm`，并经过移动，让所选内容的底部中心落在原点上。勾选**保持位置**则让它留在原处，适合你有意围绕地图原点做出来的部件，比如[随机填充](random-fill.md)套件里的那些部件。

那个文件夹里的每个 `.tdm` 都是一个部件。你自己用 *文件 > 另存为…* 把地图保存到那里，它们马上就会显示为卡片。对于手工拷进去的文件，或者在项目之间共享的一个部件文件夹，请按 ⟳ 按钮。

## 从 TrenchBroom 粘贴 { #pasting-from-trenchbroom }

TrenchDot 也能粘贴 TrenchBroom 放进剪贴板的内容。在 TrenchBroom 里，或者从网上的 TrenchBroom 预制体合集里复制笔刷，然后在地图里按 Ctrl+V。组会作为组过来，实体作为实体过来，坐标轴的转向与[导入 .map](importing.md) 时相同。纹理名会保留，其他游戏的工具纹理则换成项目自己的。

## MCP { #mcp }

`prefab_library` 工具可以列出部件（`op: list`），按 `category/name` 粘贴一个部件（`op: paste`，带 `origin` 或 `offset`），返回它的剪贴板文本（`op: copy`），并把对象添加到项目的库里（`op: add`，除非给了 `ids`，否则用当前选择）。`run_action` 配合 `paste`，除了 TrenchDot 的剪贴板文本，也接受 TrenchBroom 的剪贴板文本。
