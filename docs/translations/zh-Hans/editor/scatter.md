# 散布 { #scatter }

**散布**工具（B）会把树木、岩石和草绘制到你选定的表面上，让你几秒钟就能盖满一面山坡，不用一个个手工摆放模型。[海岛教程](../tutorials/sea-island-scatter.md)会带你走一遍完整的设置。

![用散布工具在岛上刷出一条森林带](../assets/scatter/scatter-paint.gif)

## 散布集合 { #scatter-sets }

你散布的一切都放在各自图层上的**散布集合**里，比如一个集合放树，一个放草。按 B，散布面板就会在右侧打开，当前集合里的每个模型都有一张卡片。

![散布面板，灌木集合处于激活状态：集合菜单、+、预设、重命名，以及每个模型一张卡片](../assets/scatter/scatter-panel.png)

| 想做的事 | 这样做 |
| --- | --- |
| 新建一个空集合 | 集合菜单旁边的 **+** |
| 从预设开始 | **预设**，然后从十个内置集合里选一个 |
| 添加模型 | 从模型面板拖进来，或者用**添加模型…**。**添加所选道具**会取所选实体的模型 |
| 不再绘制某个模型 | 取消勾选它卡片上的**绘制**。已经放下的保持不变 |
| 调整某个模型 | 点击它卡片右侧的箭头 |

![预设菜单已展开，列出森林、松树、混交林、精细森林、低多边形树木、灌木、林下植被、岩石、巨石和草，鼠标停在岩石上](../assets/scatter/preset-menu.png)

岩石、巨石、草、林下植被和低多边形树木这几个预设使用编辑器内置的 Blockbench 模型。选择其中一个，会离线把它需要的模型加到 `res://trenchdot/nature`。森林、松树、混交林、精细森林和灌木这几个预设使用自然资源包里的 glTF 树木和灌木，那是个约 23 MB 的下载。在没有它的项目里，选择这些预设会打开 *Godot > 向项目添加内容…* 并定位到自然模型，而不是做出一个缺少模型的集合。*地形 > 散布 > 安装自然模型…*，或者面板底部的**安装自然模型…**，也会打开它。项目里已有的文件绝不会被覆盖。

### 模型卡片 { #model-cards }

点开卡片的箭头，调整那一个模型。

![展开的 bush_round 卡片，有缩放、间距、对齐、倾斜、下沉、随机朝向和材质](../assets/scatter/model-card.png)

| 卡片设置 | 作用 |
| --- | --- |
| 权重 | 这个模型和集合里其他模型相比被选中的频繁程度 |
| 缩放 | 两个数值之间的随机大小 |
| 间距 | 到任何其他实例的最小距离，以地图单位计 |
| 对齐 | 0 让模型保持直立，1 让它倾斜以贴合表面 |
| 倾斜 | 随机倾斜的最大角度，以度计 |
| 下沉 | 模型被压进地里多深，用来藏住树干或岩石的底部 |
| 随机朝向 | 把每个实例转向随机的方向 |
| 材质 | 用它来绘制，取代模型自带的材质。留空时，如果集合有材质，就用集合的材质 |

## 目标 { #targets }

集合只会落在它的**目标**上，所以画在地形上的森林绝不会盖住地形上的房子。在视图里 Alt+点击，或者点击*目标*右侧的吸管再在视图里点击，就能添加或移除目标。没有目标的集合，会接受它第一笔落到的任何东西。另一个集合也可以做目标，草就是这样长在巨石上的。

![散布面板的目标部分，目标是地形，吸管在右上角](../assets/scatter/targets.png)

勾选**跟随光标**会忽略目标，在笔刷下的任何表面或已散布的道具上绘制。

## 绘制 { #painting }

快速设置在左上角的工具选项栏里：集合、**绘制**或**擦除**、半径、密度、最大坡度、**跟随光标**、吸管和**填充**。如果你把散布面板关掉了，**散布面板**可以把它调回来。

![散布工具的选项栏，灌木集合、绘制、半径 512 u、密度 1.00 和最大坡度 40°](../assets/scatter/scatter-toolbar.png)

| 输入 | 动作 |
| --- | --- |
| 左键拖动 | 绘制 |
| Shift+左键拖动 | 擦除，只作用于当前集合 |
| Ctrl+滚轮 | 调整笔刷大小 |
| **填充目标** | 一次盖满每个目标，遵守坡度和高度的限制 |

面板的*笔刷*部分放着其余的设置。

![散布面板的笔刷部分：半径、密度、坡度、高度、衰减、仅暴露处、擦除量、种子、输出，以及它们下面的复选框](../assets/scatter/brush-settings.png)

**密度**是笔刷每 64 乘 64 单位尝试放置多少次，而每个模型的间距限制了实际能放下多少。**仅暴露处**会跳过上方有几何体的点，让草不会长到阳台和屋顶下面。**与其他集合保持间距**默认开启，它会阻止灌木从另一个集合的树干里长出来。

## 在 Godot 里 { #in-godot }

集合的**类型**决定 Godot 构建出什么。

| 类型 | 构建为 |
| --- | --- |
| props | 带碰撞和阴影的 MultiMesh。场景带有脚本的模型会逐个实例化，让脚本能够运行 |
| foliage | 不带碰撞和阴影的 MultiMesh，默认在 2400 单位之外隐藏。适合草和小型植物 |

在大纲里选中集合，它在检查器里的**碰撞**一行决定每个实例与什么形状碰撞。新的 props 集合从凸包开始，foliage 集合从无开始。

| 碰撞 | 每个实例的形状 |
| --- | --- |
| 无 | 没有碰撞 |
| 盒体 | 围绕实例的一个盒子 |
| 凸包 | 围绕实例的一个凸包 |
| 分解 | 几个贴合凹形模型（比如拱门）的凸包，构建得更慢 |
| 三角网格 | 模型的每一个面，精确但开销最大 |

需要编辑单个道具时，用散布面板底部的**转为实体**，或者对选中的集合用 *地形 > 散布 > 散布集转实体*，把一个集合替换成每个实例一个 `prop_model` 实体。

![散布面板的底部，有类型、绘制、擦除、填充目标、清除实例、转为实体和安装自然模型…](../assets/scatter/panel-buttons.png)
