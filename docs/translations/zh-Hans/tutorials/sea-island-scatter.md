# 海岛 4：散布 { #sea-island-4-scatter }

散布可以用画笔一次放下大量的树、灌木、岩石或草，而不用一个个地放。下面每一种植被都是它自己的散布集合，一个集合只会长在它的目标上，也就是你为它选的那些表面。

## 设置一个集合 { #set-up-a-set }

本页的每个集合都以同样的方式开始。

1. 选择散布工具

    按 **B**，或者点击工具栏里的散布按钮。右侧会打开散布标签页，就在检查器旁边。（如果你把它关了，工具选项栏里的**散布面板**可以把它调回来。）

    ![工具栏里悬停着散布工具按钮，以及它的提示：拖动即可绘制当前散布集合的模型](../assets/sea-island/toolbar-scatter.png)

2. 从预设开始

    点击散布面板顶部的**预设**，选择该步骤指明的预设。

    ![散布面板，预设菜单展开，混交林处于悬停状态](../assets/sea-island/scatter-preset-menu.png)

3. 以地形为目标

    点击**目标**旁边的吸管，然后在 3D 视图里点击地形。你应该会在目标下看到它被列出来，名字类似 `terrain #2`。

    ![散布面板的目标一行，吸管处于悬停状态并显示它的提示](../assets/sea-island/scatter-eyedropper.png)

请让**跟随光标**保持不勾选，因为它会在画笔下的任何东西上绘制，而忽略目标。请让**与其他集合保持间距**保持勾选，这样各个集合会彼此保持距离，也不会有东西从树干里长出来。

## 林地 { #woodland }

1. **预设** > *混交林*，然后点击顶部的**重命名**，把它叫作 `woodland`。以地形为目标。
2. 在笔刷部分把**密度**设为 0.16，**坡度**设为 0 到 30，并勾选**高度**，120 到 2000。坡度范围让树远离悬崖，高度范围让树远离沙滩。

    ![下半部分的散布面板：目标是 terrain #2，跟随光标未勾选，密度 0.16，坡度 0 到 30，高度已勾选且为 120 到 2000，与其他集合保持间距已勾选，填充目标按钮处于悬停状态](../assets/sea-island/scatter-woodland-settings.png)

3. 点击面板底部的**填充目标**，一次种满整块地形。

密度统计的是每 64 x 64 个单位内的尝试次数，所以 0.16 大约是每 5 米一棵树。

![点击填充目标后的林地](../assets/sea-island/scatter-woodland.jpg)

按住 **Shift**，用半径 260 沿着每条小路拖动，把那里的树擦掉。在主山顶擦出一块空地（半径约 520），在沙滩后面擦出一片草甸（约 700）。

![擦掉小路上的树](../assets/sea-island/scatter-erase-paths.jpg)

## 主景树、灌木和巨石 { #hero-trees-bushes-and-boulders }

每一行都是用指定预设新建的一个集合，和林地一样以地形为目标。主景树是少量高大、精细的树，放在玩家会仔细看的地方。

| 集合 | 预设 | 怎样放置 | 半径 | 密度 | 坡度 | 高度 |
| --- | --- | --- | --- | --- | --- | --- |
| 主景树 | 精细森林 | 在小路离开沙滩的地方和山顶空地周围单击 | 260 | 0.08 | 0 到 30 | 关 |
| 灌木 | 灌木 | **填充目标**，然后用半径 190 沿着小路擦除 | | 0.35 | 0 到 32 | 45 到 200 |
| 巨石 | 巨石 | 沿着悬崖顶部画一笔 | 1100 | 0.035 | 12 到 50 | 20 到 2000 |

![小路脚下的主景树](../assets/sea-island/scatter-hero-trees.jpg)

![沙子上方一带的灌木](../assets/sea-island/scatter-bushes.jpg)

![沿悬崖分布的巨石](../assets/sea-island/scatter-boulders.jpg)

## 草 { #grass }

1. 用*草*预设新建一个集合。草是植被，渲染时没有碰撞和阴影，所以可以很密，也不会拖慢游戏。
2. 用半径 650、密度 2.5、坡度 0 到 28、高度 45 到 2000 画开阔的草甸。用半径 170 把小路上的草擦掉。

    ![沙滩后面的草甸草](../assets/sea-island/scatter-meadow.jpg)

3. 要让巨石上也长草，再新建一个*草*集合。用吸管点击一块巨石而不是地形，让巨石集合成为它的目标。你应该会在目标下看到它，名字后面带着 `(set)`。然后用密度 6、坡度 0 到 45 **填充目标**。

    ![目标一行列出了 cliff boulders (set) 作为目标](../assets/sea-island/scatter-target-boulders.png)

> [!NOTE]
> 填充会按巨石在那一刻的样子往上放草，所以请先把巨石做完。

![长在巨石上的草](../assets/sea-island/scatter-boulder-grass.jpg)
