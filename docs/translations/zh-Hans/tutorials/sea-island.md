# 海岛 1：地形 { #sea-island-1-terrain }

一座大岛，有两座山丘、悬崖、沙滩、小路、林地和一座码头，分五个部分搭建。这里的数值就是做图时用的，单位是地图单位，每米 32 个。

![从南面看完成的海岛](../assets/sea-island/island-finished.jpg)

## 创建地形 { #create-the-terrain }

在菜单栏里打开 *地形 > 创建地形…*。

![地形菜单，创建地形… 处于悬停状态](../assets/sea-island/menu-create-terrain.png)

像这样填写对话框：

| 设置 | 值和原因 |
| --- | --- |
| 分辨率，单元大小 | 257 x 257 个点，间距 64 个单位。下面的“大小”一行会显示结果：16384 个单位（512 米） |
| 形状 | 岛屿，高度 1600，特征大小 3000，侵蚀 20，种子 1。岛屿在中间隆起，向边缘下降。特征大小是最大起伏的宽度，侵蚀会让陡坡塌下来，看起来像风化过的 |
| 基础图层，坡面图层，峰顶图层，低地图层 | `showcase/grass`、`showcase/cliff`、`showcase/dirt`、`showcase/sand`。前两个平铺 256，其余的平铺 192。基础图层覆盖所有你没有涂上其他图层的地方，其他几个分别用于陡坡、高处和低处 |
| 居中 | 取消勾选 **3D 光标**，然后填 `0 -576 0` |
| 按坡度和高度绘制图层 | 不勾选，第 3 部分会手动绘制 |

（平铺值是纹理重复一次所覆盖的单位数。）

![填好的创建地形对话框：257 x 257，单元大小 64，岛屿，高度 1600，特征大小 3000，侵蚀 20，种子 1，四个展示图层，中心 0 -576 0，并且没有勾选按坡度和高度绘制图层](../assets/sea-island/create-terrain-dialog.png)

点击底部的 **创建**。你应该会看到一座绿色的岛出现，并且已经被选中，编辑器还会自动切换到雕刻工具。

海面会在高度 0，所以把地形降低 576 会淹没它的外圈，让中间保持干燥。后面的部分会用槽位编号来指代图层：0 草地，1 悬崖，2 泥土，3 沙子。

## 加上大海 { #add-the-sea }

大海是玩家可以走进去的一个平整的笔刷。

1. 画一个巨大的方块

    按 **Q** 切换到选择工具，再按 **Escape** 取消选中地形，否则你的拖动会雕刻或移动它。然后在顶视图里拖出一个比地形大很多倍的方块，不然它的边缘会出现在地平线上。

2. 把它压平

    在前视图里，把它做成 32 个单位厚，顶部在高度 0。

3. 把它变成水

    选中这个方块，在材质标签页里点击 `showcase/water`。然后按住 Shift 点击 3D 视图里的水面，只选中它的顶面，并在检查器的 *对齐方式* 部分把 *缩放* 设为 8 和 8。这样水的纹理就不会每隔几米就重复一次。

    ![检查器显示已选 1 个面，材质 showcase/water，对齐方式的缩放为 8.00 和 8.00](../assets/sea-island/inspector-alignment-scale.png)

4. 让玩家能涉水进去

    在远离岛的地方点击一次水面，这样整个方块会重新被选中，而不只是它的顶面。然后右键点击它，选择 *创建笔刷实体 > func_illusionary*。它渲染时没有碰撞，所以玩家可以走进水里。

现在你应该有一座位于海中的岛，可以开始雕刻了：

![海中生成的岛，雕刻之前](../assets/sea-island/fresh-island.jpg)
