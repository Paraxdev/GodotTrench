# 海岛 3：绘制 { #sea-island-3-painting }

按 **Shift+G** 切换到混合工具，或者点击工具栏里紧挨着雕刻的混合按钮。和雕刻一样，它作用于所选的地形，没有选中任何东西时则作用于全部地形。它的设置在左上角的工具选项栏里。

![工具栏里悬停着混合工具按钮，以及它的提示：拖动即可在地形图层、置换和带混合材质的面上绘制混合](../assets/sea-island/toolbar-blend.png)

**坡度**和**高度**模式只会在地面的陡峭程度或高度处于某个范围内的地方绘制。半径 12000 能覆盖整座岛，所以在这些模式下点一下，就能一次画遍所有海岸或悬崖。

## 沙子和岩石 { #sand-and-rock }

| 设置 | 沙子 | 岩石 |
| --- | --- | --- |
| 模式 | 高度，从 `-3000` 到 `40` | 坡度，从 `32` 到 `90` |
| 衰减 | 恒定，整个画笔上都是满强度 | 恒定 |
| 图层 | 3 | 1 |
| 半径，强度 | 12000，1 | 12000，1 |

设好这些，然后每种在岛中间点一下。你应该会看到所有低于 40 的地方变成沙子，所有陡坡变成岩石：

![高度模式：所有低于 40 个单位的地方都变成沙子](../assets/sea-island/sand-height.jpg)

![坡度模式：所有比 32° 更陡的地方都变成岩石](../assets/sea-island/rock-slope.jpg)

想把沙滩拓宽，就在**绘制**模式下沿南岸绘制图层 3，衰减选平滑，半径 700，强度 0.7。平滑衰减会向画笔边缘逐渐淡出，所以沙子的边缘会保持柔和。

## 小路 { #paths }

模式**绘制**，衰减平滑，图层 2，半径 140，强度 0.8。拖动：

1. 从沙滩上方，以长长的曲线一直画到主山丘。
2. 从主山顶沿着山脊画到悬崖顶。
3. 从沙滩东端画到第二座山丘。

![绘制通往主山丘的小路](../assets/sea-island/paths.jpg)

![近看小路](../assets/sea-island/path-close.jpg)

## 打散重复 { #break-up-the-repeat }

从远处看，重复的纹理会显出网格。在大纲里选中地形（在视图里点一下会用混合工具绘制），然后在检查器里的每一行图层上设置**去平铺**和**锐化**。锐化会让去平铺后的纹理保持清晰，而不是变软。

| 图层 | 去平铺 | 锐化 |
| --- | --- | --- |
| 0 草地 | 0.5 | 0.5 |
| 1 悬崖 | 0.7 | 0.4 |
| 2 泥土 | 0.5 | 0.5 |
| 3 沙子 | 0.4 | 0.5 |

![地形的检查器，有四行图层，每行都有材质、平铺、去平铺和锐化](../assets/sea-island/inspector-terrain-layers.png)
