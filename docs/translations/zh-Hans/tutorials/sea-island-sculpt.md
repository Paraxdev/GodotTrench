# 海岛 2：雕刻 { #sea-island-2-sculpting }

雕刻会把生成出来的地面推成你想要的形状。

1. 选择雕刻工具

    先按 **Escape**，因为上一部分做的海还处于选中状态，这时雕刻不会有任何作用。它作用于所选的地形，没有选中任何东西时则作用于所有地形。然后按 **G**，或者点击工具栏里的雕刻按钮。

    ![工具栏里悬停着雕刻工具按钮，以及它的提示：在地形或置换上拖动，用所选模式为其塑形](../assets/sea-island/toolbar-sculpt.png)

2. 找到它的设置

    模式、半径和强度在工具栏正下方左上角的工具选项栏里。拖动时按住 **Ctrl** 就是平滑，不管当前是什么模式。

    ![雕刻工具选项，半径 2800，强度 32，模式列表展开，有抬升、降低、平滑、压平、噪声、梯田和绘制 Alpha](../assets/sea-island/sculpt-mode-list.png)

3. 留意高度

    右下角的状态栏显示指针下方的点，它中间的数字就是高度。很适合用来判断你把某个地方抬高或降低了多少。

    ![状态栏的坐标 -2200.0、1549.2 和 -600.0，中间那个是高度](../assets/sea-island/status-bar-height.png)

## 山丘 { #hills }

1. **抬升**，半径 2800，强度 32。在中心偏西的位置按住鼠标按钮约四秒，直到状态栏显示山丘大约有 1500 个单位高。

    ![雕刻工具处于抬升模式，半径 2800，强度 32，按住按钮时画笔圈下面长出一座山丘](../assets/sea-island/sculpt-raise.gif)

2. 在同一个位置用半径 1300，让山顶更陡。画笔越小，抬起的区域越窄，所以山顶会更尖。
3. 用半径 1900 在东南方向做一座更矮的第二座山丘。

## 悬崖 { #cliffs }

1. **抬升**，半径 1800。沿着东北海岸、稍微靠内陆的地方拖动，做出一个岬角。然后用一个非常大的画笔对整座岛 **平滑** 一次，把疙瘩抹掉。
2. **降低**，半径 1000。在那段海岸前面的海里拖动，让它更深，这样悬崖就会落进深水里，而不是浅滩。
3. **梯田**，步长 300，半径 1000。梯田会把高度吸附到给定大小的台阶上。沿着海岸线拖动，让它断成一级级台地和陡面，然后再用轻一点的 **平滑** 过一遍。

![沿海岸以 300 个单位的步长做出的梯田](../assets/sea-island/terrace-cliffs.jpg)

## 沙滩 { #beach }

1. **压平**，半径 900。压平会保持笔划起点的高度，所以请正好从南岸的水线处开始，沿着海岸拖动。
2. 用稍大一点的画笔 **平滑**，让沙滩和陆地衔接起来，不留台阶。

![在南岸压平](../assets/sea-island/beach-flatten.jpg)
