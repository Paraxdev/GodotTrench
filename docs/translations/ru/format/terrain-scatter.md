# Ландшафт и разброс { #terrain-and-scatter }

## Ландшафт { #terrain }

Карта высот на регулярной сетке, по одной высоте на вершину сетки, раскрашенная не более чем четырьмя слоями текстур.
Основные данные это текст base64 в JSON и сырые байты в [бинарном контейнере](container.md#value-encoding).

| Ключ | Тип | По умолчанию | Значение |
| --- | --- | --- | --- |
| `origin` | `[x, y, z]` | обязателен | Мировая позиция первой вершины |
| `resolution` | `[nx, nz]` | обязателен | Число вершин вдоль X и Z, не менее 2 каждое |
| `cell_size` | число | обязателен | Единиц карты между соседними вершинами |
| `heights` | base64 | обязателен | 32-битные float little endian, по одной высоте на вершину |
| `layers` | массив | обязателен | Не более четырёх слоёв текстур, см. ниже |
| `splat` | base64 | опускается | Четыре байта веса на вершину, по одному на слой, показывающие, насколько каждый слой виден в этом месте |
| `holes` | base64 | опускается | Один байт на ячейку, ненулевое значение вырезает ячейку из ландшафта |
| `chunk_cells` | целое число | `32` | Записывается всегда. Ячеек на сторону чанка. Для отрисовки и коллизий ландшафт делится на чанки такого размера |

Вершина `(i, j)` находится в `origin + (i * cell_size, heights[j * nx + i], j * cell_size)`. `splat` использует тот же
порядок, его веса нормализуются при чтении, а запись из одних нулей означает слой 0. `holes` покрывает `(nx - 1) * (nz - 1)`
ячеек в том же порядке.

Каждый слой:

| Ключ | Тип | По умолчанию | Значение |
| --- | --- | --- | --- |
| `material` | строка | обязателен | Материал, которым красит этот слой |
| `tile` | число | `256` | Единиц карты на одно повторение текстуры |
| `detile` | число | `0` | От 0 до 1, насколько сильно повторение разбивается, чтобы узор сетки перестал быть заметен |
| `detile_sharpen` | число | `0.5` | От 0 до 1, насколько чётким остаётся результат антитайла |

О том, как эти настройки выглядят на практике, см. [Слои ландшафта](../editor/terrain-layers.md).

Ландшафты остаются выровненными по осям. Экземпляр сдвигает центр ландшафта всей своей трансформацией, включая поворот,
но саму сетку никогда не поворачивает.

## Разброс { #scatter }

Набор разброса хранит в одном узле много копий нескольких моделей, например деревьев, камней или травы, нарисованных на
поверхностях. О стороне редактора см. [Разброс](../editor/scatter.md). Каждый ключ, кроме `targets` и `material`,
записывается всегда.

| Ключ | Тип | По умолчанию | Значение |
| --- | --- | --- | --- |
| `name` | строка | обязателен | Имя, показываемое в редакторе |
| `kind` | строка | `props` | Что строит Godot. `props` сохраняет скрипты и коллизии, `foliage` это MultiMesh без коллизий |
| `targets` | массив идентификаторов узлов | опускается | Поверхности, на которые набор нарисован |
| `items` | массив | обязателен | Модели, которые он разбрасывает, см. ниже |
| `collision` | строка | `none` для листвы, иначе `convex` | Форма коллизии на экземпляр: `none`, `box`, `convex`, `decomposition` или `trimesh` |
| `cast_shadows` | bool | `true` | Отбрасывают ли экземпляры тени |
| `visibility_range` | число | `0` | Скрывать экземпляры дальше этого расстояния, 0 значит никогда |
| `chunk_size` | число | `0` | Делит набор на ячейки такого размера, чтобы Godot мог отсекать то, что вне экрана, 0 это одна ячейка. Новые наборы используют 2048 |
| `static_props_multimesh` | bool | `false` | Рисовать сцены предметов со скриптами тоже как MultiMesh. Дешевле для множества предметов, но их скрипты отбрасываются |
| `material` | строка | опускается | Переопределение материала для всего набора |
| `instances` | массив | пусто | Размещённые экземпляры, см. ниже |

Если скопировать набор вместе с поверхностью, на которую он нацелен, копия нацелится на скопированную поверхность.

Каждый предмет это одна модель, которую набор может разместить:

| Ключ | Тип | По умолчанию | Значение |
| --- | --- | --- | --- |
| `source` | строка | обязателен | Модель или сцена `res://` |
| `weight` | число | `1` | Относительный шанс того, что выберут этот предмет |
| `scale` | `[min, max]` | `[0.8, 1.2]` | Диапазон случайного равномерного масштаба |
| `spacing` | число | `48` | Минимальное расстояние до каждого другого экземпляра |
| `align` | число | `0` | 0 ставит прямо, 1 следует нормали поверхности, промежуточные значения наклоняют частично |
| `random_yaw` | bool | `true` | Поворачивать каждый экземпляр в случайном направлении |
| `tilt` | число | `0` | Наибольший случайный наклон в градусах |
| `sink` | число | `0` | Единиц карты, вдавленных в поверхность, чтобы корни и основания камней не парили |
| `material` | строка | опускается | Переопределение материала для этого предмета. Оно главнее материала набора |
| `enabled` | bool | `true`, опускается | Рисует ли кисть этот предмет. Уже размещённые экземпляры остаются |

Каждый экземпляр это плоский массив `[item, x, y, z, pitch, yaw, roll, scale]`, где `item` это индекс в `items`, а углы
даны в градусах в порядке YXZ. При сохранении позиция округляется до 0.01, углы до 0.1, а масштаб до 0.001, что позволяет
контейнеру хранить их как [целочисленные столбцы](container.md#value-encoding).
