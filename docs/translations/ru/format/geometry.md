# Геометрия { #geometry }

## Браш { #brush }

Выпуклое тело, хранящееся как его точные углы плюс список граней, которые ссылаются на них по индексам, так что углы
получаются без пересечения плоскостей. Плоскости граней пересчитываются при загрузке.

| Ключ | Тип | Значение |
| --- | --- | --- |
| `vertices` | массив `[x, y, z]` | Углы в единицах карты |
| `faces` | массив граней | Один многоугольник на грань |

Каждая грань:

| Ключ | Тип | По умолчанию | Значение |
| --- | --- | --- | --- |
| `indices` | массив целых чисел | обязателен | Индексы в `vertices`, не менее трёх, против часовой стрелки при взгляде снаружи |
| `material` | строка | `""` | Записывается всегда. Имя текстуры, например `base/wall` |
| `uv` | объект | параксиальная | Записывается всегда. Как текстура уложена на грань, см. [Проекцию текстуры](#texture-projection) |
| `props` | объект из строки в строку | опускается | Произвольные атрибуты грани, например ключи смешивания ниже |
| `disp` | объект | опускается | Превращает грань в [дисплейсмент](#displacement) |
| `colors` | массив `[r, g, b, a]` | опускается | [Раскраска вершин](../editor/texturing.md#vertex-paint), один цвет на индекс |

Сборка Godot пропускает браш, у которого меньше четырёх вершин или граней, поскольку у замкнутого тела их не бывает
меньше.

Грань может также смешивать два материала. Это настраивают свойства грани `blend_material`, `blend_detile`,
`blend_uv_scale` и `blend_detile_sharpen`, после чего альфа цвета вершин плавно переводит грань от `material` к
`blend_material`.

## Проекция текстуры { #texture-projection }

`uv` это проекция в стиле Valve 220 с явными осями: два мировых направления говорят, куда текстура идёт по грани, а
смещение и масштаб её размещают.

| Ключ | Тип | Значение |
| --- | --- | --- |
| `u_axis`, `v_axis` | `[x, y, z]` | Мировое направление u и v текстуры |
| `offset` | `[u, v]` | Сдвиг в текселях |
| `scale` | `[u, v]` | Единиц карты на тексел |
| `rotation` | число | Необязателен и только справочный, оси уже содержат поворот |

Точка `p` попадает в тексел `dot(p, u_axis) / scale.x + offset.x`, и так же для v. Чтобы получить итоговые UV, разделите
это на размер текстуры. Это `texture_size` материала, если он есть, см. [Материалы](../godot/materials.md), а иначе
размер изображения в пикселях.

Отсутствующий `uv` означает `u_axis = [1, 0, 0]` и `v_axis = [0, 0, 1]` с масштабом 1. Когда `uv` есть, обязательны все
ключи, кроме `rotation`.

## Настройки текстур { #texture-settings }

Объект верхнего уровня `textures` хранит настройки, общие для каждой грани с материалом, с ключом по имени материала.
Записываются только настройки, отличающиеся от значений по умолчанию, а материал без них опускается.

| Ключ | Тип | По умолчанию | Значение |
| --- | --- | --- | --- |
| `bake` | bool | `true` | Грани получают место в лайтмапе. Если выключено, Godot даёт им средний запечённый свет |
| `casts` | bool | `true` | Грани перекрывают свет при запекании |
| `texel_scale` | число | `1` | Умножает размер тексела лайтмапа на этих гранях, от 0.125 до 16 |
| `size` | `[w, h]` | нет | Сколько единиц карты покрывает одно повторение, используется вместо размера текстуры выше |
| `projection` | строка | `"face"` | `"world"` игнорирует `uv` каждой грани браша и использует сброшенную проекцию по её нормали, со смещением 0 и масштабом 1 |

`world` применяется только к граням брашей, грани мешей сохраняют свою проекцию.

## Дисплейсмент { #displacement }

Четырёхугольная грань может нести дисплейсмент в стиле Hammer, сетку вершин, каждая из которых выдвигается вдоль
нормали грани.

| Ключ | Тип | По умолчанию | Значение |
| --- | --- | --- | --- |
| `power` | целое число | обязателен | От 1 до 4. В сетке `2^power + 1` вершин на сторону |
| `heights` | массив чисел | обязателен | На сколько каждая вершина сетки выдвинута вдоль нормали |
| `alphas` | массив чисел | опускается | Вес смешивания на вершину сетки, 0 показывает материал грани |

Оба массива идут по строкам и содержат `(2^power + 1)^2` записей. Строки идут от первого угла грани к четвёртому,
столбцы от первого угла ко второму.

## Меш { #mesh }

Редактируемая полигональная сетка. В отличие от браша, она может быть вогнутой, открытой или иметь неплоские грани.

| Ключ | Тип | По умолчанию | Значение |
| --- | --- | --- | --- |
| `vertices` | массив `[x, y, z]` | обязателен | Углы в единицах карты |
| `faces` | массив граней | обязателен | Те же ключи, что у граней браша, плюс `uvs` |
| `smooth_angle` | число | `0`, опускается | Грани, сходящиеся под углом меньше этого числа градусов, делят нормали и затеняются плавно. 0 это плоское затенение |
| `decal` | bool | `false`, опускается | Помечает меш как [декаль](../editor/decals.md) |

Сглаживание сравнивает каждый угол грани с каждой гранью вокруг его вершины. Меш, которому нужно больше 64 сравнений на
угол, плюс 262 144 всего, затеняется плоско. Сюда попадает только вершина, общая для сотен граней, например вершина
конуса, у которого больше примерно 650 сторон.

`uvs` грани меша это массив `[u, v]`, по одному на индекс, в ширинах текстуры. Когда он есть, он заменяет `uv`, а число,
не совпадающее с `indices`, заставляет редактор отклонить карту.
