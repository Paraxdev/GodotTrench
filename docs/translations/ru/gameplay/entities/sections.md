# Потоковые секции { #streamed-sections }

> [!NOTE]
> Эти сущности входят в пакет сущностей геймплея, см.
> [Установка и настройка](README.md#installing-and-customizing).

Сущности для прохождения нескольких карт как одного мира без экрана загрузки. Каждая карта это секция, а секции встречаются в соединительной комнате, точную копию которой хранят обе карты. Как это настроить, шаг за шагом рассказывает страница [Стриминг секций](../../godot/streaming.md#streaming-sections).

## info_landmark { #info_landmark }

Общая точка соединительной комнаты. Поставьте одну в середину комнаты, с одним и тем же именем в обеих копиях. Когда подгружается следующая секция, она размещается так, чтобы её ориентир попал точно туда, где был прежний.

* **Ключи:** `targetname`

## func_section_stream { #func_section_stream }

Одна половина соединительной комнаты, невидимый объём. Пока игрок стоит в нём, загружена та секция, которую он называет. Соединителю нужны два, по одному с каждой стороны, а линия, где они встречаются, это место смены секций, так что ставьте её там, откуда не видно ни одного конца комнаты, например посередине Z-образного коридора.

* **Ключи:** `section` (секция на этой стороне: путь её сцены, например `res://levels/pools_2.tscn`, или имя, которое находится в `sections_dir` стримера), `landmark` (`targetname` сущности `info_landmark` этой комнаты)

## TDSectionStreamer { #tdsectionstreamer }

Не сущность, а узел, который выполняет стриминг. Добавьте его в сцену вашего мира и задайте:

| Свойство | Что это |
| --- | --- |
| `first_section` | Секция, в которой начинается игра, путь сцены или имя |
| `sections_dir` | Папка, в которой ищутся короткие имена, как `name.tscn` или `name.scn` |
| `player_scene` | Игрок, который создаётся в `info_player_start` первой секции |
| `player_path` | Или игрок, уже стоящий в сцене. Если нет ни того, ни другого, остаётся первый узел группы `player`, который принесла секция |
| `recenter_distance` | Сколько метров цепочка секций может уйти от начала координат, прежде чем весь мир сдвинется обратно, 8000 |

После каждой смены он испускает `section_changed(from, to)`.
