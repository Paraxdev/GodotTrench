# Логика { #logic }

> [!NOTE]
> Эти сущности входят в пакет сущностей геймплея, см.
> [Установка и настройка](README.md#installing-and-customizing).

Невидимые точечные сущности, которые решают, когда что-то происходит. Они стоят между триггером или кнопкой и тем, на что те влияют, и формируют сигнал по дороге. Сущности для работы с числами описаны на странице [Математика и значения](math.md), а те, что запускают код или анимации, на странице [Скрипты и вызовы](scripting.md).

## logic_relay { #logic_relay }

Передаёт `trigger` дальше как `triggered`, пока включено. Подключите к одному реле несколько вещей, а затем отправьте ему `disable`, чтобы выключить всю цепочку разом.

* **Входы:** `trigger(activator)`, `enable`, `disable`, `toggle`
* **Выходы:** `triggered(activator)`
* **Ключи:** `start_disabled` 0

## logic_branch { #logic_branch }

Помнит «истину» или «ложь» и по `test` запускает `on_true` или `on_false`, для проверок вроде «дверь открывается, только если включено питание». Генератор ставит значение в «истину», кнопка двери его проверяет.

* **Входы:** `set_true`, `set_false`, `toggle`, `test`, `set_and_test(value)`
* **Выходы:** `on_true`, `on_false`
* **Ключи:** `start_value` 0

## logic_gate { #logic_gate }

Хранит два булевых значения, `a` и `b`, и объединяет их логическим вентилем, для проверок вроде «дверь открывается, когда питание включено **и** рычаг потянут». Каждое изменение входа, меняющее результат, запускает `changed(on)`, а затем `on_true` или `on_false`, так что спрашивать ничего не нужно. `test` запускает текущий результат ещё раз, на случай если что-то другое хочет узнать его прямо сейчас.

* **Входы:** `set_a(value)`, `set_b(value)`, `toggle_a`, `toggle_b`, `test`
* **Выходы:** `on_true`, `on_false`, `changed(on)`
* **Ключи:** `gate` and, `start_a` 0, `start_b` 0

| `gate` | Истина, когда |
| --- | --- |
| `and` | оба значения истинны |
| `or` | истинно хотя бы одно |
| `xor` | истинно ровно одно |
| `nand` | оба истинны не одновременно |
| `nor` | ни одно не истинно |
| `xnor` | оба значения одинаковы |
| `not` | `a` ложно, `b` игнорируется |

`set_a` и `set_b` без значения ставят «истину», так что выход `entered` триггера, подключённый к `set_a`, включает `a`. Число истинно, если оно не равно 0, а текст истинен только для `true`, `yes` или `1`. Начальные значения ничего не запускают, как и изменение, которое оставляет результат прежним.

## logic_flipflop { #logic_flipflop }

Чередуется при каждом срабатывании, так что одна кнопка может включать что-то и снова выключать. `on_a` срабатывает при включении, а `on_b` при выключении. `reset` возвращает его к `start_on` без запуска обоих выходов и запускает только `changed`, если состояние изменилось.

* **Входы:** `trigger`, `reset`
* **Выходы:** `on_a`, `on_b`, `changed(on)`
* **Ключи:** `start_on` 0 (включён, так что первый `trigger` запускает `on_b`)

## logic_case { #logic_case }

Сравнивает полученное значение с вариантами, их до восьми, и запускает выход первого совпавшего или `on_default`, если не совпал ни один. Он превращает число, например индекс от `logic_random` или счёт от `math_value`, в разные события.

* **Входы:** `in_value(value)`
* **Выходы:** с `on_case_1` по `on_case_8`, `on_default`
* **Ключи:** с `case_1` по `case_8`, пусто

Числа сравниваются по значению, так что вариант `2` совпадает и со значением 2, и с `2.0`. Текст должен совпадать точно, `Red` не равно `red`, а пробелы вокруг варианта игнорируются. Пустые варианты пропускаются, побеждает первое совпадение, а отсутствующее значение уходит в `on_default`.

## logic_random { #logic_random }

Случайно выбирает один из восьми выходов или бросает кубик на шанс. Подключите `out_1` по `out_3` к трём лампам, и `pick` зажжёт одну из них. `roll` решает по шансу, например есть ли в сундуке добыча.

* **Входы:** `pick`, `roll`
* **Выходы:** с `out_1` по `out_8`, `picked(index)`, `on_success`, `on_fail`
* **Ключи:** `count` 3 (от 1 до 8), `no_repeat` 0, `chance` 50 (проценты)

`pick` запускает `picked` с номером выбранного выхода, а затем сам этот выход, так что `picked` можно подать в [`logic_case`](#logic_case). С `no_repeat` он никогда не выбирает выход, выбранный в прошлый раз, если только `count` не равен 1. `roll` запускает `on_success` с вероятностью `chance` процентов, иначе `on_fail`, так что 0 никогда не удаётся, а 100 удаётся всегда.

## logic_counter { #logic_counter }

Считает между `min` и `max`, для головоломок вроде «нажмите все три кнопки»: каждая кнопка шлёт `add`, а `hit_max` открывает дверь. Значение ограничивается, и ничего не запускается, пока оно не изменится. `hit_max` и `hit_min` срабатывают, когда изменение приводит к пределу, `reset` запускает только `changed`.

* **Входы:** `add(amount)` (по умолчанию 1), `subtract(amount)`, `set_value(value)`, `reset`
* **Выходы:** `hit_max`, `hit_min`, `changed(value)`
* **Ключи:** `min` 0, `max` 3, `start_value` 0

## logic_timer { #logic_timer }

Запускает `timer` снова и снова, для всего, что повторяется, например мерцающего света или волн врагов. Между срабатываниями он ждёт `interval` секунд и работает с загрузки карты, если только `start_on` не равен 0. Если `random_max` больше `random_min`, каждое ожидание случайно в этом диапазоне, так что повторы выглядят менее механическими. `once` останавливает его после первого срабатывания, из-за чего он становится простой задержкой.

* **Входы:** `start`, `stop`, `toggle`, `fire` (один раз, сейчас)
* **Выходы:** `timer`
* **Ключи:** `interval` 1.0, `random_min` 0, `random_max` 0, `start_on` 1, `once` 0

## logic_auto { #logic_auto }

Один раз запускает `map_spawn`, когда все сущности карты готовы. Подключите сюда всё, что работает с самого начала, например музыку или вступительный текст.

* **Выходы:** `map_spawn`

## logic_sequence { #logic_sequence }

Таймлайн катсцены. Он запускает по порядку до восьми пронумерованных шагов и ждёт перед каждым из них, включая первый. Подключите каждый шаг к тому, что происходит в этот момент: открывается дверь, появляется строка текста, идёт актёр.

* **Входы:** `start`, `stop`, `reset`
* **Выходы:** с `step_1` по `step_8`, `step(index)`, `finished`
* **Ключи:** `steps` 3 (от 1 до 8), `interval` 1.0, `times` пусто, `start_active` 0 (работает с загрузки карты), `loop` 0

`times` задаёт ожидание для каждого шага, например `0 1 0.5`, а шаги без него используют `interval`. Зацикленная последовательность никогда не запускает `finished`. Пока она работает, `start` игнорируется, а после `stop` она начинается снова с шага 1. См. [урок про катсцену](../../tutorials/cutscene.md).
