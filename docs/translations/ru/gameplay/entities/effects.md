# Пропы, свет и эффекты { #props-lights-and-effects }

> [!NOTE]
> Эти сущности входят в пакет сущностей геймплея, см.
> [Установка и настройка](README.md#installing-and-customizing). `light`, `light_spot` и зонды
> (`light_probe`, `env_reflection_probe` и `env_voxel_gi`) входят в базовый набор аддона и работают без него.

## prop_physics { #prop_physics }

Ящик или бочка, которые можно бросать, повреждать и ломать. Ломается при 0 здоровья, при ударе быстрее `impact_speed`, по `smash` или через `fuse` секунд после `ignite`. Взрывоопасный проп взрывается, когда ломается.

| Ключ | По умолчанию | Что делает |
| --- | --- | --- |
| `model` | | Сцена, как он выглядит, только для внешнего вида |
| `size` | 16 16 16 | Половинные размеры его коробчатой коллизии, так что по умолчанию он метр шириной |
| `collision` | default | default и box используют `size`, convex hull и convex decomposition следуют за моделью, см. [Коллизия](collision.md) |
| `collision_layer`, `collision_mask` | пусто | Номера слоёв, например `1, 3`, пусто оставляет значение проекта по умолчанию |
| `mass` | 5.0 | Масса в килограммах |
| `health` | 30 | Сколько урона он выдерживает до поломки |
| `explosive` | 0 | Взрывается, когда ломается |
| `explosion_radius`, `explosion_damage` | 192, 40 | Размер и сила этого взрыва |
| `fuse` | 0.6 | Сколько секунд горит подожжённый проп до поломки |
| `impact_speed` | 0 | Ломается, когда ударяется обо что-то быстрее этой скорости в м/с. 0 значит никогда не ломается от удара |
| `debris_scene` | | Сцена, создаваемая там, где он сломался, например доски |

* **Входы:** `smash`, `ignite(activator)`, `push(direction)`, `take_damage(amount, source)`
* **Выходы:** `damaged(hp)` с оставшимся здоровьем, `broken`

`push` принимает скорость в единицах карты в секунду. `broken` срабатывает после взрыва, так что всё, что он запускает, уже видит урон.

Проп строит свою модель и коробку коллизии при каждой загрузке сцены. Редактор Godot показывает их как предпросмотр, который вместе со сценой не сохраняется.

## prop_model { #prop_model }

Статичная модель с необязательной коллизией, для мебели, камней и других пропов, которые не должны двигаться.

* **Ключи:** `model` (.bbmodel, .glb, .gltf или .tscn), `model_node`, `collision`, `collision_layer`,
  `collision_mask`, `scale` 1.0

`collision` default даёт каждому мешу выпуклую оболочку, это годится для коробчатых форм. Для форм, через которые или по которым игрок ходит, например арки, выберите convex decomposition или trimesh, а box это самая дешёвая форма, см. [Коллизия](collision.md). Коллизия создаётся, только если у модели нет своей. Модели, размещённые через *Модель-проп*, и модели внутри префабов это сущности prop_model, так что коллизия у них работает так же. Для файла, в котором рядом лежат несколько вариантов, `model_node` оставляет только узел с этим именем и переносит его в начало координат пропа.

## env_explosion { #env_explosion }

Взрыв под управлением скрипта, например заряд у стены. По `explode` он вызывает `damage_method` у каждого узла в пределах `radius` с `damage * (1 - distance / radius)`, отталкивает твёрдые тела и создаёт `effect_scene` для вспышки и грохота.

* **Входы:** `explode(activator)`
* **Выходы:** `exploded`
* **Ключи:** `radius` 256, `damage` 50, `force` 8 (м/с в центре, независимо от массы), `damage_method` take_damage,
  `effect_scene`

Расстояние измеряется до начала координат каждого узла без проверки линии видимости, так что урон проходит сквозь стены.

## game_text { #game_text }

Показывает строку текста в мире, на HUD или в обоих местах, для подсказок, вывесок или субтитров катсцен.

| Ключ | По умолчанию | Что делает |
| --- | --- | --- |
| `text` | | Текст, который нужно показать |
| `place` | world | `world` парит у сущности, `hud` показывает на экране, `both` делает и то и другое |
| `start_visible` | 0 | Виден с загрузки карты |
| `duration` | 0 | Скрывает через столько секунд, 0 держит до `hide` |
| `text_color` | 255 255 255 | Цвет текста |
| `world_size` | 0.01 | Размер надписи в мире в метрах на пиксель |
| `billboard` | 1 | Надпись в мире смотрит на камеру и рисуется сквозь стены. Выключите для вывесок, тогда они сохраняют углы сущности и прячутся за стенами |

* **Входы:** `show`, `hide`, `set_text(text)`, `flash(seconds)`
* **Выходы:** `shown`, `hidden`

`show` и `hide` переключают надпись, а не узел. `flash` показывает её на столько секунд, сколько указано в параметре, иначе на `duration`, иначе на 2.

## light и light_spot { #light-and-light_spot }

Всенаправленные и прожекторные источники света, которые входы включают и выключают, для выключателей, сигнализаций и мерцающих ламп. `switched` срабатывает, только когда состояние действительно меняется. Они входят в базовый набор аддона, так что есть в каждом проекте.

* **Входы:** `turn_on`, `turn_off`, `toggle`
* **Выходы:** `switched(on)`
* **Ключи:** `light_energy` 1.0 (1.5 у прожекторов), `light_color` 255 255 255, `start_on` 1, `shadows` 0 (рендерить дороже), `fixture`, `fixture_off` hide, а также `omni_range` 10 или `spot_range` 15 и `spot_angle` 35 (половина угла конуса в градусах), `bake_mode` auto, `light_size` 0, `light_indirect_energy` 1, а также `omni_attenuation` 1 или `spot_attenuation` 1 и `spot_angle_attenuation` 1. Эти последние ключи задают свойства света Godot с теми же именами, и запекание тоже их использует

**Арматура** держит модель лампы в согласии со светом. Дайте светящейся геометрии лампы targetname и впишите его в `fixture`, завершающая `*` совпадает с префиксом, так что `hall_tube_*` охватывает все трубки. Она видна, пока свет включён, и скрыта, пока выключен, без всякого связывания. Если `fixture_off` равно `dark`, она остаётся видимой с выключенным свечением. `fixture` принимает и другие формы [цели](../parameters.md#targets), `@lamps` для группы узлов и `/root/...` для пути узла. Редактор показывает предпросмотр для всех форм, кроме пути узла, который может разрешить только Godot.

`bake_mode` и `light_size` решают, как [Запечь освещение](../../editor/light-baking.md#light-keys) обращается со светом. При `auto` свет, который может переключать I/O, то есть с targetname или `start_on` 0, остаётся работающим в реальном времени.

## env_sound { #env_sound }

Звук, который играет из точки уровня, для сигнализаций, механизмов или грохота, привязанного к событию.

* **Входы:** `play`, `stop`, `toggle`
* **Выходы:** `finished`
* **Ключи:** `sound` (аудиофайл `res://`), `volume_db` 0, `max_distance` 0 (без ограничения), `autoplay_on` 0 (играет с загрузки карты), `loop_sound` 0

## env_particles { #env_particles }

Эффект частиц для огня, дыма, искр, пыли и дождя со встроенным внешним видом, так что собирать его самому не нужно. `burst` выпускает один залп, а работающий эффект продолжает идти.

* **Входы:** `start`, `stop`, `toggle`, `burst`
* **Выходы:** `finished`
* **Ключи:** `amount` 32 (частиц живёт одновременно), `lifetime` 2.0, `one_shot` 0, `start_emitting` 0, `effect` rise,
  `color` 255 255 255, `size` 0, `blend` auto, `area` 10 1 10

`effect` это `rise` (светящаяся пыль или угольки), `fire`, `smoke`, `sparks` или `rain` (падает из коробки `area` метров шириной, высотой и глубиной). `color` тонирует его, а белый оставляет собственные цвета эффекта. `size` задаёт размер частицы в метрах, 0 берёт собственный размер эффекта. `blend` это `add` для свечения или `mix` для дыма. Значения по умолчанию у каждого эффекта выглядят нормально сами по себе, так что начните только с `effect`.

## infodecal { #infodecal }

Проецируемая декаль, коробка, которая светит материалом на всё внутри себя, для пятен, обёртывающих ступеньки, трубы или неровную землю. Как её разместить и на что обратить внимание, показывает страница [Проецируемые декали](../../editor/projected-decals.md).

* **Ключи:** `material` (имя вроде `base/stain` или путь `res://`), `texture`, `normal_texture`, `size` 64 32 64,
  `modulate` 255 255 255

`material` приносит свои текстуры и цвет, `texture` и `normal_texture` это изображения `res://`, используемые без него. `size` это ширина, глубина и высота коробки в единицах карты. Если оставить 64 32 64, ширину и высоту вместо этого задаёт [размер текстуры](../../godot/materials.md#texture-size) материала. `modulate` тонирует декаль.

## light_probe, env_reflection_probe и env_voxel_gi { #light_probe-env_reflection_probe-and-env_voxel_gi }

Зонды, которые освещают и отражают движущиеся объекты, см. [Запечённое освещение в Godot](../../godot/baked-lighting.md). Ни у одного нет входов или выходов.

| Сущность | Что это | Ключи |
| --- | --- | --- |
| `light_probe` | Точка, добавляющая в запекание один световой зонд, для мест, которые сетка зондов упускает | Нет |
| `env_reflection_probe` | Браш-объём, который становится `ReflectionProbe` размером с браш | `intensity` 1.0, `update` once, `box_projection` 1, `interior` 0, `max_distance` 0 |
| `env_voxel_gi` | Браш-объём, который становится `VoxelGI` размером с браш и запекается в редакторе Godot при каждой сборке | `subdiv` 128, `energy` 1.0, `bake_on_build` 1 |

`update`, установленный в `always`, снимает отражение зонда каждый кадр, для движущихся объектов, и это стоит дорого. `box_projection` выравнивает отражения по стенам комнаты, `interior` убирает небо для комнат без окон, а `max_distance` это сколько метров зонд видит за пределами своей коробки. `subdiv` это 64, 128, 256 или 512 вокселей вдоль самой длинной стороны, чем больше, тем чётче и дольше запекать.
