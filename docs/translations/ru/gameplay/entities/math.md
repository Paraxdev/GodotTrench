# Математика и значения { #math-and-values }

> [!NOTE]
> Эти сущности входят в пакет сущностей геймплея, см.
> [Установка и настройка](README.md#installing-and-customizing).

Невидимые точечные сущности, которые хранят, вычисляют и сравнивают числа, так что счёт, количество или цена могут управлять картой без скрипта. Они соединяются, как и любые сущности. Число идёт по соединению как значение выхода, например `changed(value)` или `result(value)`, и его получает вход, у которого нет собственного параметра, см. [Без параметра](../parameters.md#no-parameter). Параметр, введённый в соединение, важнее значения.

Целые числа остаются целыми, `2 + 3` это `5`, а не `5.0`, и число, пришедшее как текст вроде `2.5`, считается числом. Всё, что не число, считается текстом.

## math_value { #math_value }

Хранит одно число или кусок текста, как переменная. Кнопки делают `add`, а `changed` сообщает остальной карте, чему оно теперь равно. `changed` срабатывает, только когда значение отличается от прежнего.

* **Входы:** `set_value(value)`, `add(amount)` (по умолчанию 1), `get_value`, `reset`
* **Выходы:** `value(value)`, `changed(value)`
* **Ключи:** `start_value` 0, число или текст

`add` складывает два числа, а если одно из них текст, дописывает, так что добавление `!` к `hello` даёт `hello!`. `get_value` запускает `value` с тем, что хранится, на случай если числу нужно без ожидания изменения. `reset` возвращает к `start_value`. `set_value` без значения оставляет хранимое как есть.

## math_calc { #math_calc }

Делает одно вычисление над полученным числом и запускает ответ. Ничего не запоминает, так что один и тот же вход всегда даёт один и тот же ответ. Свяжите несколько в цепочку, чтобы считать по шагам.

* **Входы:** `calculate(value)`, отсутствующее значение считается 0
* **Выходы:** `result(value)`
* **Ключи:** `operation` add, `operand` 1

| `operation` | `result` |
| --- | --- |
| `add`, `subtract`, `multiply` | значение плюс, минус или умноженное на `operand` |
| `divide` | значение, делённое на `operand` |
| `modulo` | остаток от деления, для положительного `operand` никогда не отрицательный, так что `-1` по модулю `3` это `2` |
| `power` | значение в степени `operand` |
| `min`, `max` | меньшее или большее из двух |
| `abs`, `negate` | значение без знака или с обратным знаком |
| `round`, `floor`, `ceil` | ближайшее целое (половины округляются от 0), округление вниз, округление вверх |

`abs`, `negate`, `round`, `floor` и `ceil` игнорируют `operand`. Когда ответа нет, например при `divide` или `modulo` на 0 или корне из отрицательного числа, ничего не запускается, а Godot один раз выводит предупреждение.

## math_compare { #math_compare }

Сравнивает хранимое значение с `compare_value` и запускает ту сторону, на которую оно попало. `on_not_equal` срабатывает вместе с `on_less` и `on_greater`, на случай если важна только разница.

* **Входы:** `set_value(value)`, `set_compare_value(value)`, `compare`, `set_and_compare(value)`
* **Выходы:** `on_less`, `on_equal`, `on_not_equal`, `on_greater`
* **Ключи:** `compare_value` 0

`set_value` и `set_compare_value` только сохраняют, `compare` сравнивает то, что хранится, а `set_and_compare` делает и то и другое, так что именно его нужно подключать к выходу `changed(value)`. Числа сравниваются по значению, и `10` больше, чем `9`. Два куска текста сравниваются в словарном порядке, заглавные буквы идут перед строчными. Почти равные десятичные числа, например `0.1 + 0.2` и `0.3`, считаются равными.

## Пример: счёт, открывающий дверь { #example-a-score-that-opens-a-door }

Три кнопки с монетами и рычаг открывают дверь хранилища, когда набралось хотя бы три монеты.

1. Разместите `math_value` с именем `score`, `math_compare` с именем `enough` и `compare_value` 3 и `logic_gate` с именем `door_gate` и `gate` and.
2. Подключите `pressed` каждой кнопки с монетой к `score`, вход `add`. Каждое нажатие добавляет 1.
3. Подключите `changed` у `score` к `enough`, вход `set_and_compare`. Он передаёт дальше новый счёт.
4. Подключите `on_less` у `enough` к `door_gate`, вход `set_a`, параметр `false`. Так же подключите `on_equal` и `on_greater`, но с параметром `true`. Теперь `a` у вентиля говорит, достаточно ли монет.
5. Подключите `pressed` рычага к `door_gate`, вход `toggle_b`.
6. Подключите `on_true` у `door_gate` к двери со входом `open`, а `on_false` со входом `close`.

Дверь открывается, когда падает третья монета при потянутом рычаге, или наоборот. Если потянуть рычаг обратно или сбросить счёт, она закроется. Чтобы показать счёт, подключите `changed` у `score` к `game_text` со входом `set_text` или поставьте между ними `math_calc`, чтобы показывать очки вместо монет.

Карта logic playground строит этот зал и добавляет световую лотерею на `logic_random` и `logic_case` и выключатель лампы на `logic_flipflop`. Откройте `godot/demo/maps/logic_playground.tdm` в демо-проекте или посмотрите, как она сделана, в [`examples/mcp/logic_playground.json`](https://github.com/Paraxdev/TrenchDot/blob/main/examples/mcp/logic_playground.json).

## MCP { #mcp }

Скрипт выше размещает сущности через `gameplay place`, по одному вызову на каждую:

```json
{ "tool": "gameplay", "args": { "op": "place", "classname": "math_value", "origin": [-280, 40, 40],
  "properties": { "targetname": "score" },
  "outputs": [ { "output": "changed", "target": "enough", "input": "set_and_compare" } ] } }
{ "tool": "gameplay", "args": { "op": "place", "classname": "math_compare", "origin": [-280, 40, -40],
  "properties": { "targetname": "enough", "compare_value": "3" },
  "outputs": [ { "output": "on_greater", "target": "door_gate", "input": "set_a", "parameter": "true" } ] } }
```
