# Коллизия { #collision }

У каждой браш-сущности пакета геймплея и у каждой модельной сущности есть коллизия без всяких настроек. Двери, кнопки, лифты, поезда и триггеры получают выпуклую оболочку на каждый браш, а `prop_model`, `prop_physics`, `npc_walker` и пропы разброса получают форму, построенную из их модели. Ключи ниже нужны, только когда вариант по умолчанию не подходит.

## Ключи { #the-keys }

Выделите сущность и найдите эти строки в Инспекторе. Наведите курсор на строку, чтобы прочитать, что делает каждый вариант.

![Инспектор func_door с открытым меню коллизии на значении default, с вариантами none, box, convex hull, convex decomposition и trimesh и строками collision_layer и collision_mask под ним](../../assets/collision/inspector.png)

| Ключ | По умолчанию | Что делает |
| --- | --- | --- |
| `collision` | default | Форма: default, none, box, convex hull, convex decomposition или trimesh |
| `collision_layer` | пусто | Физические слои, на которых находится тело, в виде номеров слоёв, например `1, 3`. `none` не ставит его ни на один слой |
| `collision_mask` | пусто | Физические слои, которые тело замечает, в том же виде. `none` ничего не замечает |

Пустой слой или маска оставляют значение по умолчанию: слой и маску из определения сущности для браш-сущностей, где триггеры берут *Trigger Collision Mask* из настроек карты, и настройки проекта ниже для модельных сущностей.

## Выбор формы { #picking-a-shape }

| Форма | Браш-сущности | Модели |
| --- | --- | --- |
| default | Форма класса, выпуклая оболочка на каждый браш | Настройка проекта, выпуклая оболочка на каждый меш, если не изменить. `prop_physics` использует коробку из `size` |
| none | Без коллизии | Без коллизии |
| box | Одна коробка вокруг всех брашей | Одна коробка вокруг модели, самая дешёвая форма |
| convex hull | Оболочка на каждый браш | Оболочка на каждый меш, годится для коробчатых моделей |
| convex decomposition | То же, что convex hull, браш уже выпуклый | Несколько оболочек, повторяющих вогнутую модель вроде арки, строится дольше |
| trimesh | Каждая грань, только для статичных тел | Каждый треугольник, точно, но дороже всего |

Trimesh работает только на статичных телах. Двери, кнопки, лифты и поезда это анимируемые тела, которые считаются статичными, так что они могут его использовать. Триггеры, `prop_physics` и `npc_walker` вместо этого строят выпуклые оболочки, а триггер с trimesh выдаёт предупреждение при сборке карты.

У `prop_model`, в модели которого уже есть тело коллизии, остаётся это тело, и собственной формы он не строит.

## Значения проекта по умолчанию { #project-defaults }

Модельные сущности с пустыми ключами следуют трём настройкам в *Project Settings* Godot, в разделе *Trenchdot > Collision*. Они появляются, когда включён плагин TrenchDot.

| Настройка | По умолчанию | Что делает |
| --- | --- | --- |
| *Model Shape* | convex | Форма, которую обозначает default у `prop_model` и `npc_walker` |
| *Model Layer* | 1 | Слой, на котором находятся тела моделей |
| *Model Mask* | 1 | Слои, которые замечают тела моделей |

Наборы разброса выбирают форму в собственной строке *Коллизия* набора разброса, см. [Разброс](../../editor/scatter.md).

## Свои браш-сущности { #your-own-brush-entities }

Браш-сущность, которую вы определили сами, получает коллизию как тело, названное в её *Node Class*. Если *Node Class* пуст, берётся тело, которое наследует её скрипт, а без скрипта, или со скриптом, наследующим `Node3D`, она становится `StaticBody3D`. Только скрипт, наследующий какой-то другой узел, например `Marker3D`, оставляет её без коллизии, и сборка об этом предупреждает. См. [Собственные сущности на GDScript](../custom-entities.md).

Вьюпорт редактора не рисует формы коллизии. Godot показывает их через *Debug > Visible Collision Shapes*, пока идёт игра, и в живой сессии, и в полной сборке одинаково. Браш-сущности и `prop_model` сохраняют свои формы в собранной сцене, а `prop_physics` и `npc_walker` строят свои при каждой загрузке сцены, так же, как загружают свою модель. У `prop_model` или `npc_walker`, в сцене модели которых уже есть физическое тело, остаётся это тело, и собственных форм они не строят.
