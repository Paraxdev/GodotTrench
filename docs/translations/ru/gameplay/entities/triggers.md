# Триггеры { #triggers }

> [!NOTE]
> Эти сущности входят в пакет сущностей геймплея, см.
> [Установка и настройка](README.md#installing-and-customizing).

Невидимые браш-объёмы, которые реагируют, когда в них входит тело. Так уровень замечает игрока: дверной проём запускает катсцену, яма ранит, площадка подбрасывает. Рисуйте их инструментом **Объём** (Shift+E).

## Общие входы, выходы и ключи { #shared-inputs-outputs-and-keys }

У каждого триггера ниже есть это в дополнение к его собственным.

* **Входы:** `enable`, `disable`, `toggle`
* **Выходы:** `triggered(activator)`, `entered(activator)`, `exited(activator)`
* **Ключи:** `filter_group` player, `start_disabled` 0

`filter_group` ограничивает триггер телами из этой группы Godot, так что враги и ящики не срабатывают на триггер для игрока. Оставьте пустым, чтобы принимать любое тело.

| Выход | Когда срабатывает |
| --- | --- |
| `entered` | При каждом принятом входе, пока включён |
| `triggered` | При принятом входе, не чаще раза за `cooldown` для каждого тела. Большинство связей использует именно его |
| `exited` | При выходе, даже когда триггер отключён, чтобы отменить что-то, когда тело уходит |

Триггеры замечают тела на физическом слое 1. Если игрок на другом слое, добавьте его в **Trigger Collision Mask** в настройках карты (ресурс `FuncGodotMapSettings` в Godot), иначе триггеры никогда не сработают.

## trigger_once { #trigger_once }

Срабатывает один раз и отключается, для одноразовых событий вроде катсцены или подсказки. `enable` взводит его снова.

* **Ключи:** `once` 1

## trigger_multiple { #trigger_multiple }

Срабатывает при каждом входе, не чаще раза за `cooldown` для каждого тела, для того, что происходит каждый раз, например звонка в магазине.

* **Ключи:** `cooldown` 0.5

## trigger_hurt { #trigger_hurt }

Наносит урон телам, пока они внутри, для лавы, шипов или зоны смерти под картой. Он вызывает у них `damage_method(amount, source)` каждые `interval` секунд, с `damage * interval` в качестве величины.

* **Выходы:** `hurt(activator)`, для каждого раненого тела на каждом тике
* **Ключи:** `damage` 10 (в секунду), `damage_method` take_damage, `interval` 0.5, `filter_group` пусто

С пустым `filter_group` по умолчанию он ранит всё, у чего есть метод, а не только игрока. Если группа задана, `hurt` срабатывает для каждого тела группы, даже без метода.

## trigger_teleport { #trigger_teleport }

Перемещает тела к сущности с именем из `destination`, обычно к [`info_teleport_destination`](actors.md#info_teleport_destination), и поворачивает их по её рысканию. Он останавливает их, если только `keep_velocity` не равен 1, для портала, через который игрок должен падать или пробегать, не теряя скорости.

* **Выходы:** `teleported(activator)`
* **Ключи:** `destination`, `keep_velocity` 0, `cooldown` 0.5

## trigger_push { #trigger_push }

Толкает тела с `push`, скоростью в единицах карты в секунду, которую можно направить ручкой во вьюпорте. При `once` 1 каждый вход даёт один импульс, как у прыжковой площадки. При 0 он толкает постоянно, как аэродинамическая труба или конвейер, а твёрдое тело перестаёт ускоряться на скорости `push`.

* **Выходы:** `pushed(activator)`, один раз за вход
* **Ключи:** `push` 0 384 0, `filter_group` пусто, `once` 1

## trigger_call { #trigger_call }

Вызывает метод при срабатывании, по умолчанию у `!activator`, так что триггер может обратиться прямо в скрипт игрока, например чтобы сохранить контрольную точку. `call_target` и `arguments` работают как в [`logic_call`](scripting.md#logic_call).

* **Входы:** `trigger(activator)`
* **Выходы:** `called(result)`
* **Ключи:** `call_target` `!activator`, `method`, `arguments` `[]`, `once` 0, `cooldown` 0.5

## trigger_spawn_area { #trigger_spawn_area }

Создаёт сцены в случайных местах внутри своего объёма, по умолчанию когда входит игрок, для засады, когда игрок заходит в комнату. Его ключи работают как у [`info_spawner`](actors.md#info_spawner). `start` запускает таймер создания, когда `interval` больше 0, а `toggle` здесь переключает этот таймер, а не сам триггер.

* **Входы:** `spawn`, `start`, `stop`, `toggle`, `kill_all`
* **Выходы:** `spawned(node)`, `all_dead`, `exhausted` (один раз, когда впервые достигнут `total`)
* **Ключи:** `scene`, `count` 3, `max_alive` 10, `total` 0, `interval` 0, `spawn_on_enter` 1, `spawn_group` enemies,
  `snap_to_ground` 1, `cooldown` 0.5

## trigger_area { #trigger_area }

Обычный объём `Area3D` без скрипта, чтобы подключать события входа в комнату и выхода из неё прямо к другим сущностям. У него нет ни одного из общих ключей выше, и он срабатывает для каждого тела, так что фильтруйте в вызываемой сущности, когда это важно.

* **Выходы:** `body_entered(body)`, `body_exited(body)`
* **Ключи:** `targetname`
