# Спавнеры и пути { #spawners-and-paths }

> [!NOTE]
> Эти сущности входят в пакет сущностей геймплея, см.
> [Установка и настройка](README.md#installing-and-customizing).

## info_spawner { #info_spawner }

Создаёт сцену, например врага или подбираемый предмет, в случайных местах в пределах `radius`. Запустите `spawn` из триггера для засады или задайте `interval` и сделайте `start` для равномерного потока. Чтобы разбросать создаваемое по комнате, используйте [`trigger_spawn_area`](triggers.md#trigger_spawn_area).

| Ключ | По умолчанию | Что делает |
| --- | --- | --- |
| `scene` | | Сцена `res://`, которую нужно создавать |
| `count` | 1 | Сколько создавать за раз |
| `max_alive` | 5 | Живых одновременно не больше этого числа, лишнее создание пропускается |
| `total` | 0 | Останавливается насовсем после стольких штук, 0 значит без ограничения |
| `interval` | 0 | Секунд между созданиями, пока работает таймер. 0 создаёт только по `spawn` |
| `radius` | 64 | Как далеко от спавнера они могут появиться. Потяните его ручку во вьюпорте |
| `start_active` | 0 | Запускает таймер с загрузки карты |
| `spawn_on_ready` | 0 | Создаёт один раз при загрузке карты |
| `spawn_group` | enemies | Группа Godot, которую получает каждый созданный узел |
| `snap_to_ground` | 1 | Опускает каждый созданный объект на пол под ним |

* **Входы:** `spawn`, `start`, `stop`, `toggle`, `kill_all`
* **Выходы:** `spawned(node)`, `all_dead`, `exhausted` (один раз, когда впервые достигнут `total`)

`all_dead` срабатывает, когда не осталось ни одного созданного узла, для сценария «зачистите комнату, чтобы открыть дверь». У созданных узлов нет targetname, достаньте их через `spawn_group`, например `@enemies`.

С ключами по умолчанию он ничего не создаёт, пока что-то не запустит у него `spawn`. Чтобы создавать без триггера, задайте `spawn_on_ready` или `interval` вместе с `start_active`. Создание происходит только в запущенной игре, в редакторе Godot спавнер остаётся пустым узлом.

## info_teleport_destination { #info_teleport_destination }

Отмечает, куда `trigger_teleport` отправляет тела. Направьте его так, как игрок должен смотреть по прибытии, его рыскание становится направлением взгляда. Единственный его ключ это `targetname`.

## path_corner { #path_corner }

Одна остановка на маршруте `func_train` или `npc_walker`, где `target` называет следующую. Выставьте цепочку инструментом **Путь** (Shift+P). Она запускает `reached`, когда прибывает поезд или ходок, для звука или события на этой остановке.

* **Выходы:** `reached(train)`
* **Ключи:** `target`, `wait` 0 (сколько секунд ждать здесь), `speed` 0 (новая скорость поезда с этого места, 0 оставляет прежнюю)

`speed` влияет только на поезда, у ходоков своя скорость.

## npc_walker { #npc_walker }

Актёр под управлением скрипта, который идёт по цепочке путевых точек и проигрывает анимации, для катсцен, а не для ИИ, например стражник, проходящий мимо окна. Он движется по прямым, игнорируя гравитацию и стены, так что кладите точки там, где он может пройти.

| Ключ | По умолчанию | Что делает |
| --- | --- | --- |
| `model` | | Сцена, дающая ему меш и `AnimationPlayer` |
| `target` | | Первая путевая точка, к которой идти |
| `speed` | 2.0 | Метров в секунду |
| `loop` | 0 | Возвращается к первой точке после последней |
| `start_active` | 0 | Идёт с загрузки карты |
| `walk_anim`, `idle_anim` | walk, idle | Анимации, проигрываемые при ходьбе и при остановке |
| `face_travel` | 1 | Поворачивается лицом в сторону движения |
| `collision` | default | Форма, построенная из его модели, чтобы другие тела на него натыкались, см. [Коллизия](collision.md) |
| `collision_layer`, `collision_mask` | пусто | Номера слоёв, например `1, 3`, пусто оставляет значение проекта по умолчанию |

* **Входы:** `start`, `stop`, `walk_to(corner)`, `play_anim(name)`, `face(target)`
* **Выходы:** `arrived(corner)`, `reached_goal`, `finished` (оба на последней точке, когда не зациклен)

`face` и `walk_to` принимают любую цель, например `!player`. `walk_to` бросает текущий отрезок и идёт прямо туда.

Он загружает свою `model` только в запущенной игре, так что в редакторе Godot это пустой узел.
