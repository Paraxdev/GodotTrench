# Двери, движущиеся объекты и кнопки { #doors-movers-and-buttons }

> [!NOTE]
> Эти сущности входят в пакет сущностей геймплея, см.
> [Установка и настройка](README.md#installing-and-customizing).

Браш-сущности, которые движутся как одно тело и несут всё, что на них стоит, так что лифт везёт игрока с собой.

> [!NOTE]
> Двери и кнопки сами не реагируют на игрока. Скрипт вашего игрока вызывает у них `use(activator)`, например из луча взаимодействия, см. [Кнопка открывает дверь](../../tutorials/button-door.md). Поставьте `interact` в 0 для той, которую должны двигать только I/O или скрипт.

## func_door { #func_door }

Раздвижная дверь, люк или ставни. При открытии она сдвигается на `travel`, а при закрытии возвращается, потяните за ручку во вьюпорте, чтобы задать это. Запертая дверь игнорирует `open` и `use` и вместо этого запускает `locked_use`, для сообщения «заперто».

| Ключ | По умолчанию | Что делает |
| --- | --- | --- |
| `travel` | 0 64 0 | Смещение, на которое она сдвигается, в единицах карты |
| `speed` | 2.0 | Метров в секунду |
| `wait` | -1 | -1 остаётся открытой, положительное значение закрывает её снова через столько секунд |
| `locked` | 0 | Начинает запертой |
| `start_open` | 0 | Начинает в открытом положении |
| `interact` | 1 | Открывается, когда игрок вызывает у неё `use` |

* **Входы:** `open`, `close`, `toggle`, `lock`, `unlock`, `use(activator)`
* **Выходы:** `opened`, `closed`, `started_opening`, `started_closing`, `locked_use(activator)`

## func_door_rotating { #func_door_rotating }

Дверь или ворота, которые поворачиваются вокруг петли, перетащенной на место во вьюпорте. `open` принимает активатор, чтобы `open_away` мог распахнуть её от него, а не ему в лицо.

| Ключ | По умолчанию | Что делает |
| --- | --- | --- |
| `hinge` | 0 0 0 | Положение петли относительно центра двери |
| `axis` | y | Ось поворота. `y` это вертикальная петля, `x` или `z` дают люк или подъёмный мост |
| `open_angle` | 95 | Градусов поворота, отрицательное значение поворачивает в другую сторону |
| `speed` | 120 | Градусов в секунду |
| `open_away` | 1 | Распахивается от того, кто её открывает |
| `wait`, `locked`, `start_open`, `interact` | -1, 0, 0, 1 | Как у `func_door` |

* **Входы:** `open(activator)`, `close`, `toggle(activator)`, `lock`, `unlock`, `use(activator)`
* **Выходы:** те же, что у `func_door`

`func_gate` это старый псевдоним, у которого из ключей только `hinge`, `open_angle` 100 и `speed` 90. Используйте `func_door_rotating`.

## func_platform { #func_platform }

Лифт или движущаяся платформа между своим началом и `start + travel`, для лифтов или полов, пересекающих провал.

* **Входы:** `start`, `stop`, `toggle`, `go_to_end`, `go_to_start`
* **Выходы:** `reached_end`, `reached_start`, `started`
* **Ключи:** `travel` 0 128 0, `speed` 2.0, `wait` 1.0, `mode` 0, `start_active` 0 (движется с загрузки карты)

| `mode` | Что делает `start` | Типичное применение |
| --- | --- | --- |
| 0, toggle | Едет к другому концу | Лифт, который вызывает кнопка |
| 1, ping pong | Ездит туда и обратно до `stop`, ожидая `wait` секунд на каждом конце | Платформа, которая ходит по кругу |
| 2, once | Едет к концу и остаётся там | Мост, который выдвигается один раз |

## func_train { #func_train }

Следует по цепочке сущностей `path_corner` начиная с `target`, для всего, что ходит по маршруту с несколькими остановками, например трамвая или вагонетки на рельсах. `wait` и `speed` каждой точки применяются по прибытии. Он начинает движение при загрузке карты и ходит по кругу, так что поставьте `start_active` или `loop` в 0 для разовой поездки.

* **Входы:** `start`, `stop`, `toggle`
* **Выходы:** `arrived(corner)`, `finished` (только когда не зациклен)
* **Ключи:** `target`, `speed` 3.0, `loop` 1, `start_active` 1, `orient` 0 (1 поворачивает его лицом в сторону движения)

## func_button { #func_button }

Утапливается на `travel`, пока нажата, и запускает `pressed`. Через `wait` секунд она снова выскакивает, а -1 оставляет её нажатой, для одноразового переключателя. Запертая кнопка вместо этого запускает `locked_use`, это удобно для панели, которой сначала нужно питание.

* **Входы:** `press(activator)`, `release`, `lock`, `unlock`, `use(activator)`
* **Выходы:** `pressed(activator)`, `released`, `locked_use(activator)`
* **Ключи:** `travel` 0 -2 0, `wait` 1.0, `locked` 0, `interact` 1
