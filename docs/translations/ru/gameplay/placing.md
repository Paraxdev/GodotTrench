# Размещение и связывание { #placing-and-wiring }

## Размещение сущностей { #placing-entities }

Откройте вкладку **Сущности**, она находится справа рядом с Инспектором. Для каждого класса, который знает ваш проект, там есть карточка, сгруппированная по категориям. Наведите указатель на карточку, чтобы увидеть, что она делает.

![Панель «Сущности» с наведённой карточкой func_door, подсказка гласит: браш-сущность, раздвижная дверь](../assets/placing/entities-panel.png)

Перетащите карточку в любой вид, чтобы разместить сущность, или дважды щёлкните по ней, чтобы поставить её в 3D-курсор. (Ctrl- или Shift-щелчок выбирает несколько карточек, перетащите их вместе, и они лягут в ряд.) Карточка браш-сущности идёт с коробкой. Если выделены браши, дважды щёлкните по ней, чтобы вместо этого обернуть эти браши в сущность.

Сущность ложится на первую твёрдую поверхность под указателем. Триггерные объёмы, браши только из служебных текстур и другие сущности пропускаются. Пока вы перетаскиваете, голубой маркер показывает, куда она ляжет. 2D-вид не может показать глубину, поэтому там маркер подписан высотой (или глубиной), на которой она окажется. В виде «Сверху» на пути стоит крыша комнаты, поэтому удерживайте Alt при отпускании, и сущность пройдёт сквозь крышу и ляжет на пол внутри. В видах «Спереди» и «Сбоку» Alt пропускает ближнюю стену и ставит сущность на полпути через комнату.

### Браш-сущности { #brush-entities }

Двери, кнопки и триггеры это браш-сущности, они получают форму от брашей, которые вы построили.

1. Постройте форму, например тонкую коробку там, где будет дверь, и выделите её.
2. Щёлкните правой кнопкой в виде и выберите класс в разделе *Создать браш-сущность*. В *Браш > Сущность-браш* тот же список.

![Контекстное меню вида с открытым пунктом «Создать браш-сущность» и наведённым trigger_once](../assets/placing/context-create-brush-entity.png)

Для распространённых случаев есть пути быстрее:

| Инструмент или меню | Что создаёт |
| --- | --- |
| *Геймплей > Двери и подвижные части* | Дверь на петлях или раздвижную дверь с её триггером, либо лифт, из выделенных брашей |
| *Геймплей > Триггеры* | Триггерный объём по размеру выделения |
| Инструмент **Объём** (Shift+E) | Сразу вытягивает любой триггерный объём, предварительный браш не нужен |
| Инструмент **Путь** (Shift+P) | Щелчок за щелчком, цепочка сущностей `path_corner`, по которой едут поезда и идут ходоки, Enter завершает |

![Меню «Геймплей» с открытым пунктом «Двери и подвижные части»: двери на петлях, раздвижные двери и «Лифт, движущаяся платформа»](../assets/placing/gameplay-doors-menu.png)

![Панель инструментов с наведённым инструментом «Объём» и его подсказкой: Инструмент объёма (Shift+E), вытяните триггерный объём, объём появления, урона, телепорта или толчка](../assets/placing/toolbar-volume-tool.png)

### Ручки { #handles }

Выделите дверь, ворота, платформу, кнопку, толкающий триггер, спавнер, взрыв или физический проп, и в видах появятся ручки. Тяните их, чтобы задать петлю, на сколько он открывается или едет, его радиус или размер, вместо ввода чисел. Угол петли привязывается шагами по 15 градусов, удерживайте Shift для отдельных градусов.

![Перетаскивание ручки угла двери на петлях в виде «Сверху», подпись меняется с 95° до 30°](../assets/placing/door-hinge-handle.gif)

## Связывание { #wiring }

Соединение живёт на сущности, которая его запускает. Выделите эту сущность и найдите **Выходы** внизу Инспектора. **+ Добавить выход** добавляет соединение, затем вы заполняете выход, цель и вход. Что делает каждое поле, описано в [Как работает entity I/O](io.md).

![Раздел «Выходы» в Инспекторе кнопки: выход pressed, цель front_door, вход open](../assets/io/inspector-outputs.png)

Чтобы соединить две сущности быстрее, выделите обе и выберите *Геймплей > Логика > Связать две выбранные сущности…*. Инспектор также показывает кнопку **Связать…**, пока выделены ровно две сущности.

![Меню «Геймплей» с открытым пунктом «Логика» и наведённым «Связать две выбранные сущности…»](../assets/placing/menu-link-two-entities.png)

Окно *Связать сущности* показывает источник слева и цель справа. Выберите выход в поле *Когда*, вход в поле *вызвать* и нажмите **Связать**.

![Окно «Связать сущности»: func_button слева, light справа, «Когда» pressed, «вызвать» turn_on, и подсказка кнопки «Поменять»](../assets/placing/link-dialog.png)

> [!WARNING]
> Источник не всегда та сущность, по которой вы щёлкнули первой. Проверьте два имени вверху и нажмите кнопку **Поменять** между ними, если они стоят не в том порядке.

[Логический граф](logic-graph.md) показывает все связи сразу и соединяет сущности перетаскиванием от пина к пину.

## Проверка связей без Godot { #checking-wiring-without-godot }

Выделите сущность в [Логическом графе](logic-graph.md#simulate), нажмите **Симулировать** и выберите выход. Граф подсвечивает каждый шаг `source.output → target.input`, который последует дальше, и перечисляет их с задержками, так что вы можете проследить длинную цепочку, не собирая и не запуская игру. Красным отмечена цель, которой не существует, обычно это опечатка в targetname. Синим отмечена цель времени выполнения вроде `!player` или `@enemies`, которая существует только в игре, дальше она не прослеживается.

## Код для любой сущности { #code-for-any-entity }

Панель **Справка** показывает GDScript и C# для любого класса сущности. Она пригодится, когда коду игры нужно поговорить с сущностью карты, например открыть дверь или слушать кнопку. Откройте её через *Вид > Панели > Справка*, через *Справка > Справочник по сущностям и коду* или через **Справка по коду** в Инспекторе, которая сразу переходит к классу выбранной сущности. Перетащите разделитель между списком классов и подробностями, чтобы изменить размер списка, дважды щёлкните по нему, чтобы подогнать под имена.

![Панель «Справка» с выбранным func_button: его входы и выходы и «Использование в GDScript»](../assets/placing/reference-panel.png)

Выберите класс слева, затем вкладку. *Использование в GDScript* и *Использование в C#* показывают, как вызывать сущность, *Класс GDScript*, *Класс C#* и *FGD (.tres)* это заготовки для написания своей. **Копировать** кладёт код в буфер обмена. На вкладках с заготовками **Создать в проекте** записывает файл в `res://entities/` и не трогает уже существующий файл.
