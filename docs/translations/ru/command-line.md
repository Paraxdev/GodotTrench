# Командная строка { #command-line }

```sh
trenchdot [options] [map]
```

Без параметров редактор просто открывается, а если вы указали карту, то с ней. `trenchdot --help` (или `-h`) выводит
список параметров и завершается.

| Параметр | Что делает |
| --- | --- |
| `--project <dir>` | Загружает проект Godot из `<dir>` или из папки выше и доверяет ему на время сеанса, см. [Доверие к проекту](godot/running-godot.md#project-trust). Без него редактор загружает последний проект |
| `--default-prefs` | Запускается с настройками по умолчанию и никогда их не сохраняет. Удобно для скриптов и тестов и чтобы проверить, не в ваших ли настройках причина проблемы |
| `--offscreen` | Открывает окно за пределами всех экранов, без фокуса и кнопки на панели задач. Оно всё равно рисуется, поэтому скрипты и тесты могут делать скриншоты, пока вы продолжаете работать |
| `--live-link-port=<port>` | Общается с редактором Godot через этот порт, а не через порт *Live Link с Godot* из настроек, только на этот запуск. Скрипты и тесты передают свободный порт, чтобы их сохранения никогда не пересобирали карты в открытом у вас Godot |
| `--hot-reload-port=<port>` | Делает то же для порта *Горячая перезагрузка запущенной игры*, который слушает запущенная игра, чтобы перезагружать сохранённые карты |
| `--dump <map>` | Выводит карту как JSON и завершается |
| `--to-json <map> <out>` | Записывает карту как JSON и завершается |
| `--to-tdm <map> <out>` | Записывает карту как двоичный `.tdm` и завершается |
| `--export-glb <map> <out.glb>` | Записывает геометрию и материалы карты как двоичный glTF для Blender и других 3D-инструментов и завершается |
| `--export-obj <map> <out.obj>` | Записывает то же как OBJ, с `.mtl` и папкой текстур рядом, и завершается |

Неизвестный параметр или параметр без значения выводит ошибку и завершается с кодом 2, окно не открывается. Если
преобразование или экспорт не удался, выводится причина и код завершения 1.

Преобразования и экспорт никогда не открывают окно, поэтому их безопасно запускать в скриптах и git-хуках, см.
[Файлы карт в git](development.md#map-files-in-git).

Экспорт находит проект Godot карты по её папке и использует значения по умолчанию из *Файл > Экспорт*: вся карта, без
скрытых объектов и экземпляров разброса. Логика сущностей, триггеры и скрипты не попадают в экспорт, см.
[Экспорт в Blender и другие 3D-инструменты](editor/exporting.md).

## MCP { #mcp }

Эти параметры настраивают [MCP-сервер](mcp.md), чтобы скрипты и ИИ-агенты могли управлять редактором.

| Параметр | Что делает |
| --- | --- |
| `--mcp` | Отдаёт MCP через stdin и stdout |
| `--mcp-http[=<port>]` | Отдаёт MCP по HTTP на 127.0.0.1, по умолчанию порт 7841 |
| `--mcp-token=<token>` | Заставляет HTTP-клиентов присылать этот токен, что бы ни говорили настройки. Он главнее `TRENCHDOT_MCP_TOKEN`, см. [HTTP-токен](mcp.md#the-http-token) |

`--default-prefs` хорошо сочетается с любым из них, так что сеанс со скриптом каждый раз стартует с одних и тех же
настроек. Если задано `TRENCHDOT_DISABLE_MCP=1`, ни один из параметров не запускает сервер, см.
[Отключение MCP](mcp.md#turning-mcp-off).
