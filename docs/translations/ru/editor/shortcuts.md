# Горячие клавиши { #shortcuts }

Это клавиши по умолчанию, пресет TrenchBroom.

Хотите другие клавиши? *Справка > Горячие клавиши…* перечисляет все сочетания. Наберите что-нибудь в фильтре, чтобы найти нужное, нажмите **Задать**, а затем новое сочетание. **Пресет** вверху этого окна или *Файл > Настройки > Набор сочетаний клавиш* переключает на Hammer или Blender, см. [Другие пресеты](#other-presets).

![Окно «Горячие клавиши» с фильтром csg, выпадающим списком «Пресет», кнопкой «Сбросить изменения» и кнопками «Задать» и «Очистить» в каждой строке](../assets/shortcuts/keyboard-shortcuts-window.png)

Сочетания ждут, пока вы печатаете в поле или открыто меню. Пока указатель над плавающим окном, например Генератором форм, работают только сохранение, отмена и повтор, так что клавиша, предназначенная окну, никогда не удалит и не изменит вашу карту.

## Инструменты { #tools }

Нажмите клавишу инструмента ещё раз, чтобы вернуться к «Выделить». Esc отменяет перетаскивание или мазок, а в остальных случаях возвращает к «Выделить», а в нём снимает выделение.

| Клавиша | Инструмент |
| --- | --- |
| Q | Выделить, рисовать браши и двигать объекты |
| C | Отсечение, чтобы резать браши плоскостью |
| V | Вершина, чтобы тянуть углы брашей |
| R | Поворот |
| T | Масштаб |
| Tab | Править выделенное там, где оно стоит: меши в инструменте «Меш», браши в инструменте «Вершина». Он никогда не преобразует браш, это делает *Меш > Править меш* |
| Shift+T | Текстура, чтобы выравнивать текстуры на гранях |
| P | Рисование, чтобы рисовать цвета вершин на гранях |
| G | Лепка ландшафта и дисплейсментов |
| Shift+G | Смешивание слоёв ландшафта |
| B | Разброс |
| Shift+E | Объём, чтобы растянуть триггерный объём |
| Shift+P | Путь, чтобы расставить цепочку сущностей `path_corner` |
| M | Измерение расстояний |

## Мышь в видах { #mouse-in-the-views }

| Ввод | Результат |
| --- | --- |
| Перетащить мимо выделения | Нарисовать браш |
| Перетащить выделение | Двигать. Ctrl копирует, Shift фиксирует ось, Alt двигает по вертикали в 3D |
| Щелчок, двойной щелчок | Выделить, выделить всю группу |
| Ещё один щелчок скоро на том же месте или Alt+щелчок (2D) | Выделить следующий объект под курсором, например стену под потолком в виде сверху |
| Ctrl+щелчок | Добавить в выделение или убрать из него, в видах и в Структуре |
| Shift+щелчок в Структуре | Выделить строки от последней, по которой щёлкали |
| Shift+щелчок, Ctrl+Shift+щелчок | Выделить одну грань, добавить или убрать грань |
| Shift+перетаскивание выделенной грани (3D) | Вдавить или вытянуть её |
| Ctrl+Shift+перетаскивание выделенной грани (3D) | Выдавить новый браш |
| Перетаскивание правой кнопкой (3D) | Осмотреться. Удерживайте её и используйте WASD, чтобы лететь, Q и E, чтобы опускаться и подниматься |
| Перетаскивание средней кнопкой | Панорамирование |
| Alt+перетаскивание левой кнопкой (3D) | Облёт. В инструменте «Выделить» перетаскивание, начатое на выделении или его гизмо, вместо этого двигает его по вертикали |
| Ctrl+колесо (Лепка, Смешивание, Рисование, Разброс) | Изменить размер кисти |

## Правка { #editing }

| Клавиша | Действие |
| --- | --- |
| Ctrl+Z, Ctrl+Shift+Z или Ctrl+Y | Отменить, повторить |
| Ctrl+X, Ctrl+C, Ctrl+V | Вырезать, копировать, вставить под курсор мыши |
| Ctrl+D, Ctrl+Shift+D | Дублировать, дублировать со связью |
| F2 | Переименовать выбранный объект в Структуре |
| Ctrl+R | Повторить последний поворот, отражение, сдвиг или дублирование. При правке меша делает петлевой разрез |
| Delete или Backspace | Удалить |
| Ctrl+A, Esc, Ctrl+I | Выделить всё, ничего, инвертировать |
| Ctrl+T, Ctrl+Shift+T | Использовать выбранные браши как трафарет и выделить то, чего они касаются, или то, что лежит внутри них. Браши-трафареты удаляются |
| Ctrl+G, Ctrl+Shift+G | Сгруппировать, разгруппировать |
| Ctrl+H, Ctrl+J, Ctrl+Shift+H | Скрыть выделенное, изолировать его, скрыв всё остальное, показать всё |
| Стрелки, Page Up, Page Down | Сдвинуть на один шаг сетки |

## Браши, меши и текстуры { #brushes-meshes-and-textures }

| Клавиша | Действие |
| --- | --- |
| Ctrl+K, Ctrl+M, Ctrl+L | CSG: вычесть (вырезать выделенное из того, чего оно касается), выпуклое слияние, пересечение |
| Ctrl+Shift+K | Сделать полым, превратить сплошной браш в комнату со стенами |
| Ctrl+Shift+B | Генератор форм, для арок, цилиндров, лестниц и других готовых форм |
| Ctrl+Shift+E, Ctrl+Shift+J | Преобразовать браши в меш, объединить меши |
| Ctrl+Shift+W | Переместить браши в мир, вынув их из сущности, так что они становятся обычной геометрией уровня |
| Ctrl+Shift+U | Включить или выключить блокировку UV, которая держит текстуры прикреплёнными к брашу, пока он двигается |
| Alt+H | Подгонка к хотспоту, она подбирает выбранным граням подходящий прямоугольник трим-листа |

## Вид и файлы { #view-and-files }

| Клавиша | Действие |
| --- | --- |
| F или Ctrl+U | Показать в кадре выделенное или всю карту |
| `[` и `]` или `-` и `=` | Уменьшить или увеличить сетку вдвое |
| F4, F3 | Переключить затенение (с текстурами, плоское, освещённое, каркас), включить освещённый просмотр |
| Shift+Space | Развернуть вид под указателем |
| Ctrl+Shift+1 до 9, Ctrl+1 до 9 | Сохранить, вызвать закладки камеры |
| Ctrl+=, Ctrl+-, Ctrl+0 | Масштаб интерфейса больше, меньше, сброс |
| F1 | Открыть [руководство](interface.md#help-and-the-manual) на инструменте, вкладке панели, пункте меню или разделе Инспектора под указателем, в остальных местах палитру команд |
| Ctrl+щелчок по инструменту на панели инструментов, Cmd+щелчок на macOS | Открыть его страницу в руководстве |
| Ctrl+Shift+P | Палитра команд |
| Ctrl+N, Ctrl+O | Новая карта, открыть карту |
| Ctrl+S, Ctrl+Shift+S | Сохранить, сохранить как |
| Ctrl+Shift+N, Ctrl+Tab, Ctrl+W | Новая вкладка, следующая вкладка, закрыть вкладку |
| F5 | Запустить проект Godot |

> [!NOTE]
> Раньше F2 переключала затенение. Теперь она переименовывает, как в Godot, Blender и большинстве файловых менеджеров, а затенение переехало на F4. Сочетание, которое вы задали сами в окне горячих клавиш, остаётся как было.

## Другие пресеты { #other-presets }

Пресет меняет только клавиши ниже, всё остальное остаётся как выше. Ваши собственные сочетания лежат поверх любого пресета, а **Сбросить изменения** в окне горячих клавиш их очищает.

| Клавиша | Пресет Hammer |
| --- | --- |
| Shift+S, Shift+X, Shift+V, Shift+A | Инструменты «Выделить», «Отсечение», «Вершина», «Текстура» |
| H, Ctrl+H, U | Скрыть, изолировать, показать всё |
| Ctrl+W | Переместить браши в мир |
| Ctrl+M | Генератор форм |
| Ctrl+L | Повернуть на 90° вокруг вертикальной оси |
| Ctrl+Shift+M, Ctrl+Shift+L | CSG: выпуклое слияние, пересечение |
| Ctrl+F4 | Закрыть вкладку |

| Клавиша | Пресет Blender |
| --- | --- |
| A, Alt+A | Выделить всё, ничего |
| X | Удалить |
| Shift+D, Alt+D | Дублировать, дублировать со связью |
| S | Инструмент «Масштаб» |
| H, Alt+H, / | Скрыть, показать всё, изолировать |
| Ctrl+J | Объединить меши |
| Z | Переключить затенение |
| Shift+A | Генератор форм |
| F3 | Палитра команд |
| F4 | Освещённый просмотр |
| Alt+Shift+H | Подгонка к хотспоту |
