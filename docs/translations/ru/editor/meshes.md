# Меши { #meshes }

В отличие от брашей, меши могут иметь вмятины, дыры и изогнутые грани, поэтому используйте их для камней, труб, плавных арок и других форм, которые браши сделать не могут.

## Правка меша { #editing-a-mesh }

Выделите браши, которые хотите переформировать, и выберите *Меш > Править меш*. Он превращает их в меш и сразу начинает правку.

![Меню «Меш» с наведённым пунктом «Править меш», далее «Брашы в меш» (Ctrl+Shift+E), «Меши в брашы», «Объединить меши» (Ctrl+Shift+J) и подменю «Топология», «Компоненты», «Нормали и шейдинг» и «Трансформация»](../assets/meshes/menu-edit-mesh.png)

Когда выделен меш, то же делает **Tab**, а повторный Tab возвращает вас к объектам. Tab на брашах открывает вместо этого инструмент «Вершина», поэтому случайное нажатие клавиши никогда не превратит браш в меш. Кнопка инструмента «Меш» на панели инструментов начинает правку, ничего не преобразуя. Ctrl+Shift+E только преобразует, а Ctrl+Shift+J объединяет меши в один.

Пока вы правите, панель параметров инструмента сверху переключается между режимами **Вершина**, **Ребро** и **Грань** и содержит кнопки для частых операций.

![Панель параметров инструмента «Меш» с режимами «Вершина», «Ребро» и «Грань», затем «Подразделить», «Слить», «Заполнить», «Удалить», «Сгладить» и «Плоский»](../assets/meshes/mesh-tool-options.png)

## Клавиши { #keys }

Клавиши повторяют Blender. Например, нажмите 3, щёлкните верхнюю грань коробки и нажмите E, затем двиньте мышь вверх и щёлкните, чтобы выдавить её:

![Меш-коробка в режиме граней, её верхняя грань выдавлена вверх шагами сетки](../assets/meshes/extrude-face.gif)

| Клавиша | Действие |
| --- | --- |
| 1, 2, 3 | Работать с вершинами, рёбрами или гранями |
| A, Alt+A | Выделить всё, снять выделение |
| Alt+щелчок, Ctrl+Alt+щелчок | Выделить петлю рёбер через щёлкнутое ребро или кольцо поперёк него |
| Ctrl+L | Выделить всё, что связано с выделением |
| G, R, S | Переместить, повернуть, масштабировать |
| E | Выдавить новую геометрию из выделения |
| I | Отступ, меньшая грань внутри каждой выделенной грани |
| Ctrl+B, Ctrl+Shift+B | Фаска рёбер или вершин, срезающая угол |
| Ctrl+R | Петлевой разрез, новое кольцо рёбер поперёк меша. Колесо или + и - задают число разрезов |
| K | Нож, щёлкните две точки, чтобы разрезать по этой линии |
| M | Слить выделенные вершины в их центре |
| F | Заполнить, новая грань на выделенных вершинах |
| X или Delete | Удалить |
| Shift+D | Дублировать и переместить |
| P | Отделить выделение в новый меш |
| Alt+F | Перевернуть нормали для граней, которые видны не с той стороны |

Во время перемещения, поворота или масштабирования нажмите X, Y или Z, чтобы зафиксировать эту ось, или Shift с буквой, чтобы исключить её. Введите число для точного значения. Щелчок или Enter подтверждает, правый щелчок или Escape отменяет. Строка подсказки внизу вида перечисляет это по ходу дела.

## Гизмо { #gizmo }

Дважды щёлкните элемент, чтобы поставить на него гизмо перемещения, поворота и масштаба. Это чистый способ сдвинуть вершину вдоль одной оси, и он работает и в 2D-видах. Escape скрывает его и сохраняет выделение.

Остальное лежит в меню *Меш*, например подразделение, триангуляция, придание толщины, зеркало и плавное затенение.
