# Импорт карт Hammer и TrenchBroom { #importing-hammer-and-trenchbroom-maps }

Есть уровень из Hammer или TrenchBroom? Перенесите его, а не стройте заново. *Файл > Импорт* открывает `.vmf` из Hammer или `.map` из TrenchBroom, Quake или Qodot как новую несохранённую карту (в новой вкладке, если в открытой карте есть несохранённые изменения). Сохраните её как `.tdm`, и Godot соберёт её, как любую другую карту.

## Шаги { #steps }

1. Сначала откройте проект Godot

    Откройте проект, для которого предназначена карта, через *Godot > Открыть проект Godot…*, потому что конвертированные текстуры попадают в его папку текстур.

2. Импортируйте карту

    Выберите *Файл > Импорт* и пункт *Файл .vmf (Hammer)…* или *Файл .map (TrenchBroom, Quake)…*, затем сам файл.

    ![Меню «Файл» с открытым «Импорт» и выделенным «Файл .vmf (Hammer)…», ниже «Конвертировать текстуры» и импорт моделей](../assets/importing/file-import-menu.png)

3. Конвертируйте текстуры

    Если рядом с картой лежат её текстуры, редактор спросит «Преобразовать текстуры карты?» про те, которых нет в проекте. Согласитесь, см. [Конвертацию текстур](importing-textures.md).

4. Загляните во вкладку «Проблемы»

    Откройте вкладку «Проблемы» вверху слева, рядом со «Структурой» и «Историей». Каждый материал, которого в проекте всё ещё нет, появляется там как предупреждение, а его грани рисуются шашечкой.

    ![Вкладка «Проблемы» с двумя предупреждениями, Material 'castle/brick_wall' is not in the project (12 faces), и 3D-вид, где эти стены и ступени нарисованы серой шашечкой](../assets/importing/issues-missing-materials.png)

    Грани сохраняют название материала, так что позднее добавленная текстура всё исправит. Когда все текстуры на месте, эти предупреждения исчезают.

    ![Та же карта после конвертации текстур: вкладка «Проблемы» сообщает «Проблем не найдено», а на стенах видна кирпичная текстура](../assets/importing/textures-converted.png)

5. Сохраните её

    Выберите *Файл > Сохранить как…* и сохраните карту как `.tdm` внутри проекта.

> [!NOTE]
> Единицы остаются как есть. Карты Source рассчитаны примерно на 40 единиц в метре, а карты Quake примерно на 32, так что карта Source получится чуть больше, чем в своей игре, если только в проекте не другой масштаб.

## Что сохраняет импорт { #what-the-import-keeps }

| Hammer | В TrenchDot |
| --- | --- |
| Служебные материалы (`tools/toolsnodraw`, `toolsclip`, `toolsplayerclip`, `toolstrigger`, `toolsorigin`, ...) | Текстуры skip, clip и origin проекта и `special/trigger` |
| Грани неба | Текстура неба проекта, по умолчанию `special/sky` |
| Дисплейсменты | Дисплейсменты с их высотами и альфами смешивания |
| `func_instance` | Группа с содержимым инстанса, сдвинутая на место. Имена внутри получают fixup инстанса, его замены `$` и `#` подставляются, а выходы, нацеленные на `instance:name;Input`, подключаются к настоящей сущности |
| Visgroups | Слои |
| Скрытые объекты | Скрытые узлы |
| Ключи и выходы сущностей | Свойства и выходы сущностей |

Слои и группы TrenchBroom остаются слоями и группами, а служебные текстуры Quake точно так же становятся служебными текстурами проекта.

Нужно всего несколько брашей? Скопируйте их в TrenchBroom и нажмите Ctrl+V в TrenchDot, они придут сконвертированными так же, см. [Библиотеку префабов](prefab-library.md#pasting-from-trenchbroom).

Грани неба в Godot имеют коллизию, но ничего не рисуют. Ключ worldspawn `sky_source` хранит текстуру, которая у них была, а конвертация текстур превращает её в процедурное небо, см. [Конвертацию текстур](importing-textures.md#skies).

## Известные ограничения { #known-limitations }

| Ограничение | Что делать |
| --- | --- |
| Текстуры внутри архивов `.vpk` или `.pak` не читаются | Сначала распакуйте их, например с помощью VPKEdit |
| Инстансы ищутся рядом с картой и в папках выше | Сохраните структуру папки `maps` игры. Ненайденные инстансы остаются сущностями `func_instance` |
| У классов сущностей Valve и Quake в новом проекте нет определений, поэтому редактор не знает их ключи | Добавьте их в свой FGD или замените своими классами. Вкладка «Проблемы» их перечисляет |
| Часть возможностей материалов Source не переносится: смешивание `$basetexture2`, детальные текстуры, env maps и прокси | Настройте их в Godot |
| Патчи Quake 3 (изогнутые поверхности) и примитивы браша пропускаются. Строка состояния сообщает, сколько их | Пересоберите их как меши |
| Дисплейсменты, вершины которых сдвигаются вбок, а не только вверх и вниз, становятся мешами без альф смешивания | Правьте их как меши |
