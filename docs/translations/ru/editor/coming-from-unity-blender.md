# Если вы пришли из Unity или Blender { #coming-from-unity-or-blender }

TrenchDot это редактор брашей в духе TrenchBroom и Hammer. Уровень начинается с сплошных блоков, которые вы рисуете на сетке, а не с импортированных мешей. Почти всё, что вы знаете по Unity и Blender, здесь тоже есть, только под другими названиями и на других клавишах. Эта страница сопоставляет их, а [Первые шаги](../getting-started.md) проведут вас через первую комнату.

## Где что находится { #where-things-are }

| В Unity или Blender | В TrenchDot |
| --- | --- |
| Hierarchy, Outliner | **Структура**, где вместо родительских объектов есть [слои и группы](organizing.md) |
| Inspector, панель N | **Инспектор**. Его поля положения и размера принимают набранные значения, Enter их применяет |
| Scene view, viewport | 3D-вид плюс виды сверху, спереди и сбоку. Рисовать и выравнивать проще всего в 2D |
| Фигуры ProBuilder, меню Add | Потяните в любом виде, чтобы нарисовать коробку-[браш](brushes.md), Ctrl+Shift+B для арок, лестниц и цилиндров |
| Модификатор Boolean | *Браш > CSG*: вычитание (Ctrl+K), слияние, пересечение и «Сделать полым». Они сразу меняют браши, стека модификаторов нет |
| Edit mode | Инструмент **Вершина** для брашей, инструмент **Меш** для [мешей](meshes.md), оба на Tab |
| Prefabs | [Префабы](organizing.md#prefabs), которые сохраняются как отдельная карта и обновляются в каждом экземпляре |
| Linked duplicate (Alt+D) | Дублировать со связью, Ctrl+Shift+D, так что копии делят общую геометрию |
| Единицы, 1 м | 32 единицы карты равны одному метру, шаг сетки по умолчанию 16 |

Точные числа вводятся в Инспекторе справа. Выделите что-нибудь, наберите новое положение или размер и нажмите Enter. Положение это нижний угол выделения, а не его центр и не точка опоры.

![Инспектор с выделенным брашем, его положение и размер в виде полей X, Y и Z над разделом «Выделение»](../assets/coming-from-unity-blender/inspector-position-size.png)

## Клавиши, которые отличаются { #keys-that-differ }

Клавиши по умолчанию следуют TrenchBroom, и три из них сбивают с толку пользователей Blender:

* **G** это инструмент лепки ландшафта, а не захват.
* **R** и **T** выбирают инструменты «Поворот» и «Масштаб», которые работают с выделением через маркеры, а не следуют за мышью.
* **Tab** правит выделение там, где оно стоит.

Чтобы что-то переместить, потяните его в любом виде или воспользуйтесь гизмо в 3D-виде, а для точных чисел берите Инспектор.

Хотите оставить клавиши Blender? Переключите *Файл > Настройки > Набор сочетаний клавиш* на Blender.

![Выпадающий список «Набор сочетаний клавиш» в окне настроек, открытый, с TrenchBroom, Hammer и Blender](../assets/coming-from-unity-blender/keymap-preset.png)

Он добавляет A для выделения всего, X для удаления, Shift+D для дублирования, H и Alt+H для скрытия и показа, S для инструмента «Масштаб» и Shift+A для генератора форм. G остаётся лепкой, а ввод числа во время перемещения работает только внутри инструмента «Меш». Полный список лежит в разделе [Другие наборы](shortcuts.md#other-presets).

Видов на цифровой клавиатуре нет. Виды сверху, спереди и сбоку всегда открыты, Shift+Space разворачивает тот, что под указателем, а *Вид > Виды* переключает между одним, двумя и четырьмя.

## Привычки, которые сохраняются { #habits-that-carry-over }

В инструменте «Меш» клавиши следуют Blender: 1, 2 и 3 для вершин, рёбер и граней, G, R и S с X, Y или Z, чтобы зафиксировать ось, E для выдавливания, Ctrl+R для петлевого разреза и Ctrl+B для фаски.

Правая кнопка мыши с WASD управляет полётом 3D-камеры, как в Scene view Unity, а F наводит кадр на выделение. Ctrl+Z и Ctrl+Shift+Z отменяют и возвращают действие, а F2 переименовывает.
