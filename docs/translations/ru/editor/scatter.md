# Разброс { #scatter }

Инструмент **Разброс** (B) рисует деревья, камни и траву на выбранных вами поверхностях, так что склон холма можно покрыть за секунды, а не расставлять каждую модель вручную. [Руководство по морскому острову](../tutorials/sea-island-scatter.md) проводит через полную настройку.

![Рисование полосы леса через остров инструментом «Разброс»](../assets/scatter/scatter-paint.gif)

## Наборы разброса { #scatter-sets }

Всё, что вы разбрасываете, принадлежит какому-то набору. Каждый такой **набор разброса** лежит на собственном слое, например один набор для деревьев и один для травы. Нажмите B, и справа откроется панель разброса с карточкой для каждой модели активного набора.

![Панель разброса с активным набором bushes: меню наборов, +, «Пресет», «Переименовать» и карточка на каждую модель](../assets/scatter/scatter-panel.png)

| Что сделать | Как |
| --- | --- |
| Начать пустой набор | **+** рядом с меню наборов |
| Начать с пресета | **Пресет**, затем один из десяти встроенных наборов |
| Добавить модели | Перетащите их с панели «Модели» или нажмите **Добавить модели…**. **Добавить выбранные пропы** берёт модели выделенных сущностей |
| Перестать рисовать одну модель | Снимите галочку **краска** на её карточке. То, что она уже поставила, остаётся |
| Настроить модель | Нажмите стрелку справа на её карточке |

![Открытое меню «Пресет»: лес, сосны, смешанный лес, детальный лес, низкополигональные деревья, кусты, подлесок, камни, валуны и трава, наведены камни](../assets/scatter/preset-menu.png)

Пресеты «камни», «валуны», «трава», «подлесок» и «низкополигональные деревья» используют модели Blockbench, встроенные в редактор. Выбор одного добавляет нужные модели в `res://trenchdot/nature`, без интернета. Пресеты «лес», «сосны», «смешанный лес», «детальный лес» и «кусты» используют деревья и кусты glTF из пакета природы, это загрузка примерно в 23 МБ. В проекте без него выбор такого пресета открывает *Godot > Добавить контент в проект…* на моделях природы, а не создаёт набор с отсутствующими моделями. Тот же диалог открывают *Ландшафт > Разброс > Установить модели природы…* и кнопка **Установить модели природы…** внизу панели. Файлы, уже лежащие в проекте, никогда не перезаписываются.

### Карточки моделей { #model-cards }

Откройте карточку стрелкой, чтобы настроить эту одну модель.

![Открытая карточка bush_round с «Масштаб», «Интервал», «Выравнивание», «Наклон», «Погружение», «Случайный поворот» и «Материал»](../assets/scatter/model-card.png)

| Настройка карточки | Что делает |
| --- | --- |
| вес | Как часто выбирается эта модель по сравнению с остальными в наборе |
| Масштаб | Случайный размер между двумя значениями |
| Интервал | Наименьшее расстояние в единицах карты до любого другого экземпляра |
| Выравнивание | 0 ставит модель прямо, 1 наклоняет её вслед за поверхностью |
| Наклон | Наибольший случайный наклон в градусах |
| Погружение | Насколько модель вдавлена в землю, чтобы скрыть низ ствола или камня |
| Случайный поворот | Поворачивает каждый экземпляр в случайную сторону |
| Материал | Рисуется вместо собственных материалов модели. Если пусто, действует материал набора, когда он есть |

## Цели { #targets }

Набор ложится только на свои **цели**, так что лес, нарисованный на ландшафте, никогда не покроет стоящий на нём дом. Alt+щелчок в виде или щелчок по пипетке справа от *Цели* и затем щелчок в виде добавляет или убирает цель. Набор без целей берёт то, на что попал его первый мазок. Целью может быть и другой набор, так на валунах растёт трава.

![Раздел «Цели» панели разброса с ландшафтом в роли цели, пипетка вверху справа](../assets/scatter/targets.png)

Если отметить **За курсором**, цели игнорируются, и рисование идёт по любой поверхности или разбросанному пропу под кистью.

## Рисование { #painting }

Быстрые настройки лежат на панели параметров инструмента вверху слева: набор, **Рисование** или **Стереть**, радиус, плотность, макс. уклон, **За курсором**, пипетка и **Заполнить**. **Панель разброса** возвращает панель, если вы её закрыли.

![Панель параметров инструмента «Разброс» с набором bushes, «Рисование», радиус 512 u, плотность 1,00 и макс. уклон 40°](../assets/scatter/scatter-toolbar.png)

| Ввод | Действие |
| --- | --- |
| Перетаскивание левой кнопкой | Рисование |
| Shift+перетаскивание левой кнопкой | Стирание, только из активного набора |
| Ctrl+колесо | Размер кисти |
| **Заполнить цели** | Покрыть сразу все цели в пределах ограничений по уклону и высоте |

Остальное лежит в разделе *Браш* панели.

![Раздел «Браш» панели разброса: Радиус, Плотность, Уклон, Высота, Спад, «Только открытое», «Сила стирания», «Зерно», «Вывод» и флажки под ними](../assets/scatter/brush-settings.png)

**Плотность** это сколько размещений кисть пробует на каждые 64 на 64 единицы, а интервал каждой модели ограничивает, сколько их реально поместится. **Только открытое** пропускает точки, над которыми есть геометрия, это не пускает траву под балконы и крыши. **Держать интервал до других наборов**, по умолчанию включено, не даёт кусту прорасти сквозь ствол из другого набора.

## В Godot { #in-godot }

**Тип** набора решает, что строит Godot.

| Тип | Строится как |
| --- | --- |
| props | MultiMesh с коллизией и тенями. Модели, чьи сцены несут скрипты, создаются по одной, чтобы скрипты работали |
| foliage | MultiMesh без коллизии и теней, по умолчанию скрыты дальше 2400 единиц. Для травы и мелких растений |

Выделите набор в Структуре, и строка **Коллизия** в Инспекторе выбирает форму, с которой сталкивается каждый экземпляр. Новые наборы props начинаются с выпуклой формы, а наборы foliage без неё.

| Коллизия | Форма на экземпляр |
| --- | --- |
| нет | Без коллизии |
| бокс | Один бокс вокруг экземпляра |
| выпуклая | Одна выпуклая оболочка вокруг экземпляра |
| декомпозиция | Несколько выпуклых оболочек, повторяющих вогнутые модели, например арку, строится медленнее |
| trimesh | Каждая грань модели, точно, но дороже всего |

Когда нужно править отдельные пропы, **В сущности** внизу панели разброса, или *Ландшафт > Разброс > Наборы разброса в сущности* для выбранных наборов, заменяет набор одной сущностью `prop_model` на каждый экземпляр.

![Низ панели разброса: «Тип», «Рисование», «Стереть», «Заполнить цели», «Очистить экземпляры», «В сущности» и «Установить модели природы…»](../assets/scatter/panel-buttons.png)
