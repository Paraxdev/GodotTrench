# Библиотека префабов { #prefab-library }

Вкладка **Префабы** внизу, рядом с «Материалы» и «Модели», хранит готовые куски для вставки в карту: лестницы, дверные проёмы, колонны, небольшие комнаты и детали. Представьте коллекции префабов, из которых копируют картостроители TrenchBroom, только встроенные в редактор.

![Вкладка «Префабы» с «Поиск префабов», списком категорий, ползунком размера карточек и карточкой на каждый встроенный кусок, наведена лестница Switchback с подсказкой: Stairs/Switchback stair, 192 × 128 × 352 единицы, встроенный](../assets/prefab-library/prefabs-panel.png)

Каждая карточка рисует свой кусок с той стороны, которая показывает больше всего: сверху для планов этажа вроде лестницы, спереди для стен вроде дверного проёма. Чем светлее, тем ближе.

## Вставка куска { #pasting-a-piece }

1. Укажите место

    Наведите курсор на место в виде, куда должен лечь кусок, так задаётся 3D-курсор.

2. Щёлкните карточку

    Наберите что-нибудь в *Поиск префабов* или выберите категорию, чтобы найти нужную, затем щёлкните её. Кусок вставляется по центру этого места и привязывается к сетке, как при Ctrl+V.

    ![Лестница Switchback, вставленная в небольшую комнату, её ступени из серых dev-материалов](../assets/prefab-library/pasted-switchback-stair.png)

За курсором следует только место на плане этажа. Высота остаётся такой, какой кусок был сохранён, поэтому на верхнем этаже потом поднимите его.

Вставка это обычная копия без связи с библиотекой, так что меняйте форму и текстуры свободно. Встроенные куски используют материалы `dev/`, которые есть в каждом проекте, перетекстурируйте их на вкладке «Материалы».

Щёлкните карточку правой кнопкой, чтобы увидеть *Вставить* и *Копировать*. «Копировать» кладёт кусок в буфер обмена, чтобы вставить в другую карту или поделиться текстом.

Чтобы покрыть целую область случайно выбранными кусками, воспользуйтесь [случайным заполнением](random-fill.md).

> [!TIP]
> После вставки кусок это обычное содержимое карты. Для того, что должно оставаться синхронным везде, где используется, например оконная рама, повторённая по зданию, сделайте вместо этого [экземпляр префаба](organizing.md#prefabs).

## Свои куски { #your-own-pieces }

1. Выделите объекты

    Выделите то, что должно стать куском, при открытом проекте Godot.

2. Добавьте выделенное

    Откройте **Добавить выделенное** вверху вкладки «Префабы», задайте куску имя и категорию и нажмите **Добавить**.

    ![Раскрытое «Добавить выделенное» с именем Grand stair, категорией Stairs, снятой галочкой «Сохранить позицию» и подсказкой «Добавить»: сохраняет выделенное как .tdm в res://prefab_library, центр низа в начале координат](../assets/prefab-library/add-the-selection.png)

3. Найдите новую карточку

    Она появляется первой, в синей рамке. Щёлкните её правой кнопкой, чтобы увидеть *Открыть для правки*, что открывает кусок как карту, и *Показать в файловом менеджере*. Встроенные куски править нельзя.

    ![Контекстное меню карточки Grand stair: «Вставить», «Копировать», наведено «Открыть для правки» и «Показать в файловом менеджере»](../assets/prefab-library/card-menu.png)

Кусок сохраняется как `.tdm` в `res://prefab_library/<category>/`, со сдвигом так, чтобы центр низа выделенного оказался в начале координат. Отметьте **Сохранить позицию**, чтобы вместо этого оставить его где есть, для куска, который вы намеренно построили вокруг начала координат карты, как куски набора для [случайного заполнения](random-fill.md).

Каждый `.tdm` в этой папке это кусок. Сохраняйте туда карты сами через *Файл > Сохранить как…*, и они сразу появятся карточками. Для файлов, скопированных вручную, или папки с кусками, общей для проектов, нажмите кнопку ⟳.

## Вставка из TrenchBroom { #pasting-from-trenchbroom }

TrenchDot вставляет и то, что TrenchBroom кладёт в буфер обмена. Скопируйте браши в TrenchBroom или из коллекции префабов TrenchBroom в интернете и нажмите Ctrl+V в карте. Группы приходят как группы, сущности как сущности, а оси поворачиваются так же, как при [импорте .map](importing.md). Имена текстур сохраняются, служебные текстуры других игр заменяются текстурами проекта.

## MCP { #mcp }

Инструмент `prefab_library` перечисляет куски (`op: list`), вставляет один по его `category/name` (`op: paste`, с `origin` или `offset`), возвращает его текст для буфера обмена (`op: copy`) и добавляет объекты в библиотеку проекта (`op: add`, выделенное, если не заданы `ids`). `run_action` с `paste` принимает и текст буфера обмена TrenchBroom, и TrenchDot.
