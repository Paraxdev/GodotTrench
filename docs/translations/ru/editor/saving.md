# Сохранение и восстановление { #saving-and-recovery }

Нажмите Ctrl+S, чтобы сохранить, или Ctrl+Shift+S для *Сохранить как…*. Диалоги файлов открываются в папке текущей карты, а для карты, которую вы ещё не сохраняли, в проекте Godot, потому что аддон загружает карты по пути `res://`. *Файл > Карты проекта* показывает все карты проекта, если нужно просто быстро открыть одну из них.

## Резервные копии и автосохранение { #backups-and-autosave }

Редактор хранит рядом с картой копии двух видов:

| Файл | Когда записывается |
| --- | --- |
| `<map>.tdm.bak` | При каждом сохранении, копия предыдущей версии. Переименуйте её в `.tdm`, чтобы вернуться на одно сохранение назад |
| `<map>.tdm.autosave` | Каждые три минуты, для каждой вкладки с несохранёнными изменениями |

Чтобы менять частоту автосохранения, откройте *Файл > Настройки* и задайте *Автосохранение (минуты, 0 = выкл.)*.

![Поле «Автосохранение (минуты, 0 = выкл.)» в настройках, значение 3](../assets/saving/prefs-autosave.png)

Автосохранения получают расширение, которое Godot не импортирует, поэтому недоделанная карта никогда не попадёт в вашу игру. Когда вы сохраняете карту, её автосохранение удаляется.

## Восстановление карты { #recovering-a-map }

Если редактор закрылся до сохранения, откройте автосохранение:

1. Выберите *Файл > Открыть карту…*.
2. Выберите тип файла **Автосохранение (восстановить карту)** и откройте файл `.tdm.autosave`. В строке состояния должно появиться сообщение, что карта восстановлена из автосохранения.
3. Сохраните. Так снова запишется настоящий `.tdm`.

Карты, которые вы ни разу не сохраняли, автосохраняются во временный файл. Их можно найти в *Файл > Открыть недавние*, под пунктом *Автосохранённые безымянные карты*.

![Файл > Открыть недавние: вверху «Нет недавних карт», ниже список автосохранённых безымянных карт](../assets/saving/open-recent-autosaves.png)

## Повреждённые файлы { #damaged-files }

Карта с повреждённым на диске файлом всё равно откроется. Редактор прочитает все уцелевшие части, объекты, у которых потерялся слой, группа или сущность, положит в слой с названием *Recovered*, а в строке состояния сообщит, что прочитать не удалось. При сохранении повреждённый оригинал остаётся как `<map>.tdm.bak`, так что его всё ещё можно вернуть из системы контроля версий.
