# Текстурирование { #texturing }

## Применение материалов { #applying-materials }

Ваши текстуры лежат на панели **Материалы** внизу окна под видами. Поле поиска слева вверху фильтрует их по имени, **Используются на карте** и **Избранное** сужают список, а ползунок задаёт размер миниатюр.

![Панель «Материалы» с полем поиска, списком папок, «Используются на карте», «Избранное» и ползунком размера, ниже миниатюры материалов, на dev/blue наведён курсор и видны его имя и размер](../assets/texturing/materials-panel.png)

| Сделайте так | Результат |
| --- | --- |
| Щёлкните миниатюру | Применить её к выделению и использовать для новых брашей |
| Перетащите миниатюру на грань | Применить её к этой грани |
| Shift при отпускании | Применить её ко всему брашу или мешу |
| Alt при отпускании | Разместить её как [декаль](decals.md) |

Пока вы тянете, рядом с курсором висит небольшая подсказка с модификаторами, а грань меняется, как только вы отпускаете кнопку.

![Перетаскивание withered/mossy_plaster на лицевую сторону кирпичной стены, затем та же стена с штукатуркой только на лицевой грани](../assets/texturing/drop-on-face.png)

Чтобы наложить текстуру на одну грань без перетаскивания, сначала щёлкните её в виде с Shift, затем щёлкните миниатюру. Ctrl+Shift+щелчок добавляет или убирает ещё грани.

Щёлкните миниатюру правой кнопкой, чтобы увидеть больше: добавить её в избранное, выделить грани, которые её используют, заменить ею текущий материал на всей карте, открыть редактор хотспотов или *Показать в файловом менеджере*, чтобы открыть папку её текстуры с выделенным файлом, например чтобы его отредактировать.

![Контекстное меню миниатюры: «Применить к выделению», «Добавить в избранное», «Выделить грани с ним», замена showcase/red_bricks ею на карте, «Редактор хотспотов», «Копировать имя» и «Показать в файловом менеджере»](../assets/texturing/material-context-menu.png)

Если бросить материал на ландшафт, он вместо этого задаёт слой ландшафта, см. [Слои ландшафта](terrain-layers.md).

Блокировка UV (Ctrl+Shift+U) по умолчанию включена, поэтому текстуры остаются привязанными к брашу, пока вы его двигаете.

## Встроенные цвета { #built-in-colors }

Панель «Материалы» всегда предлагает `dev/grey`, `dev/dark`, `dev/orange`, `dev/blue` и `dev/green`, сеточные текстуры для блокаута уровня, пока в нём нет графики. Цветовая разметка комнат с ними переживает сборку, потому что аддон поставляет те же сетки, а Godot использует их, когда в проекте нет текстуры с таким именем. Ваша собственная текстура, например `res://textures/dev/grey.png`, заменяет такую сетку.

## Служебные текстуры { #tool-textures }

Редактор рисует служебные текстуры прозрачными, с полосами, а сборка Godot не создаёт для них видимого меша. Считается каждая текстура из папки `special/`, `tools/` или `td/`, а также любая текстура, названная как один из инструментов ниже, например `common/caulk`.

![Блок dev/dark, перед ним прозрачная фиолетовая стена special/clip и оранжевая полосатая коробка special/trigger](../assets/texturing/tool-textures.png)

| Текстура | В Godot |
| --- | --- |
| `special/clip`, `playerclip`, `nodraw`, `caulk`, `trigger`, `sky` и любой другой инструмент | Сталкивается, но ничего не рисует. Триггер сохраняет форму триггера |
| `special/skip`, `origin`, `hint`, `hintskip`, `null`, `areaportal` | Не строит вообще ничего. Браш только из таких граней не сталкивается |
| `special/occluder` | Ничего не рисует и не скрывает соседей, но добавляется к окклюдеру сущности, которая его строит, например `func_geo` |

Настройки карты называют текстуры clip, skip, origin и sky, по умолчанию это `special/clip` и так далее. Браш origin задаёт начало координат своей сущности только с той текстурой, которую назвали настройки карты.

## Инструмент «Текстура» { #the-texture-tool }

Выравнивание грани это то, где на ней лежит её текстура: смещение, масштаб и поворот. Нажмите **Shift+T** для инструмента «Текстура», который правит выравнивание на месте, как режим правки граней в Hammer. Щёлкните грань, чтобы выбрать её. Она окрашивается в красный и показывает синюю рамку вокруг одного повтора текстуры, а также две короткие линии для направлений U и V. Грань под курсором получает жёлтую обводку.

![Инструмент «Текстура» с выбранной лицевой гранью кирпичной стены, синяя рамка отмечает один повтор текстуры](../assets/texturing/texture-tool-face.png)

| Ввод | Результат |
| --- | --- |
| Щелчок, Ctrl+щелчок | Щелчок выбирает грань, Ctrl+щелчок добавляет или убирает одну |
| Потянуть выбранную грань | Сдвинуть текстуру, пиксель под курсором остаётся под ним |
| Стрелки | Сдвиг на размер сетки в пикселях, с Shift на один пиксель |
| Ctrl+колесо | Масштаб вдвое, с Shift мелкими шагами |
| Alt+колесо | Поворот на 15°, с Shift на 1° |
| Alt+щелчок | Взять материал и выравнивание грани |
| Правый щелчок | Применить текущий материал |
| Ctrl+правый щелчок | Применить его и сбросить выравнивание |
| Shift+правый щелчок | Вставить взятый материал и выравнивание |
| Alt+правый щелчок | Применить текущий материал, продолжив выравнивание выбранной грани через ребро |

Alt+правый щелчок это способ провести текстуру, например трим или ряд кирпичей, чисто вокруг угла.

На панели параметров инструмента сверху есть кнопки **Выровнять**. **Слева**, **Справа**, **Сверху**, **Снизу** и **Центр** прижимают текстуру к этой стороне грани, **Вписать** растягивает её по всей грани, **Вписать по ширине** и **Вписать по высоте** только вширь или только вверх. Когда включено **Считать единым**, они работают со всеми выбранными гранями как с одной областью, так что одна текстура охватывает их все. **Выровнять по виду** проецирует текстуру вдоль 3D-камеры.

![Панель параметров инструмента «Текстура»: «Выровнять» слева, справа, сверху, снизу, по центру, «Вписать», «Вписать по ширине», «Вписать по высоте», «Считать единым», «Выровнять по виду» и «Подгонка к хотспоту»](../assets/texturing/texture-tool-options.png)

Если вы предпочитаете числа, **Инспектор** показывает ту же грань в разделе **Выравнивание**, с полями смещения, масштаба и поворота и кнопками отражения, поворота и сброса. **Инструменты текстур** под ним задают плотность текселей и копируют выравнивание с грани на грань.

![Инспектор с одной выбранной гранью, раздел «Выравнивание» со смещением, масштабом и поворотом, кнопки «Выровнять» и раздел «Инструменты текстур»](../assets/texturing/inspector-alignment.png)

Для граней с явными UV и для мешей используйте [UV-редактор](uv-editor.md).

## Масштаб текстуры { #texture-scale }

По умолчанию один пиксель текстуры покрывает одну единицу карты, так что текстура в 64 пикселя повторяется каждые два метра. Это подходит для текстур низкого разрешения, но фотография в 1024 пикселя растянулась бы на 32 метра. Задайте `metadata/texture_size` у материала равным мировому размеру, который должен покрывать один повтор, см. [Размер текстуры](../godot/materials.md#texture-size). Строка Инспектора под именем материала сообщает, что получила грань, например «1024 x 1024 px, 64 x 64 units a repeat».

Чтобы задать его только для одной карты или чтобы текстура шла бесшовно по всем граням, используйте [Настройки текстуры](light-baking.md#texture-settings) в Инспекторе. Его размер повтора главнее, чем у материала.

## Хотспоты { #hotspots }

Хотспоты позволяют одному трим-листу текстурировать множество граней разной формы. Вы один раз отмечаете его прямоугольники, а TrenchDot сам подбирает подходящий для каждой грани.

1. Щёлкните трим-лист правой кнопкой на панели «Материалы» и выберите **Редактор хотспотов**. *Текстура > Редактор хотспотов…*
    тоже открывает его, для материала выбранной грани или, если её нет, для текущего.

    ![Меню «Текстура» с наведённым пунктом «Редактор хотспотов…», «Подгонка к хотспоту» (Alt+H) внизу](../assets/texturing/menu-texture.png)

2. Потяните по текстуре, чтобы нарисовать прямоугольник, или задайте сетку и нажмите **Разбить на сетку**. Потяните прямоугольник, чтобы переместить его, маркер угла, чтобы изменить размер, а правый щелчок удаляет его.
3. Нажмите **Сохранить**. Прямоугольники попадут в `<texture>.hotspots.json` рядом с файлом текстуры.
4. Выделите грани и воспользуйтесь *Текстура > Подгонка к хотспоту* (Alt+H) или **Применить к выделению** в редакторе.

![Редактор хотспотов на withered/concrete_panels, разбитом на сетку 4 на 4, 16 прямоугольников, не сохранено](../assets/texturing/hotspot-editor.png)

Подгонка к хотспоту даёт каждой грани прямоугольник, форма которого подходит ей лучше всего, отдавая предпочтение тому, при котором текстура остаётся близкой к обычному масштабу.

## Рисование по вершинам { #vertex-paint }

Инструмент **Рисование** (P) красит вершинные цвета на гранях брашей, для грязи, оттенка и ненастоящего освещения. Выберите цвет на панели параметров инструмента, рядом с радиусом и силой кисти, затем проведите по граням. Он красит выделенные браши или все браши, если ничего не выделено. Ctrl+колесо меняет размер кисти.

![Панель параметров инструмента «Рисование» с образцом «Цвет», радиус 48 u и сила 4.0](../assets/texturing/paint-tool-options.png)
