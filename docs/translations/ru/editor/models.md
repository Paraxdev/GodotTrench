# Модели { #models }

Модели это 3D-файлы, сделанные в другой программе, например в Blender или Blockbench. TrenchDot читает файлы glTF, OBJ, Blockbench, STL, MD2 и MD3.

Найти их можно на вкладке **Модели** внизу, рядом с «Материалами» и «Префабами». Она перечисляет всё из `res://models`, а также природные модели из `res://trenchdot/nature`, когда вы их установите.

![Вкладка «Модели»: поле поиска, фильтры папок и источников, «Сортировка», «Слаги», ползунок размера миниатюр, «Вписать», множитель размера, кнопка повторного сканирования и «Импорт…» над сеткой миниатюр природных моделей](../assets/models/models-panel.png)

Новый проект начинается без моделей. *Godot > Добавить контент в проект…* добавляет природные модели, а выбор демо приносит ещё и пропы Poly Haven в `res://models/polyhaven`. Или скопируйте свои файлы в `res://models` и нажмите кнопку ⟳, чтобы пересканировать.

## Размещение модели { #placing-a-model }

Модель попадает на карту одним из двух способов. Выбирайте по тому, хотите ли вы менять её форму в редакторе.

| Как размещена | Что хранится в карте | Для чего |
| --- | --- | --- |
| Редактируемый меш | Копия геометрии, которая больше не следует за файлом | Формы, которые вы хотите править [инструментами меша](meshes.md) |
| Сущность `prop_model` | Только путь `res://`, файл загружает Godot | Пропы, которые вы оставляете как есть. Каждая копия следует за файлом, когда вы его меняете |

### Как редактируемый меш { #as-an-editable-mesh }

1. (По желанию) Задайте размер

    **Вписать** на панели инструментов «Модели» по умолчанию включено. Оно масштабирует модель, самая длинная сторона которой меньше четверти метра или больше 256 метров, до 2 метров, так что крошечные или огромные файлы всё равно приходят пригодными. Поле × рядом умножает размер сверх этого. Оба действуют при размещении, поэтому задайте их до перетаскивания.

2. Перетащите её в вид

    Потяните миниатюру с вкладки «Модели» в любой вид. Она ляжет на поверхность под указателем.

    ![Винная бочка, перетащенная с вкладки «Модели» в 3D-вид, где она ложится на пол как редактируемый меш](../assets/models/drag-model-into-view.gif)

Для файла в любом месте на диске нажмите **Импорт…** в конце панели инструментов «Модели».

### Как проп { #as-a-prop }

1. Выберите файл

    Откройте *Файл > Импорт > Модель-проп (.bbmodel, .glb)…* и выберите модель.

    ![Меню «Файл» с открытым подменю «Импорт» и наведённым пунктом «Модель-проп (.bbmodel, .glb)…»](../assets/models/file-import-model-prop.png)

2. Проверьте Инспектор

    Она появляется у 3D-курсора как сущность `prop_model`, а её ключ `model` хранит путь `res://`.

    ![Инспектор сущности prop_model с ключом model, указывающим на путь res://models/polyhaven](../assets/models/inspector-prop-model.png)

Проп должен указывать на файл, который Godot умеет загрузить. Выберите файл вне проекта, и редактор предложит сначала скопировать его в `res://models`.

У моделей Blockbench есть ещё два пути внутрь, *Файл > Импорт > Модель Blockbench как меш…* и *Модель Blockbench как брашы…*. Как браши каждый куб становится брашем, сгруппированным под именем файла.

## Текстуры размещённого меша { #textures-of-a-placed-mesh }

Редактируемый меш сохраняет внешний вид модели. Его текстуры копируются в `models/<name>` в папке текстур проекта, где `<name>` это путь модели на вкладке «Модели» или имя её файла для модели из другого места. Выделите меш, и Инспектор перечислит материалы, которыми он рисуется:

![Инспектор размещённого меша: 5966 вершин и материал models/polyhaven/containers/wine_barrel_01/tex0](../assets/models/inspector-mesh-materials.png)

Там, где обычное изображение рисовалось бы не так, как модель, в папку материалов проекта кладётся ещё и материал Godot. Так вырезанная листва, пиксель-арт и светящиеся части (включая цвет и карту свечения модели glTF) рисуются в Godot так же, как здесь. Чтобы заменить материалы, щёлкните один из них на вкладке «Материалы», пока меш выделен, а *Правка > Отменить* вернёт их обратно.

Размещение никогда не перезаписывает файл. Разместите ту же модель снова, и она переиспользует свои текстуры и сохранит материал, который вы настроили в Godot. Если в этой папке уже лежат текстуры другой модели, например у `rock.bbmodel` рядом с `rock.glb`, новые попадут в пронумерованную папку вроде `models/rock_2`. Отмена оставляет файлы на месте. Если текстуры записать нельзя, скажем в проекте только для чтения, меш приходит без текстур, а строка состояния объясняет почему.

Текстуры считаются одинаковыми по их пикселям, поэтому текстура, которую другая программа лишь пересохранила, всё равно переиспользуется. Дорисовали поверх одной? Меши, размещённые раньше, сохраняют вашу версию, а следующее размещение получает свежие копии в пронумерованной папке с новым материалом. Чтобы ваши изменения получили и более поздние размещения, примените к ним свой материал на вкладке «Материалы».

> [!NOTE]
> FuncGodot строит материал грани из `default_material` проекта, только когда нет файла материала с таким же именем. Грани размещённой модели, получившие файл материала, рисуются по этому файлу, поэтому собственный шейдер, заданный как `default_material`, до них не доходит. Чтобы изменить их, правьте файл в Godot. Проект, у которого расширение материала не `tres`, не получает файлов материалов, и к нему применяется материал по умолчанию.

## Авторы пакетов { #pack-credits }

Бесплатные пакеты моделей обычно просят указать авторство. Положите `pack.json` в папку модели или в любую папку выше (побеждает ближайший), и панель будет знать, из какого пакета модель, кто её сделал и под какой лицензией. Наведите курсор на миниатюру, чтобы увидеть это:

![Подсказка миниатюры wine_barrel_01: её путь, пакет Poly Haven, автор, лицензия CC0, url пакета и авторство модели](../assets/models/thumbnail-credit-tooltip.png)

```json
{
  "name": "Nature Kit",
  "short": "Nature",
  "author": "Some Artist",
  "license": "CC0",
  "url": "https://example.com/nature-kit",
  "credits": [{ "asset": "pine", "author": "Other Artist" }]
}
```

`short` это подпись на каждой миниатюре, пока включены «Слаги», и при отсутствии берётся из `name`. `credits` переопределяет автора, лицензию или url отдельных моделей, сопоставляя их по имени файла без расширения. Папки без `pack.json` перечисляются под именем своей верхней папки.
