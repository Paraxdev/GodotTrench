# Рисование ландшафта { #terrain-painting }

Инструмент **Смешивание** (Shift+G) раскрашивает [слои](terrain-layers.md) ландшафта, например песок вдоль пляжа или породу на утёсе. Как и «Лепка», он работает с выделенными ландшафтами или со всеми, если ничего не выделено.

## Инструмент «Смешивание» { #the-blend-tool }

1. Выберите инструмент

    Нажмите Shift+G или выберите *Ландшафт > Смешивание > Инструмент смешивания*. Его параметры появляются на панели параметров инструмента вверху слева.

    ![Параметры инструмента «Смешивание» в режиме уклона: режим, спад, слой, радиус, сила и диапазон уклона](../assets/terrain-painting/blend-toolbar.png)

2. Выберите режим

    Первое меню на панели решает, что рисует кисть, режимы перечислены ниже.

    ![Открытое меню режимов инструмента «Смешивание», наведён уклон](../assets/terrain-painting/blend-modes.png)

3. Выберите слой и рисуйте

    Задайте **слой** (от 0 до 3) нужным слоем, затем проведите по ландшафту. Несколько лёгких проходов дают более мягкие края, чем один сильный.

    ![Рисование грунтовой тропы вверх по острову слоем 2 в режиме краски](../assets/terrain-painting/blend-paint-path.gif)

| Режим | Что рисует |
| --- | --- |
| краска | Добавляет выбранный слой под кистью |
| стирание | Закрашивает обратно к слою 0, базовой земле |
| сглаживание | Смягчает границы между слоями |
| резкость | Даёт победить самому сильному слою, для чётких границ |
| шум | Только облачными пятнами заданного **размера**, для мха, сухой травы или гравия |
| уклон | Только там, где земля лежит между двумя углами. `30` и `90` кладут породу на всё круче 30° |
| высота | Только между двумя мировыми высотами, для песка у ватерлинии или снега выше границы леса |

Уклон и высота делают огромные кисти безопасными: кисть размером с холм в режиме уклона превращает в породу только утёсы.

Второе меню на панели это спад, то есть как сила затухает от центра кисти к краю.

| Спад | Форма |
| --- | --- |
| сглаживание | Мягкое затухание, обычный выбор |
| линейный | Равномерное затухание от центра к краю |
| постоянный | Весь диск с одной силой, для жёстких краёв |
| спрей | Случайные крапинки, для камешков и цветов |

Shift превращает краску, шум, уклон и высоту в стирание, а Ctrl сглаживает. Ctrl+колесо меняет размер кисти.

(Примечание: **Задать материал смешивания**, **повтор**, **антитайл**, **резкость** и **Применить тайлинг** правее на панели нужны для смешивания граней браша, ландшафт берёт эти настройки из своих слоёв.)

## Автораскраска { #auto-paint }

Автораскраска перекрашивает ландшафт по его форме, это быстрый первый проход перед ручной раскраской.

1. Выделите ландшафт

    Автораскраска трогает только выделенные ландшафты.

2. Запустите её

    Выберите *Ландшафт > Смешивание > Автокраска слоёв* или нажмите **Автораскраска** в Инспекторе.

    ![Меню «Ландшафт > Смешивание», наведена «Автокраска слоёв», галочка «Полосы от уровня моря» стоит при y 0](../assets/terrain-painting/menu-auto-paint.png)

| Слой | Куда ложится |
| --- | --- |
| 1 | Склоны круче примерно 50° |
| 2 | Верхние 20% диапазона высот |
| 3 | Нижние 8% диапазона высот |

Слой 0 покрывает всё остальное. Ландшафт с меньшим числом слоёв получает недостающие полосы в своём последнем слое.

Диапазон начинается с самой низкой точки, которая у острова это морское дно. Отметьте **Полосы от уровня моря**, чтобы мерить от заданной вами высоты, как от ватерлинии при y 0 выше.

![Морской остров до автораскраски, сплошная трава](../assets/terrain-painting/auto-paint-before.jpg)

![Тот же остров после автораскраски: порода на утёсах, грунт на вершине и песок вдоль пляжей](../assets/terrain-painting/auto-paint-after.jpg)

> [!WARNING]
> Автораскраска заменяет всю раскраску, поэтому сначала лепите, затем запускайте автораскраску, а вручную рисуйте в последнюю очередь.

## Насколько узко можно рисовать { #how-narrow-you-can-paint }

Краска живёт на вершинах, поэтому для чистой полосы мазку нужен радиус примерно в две ячейки. Меньше одной ячейки он превращается в лесенку. Для узкой тропы берите ячейки поменьше или положите сверху меш или [декаль](decals.md).

![Мазки с радиусом 40, 96 и 160 на ячейках по 64 единицы рядом с сеткой вершин, которая хранит краску](../assets/terrain-painting/brush-width-grid.jpg)
