# Случайное заполнение { #random-fill }

*Браш > Случайное заполнение…* покрывает сетку ячеек кусками из [библиотеки префабов](prefab-library.md), выбирая кусок для каждой ячейки по весу. Соберите небольшой набор кусков, например офисную комнату, коридор, сетку колонн и открытый пол, и заполнение выложит из них целый план этажа. Каждое зерно даёт свой план, а одно и то же зерно всегда даёт один и тот же.

1. Постройте куски

    Постройте каждый кусок шириной в одну ячейку (по умолчанию 128 единиц), с центром в начале координат. Не ставьте стены на границу ячейки, чтобы соседние куски всегда соединялись.

    Затем добавьте его в библиотеку: выделите, откройте **Добавить выделенное** вверху вкладки «Префабы», отметьте **Сохранить позицию**, задайте имя и нажмите **Добавить** (см. [Свои куски](prefab-library.md#your-own-pieces)).

    ![Вкладка «Префабы» с открытым «Добавить выделенное» и отмеченным «Сохранить позицию», в подсказке сказано, что начало координат карты остаётся началом куска, как у набора для случайного заполнения](../assets/random-fill/prefabs-keep-position.png)

2. Откройте диалог

    Выберите *Браш > Случайное заполнение…*.

    ![Меню «Браш», наведено «Случайное заполнение…»](../assets/random-fill/menu-random-fill.png)

3. Добавьте куски

    Выберите каждый кусок в **Добавить часть…** и задайте ему **вес**: кусок с весом 6 заполняет примерно вдвое больше ячеек, чем кусок с весом 3. **поворот** позволяет куску поворачиваться на случайное кратное 90 градусам.

    ![Диалог случайного заполнения с тремя кусками, их весами, весом пустых 4, сеткой 12 на 8 и её цветным предпросмотром](../assets/random-fill/random-fill-dialog.png)

4. (По желанию) Оставьте часть ячеек открытыми

    **вес пустых** работает как кусок, который ничего не ставит.

5. Разместите сетку

    Выделите пол и нажмите **По выделению** или задайте размер **Ячейка**, число **Ячейки** и **Угол** сами.

6. (По желанию) Сгруппируйте куски

    **Кластеризация** собирает каждый кусок в пятна размером около **Размер пятна** ячеек, так что крыло с офисами оказывается рядом с залом колонн, а не всё равномерно перемешано.

7. Заполните

    Цветная сетка показывает план заранее, по цвету на каждый кусок. Нажмите **Заполнить**, а **Перебросить** заменяет последнее заполнение следующим зерном.

    ![Пол, заполненный квадратными и круглыми колоннами и штабелями ящиков, часть ячеек оставлена пустой](../assets/random-fill/random-fill-result.jpg)

Заполнение это одна группа обычных копий, поэтому она запекается и собирается, как всё, что вы ставите вручную, и любую ячейку потом можно править. Имена сущностей каждой копии получают свой префикс, `rf<seed>_<n>-`, так что кусок с подключёнными сущностями, например лампа, мигающая по таймеру, работает сам по себе в каждой ячейке.

> [!TIP]
> Заполняйте разные виды деталей отдельными проходами по одной сетке, например один проход для стен и один для потолочных ламп, с собственными весами, скажем несколько мёртвых или мигающих ламп среди рабочих.

## MCP { #mcp }

Инструмент `random_fill` принимает `pieces` в виде `[{name, weight, rotate}]`, `empty`, `min`, `cell`, `cells`, `seed`, `cluster` и `cluster_size`. `preview: true` только возвращает план в виде наброска, `replace` сначала удаляет прежнее заполнение.
