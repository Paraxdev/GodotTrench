# UV-редактор { #uv-editor }

UV-редактор рисует выбранные грани брашей и мешей плоско поверх их повторяющейся текстуры, так что видно, какую часть текстуры показывает каждая грань. Он нужен для того, что [инструмент «Текстура»](texturing.md#the-texture-tool) не умеет в 3D-виде, например для расстановки UV меша с точностью до пикселя.

## Как открыть { #opening-it }

UV-редактор это вкладка в правой панели рядом с Инспектором, а ещё его открывает пункт *Текстура > UV-редактор*. Затем выберите грани: щёлкните одну в виде с Shift или воспользуйтесь инструментом «Текстура». Верхняя строка называет материал и число ваших граней.

![UV-редактор с одной выбранной гранью стены, нарисованной оранжевым прямоугольником поверх повторяющейся текстуры showcase/plaster](../assets/uv-editor/uv-editor-face.png)

> [!TIP]
> Пока UV-редактор остаётся видимой вкладкой своей панели, Ctrl+щелчок по брашу или мешу выбирает все его грани, так что можно текстурировать все стороны сразу. Уже выбранные браши и меши тоже превращаются в свои грани. Если в выборке есть что-то другое, например ландшафт или сущность, Ctrl+щелчок добавляет и убирает объекты как обычно.

Грань браша обычно получает текстуру из одного смещения, масштаба и поворота. Грань с **явными UV** вместо этого хранит положение текстуры для каждого угла, и именно это нужно мешам. UV-редактор рисует такие грани синим, и их углы можно выбирать по одному. Оранжевые грани не имеют явных UV и двигаются целиком.

## Управление { #controls }

**?** в конце верхней строки показывает то же самое и в редакторе.

| Ввод | Результат |
| --- | --- |
| Перетащить пустое место | Двигает текстуру или целиком грани, если у них явные UV |
| Колесо, перетаскивание правой кнопкой | Масштаб, поворот |
| Щёлкнуть угол | Выбирает его вместе с углами соседних граней, сшитыми с ним |
| Shift+щелчок, Ctrl+щелчок | Добавить, убрать |
| Alt+щелчок | Выбирает угол только этой грани, чтобы разорвать шов |
| Shift или Ctrl+перетаскивание по пустому месту | Выбор рамкой, с добавлением или удалением |
| Перетащить выбранный угол | Двигает всё выбранное |
| Двойной щелчок по углу | Манипулятор, двигающий только по U или V, Escape его скрывает |
| Перетаскивание средней кнопкой, Ctrl+колесо | Сдвиг и масштаб холста |

Если выбраны углы, колесо и перетаскивание правой кнопкой масштабируют и поворачивают их вокруг центра. Поля U и V под холстом ставят выбранное с точностью до пикселя.

Маленькие кнопки после меню переключают привязку к пикселям, показывают хотспоты текстуры, делают обычное перетаскивание выбором рамкой, показывают манипулятор, включают блокировку UV и снова вписывают грани в окно. Наведите курсор на кнопку, чтобы узнать, какая что делает.

## Проекции UV для мешей { #mesh-uv-projections }

Если выбраны грани меша, меню **Проекция** раскладывает для вас явные UV. Оно берёт плотность текселей, которую получила бы грань браша с той же текстурой, поэтому меши совпадают с окружающими брашами. Наведите курсор на пункт, чтобы увидеть объяснение в одну строку.

![Открытое меню «Проекция» UV-редактора, наведён «Цилиндр Y» и его подсказка «Оборачивает вокруг этой мировой оси через центр граней, u идёт вокруг неё»](../assets/uv-editor/projection-menu.png)

| Команда | Результат |
| --- | --- |
| *Плоская проекция*, *Плоская проекция X*, *Y*, *Z* | Проецирует вдоль направления, куда грани смотрят в основном, или вдоль одной мировой оси, сохраняя их цельными |
| *Бокс* | Проецирует каждую грань с ближайшей мировой оси, для угловатых форм |
| *Цилиндр X*, *Y*, *Z*, *Сфера* | Оборачивают текстуру вокруг граней, для труб, колонн и куполов |
| *Вид* | Проецирует прямо вдоль 3D-камеры |
| *Развернуть* | Раскладывает грани плоско ребро за ребром, так что полосы и сетки остаются непрерывными |
| *Сбросить к миру* | Проекция только что сброшенной грани браша |
| *Запечь плоскую проекцию* | Превращает плоскую текстуру в редактируемые UV углов, показывается, пока у части граней их ещё нет |
| *Очистить UV* | Снова убирает явные UV |
| *Нормализовать* | Один раз масштабирует UV по размеру текстуры |
| *Упаковать* | Упаковывает острова в текстуру с одной плотностью текселей |

Здесь 12-гранной колонне применили *Цилиндр Y*, и её боковые грани теперь идут рядом одной полосой вокруг текстуры:

![UV-редактор после «Цилиндра Y» на 12-гранной меш-колонне, её боковые грани уложены одной непрерывной полосой](../assets/uv-editor/uv-editor-cylinder.png)

Меню **UV** отражает, поворачивает, вписывает, выравнивает, распрямляет и привязывает к пикселям. Меню **Хотспот** вписывает в прямоугольник хотспота, см. [Хотспоты](texturing.md#hotspots).
