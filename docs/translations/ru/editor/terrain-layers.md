# Слои ландшафта { #terrain-layers }

У ландшафта от одного до четырёх слоёв, каждый из которых это материал плюс несколько настроек того, как он повторяется. Выделите ландшафт, и вы найдёте их в Инспекторе. Слои делят землю между собой, поэтому если нарисовать песок на траве, у травы отнимается вес.

![Инспектор ландшафта с четырьмя слоями, у каждого материал, тайл, антитайл и резкость](../assets/terrain-layers/layers-inspector.png)

| Что сделать | Как |
| --- | --- |
| Добавить слой | **+ слой (текущий материал)** под слоями, он берёт материал, по которому вы щёлкнули последним на панели «Материалы». Показывается, пока в ландшафте меньше четырёх |
| Убрать последний слой | **- последний слой** |
| Сменить материал слоя | Наберите его имя в поле слоя или перетащите материал с панели «Материалы» на ландшафт. Строка внизу Инспектора сообщает, на какой слой попадёт бросок, а при активном инструменте «Смешивание» это слой, которым он рисует |

**Слой 0 это базовая земля.** Нерисованная земля показывает слой 0, и стирание возвращает к нему, поэтому поместите туда самую обычную землю, обычно траву.

Новый ландшафт получает слои, названные в диалоге *Создать ландшафт*, по умолчанию четыре. Если бросить материал для слоя, которого в ландшафте ещё нет, он добавляется как следующий слой.

## Тайл и антитайл { #tile-and-de-tiling }

Любая текстура, повторённая на большой площади, издали показывает сетчатый узор. Эти настройки обменивают чёткость вблизи на скрытие этого узора.

| Настройка | Значение |
| --- | --- |
| тайл | Сколько единиц карты покрывает один повтор текстуры. Для земли, по которой ходят, хорошо работает от 128 до 384 |
| антитайл | От 0 до 1. Случайно поворачивает и сдвигает каждый повтор, чтобы сетка перестала быть видна |
| резкость | От 0 до 1, появляется, когда антитайл больше 0. При 0 сдвинутые повторы смешиваются равномерно, и выглядит мягко. При 1 они смешиваются только вдоль швов, и текстура остаётся чёткой |

Маленький тайл чёткий вблизи, но повтор заметен издали, большой размывается под ногами. Антитайл скрывает повтор без большего тайла, но стоит дополнительных чтений текстуры, поэтому оставьте 0 там, где повтор не виден.

![Тайл 256 с антитайлом 0 слева и 0,7 справа](../assets/terrain-painting/detile-compare.jpg)

> [!NOTE]
> `metadata/texture_size` материала на ландшафт не действует, действует только **тайл**.

## Как это выглядит в Godot { #how-it-looks-in-godot }

Каждый слой проецируется сверху и с боков, так что на утёсах видна порода, а не клякса, и это совпадает с тем, что вы видите в редакторе. Каждый слой использует цветовую текстуру материала, карту нормалей, roughness и свечение. Ambient occlusion используется, когда лежит в текстуре roughness, как в текстуре ORM, или когда у слоя нет текстуры roughness.
