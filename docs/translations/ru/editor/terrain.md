# Ландшафт { #terrain }

Ландшафт это большая сетка высот, которую вы лепите, как глину, с четырьмя текстурами, нарисованными поверх. Он подходит для открытой местности вроде холмов, пляжей и долин, где вручную формировать браши пришлось бы целую вечность.

Эта страница рассказывает, как создать ландшафт и придать ему форму инструментом «Лепка» (G). Текстурирование описано в статьях [Слои ландшафта](terrain-layers.md) и [Рисование ландшафта](terrain-painting.md).

## Создание ландшафта { #creating-a-terrain }

1. Откройте диалог

    Выберите *Ландшафт > Создать ландшафт…* в строке меню.

    ![Открытое меню «Ландшафт», наведён пункт «Создать ландшафт…»](../assets/terrain/menu-create-terrain.png)

2. Выберите размер

    **Разрешение** и **Размер ячейки** определяют, насколько большим он получится, а строка **Размер** под ними показывает результат в единицах и метрах. Значения по умолчанию, 129 x 129 вершин и ячейки по 64 единицы, дают 8192 единицы, 256 м. См. [Выбор размера ячейки](#picking-the-cell-size) ниже.

    ![Диалог создания ландшафта со значениями по умолчанию: 129 x 129, ячейки 64 u, «Холмы» и четыре поля слоёв](../assets/terrain/create-terrain-dialog.png)

3. (По желанию) Выберите начальную форму

    **Форма** это земля, с которой вы начинаете. По умолчанию это «Холмы», есть ещё «Плоский», «Гора», «Остров», «Долина» и «Хребты». **Импорт PNG…** вместо этого читает карту высот в градациях серого, где более светлые пиксели выше. То и другое работает только здесь, при создании.

4. (По желанию) Выберите слои

    **Базовый слой**, **Слой склонов**, **Слой вершин** и **Слой низин** это четыре текстуры ландшафта, а **Взять текущий** подставляет материал, по которому вы щёлкнули последним. Если отметить **Раскрасить слои по уклону и высоте**, они сразу раскрашиваются, см. [Автораскраска](terrain-painting.md#auto-paint).

5. Нажмите **Создать** внизу

    Ландшафт центрируется на 3D-курсоре или на **Центре**, который вы вводите при снятой галочке **3D-курсор**, и эта высота становится нулём ландшафта. Вы должны увидеть новый выбранный ландшафт с уже активным инструментом «Лепка».

## Выбор размера ячейки { #picking-the-cell-size }

| Настройка | Значение |
| --- | --- |
| Разрешение | Сколько вершин идёт вдоль каждой стороны, от 33 до 1025. Больше вершин вмещают больше деталей, но дороже в отрисовке и лепке |
| Размер ячейки | Расстояние в единицах карты между двумя соседними вершинами |

Например, 257 вершин с ячейками по 64 единицы дают 16384 единицы, 512 м.

Между двумя вершинами ничего нет, так что размер ячейки это самая мелкая деталь, которую способен хранить ландшафт. Горному хребту нужны большие ячейки, саду маленькие.

Выбрали неудачно? Выделите ландшафт и откройте **Пересчитать** в Инспекторе. Он перестраивает сетку на 65, 129, 257 или 513 вершин вдоль длинной стороны и сохраняет высоты, раскраску и дыры. Размер ландшафта не меняется, так что больше вершин значит меньше ячейки.

![Инспектор ландшафта с открытым меню «Пересчитать», наведено 257 вершин](../assets/terrain/inspector-resample.png)

**Ячеек в чанке** (по умолчанию 32) делит ландшафт на квадратные куски для отрисовки и столкновений. Меньшие чанки быстрее перестраиваются при лепке, большие дают меньше узлов в Godot.

## Лепка { #sculpting }

Нажмите G, выберите режим на панели параметров инструмента вверху слева и проведите по ландшафту. Инструмент работает с выделенными ландшафтами или со всеми, если ничего не выделено.

![Открытое меню режимов инструмента «Лепка» на панели параметров, рядом поля радиуса и силы](../assets/terrain/sculpt-modes.png)

Держите кнопку мыши нажатой, и земля продолжает расти под кистью.

![Удержание «Поднять» с кистью в 900 единиц вылепливает холм из острова](../assets/terrain/sculpt-raise.gif)

| Режим | Что делает |
| --- | --- |
| Поднять, Опустить | Наращивает высоту или роет вниз, пока вы держите кнопку. Щелчок делает небольшой бугор |
| Сгладить | Подтягивает каждую вершину к соседям, чтобы смягчить кочки и острые гребни |
| Разровнять | Тянет землю к высоте, с которой начался мазок, для площадок, дорог и плато |
| Шум | Добавляет мелкие случайные бугры, чтобы ровная земля выглядела менее искусственно |
| Террасы | Привязывает высоты к ступеням в **шаг** единиц, для рисовых полей или ступенчатых утёсов. Поле появляется рядом с режимом |
| Рисовать альфу, Стереть альфу, Рисовать слой | Рисуют вместо изменения формы. Режимы альфы предназначены для смещений, «Рисовать слой» рисует слоем ландшафта, заданным рядом с режимом. На ландшафте [инструмент «Смешивание»](terrain-painting.md) делает это с большим контролем |
| Дыра, Закрыть дыру | Вырезает целые ячейки или заполняет их обратно, вместе со столкновениями. Подходит для входов в пещеры и бункеры |

Ctrl+колесо меняет размер кисти, Shift меняет подъём и спуск местами, а удержание Ctrl сглаживает при любом режиме.

**Сила** задаёт, как быстро работает кисть. «Поднять» и «Опустить» двигают центр кисти на 8 единиц в секунду на пункт силы, независимо от радиуса, так что значение по умолчанию 4 наращивает 32 единицы в секунду. Для холмов и островов лучше прибавить силу, чем держать кнопку минуту.

Держите радиус больше размера ячейки ландшафта, меньшая кисть лишь подталкивает одну вершину под собой (строка состояния сообщает, когда это происходит).

Чтобы начать заново, *Ландшафт > Лепка > Разровнять* или **Разровнять** в Инспекторе возвращает весь выделенный ландшафт к нулевой высоте.

> [!TIP]
> Формируйте большой кистью и сглаживайте после каждого грубого прохода. Маленькие кисти оставляют кочки.

## В Godot { #in-godot }

Каждый ландшафт становится узлом `TrenchDotTerrain`, это `StaticBody3D` (узел Godot для твёрдой земли, которая никогда не двигается), чьи столкновения совпадают с тем, что рисуется. Для игрового кода `height_at(x, z)` возвращает высоту земли в локальной позиции, что удобно, чтобы ставить объекты на землю во время работы игры.

## MCP { #mcp }

Операция `sculpt` инструмента `terrain_edit` применяет один мазок, и его сила определяет, на сколько этот мазок двигает центр, опять же независимо от радиуса. Мазок, удерживаемый одну секунду при силе 4, соответствует мазку силы 32.
