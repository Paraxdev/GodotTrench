# Конвертация текстур { #converting-textures }

Godot не умеет загружать файлы `.vtf`, `.wad` и `.wal`, поэтому редактор превращает их в PNG, а там, где обычная картинка не может нести настройки, ещё и в `.tres`. Каждая текстура попадает в папку текстур проекта под названием материала грани, так что импортированные грани находят её сразу.

Импорт карты предлагает это для используемых ею текстур, см. [Импорт карт Hammer и TrenchBroom](importing.md). Чтобы конвертировать целую папку, сначала откройте проект Godot, а затем:

1. Откройте конвертер

    Выберите *Файл > Импорт > Конвертировать текстуры (VTF/VMT, WAD, WAL)…*.

    ![Меню «Файл» с открытым «Импорт» и наведённым курсором на «Конвертировать текстуры (VTF/VMT, WAD, WAL)…»](../assets/importing-textures/file-import-convert-textures.png)

2. Выберите папку

    Выберите папку с файлами `.vmt` и `.vtf`, `.wad` или `.wal`. Если в открытой карте каких-то из них не хватает, редактор спросит, конвертировать только **Для карты** или **Всё**.

    После этого в строке состояния должно быть написано, сколько текстур конвертировано, например «Текстуры: 12 converted», а на вкладке «Материалы» они появятся под названиями своих материалов.

    ![Вкладка «Материалы» с поиском castle, в ней brick_wall и stone_step из импортированной карты, подсказка castle/brick_wall, 1024 x 1024 px](../assets/importing-textures/converted-in-materials.png)

## Где их ищут { #where-they-are-found }

Редактор ищет в обычных местах, где каждая игра хранит свои текстуры, так что карта, скопированная вместе с папками игры, находит их без всякой настройки.

| Источник | Где ищут | Как называют |
| --- | --- | --- |
| Valve `.vmt` и `.vtf` | папку `materials` рядом с картой или на четыре папки выше | путь под `materials`, например `brick/brickwall001a` |
| Quake и Half-Life `.wad` | ключ worldspawn `wad`, затем файл с тем же именем в соседних папках | название текстуры, например `{grate` |
| Quake 2 `.wal` | папку `textures` поблизости | путь под `textures`, например `e1u1/floor1_1` |
| Отдельные `.png`, `.jpg`, `.tga` | папку `textures` поблизости, как их поставляют проекты Qodot и FuncGodot | путь под `textures`, копируется как есть |

## Материалы Valve { #valve-materials }

Файл Valve `.vmt` описывает материал списком параметров. Эти параметры переходят в материал Godot, остальные отбрасываются:

| Материал Valve | Материал Godot |
| --- | --- |
| `$basetexture` | альбедо, его альфа отбрасывается, если материал не прозрачный |
| `$bumpmap` или `$normalmap` у воды | карта нормалей, зелёный канал перевёрнут из DirectX в Godot |
| `$translucent`, `$additive` | альфа-смешивание для `$translucent`, аддитивное для `$additive` |
| `$alphatest`, `$alphatestreference` | alpha scissor с этим порогом, по умолчанию 0,5 |
| `$selfillum`, `$selfillummask` | светящаяся текстура излучения, маскированная альфой базовой текстуры или маской |
| `$nocull`, `UnlitGeneric` | двусторонний для `$nocull`, без затенения для `UnlitGeneric` |
| `$color` | цвет альбедо |
| `$surfaceprop` | `metadata/surfaceprop` у материала |
| `patch` с `include` | патч переиспользует другой материал с несколькими изменениями, поэтому он становится включённым материалом с применёнными изменениями `insert` и `replace` |

## Текстуры Quake { #quake-textures }

Текстуры, начинающиеся с `{`, вырезаются через alpha scissor, небо рисуется без затенения, а `*water` сохраняется как `water`. Анимированные текстуры, в том числе VTF с несколькими кадрами, сохраняют первый кадр.

## Небо { #skies }

Конвертация текстур карты ещё и задаёт её небо, так что импортированная карта получает небо, близкое к оригинальному. Это пропускается, если у карты уже есть `sky_top_color`.

Карта Source со скайбоксом `skyname` в `materials/skybox` получает панораму, `skybox/<skyname>_panorama.png` в папке текстур, заданную как `sky_panorama`. Остальные карты получают `sky_top_color` и `sky_horizon_color` из текстуры в `sky_source`. Если у сцены нет собственного WorldEnvironment (узла Godot, хранящего небо, туман и рассеянный свет сцены), `TrenchDotEnvironment` строит его из этих ключей.

## Форматы VTF { #vtf-formats }

Конвертер читает VTF версий с 7.0 по 7.5 в таких форматах пикселей: DXT1 (с однобитной альфой), DXT3, DXT5, 8-битные порядки RGB и RGBA, I8, IA88, A8, RGB565, BGR565, BGRA4444, BGRA5551, BGRX5551, UV88, UVWQ8888, UVLX8888 и 16-битные форматы RGBA. Другие форматы и VTF 7.6 отклоняются с названием формата, чтобы вы знали, какой файл конвертировать вручную.

## MCP { #mcp }

Через [сервер MCP](../mcp.md) папку текстур конвертирует `map_file {op: convert_textures, path}`. Добавьте `only_missing`, чтобы конвертировать только то, чего не хватает открытой карте, и `overwrite`, чтобы заменить файлы, которые уже есть в проекте.
