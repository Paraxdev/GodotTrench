# Материалы { #materials }

Каждая грань указывает на материал по его пути внутри *Base Texture Dir* из настроек карты, без расширения, например `showcase/planks`.

Когда Godot собирает карту, он ищет `showcase/planks.tres` в этой папке или, если вы задали *Base Material Dir*, в ней, и использует найденный файл как есть. Нет `.tres`? Тогда аддон делает простой материал из картинки. TrenchDot показывает тот же `.tres`, так что обе стороны выглядят одинаково.

`.tres` нужен, только когда простой картинки мало, например чтобы изменить масштаб, добавить свечение или сделать материал прозрачным. `.tres` только с `albedo_color` и без текстуры тоже работает, редактор рисует его этим цветом.

Новые текстуры и материалы появляются на вкладке «Материалы» через пару секунд, перезагружать ничего не нужно.

## Размер текстуры { #texture-size }

По умолчанию один пиксель текстуры покрывает одну единицу карты, так что текстура в 64 пикселя повторяется каждые два метра. Для пиксель-арта это здорово, но фотография 1024 пикселя двухметровой стены растянулась бы на 32 метра.

Чтобы это исправить, скажите материалу, сколько единиц карты покрывает один повтор:

```
[resource]
albedo_texture = ExtResource("1_albedo")
metadata/texture_size = Vector2(64, 64)
```

(Его можно добавить и в Инспекторе Godot в разделе *Metadata*, как `Vector2` или одно число.)

Наведите курсор на материал на вкладке «Материалы», чтобы проверить его, подсказка показывает размер картинки и сколько единиц покрывает один повтор.

![Вкладка «Материалы» с подсказкой night/shop_sign: 1024 x 256 px, 256 x 64 единиц на повтор, свечение x3](../assets/materials/tooltip-texture-size.png)

Теперь можно подставить более чёткую картинку, не меняя карту. Слои террейна игнорируют его, их настройка `tile` уже задаёт повтор.

## Светящиеся материалы { #glowing-materials }

Материал светится, когда в его файле задано `emission_enabled`. При чёрном цвете эмиссии текстура эмиссии светится в точности так, как нарисована:

```
[resource]
albedo_texture = ExtResource("1_albedo")
emission_enabled = true
emission = Color(0, 0, 0, 1)
emission_energy_multiplier = 2.5
emission_texture = ExtResource("2_emission")
```

Нет файла материала? Положите рядом картинку с именем альбедо и добавленным `_emission`, `night/sign_emission.png` рядом с `night/sign.png`, и она станет картой свечения.

Светящиеся материалы получают жёлтую метку *свечение* на вкладке «Материалы»:

![Материалы папки night на вкладке «Материалы», где apartment_lit, neon_red и shop_sign несут жёлтую метку свечения](../assets/materials/glow-tags.png)

Нажмите F3, чтобы включить освещённый просмотр и увидеть их свечение в 3D виде. Блум вокруг них виден только в Godot, см. [Ночное освещение](night-lighting.md).

## Прозрачность { #transparency }

Задайте `transparency` в файле материала, когда альфа-канал текстуры должен пропускать то, что за ней. Каждый режим по-своему обменивает качество на стоимость:

| `transparency` | Как работает | Для чего | На что обратить внимание |
| --- | --- | --- | --- |
| `1` blend | Смешивает поверхность с тем, что за ней | Стекло, мягкие пятна, дым | Не отбрасывает теней |
| `2` scissor | Пиксели либо видны полностью, либо отрезаются | Резкие вырезы вблизи, как решётки и листья | Тонкие части пропадают вдали |
| `3` hash | Дизерит пиксели, чем ниже альфа, тем меньше их показано | Тонкие вырезы, видимые издалека, как проволочные заборы | Мягкие края превращаются в шум |

Подсказка на вкладке «Материалы» сообщает, какой режим использует материал:

![Вкладка «Материалы» с подсказкой night/chainlink: альфа-hash, карта нормалей, двусторонний](../assets/materials/tooltip-alpha-hash.png)
