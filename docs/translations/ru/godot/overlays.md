# Оверлеи { #overlays }

Каждая сборка заменяет то, что сгенерировала карта, поэтому всё, что вы добавили вручную под узел карты, пропадёт при следующем сохранении. Оверлей это место для содержимого Godot, которое относится к карте и должно пережить любую пересборку: торговый автомат со своим скриптом, эффект частиц, настроенный в Godot, лампа с AnimationPlayer.

![Двор ночного района: гирлянды, светлячки и вывеска из оверлея, лампы из карты](../assets/overlays/night-district-courtyard.jpg)

## Как добавить { #adding-one }

1. Добавьте узел оверлея

    В Godot добавьте узел `TrenchDotOverlay` прямым потомком `FuncGodotMap`.

2. Положите в него свои узлы

    Сборки, живой режим и горячая перезагрузка его не трогают, так что его узлы сохраняют состояние и подключения сигналов и сохраняются вместе с вашей сценой.

(Для одного узла оверлей можно не делать: прямой потомок карты из группы `trenchdot_keep` тоже переживает сборки. Оверлей в другом месте сцены может указывать на свою карту через *Map Path*, и тогда следует за трансформацией карты.)

Содержимое оверлея использует локальное пространство карты в метрах. При 32 единицах на метр потомок в `(2, 0, -3)` находится там, где TrenchDot показывает `(64, 0, -96)`.

## Оверлей в отдельной сцене { #an-overlay-in-its-own-scene }

Оверлей может быть и отдельной сценой. Это окупается, когда несколько сцен используют одну карту и должны делить оверлей, когда один человек работает над сценой уровня, а другой над оверлеем, или когда сцену уровня генерирует скрипт, как в демо.

1. Сделайте сцену, корнем которой служит `TrenchDotOverlay`.
2. Перетащите `.tscn` на узел `FuncGodotMap`, чтобы он создался экземпляром как прямой потомок карты.

Godot показывает экземпляр сцены как один узел без стрелки раскрытия. Чтобы добраться до его содержимого:

| Вы хотите | Сделайте так |
| --- | --- |
| Править оверлей везде, где он используется | Щёлкните значок *Open in Editor* рядом с узлом в панели Scene или дважды щёлкните `.tscn` в панели FileSystem |
| Видеть или менять его узлы только в этой сцене | Щёлкните узел правой кнопкой и включите *Editable Children* |

Открытая сама по себе, сцена оверлея показывает предупреждение на корне, потому что она не под картой. Так и должно быть. Пунктирные рамки в TrenchDot обновятся при следующей сборке или сохранении сцены с картой, потому что только там оверлей знает свою карту.

## Связывание оверлеев { #wiring-overlays }

Узлы оверлея и сущности карты могут запускать друг друга через те же выходы и входы, которыми сущности карты пользуются между собой.

| Вы хотите | Сделайте так |
| --- | --- |
| Чтобы выход карты дошёл до узла оверлея | Дайте узлу потомка `TrenchDotOverlayIO` и задайте его *Targetname* |
| Чтобы узел оверлея запускал сущности карты | Добавьте потомка `TrenchDotOutput`, выберите сигнал в *Output* и заполните цель, вход и параметр |
| Чтобы содержимое ехало на движущейся сущности | Положите его под `TrenchDotAnchor` с *Target*, равным targetname сущности |

Вход, посланный `TrenchDotOverlayIO`, вызывает метод узла с таким именем, задаёт его свойство с таким именем или выполняет `show`, `hide` или `toggle`. Так что узлы без скрипта тоже работают: вход `emitting` с параметром `true` запускает `GPUParticles3D`. Каждый вход также испускает `input_received(input, parameter, activator)`.

`TrenchDotOutput` слушает любой сигнал своего родителя, поэтому `Area3D` срабатывает по `body_entered` без кода. Для собственных событий добавьте сигнал в скрипт родителя и выберите его:

```gdscript
extends StaticBody3D

signal flipped_on(activator: Node)
signal flipped_off(activator: Node)

var on := false

func use(activator: Node = null) -> void:
	on = not on
	if on:
		flipped_on.emit(activator)
	else:
		flipped_off.emit(activator)
```

Якорь хранит смещение там, где вы его поставили, и следует за сущностью через пересборки, живые правки и движение, так что предупреждающий знак поднимается вместе с рольставнями.

> [!WARNING]
> Связи переживают пересборки, состояние нет. Сущности карты возвращаются в начальное состояние, поэтому подключитесь к сигналу оверлея `map_rebuilt(map)` и верните своё состояние, например снова включите лампы.

## Посмотрите в демо { #see-it-in-the-demo }

В ночном районе демонстрационного проекта есть всё это. Его сцена `res://demo/showcase/night_district.scn` создаёт экземпляр сцены оверлея `res://demo/overlays/night_district_overlay.tscn` под своей картой, потому что демонстрационные сцены пересобирает скрипт. Откройте сцену оверлея, и вы найдёте электрощиток, который включает лампы двора, гирлянды, которые зажигает триггер карты, и вывеску, едущую на рольставнях гаража.
