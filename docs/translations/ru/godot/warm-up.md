# Прогрев шейдеров { #shader-warm-up }

Godot компилирует шейдеры, когда рисует что-то впервые, поэтому первый кадр игры подтормаживает. Прогрев делает эту работу заранее, за вашим экраном загрузки.

Если ваша игра состоит из одной карты, ничего делать не нужно. Каждая карта сама прогревается после сборки или загрузки в запущенной игре и по окончании испускает `warmed_up`.

Прогрев карты, правда, охватывает только саму карту. Если игра добавляет собственное содержимое, например игрока, врагов или оружие, при их первом появлении всё равно будут подтормаживания. В таком случае снимите флажок **Warm Up Shaders** у `FuncGodotMap` в Инспекторе Godot и прогрейте всё за один проход, когда всё уже на месте:

```gdscript
loading.show()
await build_maps()
spawn_player()
await TrenchDotWarmUp.warm_shaders([get_tree().current_scene, preload("res://enemies/crawler.tscn")]).finished
loading.hide()
```

`warm_shaders` принимает узлы, сцены, меши и материалы. Передавайте сцены, которые ещё не созданы, как враг в примере выше, чтобы они были готовы к моменту появления. Он ничего не рисует на экране и не запускает их скрипты. Подключите его сигнал `progress(done, total)`, чтобы двигать полосу загрузки.

На тестовой игре с пятью картами первый кадр игры ускорился с 360 мс до 22 мс при половине секунды прогрева.

> [!TIP]
> Включите также **Shader Baker** в пресетах экспорта, чтобы игроки не тратили время на компиляцию шейдеров при первом запуске.
