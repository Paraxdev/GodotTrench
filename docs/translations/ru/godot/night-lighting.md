# Ночное освещение { #night-lighting }

Для ночной карты вы приглушаете глобальный свет, чтобы работу делали расставленные вами лампы.

## Затемните карту { #darken-the-map }

Нажмите Escape или щёлкните по пустому месту во вьюпорте, чтобы ничего не было выделено. Тогда Инспектор справа показывает *Карта (worldspawn)*, настройки всей карты.

Задайте ключи ниже. Если ключа ещё нет в списке, введите его в поле *ключ* внизу, значение рядом с ним и нажмите **Добавить**.

| Ключ | По умолчанию | Что сделать для ночи |
| --- | --- | --- |
| `sun_energy`, `sun_color` | 1.1, `255 245 224` | Уменьшите энергию и выберите бледно-голубой цвет, и солнце будет читаться как луна |
| `ambient_energy`, `sky_energy` | 1.0, 1.0 | Уменьшите оба, чтобы неосвещённые места и небо потемнели |
| `glow_intensity` | 0 | При значении выше 0 лампы и [светящиеся материалы](materials.md#glowing-materials) дают блум в Godot |
| `ssr` | 0 | 1 включает отражения в экранном пространстве, чтобы мокрые улицы и глянцевые полы отражали лампы |

Вот что использует демонстрационная карта «ночной район»:

![Инспектор с Карта (worldspawn) ночного района: ambient_energy 0.8, glow_intensity 0.9, sky_energy 0.6, бледно-голубой sun_color и sun_energy 0.16](../assets/night-lighting/worldspawn-night.png)

## Проверьте в освещённом просмотре { #check-it-in-lit-preview }

Нажмите F3 или щёлкните *Освещённый просмотр* на панели инструментов, чтобы увидеть карту с её светом, небом и туманом.

![Панель инструментов с наведённой кнопкой «Освещённый просмотр» и её подсказкой «Шейдинг: Освещённый просмотр (F3)»](../assets/night-lighting/toolbar-lit-preview.png)

Вы должны увидеть, как лампы, освещённые окна и светящиеся вывески выделяются на тёмном небе:

![Улица ночного района в освещённом просмотре: уличные фонари, освещённые окна и светящаяся вывеска Corner Shop под тёмным небом](../assets/night-lighting/street-lit-preview.jpg)

Освещённый просмотр показывает все перечисленные выше ключи, кроме свечения и отражений, так что их проверяйте в Godot. Чтобы получить отражённый свет ламп, не платя за него в каждом кадре, [запеките освещение](../editor/light-baking.md).

## Корпуса ламп { #lamp-fixtures }

Лампа это сущность `light` или `light_spot` плюс геометрия лампы со светящейся колбой. Дайте этой геометрии targetname и впишите его в ключ `fixture` света (завершающая `*` совпадает с префиксом).

Тогда геометрия следует за светом без всякой проводки: показана, пока свет включён, и скрыта, пока выключен. Задайте `fixture_off` равным `dark`, чтобы она оставалась видимой, а её свечение выключалось.

![Инспектор света с targetname alley_lamp, fixture alley_bulb и fixture_off, заданным как dark (эмиссия выключена)](../assets/night-lighting/light-fixture-keys.png)

Остальные ключи света см. в разделе [Пропы, свет и эффекты](../gameplay/entities/effects.md).

## MCP { #mcp }

Демонстрационные карты собираются [скриптами MCP](../mcp-scripts.md), которые управляют редактором через его [сервер MCP](../mcp.md). `examples/mcp/night_district.json` и `examples/mcp/withered_city.json` это готовые ночные карты, построенные таким способом.
