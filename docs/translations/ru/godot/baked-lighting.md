# Запечённое освещение в Godot { #baked-lighting-in-godot }

Когда вы [запекаете карту в редакторе](../editor/light-baking.md), карта освещения сохраняется внутри `.tdm`. Сам Godot ничего не запекает, каждая сборка лишь превращает сохранённое запекание в собственный узел лайтмапа Godot.

## Что добавляет сборка { #what-the-build-adds }

| Часть | Что она получает |
| --- | --- |
| `LightmapGI` с именем `baked_lighting` | Дочерний узел `FuncGodotMap`, хранящий карту освещения, маску теней солнца и световые зонды |
| Запечённые меши | Координаты карты освещения как UV2 и статический режим GI, включая стримящиеся чанки |
| Источники света и солнце | Режим запекания Godot из их `bake_mode` или `sun_bake_mode`, см. [Ключи света](../editor/light-baking.md#light-keys) |

Если у солнца `bounce`, оно остаётся в реальном времени, а запечённая маска теней затеняет то, что лежит за дальностью его теней.

Грани, которые вы изменили после запекания, переходят на средний свет карты, так что выглядят правдоподобно, но плоско, пока вы не запечёте снова.

## Световые зонды { #light-probes }

Движущиеся объекты, такие как игрок, пропы и двери, берут свет из окружающих их световых зондов, поэтому подхватывают запечённый отражённый свет и вписываются в сцену.

Запекание расставляет зонды на сетке с шагом 2 метра по коробке вокруг запечённой геометрии и отбрасывает те, что внутри твёрдых тел. Там, где сетка слишком грубая, например в узком коридоре или на лестнице, добавьте сущность `light_probe`, чтобы получить ещё один. Карта получает не больше 1000 зондов, включая расставленные вручную, поэтому на большой карте сетка раздвигается.

## Сущности-зонды { #probe-entities }

| Сущность | Вид | Узел Godot | Для чего |
| --- | --- | --- | --- |
| `light_probe` | Точка | `LightmapProbe` | Дополнительный световой зонд для запекания, см. выше |
| `env_reflection_probe` | Объём из браша | `ReflectionProbe` по размеру браша | Отражения, соответствующие комнате, на глянцевых полах и металле |
| `env_voxel_gi` | Объём из браша | `VoxelGI` по размеру браша | Отражённый свет в реальном времени, следующий за движущимися источниками и объектами |

Все три находятся на вкладке «Сущности». Перетащите `light_probe` во вьюпорт. Для двух объёмов нарисуйте коробку вокруг комнаты, затем щёлкните карточку правой кнопкой и выберите **Превратить в неё выбранные браши**.

![Вкладка «Сущности» с фильтром env_, карточка env_voxel_gi с щелчком правой кнопкой и выделенным пунктом «Превратить в неё выбранные браши»](../assets/baked-lighting/entities-turn-brushes-into.png)

Браш задаёт только коробку, сборка его убирает. Ключи всех трёх перечислены в разделе [Пропы, свет и эффекты](../gameplay/entities/effects.md#light_probe-env_reflection_probe-and-env_voxel_gi).

`env_voxel_gi` запекается в редакторе Godot при каждой сборке карты. На большом объёме задайте `bake_on_build` равным 0 и запекайте его вручную кнопкой **Запечь** узла `VoxelGI` (в Godot она подписана Bake VoxelGI). Карты, собранные во время работы игры, это запекание пропускают.

## Другой лайтмаппер { #using-another-lightmapper }

Хотите запекать собственным `LightmapGI` Godot? Снимите флажок **Use Baked Lighting** у `FuncGodotMap`, чтобы сохранённое запекание не использовалось. Тогда сборка не добавит узел `baked_lighting` и не тронет режимы запекания источников света. Отметьте *Unwrap UV2* в *Build Flags*, чтобы у мешей появился UV2, нужный для запекания в Godot.
