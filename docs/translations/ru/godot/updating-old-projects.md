# Обновление проекта GodotTrench { #updating-a-godottrench-project }

Раньше TrenchDot назывался GodotTrench, а бета-сборки недолго назывались LevelBench. Если вы тогда настроили проект или сохранили карты, они продолжают работать. Аддон нужно обновить всего один раз.

## Шаги { #steps }

1. Запустите новый редактор. При первом запуске он копирует ваши настройки, доверенные проекты и недавние файлы из старой папки настроек. Старая папка остаётся на месте, так что старый редактор тоже продолжает работать.
2. Откройте проект Godot. Откроется окно настройки и сообщит, что аддон в проекте старше редактора, даже если номера версий совпадают. Сначала закройте Godot, затем нажмите **Обновить аддон до** и номер версии.
3. Один раз откройте проект в Godot. Аддон переносит настройки проекта из `godottrench/` в `trenchdot/` и пишет `trenchdot_game.json` вместо `godottrench_game.json`.

## Что переносится { #what-carries-over }

| Что у вас было | Что происходит |
| --- | --- |
| Карты `.gtm` | Они открываются как есть. Строка состояния сообщает «room.gtm обновлён из формата GodotTrench, сохраните, чтобы оставить». При сохранении имя `.gtm` сохраняется, так что ваши сцены по-прежнему находят карту. Новые карты сохраняются как `.tdm`. |
| Переменные окружения `GODOTTRENCH_` | Они по-прежнему работают. Если заданы оба имени, побеждает вариант с `TRENCHDOT_`. |
| Пакет геймплея в `res://godottrench/entities` | Он продолжает работать, и ваши скрипты, расширяющие его классы, по-прежнему компилируются. Если вы установите и новый пакет, побеждает новый там, где оба определяют сущность. Оставьте старую папку на месте, пока ваши сцены её используют. |
| Пакеты природы и модели в `res://godottrench/` | Карты, которые их размещают, продолжают работать. Пресеты разброса ищут в `res://trenchdot/nature`, так что добавьте пакет природы заново, чтобы рисовать новый разброс. |
| Сцены, собранные старым аддоном | Они загружаются, потому что Godot находит перенесённые скрипты аддона по их uid. Повторная сборка карты обновляет их. |

## Клиенты MCP { #mcp-clients }

Сервер MCP теперь называется `trenchdot`. Переименуйте его в настройках вашего клиента. Переменная токена называется `TRENCHDOT_MCP_TOKEN`, а старая `GODOTTRENCH_MCP_TOKEN` по-прежнему работает.
