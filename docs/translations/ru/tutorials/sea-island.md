# Остров в море 1: ландшафт { #sea-island-1-terrain }

Большой остров с двумя холмами, скалами, пляжем, тропинками, лесом и пирсом, который собирается в пять частей. Числа
здесь те, что использованы для картинок, в единицах карты, 32 на метр.

![Готовый остров, вид с юга](../assets/sea-island/island-finished.jpg)

## Создайте ландшафт { #create-the-terrain }

В строке меню выберите *Ландшафт > Создать ландшафт…*.

![Меню «Ландшафт», выделен пункт «Создать ландшафт…»](../assets/sea-island/menu-create-terrain.png)

Заполните диалог так:

| Настройка | Значение и зачем оно |
| --- | --- |
| Разрешение, Размер ячейки | 257 x 257 точек, шаг 64 единицы. Строка «Размер» ниже показывает, что получится, 16384 единицы (512 м) |
| Форма | Остров, Высота 1600, Размер деталей 3000, Эрозия 20, Зерно 1. Остров поднимается в середине и спадает к краям. Размер деталей это ширина самых больших бугров, а эрозия даёт крутым склонам осесть, чтобы они выглядели выветренными |
| Слой основы, склонов, вершин и низин | `showcase/grass`, `showcase/cliff`, `showcase/dirt`, `showcase/sand`. Тайл 256 у первых двух и 192 у остальных. Основа покрывает всё, что вы не закрасите, остальные предназначены для крутой, высокой и низкой земли |
| Центр | Снимите галочку **3D-курсор**, затем `0 -576 0` |
| Раскрасить слои по уклону и высоте | Галочка снята, в части 3 вы рисуете вручную |

(Значение тайла это то, сколько единиц покрывает один повтор текстуры.)

![Заполненный диалог «Создать ландшафт»: 257 x 257, размер ячейки 64, Остров, высота 1600, размер деталей 3000, эрозия 20, зерно 1, четыре слоя showcase, центр 0 -576 0 и снятая галочка «Раскрасить слои по уклону и высоте»](../assets/sea-island/create-terrain-dialog.png)

Нажмите **Создать** внизу. Появится зелёный остров, уже выделенный, а редактор сам переключится на инструмент «Лепка».

Море будет на высоте 0, поэтому опускание ландшафта на 576 затопляет его внешнее кольцо и оставляет середину сухой.
Следующие части ссылаются на слои по номеру слота: 0 трава, 1 скала, 2 земля, 3 песок.

## Добавьте море { #add-the-sea }

Море это один плоский браш, в который игрок может зайти.

1. Нарисуйте огромный ящик

    Нажмите **Q** для инструмента «Выделить» и **Escape**, чтобы ландшафт перестал быть выделенным, иначе ваше
    перетаскивание будет его лепить или двигать. Затем перетащите курсор на виде сверху и нарисуйте ящик во много раз
    больше ландшафта, иначе его край будет виден на горизонте.

2. Сплющите его

    На виде спереди сделайте его толщиной 32 единицы с верхом на высоте 0.

3. Сделайте из него воду

    Выделив ящик, щёлкните `showcase/water` на вкладке «Материалы». Затем щёлкните по воде в 3D-виде с зажатым Shift,
    чтобы выделить только её верхнюю грань, и задайте *масштаб* 8 и 8 в разделе *Выравнивание* Инспектора. Тогда
    текстура воды не будет повторяться каждые несколько метров.

    ![Инспектор с 1 выделенной гранью, материал showcase/water и масштаб выравнивания 8.00 и 8.00](../assets/sea-island/inspector-alignment-scale.png)

4. Дайте игроку зайти в воду

    Щёлкните по воде один раз, подальше от острова, чтобы снова был выделен весь ящик, а не только его верхняя грань.
    Затем щёлкните по нему правой кнопкой мыши и выберите *Создать браш-сущность > func_illusionary*. Она
    отрисовывается без коллизии, поэтому игрок может зайти в воду.

Теперь у вас должен быть остров в море, готовый к лепке:

![Сгенерированный остров в море, до лепки](../assets/sea-island/fresh-island.jpg)

Дальше: [Остров в море 2: лепка](sea-island-sculpt.md).
