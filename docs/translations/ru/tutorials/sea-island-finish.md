# Остров в море 5: пирс и Godot { #sea-island-5-pier-and-godot }

## Пирс { #the-pier }

1. Дайте ему отдельный слой

    Нажмите **Добавить слой** вверху Структуры. Новый слой становится текущим, поэтому пирс попадёт на него, и его можно
    скрывать или блокировать отдельно от ландшафта.

    ![Структура с наведённой кнопкой «Добавить слой» и её подсказкой: новый слой, он становится текущим слоем, куда попадают новые объекты](../assets/sea-island/outliner-add-layer.png)

2. Постройте его

    Нажмите **Q** для инструмента «Выделить», ведь перетаскивание инструментом «Разброс» всё ещё рисует модели. Затем
    нарисуйте простые брашы, уходящие в море от середины пляжа, с размерами из таблицы ниже.

3. Добавьте пропсы

    Выберите *Файл > Импорт > Модель-проп (.bbmodel, .glb)…* и возьмите модели из папки `models/polyhaven` демо-проекта:
    два `containers/wooden_crate_01` и `containers/wine_barrel_01` на настил, `nautical/lifebuoy` у столба и
    `nautical/ocean_buoy` в воду. Каждая появляется у 3D-курсора, оттуда переместите её на место.

    ![Меню «Файл» с открытым подменю «Импорт», наведён пункт «Модель-проп (.bbmodel, .glb)…»](../assets/sea-island/menu-import-model-prop.png)

| Часть | Размер | Материал |
| --- | --- | --- |
| Настил | 128 в ширину, 1100 в длину, 8 в толщину, верх на 48 над водой | `showcase/planks` |
| Столбы | квадрат 16 единиц, два ряда через каждые 200 единиц, от 320 под водой до настила | `showcase/beam` |
| Перила | Два коротких столба на дальнем конце, высотой 40 | `showcase/beam` |

Проп ссылается на свою модель по пути `res://`, поэтому файл должен лежать внутри открытого проекта Godot. Если выбрать
модель из другого места, редактор сначала предложит скопировать её в `res://models`.

![Пирс со стороны моря](../assets/sea-island/pier.jpg)

## Посмотрите в Godot { #see-it-in-godot }

Сохраните карту внутри проекта Godot и соберите её с помощью `FuncGodotMap`, см. [Сборка карт](../godot/building.md).
Каждая часть карты превращается в свой вид узла:

| Часть карты | Что вы получите в Godot |
| --- | --- |
| Ландшафт | `TrenchDotTerrain`, разбитый на чанки, каждый из которых это меш, смешивающий четыре слоя, со своей коллизией |
| Море | Браш `func_illusionary`, видимый без коллизии |
| Наборы деревьев, кустов и валунов | MultiMesh, плюс одно статическое тело на модель с формой коллизии для каждого экземпляра, и все они делят одну форму |
| Наборы травы | MultiMesh без коллизии, которые гаснут с расстоянием |
