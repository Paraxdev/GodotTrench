# TrenchDot { #trenchdot }

![TrenchDot, редактор уровней для Godot](assets/brand/itch-banner-960x300.png)

TrenchDot это редактор уровней для Godot на основе брашей, в духе TrenchBroom и Hammer.
Поддерживает I/O, собственные меши (Hammer, Quake, Blockbench) и многое другое!

TrenchDot во многом вдохновлён TrenchBroom и идёт своим путём там, где дело касается Godot. Он не связан с проектом
TrenchBroom.

## Скачать { #download }

У TrenchDot есть [скользящая бета на GitHub](https://github.com/Paraxdev/TrenchDot/releases/tag/beta), то есть это
всегда самая свежая версия, которую можно получить.
Проект ещё на очень ранней стадии, поэтому версия с долгой поддержкой (LTS) сейчас не планируется. Когда он станет
полезной программой, выйдет полноценный релиз.

Кроме того, он доступен на [itch.io](https://paraxdev.itch.io/trenchdot).

Чтобы собрать его из исходников, загляните в [Разработку](development.md).
