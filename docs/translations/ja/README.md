# TrenchDot { #trenchdot }

![TrenchDot、Godot向けのレベルエディタ](assets/brand/itch-banner-960x300.png)

TrenchDotは、TrenchBroomやHammerの流れをくむ、Godot向けのブラシベースのレベルエディタです。I/O、カスタムメッシュ（Hammer、Quake、Blockbench）などに対応しています。

TrenchDotはTrenchBroomから多くの着想を得ていますが、Godotまわりでは独自の道を進んでいます。TrenchBroomプロジェクトとは関係ありません。

![TrenchDotのエディター](screenshots/editor.png)

## ダウンロード { #download }

TrenchDotには[GitHubのローリングベータ](https://github.com/Paraxdev/TrenchDot/releases/tag/beta)があり、いつでも手に入る最新版です。
まだ開発の初期段階なので、LTS版の予定は今のところありません。役に立つソフトウェアとして形になったら、正式版をリリースします。

[itch.io](https://paraxdev.itch.io/trenchdot)からも入手できます。

ソースからビルドしたい場合は、[開発](development.md)をご覧ください。
