# 地形と散布 { #terrain-and-scatter }

## 地形 { #terrain }

規則的なグリッド上のハイトマップで、グリッドの頂点ごとに高さが1つあり、最大4枚のテクスチャレイヤーでペイントされます。大きなデータは、JSONではbase64のテキスト、[バイナリコンテナ](container.md#value-encoding)ではそのままのバイト列です。

| キー | 型 | デフォルト | 意味 |
| --- | --- | --- | --- |
| `origin` | `[x, y, z]` | 必須 | 最初の頂点のワールド位置 |
| `resolution` | `[nx, nz]` | 必須 | XとZ方向の頂点数。それぞれ2以上 |
| `cell_size` | number | 必須 | 隣り合う頂点の間のマップ単位 |
| `heights` | base64 | 必須 | リトルエンディアンの32ビットfloat。頂点ごとに高さ1つ |
| `layers` | array | 必須 | 最大4枚のテクスチャレイヤー。下を参照してください |
| `splat` | base64 | 省略 | 頂点ごとに重みのバイト4つ。レイヤーごとに1つで、そこで各レイヤーがどれだけ見えるかを表します |
| `holes` | base64 | 省略 | セルごとにバイト1つ。0以外だと、そのセルが地形から切り抜かれます |
| `chunk_cells` | integer | `32` | 常に書き込まれます。チャンクの1辺あたりのセル数。地形は、描画と衝突判定のために、このサイズのチャンクに分割されます |

頂点`(i, j)`は、`origin + (i * cell_size, heights[j * nx + i], j * cell_size)`にあります。`splat`も同じ順序で、重みは読み込み時に正規化され、すべて0のエントリはレイヤー0を意味します。`holes`は、`(nx - 1) * (nz - 1)`個のセルを同じ順序で並べます。

各レイヤーは次のとおりです。

| キー | 型 | デフォルト | 意味 |
| --- | --- | --- | --- |
| `material` | string | 必須 | このレイヤーがペイントするマテリアル |
| `tile` | number | `256` | テクスチャ1回の繰り返しあたりのマップ単位 |
| `detile` | number | `0` | 0から1。繰り返しをどれだけ強く崩して、格子状のパターンが見えなくなるようにするか |
| `detile_sharpen` | number | `0.5` | 0から1。タイル解消した結果をどれだけくっきり保つか |

これらの設定が実際にどう見えるかは、[地形レイヤー](../editor/terrain-layers.md)を参照してください。

地形は軸に揃ったままです。インスタンスは、地形の中心を回転も含めた変換全体で動かしますが、グリッド自体を回転させることはありません。

## 散布 { #scatter }

散布セットは、木、岩、サーフェスにペイントした草のような少数のモデルの多数のコピーを、1つのノードに保持します。エディター側については[散布](../editor/scatter.md)を参照してください。`targets`と`material`を除くすべてのキーは常に書き込まれます。

| キー | 型 | デフォルト | 意味 |
| --- | --- | --- | --- |
| `name` | string | 必須 | エディターに表示される名前 |
| `kind` | string | `props` | Godotが作るもの。`props`はスクリプトと衝突判定を保ち、`foliage`は衝突判定のないMultiMeshです |
| `targets` | ノードidの配列 | 省略 | セットをペイントするサーフェス |
| `items` | array | 必須 | 散布するモデル。下を参照してください |
| `collision` | string | foliageなら`none`、それ以外は`convex` | インスタンスごとの衝突形状。`none`、`box`、`convex`、`decomposition`、`trimesh`のいずれか |
| `cast_shadows` | bool | `true` | インスタンスが影を落とすかどうか |
| `visibility_range` | number | `0` | この距離より遠いインスタンスを隠します。0なら隠しません |
| `chunk_size` | number | `0` | セットをこのサイズのセルに分割して、Godotが画面外のものをカリングできるようにします。0なら1つのセルです。新しいセットは2048を使います |
| `static_props_multimesh` | bool | `false` | スクリプトを持つプロップのシーンも、MultiMeshとして描画します。多数のプロップでは軽くなりますが、そのスクリプトは捨てられます |
| `material` | string | 省略 | セット全体のマテリアルオーバーライド |
| `instances` | array | 空 | 配置済みのインスタンス。下を参照してください |

セットを、それが対象とするサーフェスと一緒にコピーすると、コピーはコピーしたサーフェスを対象にします。

各アイテムは、セットが配置できるモデル1つです。

| キー | 型 | デフォルト | 意味 |
| --- | --- | --- | --- |
| `source` | string | 必須 | `res://`のモデルかシーン |
| `weight` | number | `1` | このアイテムが選ばれる相対的な確率 |
| `scale` | `[min, max]` | `[0.8, 1.2]` | ランダムな均一スケールの範囲 |
| `spacing` | number | `48` | ほかのすべてのインスタンスまでの最小距離 |
| `align` | number | `0` | 0なら直立、1ならサーフェスの法線に沿い、その間の値は途中まで傾きます |
| `random_yaw` | bool | `true` | 各インスタンスをランダムな向きに回します |
| `tilt` | number | `0` | ランダムな傾きの最大値(度) |
| `sink` | number | `0` | サーフェスにめり込ませるマップ単位。根元や岩の下部が浮かないようにします |
| `material` | string | 省略 | このアイテムのマテリアルオーバーライド。セットのものより優先されます |
| `enabled` | bool | `true`、省略 | ブラシがこのアイテムをペイントするかどうか。すでに配置されたインスタンスは残ります |

各インスタンスはフラットな配列`[item, x, y, z, pitch, yaw, roll, scale]`で、`item`は`items`へのインデックス、角度は度でYXZ順です。保存するとき、位置は0.01、角度は0.1、スケールは0.001に丸められます。これによってコンテナが、それらを[整数の列](container.md#value-encoding)として保存できます。
