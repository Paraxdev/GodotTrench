# ジオメトリ { #geometry }

## ブラシ { #brush }

凸形のソリッドで、正確な頂点と、それらを参照する面のリストとして保存されています。そのため、平面を交差させなくても頂点が手に入ります。面の平面は、読み込み時に再計算されます。

| キー | 型 | 意味 |
| --- | --- | --- |
| `vertices` | `[x, y, z]`の配列 | マップ単位の頂点 |
| `faces` | 面の配列 | 面ごとに1つのポリゴン |

各面は次のとおりです。

| キー | 型 | デフォルト | 意味 |
| --- | --- | --- | --- |
| `indices` | 整数の配列 | 必須 | `vertices`へのインデックス。3つ以上で、外から見て反時計回り |
| `material` | string | `""` | 常に書き込まれます。テクスチャ名。たとえば`base/wall` |
| `uv` | object | パラキシャル | 常に書き込まれます。面へのテクスチャの貼り方。[テクスチャ投影](#texture-projection)を参照してください |
| `props` | stringからstringへのobject | 省略 | 下のブレンドキーのような、自由形式の面の属性 |
| `disp` | object | 省略 | 面を[ディスプレイスメント](#displacement)にします |
| `colors` | `[r, g, b, a]`の配列 | 省略 | [頂点ペイント](../editor/texturing.md#vertex-paint)。インデックスごとに1色 |

頂点か面が4つ未満のブラシは、閉じたソリッドにならないので、Godotのビルドはスキップします。

面は、2つのマテリアルの間でブレンドすることもできます。面のpropsの`blend_material`、`blend_detile`、`blend_uv_scale`、`blend_detile_sharpen`で設定します。すると、頂点カラーのアルファが、面全体で`material`から`blend_material`へとフェードします。

## テクスチャ投影 { #texture-projection }

`uv`はValve 220形式の投影で、軸を明示します。2つのワールド方向が、テクスチャが面の上でどちらに走るかを決め、オフセットとスケールが位置を決めます。

| キー | 型 | 意味 |
| --- | --- | --- |
| `u_axis`, `v_axis` | `[x, y, z]` | テクスチャのuとvのワールド方向 |
| `offset` | `[u, v]` | テクセル単位のずれ |
| `scale` | `[u, v]` | テクセルあたりのマップ単位 |
| `rotation` | number | 任意で、参考情報だけです。軸にすでに回転が含まれています |

点`p`は、テクセル`dot(p, u_axis) / scale.x + offset.x`に落ち、vも同様です。最終的なUVを得るには、それをテクスチャサイズで割ります。マテリアルに`texture_size`があればそれを、なければ画像のピクセルサイズを使います。[マテリアル](../godot/materials.md)を参照してください。

`uv`がないときは、`u_axis = [1, 0, 0]`、`v_axis = [0, 0, 1]`、スケール1として扱われます。`uv`がある場合は、`rotation`以外のすべてのキーが必須です。

## テクスチャ設定 { #texture-settings }

トップレベルの`textures`オブジェクトは、マテリアルを持つすべての面が共有する設定を、マテリアル名をキーにして持ちます。デフォルトと違う設定だけが書き込まれ、設定のないマテリアルは省かれます。

| キー | 型 | デフォルト | 意味 |
| --- | --- | --- | --- |
| `bake` | bool | `true` | 面がライトマップに場所を持ちます。オフだと、Godotはベイクした光の平均を面に与えます |
| `casts` | bool | `true` | 面がベイクで光をさえぎります |
| `texel_scale` | number | `1` | これらの面のライトマップのテクセルサイズに掛けます。0.125から16 |
| `size` | `[w, h]` | なし | 1回の繰り返しがカバーするマップ単位。上のテクスチャサイズの代わりに使います |
| `projection` | string | `"face"` | `"world"`は、ブラシの各面の`uv`を無視して、その法線のリセットした投影(オフセット0、スケール1)を使います |

`world`が適用されるのはブラシの面だけで、メッシュの面は投影を保ちます。

## ディスプレイスメント { #displacement }

四角形の面は、Hammer形式のディスプレイスメントを持てます。頂点のグリッドで、各頂点が面の法線方向に押し出されます。

| キー | 型 | デフォルト | 意味 |
| --- | --- | --- | --- |
| `power` | integer | 必須 | 1から4。グリッドは1辺あたり`2^power + 1`個の頂点を持ちます |
| `heights` | 数値の配列 | 必須 | グリッドの各頂点を法線方向にどれだけ押し出すか |
| `alphas` | 数値の配列 | 省略 | グリッドの頂点ごとのブレンドの重み。0なら面のマテリアルが見えます |

どちらの配列も行優先で、`(2^power + 1)^2`個の要素を持ちます。行は面の1番目の頂点から4番目に向かって、列は1番目から2番目に向かって進みます。

## メッシュ { #mesh }

編集できるポリゴンメッシュです。ブラシと違って、凹んでいても、開いていても、平らでない面があってもかまいません。

| キー | 型 | デフォルト | 意味 |
| --- | --- | --- | --- |
| `vertices` | `[x, y, z]`の配列 | 必須 | マップ単位の頂点 |
| `faces` | 面の配列 | 必須 | ブラシの面と同じキーに、`uvs`を加えたもの |
| `smooth_angle` | number | `0`、省略 | この度数より小さい角度で接する面は、法線を共有してなめらかにシェーディングされます。0はフラットシェーディングです |
| `decal` | bool | `false`、省略 | メッシュを[デカール](../editor/decals.md)にします |

スムージングは、すべての面の角を、その頂点のまわりの各面と比べます。角1つにつき64回を超える比較が必要になるメッシュや、合計で262,144回を超えるメッシュは、代わりにフラットにシェーディングされます。そこに届くのは、数百の面が共有する頂点だけで、たとえば約650辺を超える円錐の先端などです。

メッシュの面の`uvs`は`[u, v]`の配列で、インデックスごとに1つ、テクスチャの幅を単位にします。これがあるときは`uv`の代わりになり、個数が`indices`と合わないと、エディターはそのマップを拒否します。
