# コマンドライン { #command-line }

```sh
trenchdot [options] [map]
```

オプションなしで起動すると、エディターがそのまま開きます。マップを渡したときは、そのマップが開きます。`trenchdot --help`(または`-h`)で、オプションの一覧が表示されて終了します。

| オプション | 動作 |
| --- | --- |
| `--project <dir>` | `<dir>`か、その上のフォルダにあるGodotプロジェクトを読み込み、このセッションの間は信頼します。[プロジェクトの信頼](godot/running-godot.md#project-trust)を参照してください。付けないときは、最後に使ったプロジェクトを読み込みます |
| `--default-prefs` | デフォルトの設定で起動し、設定を保存しません。スクリプトやテストに便利で、問題が自分の設定のせいかを調べるときにも使えます |
| `--offscreen` | どの画面の外にもウィンドウを開き、フォーカスもタスクバーのボタンもありません。描画はされるので、あなたが作業を続けている間も、スクリプトやテストがスクリーンショットを撮れます |
| `--live-link-port=<port>` | 今回の実行に限り、設定の*Godotライブリンク*のポートではなく、このポートでGodotエディターと通信します。スクリプトやテストには空いているポートを渡すので、保存してもあなたが開いているGodotでマップが再ビルドされることはありません |
| `--hot-reload-port=<port>` | *実行中ゲームのホットリロード*のポートについて同じことをします。このポートで実行中のゲームが待ち受けていて、保存されたマップを再読み込みします |
| `--dump <map>` | マップをJSONで出力して終了します |
| `--to-json <map> <out>` | マップをJSONで書き出して終了します |
| `--to-tdm <map> <out>` | マップをバイナリの`.tdm`で書き出して終了します |
| `--export-glb <map> <out.glb>` | マップのジオメトリとマテリアルを、Blenderなどの3Dツール向けにglTFバイナリで書き出して終了します |
| `--export-obj <map> <out.obj>` | 同じ内容をOBJで書き出します。隣に`.mtl`とテクスチャのフォルダもできます。終了します |

未知のオプションや、値が足りないオプションがあると、エラーを表示してコード2で終了し、ウィンドウは開きません。変換やエクスポートに失敗したときは、理由を表示してコード1で終了します。

変換とエクスポートはウィンドウを開かないので、スクリプトやgitフックの中でも安全です。[gitでのマップファイル](development.md#map-files-in-git)を参照してください。

エクスポートは、マップのフォルダからそのGodotプロジェクトを見つけ、*ファイル > エクスポート*の既定値を使います。マップ全体で、非表示のオブジェクトと散布のインスタンスは含みません。エンティティのロジック、トリガー、スクリプトは含まれません。[Blenderなど他の3Dツールへのエクスポート](editor/exporting.md)を参照してください。

## MCP

これらのオプションは、スクリプトやAIエージェントがエディターを操作できるようにする[MCPサーバー](mcp.md)を設定します。

| オプション | 動作 |
| --- | --- |
| `--mcp` | 標準入出力でMCPを提供します |
| `--mcp-http[=<port>]` | 127.0.0.1のHTTPでMCPを提供します。ポートの既定値は7841です |
| `--mcp-token=<token>` | 設定の内容にかかわらず、HTTPクライアントにこのトークンの送信を求めます。`TRENCHDOT_MCP_TOKEN`よりも優先されます。[HTTPトークン](mcp.md#the-http-token)を参照してください |

`--default-prefs`はどちらとも相性がよく、スクリプトで動かすセッションを毎回同じ設定で始められます。`TRENCHDOT_DISABLE_MCP=1`を設定していると、どちらのオプションもサーバーを起動しません。[MCPをオフにする](mcp.md#turning-mcp-off)を参照してください。
