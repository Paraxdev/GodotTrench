# 地形のペイント { #terrain-painting }

**ブレンド**ツール（Shift+G）は、地形の[レイヤー](terrain-layers.md)をペイントします。たとえば、砂浜に沿って砂を、崖に岩を置けます。スカルプトと同じく、選択した地形に作用し、何も選択していないときはすべての地形に作用します。

## ブレンドツール { #the-blend-tool }

1. ツールを選ぶ

    Shift+Gを押すか、*地形 > ブレンド > ブレンドツール*を使います。オプションは左上のツールオプションバーに表示されます。

    ![傾斜モードのブレンドツールのオプション。モード、フォールオフ、レイヤー、半径、強さ、傾斜の範囲が並んでいる](../assets/terrain-painting/blend-toolbar.png)

2. モードを選ぶ

    バーの最初のメニューで、ブラシが何をペイントするかが決まります。モードは下の表にあります。

    ![ブレンドツールのモードメニューを開き、傾斜にカーソルを重ねたところ](../assets/terrain-painting/blend-modes.png)

3. レイヤーを選んでペイントする

    **レイヤー**（0から3）を使いたいレイヤーに設定して、地形の上をドラッグします。強い1回より、弱い何回かのほうが、縁がやわらかくなります。

    ![描画モードでレイヤー2を使い、島を登る土の道をペイントしているところ](../assets/terrain-painting/blend-paint-path.gif)

| モード | ペイントするもの |
| --- | --- |
| 描画 | ブラシの下に、選んだレイヤーを加えます |
| 消去 | ベースの地面であるレイヤー0のほうへペイントを戻します |
| スムーズ | レイヤー同士の境目をやわらげます |
| シャープ | いちばん強いレイヤーを勝たせて、境目をくっきりさせます |
| ノイズ | 指定した**サイズ**の雲のような形の部分にだけ作用します。苔、枯れ草、砂利に向いています |
| 傾斜 | 地面が2つの角度のあいだにある場所にだけ作用します。`30`から`90`なら、30°より急なところに岩が置かれます |
| 高さ | 2つのワールドの高さのあいだにだけ作用します。水際の砂や、森林限界より上の雪に向いています |

傾斜と高さのモードなら、巨大なブラシも安心して使えます。傾斜モードで丘ほどの大きさのブラシを使っても、崖だけが岩に変わります。

バーの2つ目のメニューはフォールオフで、強さがブラシの中心から縁に向かってどう弱まるかを決めます。

| フォールオフ | 形 |
| --- | --- |
| スムーズ | ゆるやかに弱まる、ふつうの選択です |
| リニア | 中心から縁まで均等に弱まります |
| 一定 | 円盤全体が同じ強さで、くっきりした縁になります |
| スプレー | ランダムな細かい点で、小石や花に向いています |

Shiftを押すと、描画、ノイズ、傾斜、高さが消去になり、Ctrlを押すとスムーズになります。Ctrl+ホイールでブラシの大きさが変わります。

（注意：バーのさらに右にある**ブレンドマテリアルを設定**、**繰り返し**、**タイル解消**、**シャープ**、**タイリングを適用**は、ブラシの面をブレンドするためのもので、地形はそれらの設定をレイヤーから受け取ります。）

## 自動ペイント { #auto-paint }

自動ペイントは、地形の形から塗り直します。手でペイントする前の、手早い最初の一手です。

1. 地形を選ぶ

    自動ペイントは、選択した地形にしか作用しません。

2. 実行する

    *地形 > ブレンド > レイヤーを自動ペイント*を開くか、インスペクターの**自動ペイント**をクリックします。

    ![地形 > ブレンドメニューで、レイヤーを自動ペイントにカーソルを重ね、海抜からの帯域がy 0でオンになっているところ](../assets/terrain-painting/menu-auto-paint.png)

| レイヤー | 置かれる場所 |
| --- | --- |
| 1 | 約50°より急な斜面 |
| 2 | 高さの範囲の上位20% |
| 3 | 高さの範囲の下位8% |

そのほかはすべてレイヤー0です。レイヤーが少ない地形では、足りない帯域は最後のレイヤーに入ります。

範囲は最も低い点から始まりますが、島では、それは海底です。**海抜からの帯域**にチェックを入れると、代わりに指定した高さから測ります。上の例では、水際のy 0です。

![自動ペイントの前の海の島。一面の草](../assets/terrain-painting/auto-paint-before.jpg)

![自動ペイントの後の同じ島。崖に岩、山頂に土、浜辺に沿って砂](../assets/terrain-painting/auto-paint-after.jpg)

> [!WARNING]
> 自動ペイントはすべてのペイントを置き換えます。そのため、先にスカルプトをして、自動ペイントをかけ、手でのペイントは最後にしてください。

## どこまで細くペイントできるか { #how-narrow-you-can-paint }

ペイントは頂点に保存されるので、きれいな帯にするには、ストロークの半径がセル2つ分ほど必要です。セル1つより小さいと階段状になります。細い道を作るなら、セルを小さくするか、メッシュや[デカール](decals.md)を上に重ねてください。

![64ユニットのセルで半径40、96、160のストロークを、ペイントを保持する頂点のグリッドと並べたところ](../assets/terrain-painting/brush-width-grid.jpg)
