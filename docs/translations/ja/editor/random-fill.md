# ランダム塗りつぶし { #random-fill }

*ブラシ > ランダム塗りつぶし…*は、セルのグリッドを、[プレハブライブラリ](prefab-library.md)の部品で覆います。各セルの部品は、重みに応じて選ばれます。オフィスの部屋、廊下、柱のグリッド、開けた床のような小さなキットを作っておけば、塗りつぶしがそこから間取り全体を組み上げます。シードが違えば別の間取りになり、同じシードならいつも同じ間取りになります。

1. 部品を作る

    部品はそれぞれ、セル1つ分の幅（デフォルトでは128ユニット）で、原点を中心に作ります。壁はセルの境界に置かないでください。そうすれば、隣り合う部品がいつもつながります。

    それからライブラリに追加します。部品を選び、プレハブタブの上にある**選択範囲を追加**を開いて、**位置を維持**にチェックを入れ、名前を付けて**追加**をクリックします（[自分の部品](prefab-library.md#your-own-pieces)を参照）。

    ![選択範囲を追加を開き、位置を維持にチェックを入れたプレハブタブ。ツールチップに、マップの原点を部品の原点として保ちます。ランダム塗りつぶし用のキットのようなものです、と出ている](../assets/random-fill/prefabs-keep-position.png)

2. ダイアログを開く

    *ブラシ > ランダム塗りつぶし…*を開きます。

    ![ブラシメニューで、ランダム塗りつぶし…にカーソルを重ねたところ](../assets/random-fill/menu-random-fill.png)

3. 部品を追加する

    **パーツを追加…**から部品を1つずつ選び、**重み**を付けます。重み6の部品は、重み3の部品の約2倍のセルを埋めます。**回転**にすると、部品が90度の倍数のランダムな角度で回ることがあります。

    ![ランダム塗りつぶしダイアログ。3つの部品とその重み、空の重み4、12 x 8のグリッドと、その色分けされたプレビュー](../assets/random-fill/random-fill-dialog.png)

4. （任意）いくつかのセルを空けておく

    **空の重み**は、何も置かない部品のように働きます。

5. グリッドを置く

    床を選んで**選択に合わせる**をクリックするか、**セル**のサイズ、**セル数**、**コーナー**を自分で設定します。

6. （任意）部品をクラスタにまとめる

    **クラスタリング**は、各部品を、約**まとまりの大きさ**のセルのかたまりに集めるので、全部が均等に混ざるのではなく、オフィスの棟が柱のホールの隣に並びます。

7. 塗りつぶす

    色分けされたグリッドが、部品ごとに1色で、配置のプレビューになります。**塗り潰し**をクリックすると塗られ、**再抽選**は、直前の塗りつぶしを次のシードのものに置き換えます。

    ![四角と丸の柱と、積んだ木箱で埋めた床。いくつかのセルは空いている](../assets/random-fill/random-fill-result.jpg)

塗りつぶしの結果は、普通のコピーを1つにまとめたグループなので、手で置いたものと同じようにベイクとビルドができ、あとからどのセルも編集できます。各コピーのエンティティ名には、それぞれ専用の接頭辞`rf<seed>_<n>-`が付くので、タイマーでちらつくランプのように配線済みのエンティティを持つ部品も、どのセルでも単独で動きます。

> [!TIP]
> 違う種類のディテールは、同じグリッドに対して別々のパスで塗りましょう。たとえば、壁用に1回、天井のライト用に1回と、それぞれに重みを付けます。ライトなら、動いているものの中に、切れているものやちらつくものを少し混ぜられます。

## MCP { #mcp }

`random_fill`ツールは、`pieces`を`[{name, weight, rotate}]`の形で受け取り、ほかに`empty`、`min`、`cell`、`cells`、`seed`、`cluster`、`cluster_size`を取ります。`preview: true`にすると、配置をスケッチとして返すだけです。`replace`は、先に前回の塗りつぶしを取り除きます。
