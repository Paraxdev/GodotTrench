# 画面構成と操作 { #interface-and-navigation }

TrenchDotはTrenchBroomとHammerに倣っているので、どちらかを使ったことがあれば、慣れた操作の大半がそのまま使えます。使ったことがなければ、このページで全体を案内します。すでに知っている考え方との対応は、[UnityやBlenderから来た方へ](coming-from-unity-blender.md)にまとめています。

## ウィンドウ { #the-window }

![小さな部屋を開いたエディター。左にアウトライナー、中央に3D、上面、正面、側面のビュー、右にインスペクター、下にマテリアルパネルがある](../assets/interface/window.png)

メニューは上部にあります。コマンドは、それが変更する対象の種類の下にあるので、CSGは*ブラシ*の下に、地形のスカルプトは*地形*の下にあります。

見つからないものがありますか。Ctrl+Shift+P（またはF1）でコマンドパレットを開いて、名前を入力してください。*中空化*や*UVロック*のように専門用語の名前が付いたコマンドは、カーソルを合わせると説明が出て、パレットでも一覧の下に同じ一行が表示されます。Escapeか外側のクリックで、何も実行せずに閉じます。

![hollowと入力したコマンドパレット。ショートカット付きでブラシ: 中空化が選ばれていて、その下に説明の一行がある](../assets/interface/command-palette.png)

ツールバーのすぐ下が**ツールオプションバー**です。有効なツールの設定が並び、設定のないツールなら、使い方を一行で説明します。そこでツールの名前に、またはツールバーのそのボタンにカーソルを合わせると、短い説明が表示されます。

![選択ツールにカーソルを合わせたツールオプションバー。ツールチップがツールを説明し、最後にF1：マニュアルとある](../assets/interface/tool-options-tooltip.png)

### 空のマップのカード { #the-empty-map-card }

新しい空のマップでは、3Dビューのカードがどこから始めればよいかを教えてくれます。上面ビューでドラッグして最初のボックスを描きましょう。上面ビューでは、その場所を黄色のラベルが示します。その下には3Dカメラの説明と、[はじめの一歩のガイド](../getting-started.md)へのリンクがあります。開いているプロジェクトにマップがあれば、**このプロジェクトのマップを開きます**に一覧が出るので、完成したマップを代わりに開けます。

![3Dビューの空のマップのカード。はじめにガイド、このプロジェクトのマップを開きます、ヒントを隠すがあり、上面ビューの黄色のラベルが隣にある](../assets/interface/empty-map-card.png)

マップに何か入ると、カードは消えます。**ヒントを隠す**でヒントがオフになり、*ファイル > 環境設定*の*空のマップでヒント表示*でまた表示できます。

### パネル { #panels }

| パネル | 位置 | 用途 |
| --- | --- | --- |
| アウトライナー | 左 | マップを[レイヤー、グループ](organizing.md)とオブジェクトのツリーとして表示する |
| 履歴 | 左 | すべての編集。クリックするとそれ以降もまとめて元に戻り、薄く表示された項目をクリックすると、そこまでやり直す |
| 問題 | 左 | 作業中に見つかった、マテリアルのない面などの問題。クリックするとオブジェクトが選択され、ほとんどには修正の提案がある |
| インスペクター | 右 | 選択したもののプロパティ。エンティティのキーや、ブラシの正確な位置とサイズなど |
| エンティティ | 右 | ビューにドラッグして置くエンティティクラス |
| UV編集 | 右 | [正確なテクスチャの配置](uv-editor.md) |
| 散布 | 右 | [散布](scatter.md)ツールが塗るモデル |
| マテリアル | 下 | プロジェクトのテクスチャ |
| モデル | 下 | 配置する[モデルファイル](models.md) |
| プレハブ | 下 | [プレハブライブラリ](prefab-library.md)にある、貼り付けられる出来合いのパーツ |
| ロジック | 最初は閉じている | [グラフで見るエンティティの配線](../gameplay/logic-graph.md)。エンティティをつなぎ、出力が何を引き起こすかをプレビューする |
| リファレンス | 最初は閉じている | スクリプトからエンティティクラスを使うためのコード |

うっかりパネルを閉じてしまいましたか。*表示 > パネル*からまた開けます。同じメニューの下部にある*レイアウトをリセット*で、すべてが最初の配置に戻ります。

![表示メニューでパネルが開き、表示中のパネルにチェックが入っていて、下部にレイアウトをリセットがある](../assets/interface/view-panels-menu.png)

## ヘルプとマニュアル { #help-and-the-manual }

ツールチップが、ボタン、タブ、設定を説明します。もっと知りたいときは、ツール、パネルのタブ、メニュー項目、インスペクターのセクションのどれかにポインターを合わせて**F1**を押すと、このマニュアルの該当ページが開きます。ツールバーのツールをCtrl+クリック（macOSではCmd+クリック）しても同じです。*F1：マニュアル*で終わるツールチップには、対応するページがあります。それ以外の場所でF1を押すと、コマンドパレットが開きます。

*ヘルプ > マニュアル*は、マニュアルの最初のページを開きます。

![ヘルプメニューでマニュアルにカーソルが合っている](../assets/interface/help-menu.png)

操作に慣れたら、*ファイル > 環境設定*の*ヘルプテキスト*のチェックを外すと、ツールオプションバーとパネルにある短い案内の行を隠せます。ツールチップは残ります。

（注：リンクはWebブラウザーで開きます。ブラウザーが開かないときは、ステータスバーにそう表示され、リンクがクリップボードにコピーされます。）

## ビュー { #views }

ビューは、3D、上面、正面、側面です。2Dビューは1つの軸に沿ってまっすぐ見るので、位置を揃えやすくなります。何かを選択していると、その上に幅、横に高さが表示されます。

![ボックスのブラシを選択した正面ビュー。上に96、横に48と表示されている](../assets/interface/front-view-size-labels.png)

2Dビューでのクリックは、ビューに沿っていちばん近いオブジェクトを選択するので、上面ビューでは、天井がその下の壁を隠します。同じ場所で1.5秒ほどのうちにもう一度クリックするか、いつでもAlt+クリックすると、カーソルの下の次のオブジェクトに移ります。

| 操作 | 結果 |
| --- | --- |
| 仕切りが交わる点をドラッグ | 4つのビューを同時にリサイズする |
| Shift+Space | ポインターの下のビューを最大化し、もう一度押すと元に戻す |
| *表示 > ビュー* | 1つ、2つ、4つのビューを切り替えるか、閉じたビューを戻す。1ビューでは最後に作業したビュー（最初は3Dビュー）が残り、1つのビューを表示している間に別のビューの名前を選ぶと、そちらに切り替わる |

![表示メニューでビューが開き、4つのビューにチェックが入り、1ビュー、2ビュー、4ビューと、Shift+Spaceのビューを最大化がある](../assets/interface/view-views-menu.png)

## タブ { #tabs }

開いているマップごとにタブができ、2つ以上開くと、ツールオプションバーの下にタブバーが表示されます。Ctrl+Shift+N（または**+**ボタン）で新しいタブを開き、Ctrl+Tabで切り替え、Ctrl+Wで閉じます。

![room.tdmとuntitled.tdmが開いているタブバー。+ボタンにカーソルを合わせ、新規タブと表示されている](../assets/interface/map-tabs.png)

現在のマップに未保存の変更があるとき、*新規マップ*とインポートは新しいタブで開きます。変更したタブを閉じるときは、保存、破棄、キャンセルのどれかを尋ねられ、終了するときは、未保存のマップがすべて一覧に出ます。

## カメラ { #camera }

| 入力 | 3Dビュー | 2Dビュー |
| --- | --- | --- |
| 右ドラッグ | 見回す。WASDで移動、QとEで下降と上昇、Shiftで速度が3倍 | パン |
| 中ドラッグ | パン | パン |
| ホイール | 前後に動く。まっすぐ前にある面が遠いほど速い | カーソルに向かってズーム |
| Alt+左ドラッグ | 周回する。ただし選択範囲の上でドラッグを始めると、垂直に移動する | |

WASDで飛び回れるのは右ボタンを押している間だけで、それ以外のときはこれらのキーはショートカットです。操作を忘れましたか。ビューのタブにカーソルを合わせてください。初めて見回すまでは、3Dビューの上にポインターがあるとき、名前の下にも操作が表示されます（空のマップのカードの**ヒントを隠す**でオフにできます）。

**F**は、すべてのビューで選択範囲にフォーカスし、何も選択していないときはマップ全体にフォーカスします。ホイールを1ノッチ回すと、どのズーム倍率でも2Dビューが同じ倍率でズームするので、大きな地形全体から1つの部屋まで寄るには約20ノッチかかります。その部屋で**F**を押すほうが早いでしょう。

Ctrl+Shift+1から9で3Dカメラをブックマークとして保存し、Ctrl+1から9で戻ります。ブックマークはマップに保存され、元に戻す操作の影響を受けません。

## シェーディング { #shading }

F4を押すと、3Dビューが、テクスチャ付き、フラット、ライトプレビュー、ワイヤーフレームの順に切り替わり、ビューの左上にモードが表示されます。マップに[ベイク](light-baking.md)があるときは、ライトプレビューの次に**ベイクしたライティング**が入ります。F3は、ほかのモードを巡らずに、**ライトプレビュー**とテクスチャ付きの間を直接行き来します。

![3Dビューが、テクスチャ、フラット、ライト、ワイヤーフレームのシェーディングを巡る](../assets/interface/shading-cycle.gif)

ライトプレビューは、Godotでビルドしなくても、マップのライト、太陽の影、空、フォグを表示します。描画されるのは、強い順に64個までのポイントライトとスポットライトだけなので、それよりずっと多いマップは、Godotより暗く見えることがあります。

## テーマ { #theme }

TrenchDotにはダークとライトの2つの見た目があります。インストール直後はダークで始まります。

1. **ファイル > 環境設定**を開きます。**テーマ**は、ウィンドウの最上部にある最初の行です。
2. ドロップダウンをクリックして、**ダーク**、**ライト**、**システム**のどれかを選びます。

    ![環境設定のテーマのドロップダウン。開いてダーク、ライト、システムが並んでいる](../assets/interface/preferences-theme.png)

3. 次のフレームでエディター全体が変わり、再起動は要りません。選んだ内容はほかの環境設定と一緒に保存されます。

    ![ライトテーマのエディター。メニューバー、アウトライナー、3Dビュー、上面ビューが見えている](../assets/interface/theme-light-window.png)

**システム**は、お使いのOSのライトまたはダークのアプリモードに従い、それに合わせて変わります。選んでいる間は、ドロップダウンに*システム (ライト)*または*システム (ダーク)*と表示されるので、システムが何を返したか分かります。システムがモードを報告しない環境では、エディターはダークのままです。

**表示 > テーマ**でも選べます。場所は*インターフェース倍率*のすぐ下です。コマンドパレットなら、*表示: テーマ: ダーク*、*ライト*、*システム*です。初期状態ではキーは割り当てられていませんが、キーマップエディターで、それぞれにキーを割り当てられます。

ライトでは、2Dビュー（上面、正面、側面）が紙のような見た目になり、明るい灰色の背景に、暗いグリッド線とブラシのエッジが表示されるので、描いた線がひと目で分かります。3Dビューは、どちらのテーマでも暗い周囲のままで、UV編集とホットスポットエディターのテクスチャキャンバスも同じです。テクスチャはどちらのテーマでも同じ見た目で、周囲が明るいと色の見え方の判断が変わってしまうからです。

<div class="td-mcp" markdown>

[MCPサーバー](../mcp.md)からは、`set_editor`に`"theme": "light"`を渡すとテーマが切り替わります。値は`dark`、`light`、`system`で、不明な値はエラーになり、何も変わりません。`get_state`は、選択を`ui.theme`、画面に表示されているものを`ui.theme_active`として報告します。

</div>

## 言語 { #language }

メニュー、パネル、ツールチップ、ステータスメッセージは、英語、ドイツ語、フランス語、スペイン語、ポルトガル語、ロシア語、簡体字中国語、日本語で表示できます。インストール直後は英語で始まります。

1. **ファイル > 環境設定**を開きます。**言語**は2行目で、**テーマ**のすぐ下です。
2. ドロップダウンをクリックして、使う言語を選びます。どの言語もその言語自身の名前で並んでいるので、エディターが読めない言語になっていても、自分の言語を見つけられます。

    ![環境設定の言語のドロップダウン。開いてEnglish、Deutsch、Français、Español、Português、Русский、简体中文、日本語が並んでいる](../assets/interface/preferences-language.png)

3. エディター全体がすぐに切り替わり、再起動は要りません。選んだ内容はほかの環境設定と一緒に保存されます。

    ![ドイツ語のファイルメニュー](../assets/interface/language-file-menu-de.png)

英語以外の言語にしている間は、この行が、たとえば*言語 (Language)*のように表示されるので、いつでも元に戻る道が見つかります。コマンドパレットでも、*表示: 言語: Deutsch*のように言語を選べます。パレットは英語の名前でも検索するので、同じコマンドがどの言語でも使えます。初期状態ではキーは割り当てられていませんが、キーマップエディターで、各言語にキーを割り当てられます。

翻訳はAIが書いたもので、ネイティブの方による確認はまだ行われていません。行の下の注記にもそう書いてあります。まだ翻訳のないテキストは英語で表示され、このバージョンが知らない言語も同様です。翻訳がおかしいと感じたら、[その言語のロケールファイル](https://github.com/Paraxdev/TrenchDot/tree/main/crates/td_editor/locales)で直せます。[翻訳](../development.md#translations)を見てください。

> [!NOTE]
> マニュアルはエディターの言語に従います。言語を選んでいると、ツール、パネル、メニューの上で押す**F1**や、**ヘルプ**メニューの項目で、そのページのあなたの言語版が開きます。マニュアルのヘッダーにある言語ボタンで、そこでの言語を切り替えられます。まだ翻訳されていないページや、翻訳後に変更されたページは、上に注記が付いた英語で表示されます。スクリーンショットは英語のエディターなので、同じ項目をあなたの言語で探すか、英語の名前をコマンドパレットに入力してください。エンティティのクラス名、マップのキー、ファイル形式、ログ、[MCPサーバー](../mcp.md)は、どの言語でも英語のままです。

<div class="td-mcp" markdown>

[MCPサーバー](../mcp.md)からは、`set_editor`に`"language": "de"`を渡すと言語が切り替わります。値は`en`、`de`、`fr`、`es`、`pt`、`ru`、`zh-Hans`、`ja`で、大文字小文字は問いません。不明な値はエラーになり、使える値がすべて示され、何も変わりません。`get_state`は、選択を`ui.language`として報告します。ツール名、応答、エラーは、どの言語でも英語のままです。`--default-prefs`で起動したエディターは英語で、e2eテストはそれに頼っています。

</div>

## インターフェースのスケール { #interface-scale }

Ctrl+=とCtrl+-でインターフェースを拡大縮小し、Ctrl+0でリセットします。同じ設定は、*ファイル > 環境設定*の最上部にある*UIスケール*にもあります。モニターが間違ったディスプレイスケールを報告するときは、そのすぐ下の*モニターに従う*のチェックを外してください。

![環境設定ウィンドウの上部。テーマはダーク、言語はEnglish、UIスケールは100%、ディスプレイスケールはモニターに従うにチェックが入り、その下に空のマップでヒント表示とヘルプテキストがある](../assets/interface/preferences-scale-and-tips.png)
