# 保存と復元 { #saving-and-recovery }

Ctrl+Sで保存し、*別名で保存…*はCtrl+Shift+Sです。ファイルダイアログは、現在のマップのフォルダで開きます。まだ保存していないマップでは、Godotプロジェクトのフォルダで開きます。アドオンはマップを`res://`パスで読み込むためです。プロジェクト内のマップをさっと開きたいときは、*ファイル > プロジェクト内のマップ*にすべてのマップが並んでいます。

## バックアップと自動保存 { #backups-and-autosave }

エディターは、マップの隣に2種類の予備コピーを作ります。

| ファイル | 書き込まれるタイミング |
| --- | --- |
| `<map>.tdm.bak` | 保存のたびに、直前のバージョンのコピーが書き込まれます。拡張子を`.tdm`に変えると、1回前の保存に戻せます |
| `<map>.tdm.autosave` | 3分ごとに、未保存の変更があるすべてのタブについて書き込まれます |

自動保存の間隔を変えるには、*ファイル > 環境設定*を開いて、*自動保存（分、0でオフ）*を設定します。

![環境設定の自動保存（分、0でオフ）の欄が3になっているところ](../assets/saving/prefs-autosave.png)

自動保存はGodotがインポートしない拡張子を使うので、作りかけのマップがゲームに現れることはありません。マップを保存すると、その自動保存は削除されます。

## マップを復元する { #recovering-a-map }

保存する前にエディターが閉じてしまったときは、自動保存を開きます。

1. *ファイル > マップを開く…*を選びます。
2. ファイルの種類で**自動保存（マップを復元）**を選び、`.tdm.autosave`ファイルを開きます。ステータスバーに、自動保存からマップを復元したと表示されるはずです。
3. 保存します。これで本物の`.tdm`が書き込まれます。

一度も保存していないマップは、代わりに一時ファイルに自動保存されます。それは*ファイル > 最近開いたもの*の、*自動保存された無題マップ*の下にあります。

![最近のマップなしが先頭にあり、その下に自動保存された無題マップの一覧がある、ファイル > 最近開いたもの](../assets/saving/open-recent-autosaves.png)

## 壊れたファイル { #damaged-files }

ディスク上で壊れたマップファイルも、開くことができます。エディターは無事な部分をすべて読み込み、レイヤー、グループ、エンティティが失われたオブジェクトは*Recovered*という名前のレイヤーに入れて、読み込めなかったものをステータスバーに表示します。保存すると、壊れた元のファイルは`<map>.tdm.bak`として残るので、バージョン管理から復元することもできます。
