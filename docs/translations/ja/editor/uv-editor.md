# UV編集 { #uv-editor }

UV編集は、選択したブラシとメッシュの面を、タイル状に敷いたテクスチャの上に平らに描くので、各面にテクスチャのどの部分が出ているかがひと目でわかります。[テクスチャツール](texturing.md#the-texture-tool)では3Dビューでできないこと、たとえばメッシュのUVをピクセル単位で置くような作業に使ってください。

## 開く { #opening-it }

UV編集は、右パネルのインスペクターの隣にあるタブで、*テクスチャ > UV編集*でも呼び出せます。そのあと面を選びます。ビューで面をShift+クリックするか、テクスチャツールを使ってください。一番上の行に、マテリアルの名前と選んだ面の数が表示されます。

![UV編集で壁の面を1つ選んだところ。タイル状に敷いたshowcase/plasterテクスチャの上に、オレンジ色の四角形で描かれている](../assets/uv-editor/uv-editor-face.png)

> [!TIP]
> UV編集がパネルで表示されているタブのあいだは、ブラシやメッシュをCtrl+クリックするとすべての面が選ばれるので、全面に一度にテクスチャを貼れます。すでに選択してあったブラシやメッシュも、その面に切り替わります。選択に地形やエンティティなどほかのものが含まれているときは、Ctrl+クリックはいつもどおりオブジェクトの追加と削除になります。

ブラシの面は、ふつう1つのオフセット、スケール、回転からテクスチャを受け取ります。**明示的なUV**を持つ面は、代わりに角ごとにテクスチャ上の位置を保存していて、メッシュにはそれが必要です。UV編集はそうした面を青で描き、角を1つずつ選べます。オレンジの面には明示的なUVがなく、全体でひとかたまりに動きます。

## 操作 { #controls }

一番上の行の端にある**?**でも、エディターの中でこれを確認できます。

| 入力 | 結果 |
| --- | --- |
| 何もない場所をドラッグ | テクスチャを動かします。面が明示的なUVを持つときは面全体を動かします |
| ホイール、右ドラッグ | 拡大縮小、回転 |
| 角をクリック | その角と、それにステッチされた隣の面の角をまとめて選びます |
| Shift+クリック、Ctrl+クリック | 追加、削除 |
| Alt+クリック | その面の角だけを選び、ステッチを分けます |
| 何もない場所でShiftまたはCtrl+ドラッグ | ボックス選択で、追加または削除します |
| 選択した角をドラッグ | 選択全体を動かします |
| 角をダブルクリック | UかVの方向にだけ動くギズモが出ます。Escapeで隠れます |
| 中ドラッグ、Ctrl+ホイール | キャンバスのパン、ズーム |

角を選んでいるときは、ホイールと右ドラッグで、その中心を軸に拡大縮小と回転ができます。キャンバスの下にあるUとVの欄では、選択をピクセル単位で配置できます。

メニューのあとにある小さなボタンで、ピクセルスナップの切り替え、テクスチャのホットスポットの表示、ふつうのドラッグをボックス選択にする切り替え、ギズモの表示、UVロックの切り替え、面を画面に収め直す操作ができます。どれがどれかは、カーソルを合わせると確認できます。

## メッシュのUV投影 { #mesh-uv-projections }

メッシュの面を選んでいるとき、**投影**メニューが明示的なUVを自動で配置します。同じテクスチャを貼ったブラシの面と同じテクセル密度を使うので、メッシュが周りのブラシとそろいます。項目にカーソルを合わせると、一行の説明が出ます。

![UV編集の投影メニューを開いたところ。円柱 Yにカーソルを重ね、ツールチップにこのワールド軸のまわり、面の中心を通るように巻きつけ、uはその周りを回る、と表示されている](../assets/uv-editor/projection-menu.png)

| コマンド | 結果 |
| --- | --- |
| *平面*、*平面 X*、*Y*、*Z* | 面がおもに向いている方向か、ワールドの1つの軸に沿って投影し、面を1つにまとめたままにします |
| *ボックス* | 面ごとに、いちばん近いワールド軸から投影します。角ばった形向けです |
| *円柱 X*、*Y*、*Z*、*球* | 面のまわりにテクスチャを巻きつけます。パイプ、柱、ドームに向いています |
| *表示* | 3Dカメラの方向にまっすぐ投影します |
| *展開* | 面を辺ごとに平らに並べるので、帯状やグリッド状の面がつながったままになります |
| *ワールドにリセット* | リセットしたばかりのブラシの面と同じ投影です |
| *平面ベイク* | 平面のテクスチャを、編集できる角のUVに変えます。明示的なUVをまだ持たない面があるときに表示されます |
| *UVをクリア* | 明示的なUVをもう一度捨てます |
| *正規化* | UVをテクスチャ1枚分に収まるように拡大縮小します |
| *パック* | アイランドを同じテクセル密度でテクスチャに詰め込みます |

ここでは、12角形の柱に*円柱 Y*を使いました。側面は、テクスチャのまわりを一周する1本の帯として並びます。

![12角形のメッシュの柱に円柱 Yを使ったあとのUV編集。側面の面が、つながった1本の帯として並んでいる](../assets/uv-editor/uv-editor-cylinder.png)

**UV**メニューでは、反転、回転、フィット、整列、まっすぐにする、ピクセルへのスナップができます。**ホットスポット**メニューでは、ホットスポットの矩形にフィットさせます。[ホットスポット](texturing.md#hotspots)を参照してください。
