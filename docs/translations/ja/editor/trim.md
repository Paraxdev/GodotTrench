# トリム { #trim }

*ブラシ > トリムを追加…*は、面のエッジに沿って、面から張り出す形でブラシの帯を並べます。壁の下端に沿えば幅木、上端に沿えば廻り縁、床の周りなら縁取り、プールの周りなら縁石になります。飾りのない部屋で、1クリックの前と後を見てみましょう。

![漆喰の部屋。出入り口があり、壁が選択されていて、まだトリムはない](../assets/trim/room-before.png)

![同じ部屋。壁の下端に沿って、出入り口まで続く暗い色の幅木が付いている](../assets/trim/room-after.png)

1. （任意）トリムのマテリアルを選ぶ

    Escapeを押して何も選択していない状態にし、マテリアルパネルでマテリアルをクリックします。マップは変わらず、そのマテリアルが現在のマテリアルになります。

2. 壁を選ぶ

    選んだブラシの垂直な面すべてにトリムが付きます。1つ1つの面だけに付けたいときは、代わりにShift+クリックで選びます。Ctrl+Shift+クリックで追加や解除ができます。

3. ダイアログを開く

    *ブラシ > トリムを追加…*を選びます。最初は現在のマテリアルが入っていて、あとから**現在を使用**を押すとまた現在のマテリアルに戻せます。下部には、見つかった面の数が表示されます。

4. 帯を設定する

    **エッジ**で、どこに付けるかを選びます。下、上、側面、またはすべてです。**高さ**は帯が面の上をどこまで伸びるか、**奥行き**はどれだけ張り出すか、**インセット**はエッジと帯の間にあける隙間です。

    ![トリムを追加ダイアログ。エッジは下、高さ6 u、奥行き2 u、インセット0 u、マテリアルはshowcase/planks_dark、エッジの下に床がある所だけにチェック、衝突はオフ、選択された面は20](../assets/trim/add-trim-dialog.png)

5. **トリムを追加**をクリックする

    ステータスバーに、いくつの帯を作ったかが表示されます。

**衝突**がオフの間（初期設定です）、帯は`func_detail_illusionary`に入るので、プレイヤーが引っかかりません。チェックを入れるか、このエンティティのないゲームを使っている場合は、帯は通常のグループに入ります。

トリムを付けた2つの面が接するところでは、一方の帯が角まで伸び、もう一方がそこで止まるので、帯が重ならずに角が閉じます。独立して立つ壁の端や出入り口の周りでは、帯が回り込みます。2枚の壁の間のまぐさの端のように、他のブラシの内側に入り込んでしまう帯は作られません。

**エッジの下に床がある所だけ**にチェックを入れると、下のトリムは何かの上に立っているエッジだけに付きます。そのため、出入り口の上のまぐさの下側には幅木が付きません。

> [!TIP]
> トリムは普通のブラシです。あとから、1本ずつテクスチャを貼り直したり、削除したり、形を変えたりできます。

## MCP { #mcp }

`trim`ツールは、`faces`（`[[brush, face], ...]`の形）、ブラシの`ids`、または選択範囲に加えて、`edges`、`height`、`depth`、`inset`、`material`、`on_floor`、`collision`を受け取ります。作られた新しいグループまたはエンティティと、作った帯の数を返します。
