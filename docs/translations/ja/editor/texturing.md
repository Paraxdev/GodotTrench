# テクスチャ貼り { #texturing }

## マテリアルを適用する { #applying-materials }

テクスチャは、ウィンドウ下部、ビューの下にある**マテリアル**パネルに入っています。左上の検索ボックスで名前から絞り込め、**マップで使用中**と**お気に入り**で一覧を絞り、スライダーでサムネイルのサイズを決めます。

![マテリアルパネル。検索ボックス、フォルダ一覧、マップで使用中、お気に入り、サイズのスライダーがあり、その下にマテリアルのサムネイルが並ぶ。dev/blueにカーソルを合わせると名前とサイズが表示されている](../assets/texturing/materials-panel.png)

| 操作 | 結果 |
| --- | --- |
| サムネイルをクリック | 選択範囲に適用し、新しいブラシにも使う |
| サムネイルを面にドラッグ | その面に適用する |
| Shiftを押しながらドロップ | ブラシまたはメッシュ全体に適用する |
| Altを押しながらドロップ | [デカール](decals.md)として置く |

ドラッグ中は、カーソルの横の小さなカードに修飾キーが表示され、離すとすぐに面が変わります。

![withered/mossy_plasterをレンガの壁の正面にドラッグしているところと、続いて正面の面だけに漆喰が貼られた同じ壁](../assets/texturing/drop-on-face.png)

ドラッグせずに1つの面にテクスチャを貼るには、先にビューでその面をShift+クリックして、サムネイルをクリックします。Ctrl+Shift+クリックで、面を追加したり外したりできます。

サムネイルを右クリックすると、さらにいろいろできます。お気に入りに追加する、それを使っている面を選択する、現在のマテリアルをマップ全体でそれに置き換える、ホットスポットエディターを開く、あるいは*ファイルマネージャーで表示*でテクスチャのフォルダをファイルを選択した状態で開く（たとえば編集するときに）、などです。

![サムネイルの右クリックメニュー。選択に適用、お気に入りに追加、これを使う面を選択、マップ内のshowcase/red_bricksをこれに置き換え、ホットスポットエディター、名前をコピー、ファイルマネージャーで表示](../assets/texturing/material-context-menu.png)

地形にマテリアルをドロップすると、代わりに地形レイヤーが設定されます。[地形レイヤー](terrain-layers.md)を見てください。

UVロック（Ctrl+Shift+U）は初期状態でオンなので、ブラシを動かしてもテクスチャはブラシに付いたままです。

## 組み込みの色 { #built-in-colors }

マテリアルパネルには、`dev/grey`、`dev/dark`、`dev/orange`、`dev/blue`、`dev/green`が常に用意されています。アートができる前のレベルをブロックアウトするためのグリッドテクスチャです。これらで部屋を色分けしておくと、ビルドしても残ります。アドオンが同じグリッドを同梱していて、その名前のテクスチャがプロジェクトにないときは、Godotがそれを使うからです。たとえば`res://textures/dev/grey.png`に自分のテクスチャを置くと、組み込みのものが置き換わります。

## ツールテクスチャ { #tool-textures }

エディターはツールテクスチャを縞模様の透けた表示で描き、Godotのビルドでは見た目のメッシュが作られません。`special/`、`tools/`、`td/`のフォルダにあるテクスチャはすべて対象で、`common/caulk`のように、下に挙げるツールのどれかの名前が付いたテクスチャも対象です。

![dev/darkのブロック、その手前の透けた紫のspecial/clipの壁、オレンジの縞模様のspecial/triggerのボックス](../assets/texturing/tool-textures.png)

| テクスチャ | Godotでは |
| --- | --- |
| `special/clip`、`playerclip`、`nodraw`、`caulk`、`trigger`、`sky`、その他のツール | 衝突はするが何も描かない。triggerはトリガーの形を保つ |
| `special/skip`、`origin`、`hint`、`hintskip`、`null`、`areaportal` | 何も作らない。これらの面だけのブラシは衝突もしない |
| `special/occluder` | 何も描かず、隣のものも隠さないが、`func_geo`のようにオクルーダーを作るエンティティでは、そのオクルーダーに加わる |

マップ設定では、クリップ、スキップ、原点、空のテクスチャを指定します。初期値は`special/clip`などです。原点ブラシは、マップ設定で指定したテクスチャのときだけ、そのエンティティの原点を決めます。

## テクスチャツール { #the-texture-tool }

面のアライメントとは、面の上でテクスチャがどこにあるかのことで、オフセット、スケール、回転で決まります。**Shift+T**を押すとテクスチャツールになり、Hammerの面編集モードのように、その場でアライメントを編集できます。面をクリックして選択します。選んだ面は赤く色づき、テクスチャ1回分の繰り返しを囲む青いボックスと、UとVの方向を示す短い線が2本表示されます。カーソルの下にある面には、黄色の輪郭が付きます。

![レンガの壁の正面の面を選択したテクスチャツール。青いボックスが、テクスチャ1回分の繰り返しを示している](../assets/texturing/texture-tool-face.png)

| 入力 | 結果 |
| --- | --- |
| クリック、Ctrl+クリック | クリックで面を選択し、Ctrl+クリックで面を追加または解除する |
| 選択した面をドラッグ | テクスチャをスライドする。カーソルの下のピクセルは、カーソルの下のまま |
| 矢印キー | グリッドサイズのピクセル数だけスライドする。Shiftでは1ピクセル |
| Ctrl+ホイール | 2倍の単位でスケールする。Shiftで細かいステップ |
| Alt+ホイール | 15°ずつ回転する。Shiftで1° |
| Alt+クリック | 面のマテリアルとアライメントを拾う |
| 右クリック | 現在のマテリアルを適用する |
| Ctrl+右クリック | 適用して、アライメントをリセットする |
| Shift+右クリック | 拾ったマテリアルとアライメントを貼り付ける |
| Alt+右クリック | 現在のマテリアルを適用し、選択した面のアライメントをエッジの向こうまで続ける |

トリムやレンガの列のようなテクスチャを角できれいに回り込ませるには、Alt+右クリックを使います。

画面上部のツールオプションバーには、**整列**ボタンがあります。**左**、**右**、**上**、**下**、**中央**は、テクスチャを面のその側へ寄せ、**合わせる**は面いっぱいに引き伸ばし、**幅合わせ**と**高さ合わせ**は横方向だけ、縦方向だけに引き伸ばします。**一体として扱う**にチェックを入れると、選択した面すべてを1つの領域として扱うので、1枚のテクスチャがそれらすべてにまたがります。**ビューに揃える**は、3Dカメラの方向にテクスチャを投影します。

![テクスチャツールのオプションバー。整列の左、右、上、下、中央、合わせる、幅合わせ、高さ合わせ、一体として扱う、ビューに揃える、ホットスポット合わせ](../assets/texturing/texture-tool-options.png)

数値のほうが好みなら、**インスペクター**の**アライメント**に同じ面が表示され、オフセット、スケール、回転の欄と、反転、回転、リセットのボタンがあります。その下の**テクスチャツール**では、テクセル密度を設定したり、面から面へアライメントをコピーしたりできます。

![面を1つ選択したインスペクター。オフセット、スケール、回転があるアライメントのセクション、整列ボタン、テクスチャツールのセクション](../assets/texturing/inspector-alignment.png)

明示的なUVを持つ面やメッシュには、[UV編集](uv-editor.md)を使います。

## テクスチャのスケール { #texture-scale }

初期状態では、テクスチャの1ピクセルがマップの1ユニットにあたるので、64ピクセルのテクスチャは2メートルごとに繰り返されます。低解像度のテクスチャには向いていますが、1024ピクセルの写真だと32メートルに引き伸ばされてしまいます。マテリアルの`metadata/texture_size`に、1回の繰り返しが覆うワールドでのサイズを設定してください。[テクスチャサイズ](../godot/materials.md#texture-size)を見てください。マテリアル名の下にあるインスペクターの行には、「1024 x 1024 px, 64 x 64 units a repeat」のように、面がどうなったかが表示されます。

1つのマップだけに設定したいときや、すべての面にまたがってテクスチャを継ぎ目なく流したいときは、インスペクターの[テクスチャ設定](light-baking.md#texture-settings)を使います。そちらの繰り返しサイズが、マテリアルのものより優先されます。

## ホットスポット { #hotspots }

ホットスポットを使うと、1枚のトリムシートで、形がさまざまな多くの面にテクスチャを貼れます。矩形を一度指定しておくと、TrenchDotが面ごとにふさわしいものを選びます。

1. マテリアルパネルでトリムシートを右クリックして、**ホットスポットエディター**を選びます。*テクスチャ > ホットスポットエディター…*でも開き、選択した面のマテリアル、なければ現在のマテリアルが対象になります。

    ![テクスチャメニュー。ホットスポットエディター…にカーソルが合っていて、下部にホットスポット合わせ（Alt+H）がある](../assets/texturing/menu-texture.png)

2. テクスチャの上をドラッグして矩形を描くか、グリッドを設定して**グリッドに分割**をクリックします。矩形をドラッグすると移動、角のハンドルをドラッグするとサイズ変更、右クリックで削除です。
3. **保存**をクリックします。矩形は、テクスチャファイルの隣の`<texture>.hotspots.json`に入ります。
4. 面を選んで、*テクスチャ > ホットスポット合わせ*（Alt+H）か、エディターの**選択に適用**を使います。

![withered/concrete_panelsを4×4のグリッドに分割したホットスポットエディター。矩形は16個で、未保存](../assets/texturing/hotspot-editor.png)

ホットスポット合わせは、各面に、形がいちばん合う矩形を割り当てます。テクスチャが通常のスケールに近いままになる矩形を優先します。

## 頂点ペイント { #vertex-paint }

**ペイント**ツール（P）は、汚れ、色付け、擬似的なライティングのために、ブラシの面に頂点カラーを塗ります。ツールオプションバーのブラシの半径と強さの隣で色を選び、面の上をドラッグしてください。選択したブラシに塗られ、何も選択していないときはすべてのブラシに塗られます。Ctrl+ホイールでブラシのサイズを変えられます。

![ペイントツールのオプションバー。色のスウォッチ、半径48 u、強さ4.0](../assets/texturing/paint-tool-options.png)
