# 地形レイヤー { #terrain-layers }

地形には1枚から4枚のレイヤーがあり、それぞれがマテリアルと、その繰り返し方についていくつかの設定でできています。地形を選ぶと、インスペクターに表示されます。レイヤーは地面を分け合うので、草の上に砂をペイントすると、草の割合がその分だけ減ります。

![4枚のレイヤーを持つ地形のインスペクター。各レイヤーにマテリアル、タイル、タイル解消、シャープがある](../assets/terrain-layers/layers-inspector.png)

| やりたいこと | 方法 |
| --- | --- |
| レイヤーを追加する | レイヤーの下にある**+ レイヤー (現在のマテリアル)**を使います。マテリアルパネルで最後にクリックしたマテリアルが使われます。地形のレイヤーが4枚に満たないあいだ表示されます |
| 最後のレイヤーを削除する | **- 最後のレイヤー** |
| レイヤーのマテリアルを変える | レイヤーの欄に名前を入力するか、マテリアルパネルから地形にマテリアルをドラッグします。インスペクターの一番下の行に、ドロップがどのレイヤーに入るかが表示され、ブレンドツールが有効なときは、そのツールがペイントするレイヤーです |

**レイヤー0がベースの地面です。** ペイントしていない地面にはレイヤー0が表示され、消しゴムで消すとそこに戻るので、いちばんよく使う地面、たいていは草をここに入れてください。

新しい地形には、*地形を作成*ダイアログで指定したレイヤーが入り、デフォルトでは4枚です。地形にまだないレイヤーのためにマテリアルをドロップすると、次のレイヤーとして追加されます。

## タイルとタイル解消 { #tile-and-de-tiling }

広い範囲に同じテクスチャを繰り返すと、遠くからはグリッドの模様が見えてしまいます。次の設定は、近くで見たときの鮮明さと引き換えに、その模様を隠します。

| 設定 | 意味 |
| --- | --- |
| タイル | テクスチャの1回の繰り返しが何マップユニットを覆うかです。歩く地面には128から384がよく合います |
| タイル解消 | 0から1です。繰り返しごとにランダムに回転とずらしを加えて、グリッドが見えなくなるようにします |
| シャープ | 0から1で、タイル解消が0より大きいと表示されます。0はずらした繰り返しを均等にブレンドするので、やわらかく見えます。1は継ぎ目に沿ってだけブレンドするので、テクスチャがくっきり保たれます |

タイルが小さいと近くでは鮮明ですが、遠くでは繰り返しがはっきり見えてしまい、大きいと足元でぼやけます。タイル解消は、タイルを大きくせずに繰り返しを隠せますが、テクスチャの読み込みが増えるので、繰り返しが目立たない場所では0のままにしてください。

![タイル256で、左がタイル解消0、右が0.7](../assets/terrain-painting/detile-compare.jpg)

> [!NOTE]
> マテリアルの`metadata/texture_size`は地形には適用されず、**タイル**だけが効きます。

## Godotでの見え方 { #how-it-looks-in-godot }

各レイヤーは上と横から投影されるので、崖はにじまずに岩として見え、エディターで見えるものと一致します。各レイヤーは、マテリアルのカラーテクスチャ、法線マップ、ラフネス、発光を使います。アンビエントオクルージョンは、ORMテクスチャのようにラフネステクスチャの中にあるときか、レイヤーにラフネステクスチャがないときに使われます。

![Godotでの、海の島のペイントされた崖](../assets/terrain-painting/godot-cliffs.jpg)
