# メッシュ { #meshes }

メッシュは、ブラシと違ってへこみや穴、曲がった面を持てます。岩やパイプ、なめらかなアーチなど、ブラシでは作れない形に使いましょう。

## メッシュを編集する { #editing-a-mesh }

形を変えたいブラシを選んで、*メッシュ > メッシュを編集*を選びます。ブラシがメッシュに変換され、そのまま編集が始まります。

![メッシュを編集にカーソルを合わせたメッシュメニュー。続いてブラシをメッシュに変換（Ctrl+Shift+E）、メッシュをブラシに変換、メッシュを結合（Ctrl+Shift+J）、そしてトポロジー、コンポーネント、法線とシェーディング、トランスフォームのサブメニューが並ぶ](../assets/meshes/menu-edit-mesh.png)

メッシュを選んでいるときは**Tab**でも同じことができ、もう一度Tabを押すとオブジェクトの操作に戻ります。ブラシでTabを押した場合は頂点ツールが開くだけなので、うっかりキーを押してもブラシがメッシュになることはありません。ツールバーのメッシュツールボタンは、何も変換せずに編集を始めます。Ctrl+Shift+Eは変換するだけで、Ctrl+Shift+Jは複数のメッシュを1つにまとめます。

編集中は、画面上部のツールオプションバーで**頂点**、**エッジ**、**面**を切り替えられます。よく使う操作のボタンも並んでいます。

![頂点、エッジ、面と、続いて細分化、マージ、フィル、削除、スムーズ、フラットが並んだメッシュツールのオプションバー](../assets/meshes/mesh-tool-options.png)

## キー { #keys }

キー操作はBlenderに合わせてあります。たとえば3を押し、ボックスの上面をクリックしてEを押し、マウスを上に動かしてクリックすると押し出せます。

![面モードのメッシュのボックス。上面がグリッド単位で上に押し出されている](../assets/meshes/extrude-face.gif)

| キー | 動作 |
| --- | --- |
| 1、2、3 | 頂点、エッジ、面を操作する |
| A、Alt+A | すべて選択、選択解除 |
| Alt+クリック、Ctrl+Alt+クリック | クリックしたエッジを通るエッジループ、またはそれと交わるリングを選択する |
| Ctrl+L | 選択部分とつながっているものをすべて選択する |
| G、R、S | 移動、回転、拡大縮小 |
| E | 選択部分から新しいジオメトリを押し出す |
| I | インセット。選んだ各面の内側に小さな面を作る |
| Ctrl+B、Ctrl+Shift+B | エッジまたは頂点をベベルして角を落とす |
| Ctrl+R | ループカット。メッシュを横切る新しいエッジの輪を作る。ホイールまたは+と-でカット数を決める |
| K | ナイフ。2点をクリックしてその線に沿って切る |
| M | 選んだ頂点を中心でマージする |
| F | フィル。選んだ頂点にまたがる新しい面を作る |
| XまたはDelete | 削除 |
| Shift+D | 複製して移動 |
| P | 選択部分を新しいメッシュとして分離する |
| Alt+F | 法線を反転する。間違った側から見えている面に使う |

移動、回転、拡大縮小の最中にX、Y、Zを押すとその軸に固定され、Shiftと文字を一緒に押すとその軸を除外します。数値を入力すれば正確な量を指定できます。クリックかEnterで確定、右クリックかEscapeでキャンセルです。画面下部のヒント行に、これらの操作がそのつど表示されます。

## ギズモ { #gizmo }

要素をダブルクリックすると、移動、回転、拡大縮小のギズモが表示されます。頂点を1つの軸に沿ってスライドさせたいときにきれいに使える方法で、2Dビューでも使えます。Escapeでギズモは隠れ、選択は残ります。

細分化、三角形化、ソリッド化、ミラー、スムーズシェーディングなどのその他の操作は、*メッシュ*メニューにまとまっています。
