# 地形 { #terrain }

地形は、粘土のようにスカルプトできる高さの大きなグリッドで、その上に最大4枚のテクスチャをペイントできます。丘、砂浜、谷のような広い地面に使ってください。そうした場所でブラシを手で整えていたら、いつまでたっても終わりません。

このページでは、地形を作ることと、スカルプトツール（G）で形を整えることを説明します。テクスチャの貼り方は[地形レイヤー](terrain-layers.md)と[地形のペイント](terrain-painting.md)にあります。

## 地形を作る { #creating-a-terrain }

1. ダイアログを開く

    メニューバーの*地形 > 地形を作成…*を開きます。

    ![地形メニューを開き、地形を作成…にカーソルを重ねたところ](../assets/terrain/menu-create-terrain.png)

2. サイズを決める

    **解像度**と**セルサイズ**で大きさが決まり、その下の**サイズ**の行に、結果がユニットとメートルで表示されます。デフォルトは頂点129 x 129、セルが64ユニットで、8192ユニット、256mになります。下の[セルサイズを決める](#picking-the-cell-size)を参照してください。

    ![デフォルトの状態の地形を作成ダイアログ。129 x 129、セル64 u、丘、4つのレイヤー欄が並んでいる](../assets/terrain/create-terrain-dialog.png)

3. （任意）最初の形を選ぶ

    **形状**は、出発点になる地面です。デフォルトは丘で、ほかにフラット、山、島、谷、尾根があります。**PNGをインポート…**は、代わりにグレースケールのハイトマップを読み込みます。明るいピクセルほど高くなります。どちらも作成するこのときだけ使えます。

4. （任意）レイヤーを選ぶ

    **ベースレイヤー**、**斜面レイヤー**、**山頂レイヤー**、**低地レイヤー**が地形の4枚のテクスチャで、**現在を使用**を押すと、最後にクリックしたマテリアルが入ります。**傾斜と高さでレイヤーをペイント**にチェックを入れると、すぐにペイントされます。[自動ペイント](terrain-painting.md#auto-paint)を参照してください。

5. 下にある**作成**をクリックする

    地形は3Dカーソルを中心に置かれます。**3Dカーソル**のチェックを外して**中央**に数値を入力した場合は、その位置が中心です。その高さが地形のゼロになります。新しい地形が選択されて、スカルプトツールがすでに有効になっているのが見えるはずです。

## セルサイズを決める { #picking-the-cell-size }

| 設定 | 意味 |
| --- | --- |
| 解像度 | 1辺に並ぶ頂点の数で、33から1025までです。頂点が多いほど細かく作れますが、描画とスカルプトの負担が増えます |
| セルサイズ | 隣り合う2つの頂点のあいだの距離で、マップユニットです |

たとえば、頂点257でセルが64ユニットなら、16384ユニット、512mです。

頂点と頂点のあいだには何もないので、セルサイズが地形で表せる最も細かい部分になります。山脈には大きなセルを、庭には小さなセルを選びます。

選び間違えたら、地形を選んでインスペクターの**リサンプル**を開いてください。長い辺の頂点が65、129、257、513のどれかになるようにグリッドを作り直し、高さ、ペイント、穴は残ります。地形の大きさは変わらないので、頂点が増えればセルは小さくなります。

![地形のインスペクターでリサンプルメニューを開き、257頂点にカーソルを重ねたところ](../assets/terrain/inspector-resample.png)

**チャンクのセル数**（デフォルトは32）は、描画と当たり判定のために地形を正方形の断片に分けます。チャンクが小さいほどスカルプト中の作り直しが速く、大きいほどGodotのノードが少なくなります。

## スカルプト { #sculpting }

Gを押し、左上のツールオプションバーでモードを選んで、地形の上をドラッグします。選択した地形に作用し、何も選択していないときはすべての地形に作用します。

![スカルプトツールのモードメニューを、ツールオプションバーの半径と強さの欄の隣で開いたところ](../assets/terrain/sculpt-modes.png)

マウスボタンを押し続けるかぎり、ブラシの下で地面が上がり続けます。

![半径900ユニットのブラシで上げるを押し続けて、島から丘を作っているところ](../assets/terrain/sculpt-raise.gif)

| モード | 働き |
| --- | --- |
| 上げる、下げる | ボタンを押しているあいだ、高さを積み上げるか掘り下げます。クリックすると小さなこぶができます |
| スムーズ | 各頂点を隣の頂点に近づけてならし、でこぼこや鋭い尾根をやわらげます |
| 平坦化 | ストロークを始めた高さまで地面を引き寄せます。足場、道、台地を作るときに使います |
| ノイズ | 小さなランダムなこぶを足して、平らな地面を人工的に見えにくくします |
| 段丘 | 高さを**ステップ**ユニット刻みにそろえます。棚田や階段状の崖に使います。欄はモードの隣に表示されます |
| アルファを描く、アルファを消す、レイヤーを描く | 形を変える代わりにペイントします。アルファのモードはディスプレースメント用です。レイヤーを描くは、モードの隣で設定した地形レイヤーをペイントします。地形では、[ブレンドツール](terrain-painting.md)のほうがより細かく制御できます |
| 穴、穴を塞ぐ | セルをまるごとくり抜くか、元に戻します。当たり判定も同じです。洞窟やバンカーの入口に使ってください |

Ctrl+ホイールでブラシの大きさが変わり、Shiftで上げると下げるが入れ替わり、Ctrlを押しているあいだは、どのモードでもスムーズになります。

**強さ**は、ブラシがどれくらい速く作用するかを決めます。上げると下げるは、半径にかかわらず、強さ1あたり毎秒8ユニットだけブラシの中心を動かすので、デフォルトの4なら毎秒32ユニットになります。丘や島を作るときは、1分間押し続けるのではなく、強さを上げてください。

半径は地形のセルサイズより大きくしてください。それより小さいブラシは、その下にある頂点1つをつつくだけです（そうなったときはステータスバーが教えてくれます）。

最初からやり直すには、*地形 > スカルプト > 平坦化*か、インスペクターの**平坦化**で、選択した地形全体がゼロの高さに戻ります。

> [!TIP]
> 大きなブラシで形を作り、荒い作業のたびにスムーズをかけましょう。小さなブラシではこぶが残ります。

## Godotで { #in-godot }

地形はすべて`TrenchDotTerrain`ノードになります。これは`StaticBody3D`（動かない固い地面のためのGodotのノード）で、当たり判定は描画されているものと一致します。ゲームプレイのコードでは、`height_at(x, z)`がローカル位置の地面の高さを返すので、実行時にものを地面に置くのに便利です。

## MCP { #mcp }

`terrain_edit`ツールの`sculpt`オペレーションは1回分のダブを適用し、その強さは、やはり半径にかかわらず、ダブがどれだけ中心を動かすかを表します。強さ4で1秒間ストロークを続けるのは、強さ32のダブと同じです。
