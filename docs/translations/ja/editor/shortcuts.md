# ショートカット { #shortcuts }

ここに載せているのは、TrenchBroomプリセットのデフォルトのキーです。

別のキーにしたいですか。*ヘルプ > キーボードショートカット…*にすべての割り当てが一覧になっています。フィルターに入力して探し、**設定**を押してから新しいショートカットを押してください。そのウィンドウの上部にある**プリセット**か、*ファイル > 環境設定 > キーマッププリセット*で、HammerやBlenderに切り替えられます。[他のプリセット](#other-presets)を参照してください。

![csgで絞り込んだキーボードショートカットウィンドウ。プリセットのドロップダウン、カスタムをリセット、各行の設定とクリアのボタンが見える](../assets/shortcuts/keyboard-shortcuts-window.png)

欄に入力しているあいだや、メニューが開いているあいだは、ショートカットは待機します。形状ジェネレーターのような浮動ウィンドウの上にポインターがあるあいだは、保存、元に戻す、やり直しだけが働くので、ウィンドウ向けのキーがマップを削除したり変更したりすることはありません。

## ツール { #tools }

ツールのキーをもう一度押すと、選択に戻ります。Escはドラッグやストロークをキャンセルし、それ以外のときは選択に戻り、選択ツールでは選択を解除します。

| キー | ツール |
| --- | --- |
| Q | 選択。ブラシを描いたり、物を動かしたりします |
| C | クリップ。ブラシを平面で切ります |
| V | 頂点。ブラシの角をドラッグします |
| R | 回転 |
| T | スケール |
| Tab | 選択したものをその場で編集します。メッシュはメッシュツールで、ブラシは頂点ツールで開きます。ブラシが変換されることはなく、変換するのは*メッシュ > メッシュを編集*です |
| Shift+T | テクスチャ。面のテクスチャを整えます |
| P | ペイント。面に頂点カラーをペイントします |
| G | 地形とディスプレイスメントをスカルプトします |
| Shift+G | 地形のレイヤーをブレンドします |
| B | 散布 |
| Shift+E | ボリューム。トリガーボリュームをドラッグで作ります |
| Shift+P | パス。`path_corner`エンティティの連なりを置きます |
| M | 距離を計測します |

## ビューでのマウス { #mouse-in-the-views }

| 入力 | 結果 |
| --- | --- |
| 選択の外をドラッグ | ブラシを描く |
| 選択をドラッグ | 移動する。Ctrlでコピー、Shiftで軸をロック、Altで3Dでの垂直移動 |
| クリック、ダブルクリック | 選択する、グループ全体を選択する |
| 同じ場所をすぐにもう一度クリック、またはAlt+クリック（2D） | カーソルの下の次のオブジェクトを選択する。たとえば、上ビューで天井の下にある壁 |
| Ctrl+クリック | 選択に加える、または外す。ビューでもアウトライナーでも働く |
| アウトライナーでShift+クリック | 最後にクリックした行からの行を選択する |
| Shift+クリック、Ctrl+Shift+クリック | 面を1つ選択する、面を追加または外す |
| 選択した面をShift+ドラッグ（3D） | 押し込む、引き出す |
| 選択した面をCtrl+Shift+ドラッグ（3D） | 新しいブラシを押し出す |
| 右ドラッグ（3D） | 見回す。押したままWASDで飛び、QとEで下がる、上がる |
| 中ドラッグ | パン |
| Alt+左ドラッグ（3D） | オービット。選択ツールで、選択やそのギズモから始めたドラッグは、代わりにそれを垂直に動かす |
| Ctrl+ホイール（スカルプト、ブレンド、ペイント、散布） | ブラシのサイズを変える |

## 編集 { #editing }

| キー | 操作 |
| --- | --- |
| Ctrl+Z、Ctrl+Shift+ZまたはCtrl+Y | 元に戻す、やり直し |
| Ctrl+X、Ctrl+C、Ctrl+V | 切り取り、コピー、マウスの下に貼り付け |
| Ctrl+D、Ctrl+Shift+D | 複製、リンクして複製 |
| F2 | アウトライナーで選択中のオブジェクトの名前を変える |
| Ctrl+R | 直前の回転、反転、ナッジ、複製を繰り返す。メッシュ編集では、ループカットを入れる |
| DeleteまたはBackspace | 削除 |
| Ctrl+A、Esc、Ctrl+I | すべて選択、選択解除、選択反転 |
| Ctrl+T、Ctrl+Shift+T | 選択したブラシをステンシルとして使い、それが触れているもの、またはその内側にあるものを選択する。ステンシルのブラシは削除される |
| Ctrl+G、Ctrl+Shift+G | グループ化、グループ解除 |
| Ctrl+H、Ctrl+J、Ctrl+Shift+H | 選択を隠す、それ以外をすべて隠して選択だけを残す、すべて表示する |
| 矢印、Page Up、Page Down | グリッド1段分ナッジする |

## ブラシ、メッシュ、テクスチャ { #brushes-meshes-and-textures }

| キー | 操作 |
| --- | --- |
| Ctrl+K、Ctrl+M、Ctrl+L | CSG減算（選択を、それが触れているものからくり抜く）、凸形マージ、交差 |
| Ctrl+Shift+K | 中空化。中身の詰まったブラシを、壁のある部屋にする |
| Ctrl+Shift+B | 形状ジェネレーター。アーチ、円柱、階段、その他の既成の形を作る |
| Ctrl+Shift+E、Ctrl+Shift+J | ブラシをメッシュに変換、メッシュを結合 |
| Ctrl+Shift+W | ブラシをワールドへ移動。エンティティから外して、ただのレベルジオメトリにする |
| Ctrl+Shift+U | UVロックの切り替え。ブラシを動かしてもテクスチャがブラシに付いたままになる |
| Alt+H | ホットスポット合わせ。選択した面を、トリムシートのいちばん合う長方形に合わせる |

## ビューとファイル { #view-and-files }

| キー | 操作 |
| --- | --- |
| FまたはCtrl+U | 選択、またはマップ全体をフレームに収める |
| `[`と`]`、または`-`と`=` | グリッドを半分にする、2倍にする |
| F4、F3 | シェーディングを順に切り替える（テクスチャ、フラット、ライト、ワイヤーフレーム）、ライトプレビューを切り替える |
| Shift+Space | ポインターの下のビューを最大化する |
| Ctrl+Shift+1から9、Ctrl+1から9 | カメラのブックマークを保存する、呼び出す |
| Ctrl+=、Ctrl+-、Ctrl+0 | インターフェースのスケールを上げる、下げる、リセットする |
| F1 | ポインターの下にあるツール、パネルのタブ、メニュー項目、インスペクターのセクションについて[マニュアル](interface.md#help-and-the-manual)を開く。それ以外の場所ではコマンドパレット |
| ツールバーのツールをCtrl+クリック、macOSではCmd+クリック | マニュアルのそのページを開く |
| Ctrl+Shift+P | コマンドパレット |
| Ctrl+N、Ctrl+O | 新規マップ、マップを開く |
| Ctrl+S、Ctrl+Shift+S | 保存、別名で保存 |
| Ctrl+Shift+N、Ctrl+Tab、Ctrl+W | 新しいタブ、次のタブ、タブを閉じる |
| F5 | Godotプロジェクトを実行する |

> [!NOTE]
> F2は以前、シェーディングを切り替えていました。今は、Godot、Blender、ほとんどのファイルマネージャーと同じく名前変更で、シェーディングはF4に移りました。ショートカットウィンドウで自分で設定した割り当ては、そのまま残ります。

## 他のプリセット { #other-presets }

プリセットが変えるのは、下のキーだけで、それ以外は上のとおりです。自分の割り当てはどのプリセットの上にも重なり、ショートカットウィンドウの**カスタムをリセット**で消せます。

| キー | Hammerプリセット |
| --- | --- |
| Shift+S、Shift+X、Shift+V、Shift+A | 選択、クリップ、頂点、テクスチャのツール |
| H、Ctrl+H、U | 隠す、選択だけを残す、すべて表示 |
| Ctrl+W | ブラシをワールドへ移動 |
| Ctrl+M | 形状ジェネレーター |
| Ctrl+L | 垂直軸まわりに90°回転 |
| Ctrl+Shift+M、Ctrl+Shift+L | CSG凸形マージ、交差 |
| Ctrl+F4 | タブを閉じる |

| キー | Blenderプリセット |
| --- | --- |
| A、Alt+A | すべて選択、選択解除 |
| X | 削除 |
| Shift+D、Alt+D | 複製、リンクして複製 |
| S | スケールツール |
| H、Alt+H、/ | 隠す、すべて表示、選択だけを残す |
| Ctrl+J | メッシュを結合 |
| Z | シェーディングを順に切り替える |
| Shift+A | 形状ジェネレーター |
| F3 | コマンドパレット |
| F4 | ライトプレビュー |
| Alt+Shift+H | ホットスポット合わせ |
