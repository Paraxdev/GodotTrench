# UnityやBlenderから来た方へ { #coming-from-unity-or-blender }

TrenchDotは、TrenchBroomやHammerの流れをくむブラシエディターです。レベルは、インポートしたメッシュではなく、グリッド上に描く中身の詰まったブロックから始まります。UnityやBlenderで身につけたことの大半は、名前やキーが違うだけで、ここでも居場所があります。このページではそれらを対応づけます。最初の部屋づくりは[はじめの一歩](../getting-started.md)で順に案内しています。

## 機能の場所 { #where-things-are }

| UnityやBlenderでは | TrenchDotでは |
| --- | --- |
| ヒエラルキー、アウトライナー | **アウトライナー**。親オブジェクトの代わりに[レイヤーとグループ](organizing.md)を使います |
| インスペクター、Nパネル | **インスペクター**。位置とサイズの欄には数値を直接入力でき、Enterで反映されます |
| シーンビュー、ビューポート | 3Dビューと、上面、正面、側面のビュー。描いたり位置を揃えたりするには2Dがいちばん楽です |
| ProBuilderのシェイプ、追加メニュー | どのビューでもドラッグしてボックスの[ブラシ](brushes.md)を描きます。アーチや階段、円柱はCtrl+Shift+Bです |
| ブーリアンモディファイア | *ブラシ > CSG*。減算（Ctrl+K）、マージ、交差、中空化があります。ブラシはその場で変わり、モディファイアスタックはありません |
| 編集モード | ブラシには**頂点**ツール、[メッシュ](meshes.md)には**メッシュ**ツール。どちらもTabで入ります |
| プレハブ | [プレハブ](organizing.md#prefabs)。専用のマップとして保存され、すべてのインスタンスで更新されます |
| リンク複製（Alt+D） | リンクして複製、Ctrl+Shift+D。コピー同士でジオメトリを共有します |
| 単位、1 m | 32マップユニットが1メートルで、グリッドの初期ステップは16です |

正確な数値は、右側のインスペクターに入力します。何かを選んで、新しい位置やサイズを入力し、Enterを押してください。位置は選択範囲のいちばん低い角で、中心でもピボットでもありません。

![ブラシを選択したインスペクター。位置とサイズが、選択セクションの上にX、Y、Zの欄として並んでいる](../assets/coming-from-unity-blender/inspector-position-size.png)

## 違うキー { #keys-that-differ }

初期のキーはTrenchBroomに合わせてあり、そのうち3つはBlenderユーザーが戸惑いやすいところです。

* **G**は地形のスカルプトツールで、グラブではありません。
* **R**と**T**は回転ツールと拡大縮小ツールを選びます。マウスに追従するのではなく、ハンドルを使って選択範囲を操作します。
* **Tab**は、選択したものをその場で編集します。

ものを動かすには、どのビューでもドラッグするか、3Dビューのギズモを使い、正確な数値にはインスペクターを使います。

Blenderのキーのほうが好みですか。*ファイル > 環境設定 > キーマッププリセット*をBlenderに切り替えてください。

![環境設定ウィンドウのキーマッププリセットのドロップダウン。開いてTrenchBroom、Hammer、Blenderが並んでいる](../assets/coming-from-unity-blender/keymap-preset.png)

Aで全選択、Xで削除、Shift+Dで複製、HとAlt+Hで非表示と表示、Sで拡大縮小ツール、Shift+Aでシェイプジェネレーターが加わります。Gはスカルプトのままで、移動中に数値を入力できるのはメッシュツールの中だけです。全一覧は[ほかのプリセット](shortcuts.md#other-presets)にあります。

テンキーのビューはありません。上面、正面、側面のビューは常に開いていて、Shift+Spaceでポインターの下のビューが最大化され、*表示 > ビュー*で1つ、2つ、4つに切り替えられます。

## そのまま使える習慣 { #habits-that-carry-over }

メッシュツールでは、キーはBlenderに合わせてあります。1、2、3で頂点、エッジ、面、G、R、SにX、Y、Zを組み合わせて軸を固定、Eで押し出し、Ctrl+Rでループカット、Ctrl+Bでベベルです。

右ドラッグしながらWASDを押すと、Unityのシーンビューのように3Dカメラが飛び回り、Fで選択範囲にフォーカスします。Ctrl+ZとCtrl+Shift+Zで元に戻すとやり直し、F2で名前の変更です。
