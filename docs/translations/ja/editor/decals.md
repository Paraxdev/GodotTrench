# デカール { #decals }

デカールを使うと、面に汚れやしみ、ひび割れ、ポスター、看板を貼れます。デカールは背後の壁よりほんの少しだけカメラ寄りに描かれ、壁の上にブレンドされるので、壁ともデカール同士とも、ちらつくことがありません。

## デカールを置く { #placing-a-decal }

1. マテリアルを探す

    マテリアルパネルで探します。左上の検索ボックスが役に立ちます。

2. Altを押しながら、面にドラッグする

    カーソルの横のカードに、Altでデカールを置けると表示されます。

    ![night/shop_signをレンガの壁にドラッグしているところ。カーソルの横のカードには、面にドロップ、Shiftでブラシ全体を覆う、Altでデカールを置く、と表示されている](../assets/decals/decal-alt-drop.png)

3. 離す

    デカールは、ドロップした場所に1メートル四方（32×32ユニット）で、面から外向きに置かれます。

    ![レンガの壁に貼られた店の看板のデカール](../assets/decals/decal-on-wall.png)

デカールは普通のメッシュなので、ほかのものと同じように移動、回転、拡大縮小ができます。選択すると、インスペクターで**デカール (ブレンド、両面)**にチェックが入っているのが見え、位置とサイズの欄で正確に配置できます。

![デカールを選択したインスペクター。デカール (ブレンド、両面)にチェックが入り、サイズは32×32](../assets/decals/decal-inspector.png)

同じチェックボックスを使えば、薄いメッシュならどれでもデカールにできます。輪郭を自由に作りたいときに便利です。

縁のやわらかさは、そのまま残ります。くっきり切り抜きたいときは、アルファシザーモードのマテリアルを使ってください。[透明](../godot/materials.md#transparency)を見てください。

## 薄いブラシではだめな理由 { #why-not-a-thin-brush }

> [!WARNING]
> 薄いブラシや、壁から数ミリ浮かせたメッシュでデカールの代わりをしないでください。ちらつきます。

近くで見ると、薄いブラシはきれいに見えます。ところが少し離れると、動くにつれて縞模様が這うように、壁越しにちらつき始めます。これをZファイティングと呼びます。

GPUはピクセルごとに、深度を比べてどの面がいちばん手前かを判断します。深度は限られた段階数で保存されていて、面が遠いほど、また面に沿って平らに見るほど、段階が粗くなります。数メートル離れると、ブラシと壁が同じ段階に丸められ、各ピクセルはほとんど行き当たりばったりでどちらかを選び、その選択はカメラが動くたびに変わります。ブラシを壁からさらに離しても、ちらつきがもっと遠くへ移るだけで、近くで見ると今度はブラシが壁の手前に浮いているのがはっきり分かってしまいます。

デカールにはこの問題がありません。Godotがマップをビルドするとき、各デカールを距離の0.05パーセントだけカメラの方へ引き寄せます。1メートルなら0.5ミリ、100メートルなら5センチなので、どんな距離でも壁の手前に収まります。この引き寄せは視線に沿って行われるため、デカールは画面上でずれません。さらに、デカール自身は深度を書き込まないので、重なったデカール同士も競り合わずにブレンドされます。

薄いメッシュでも、**デカール (ブレンド、両面)**にチェックを入れれば問題ありません。それで本物のデカールになります。

## 投影デカール { #projected-decals }

通常のデカールは平らです。段差やパイプ、でこぼこの地面に回り込むしみには、代わりに投影デカールを使います。これはエンティティで、ボックスの内側にあるものすべて（プロップも含みます）にマテリアルを投影します。描画のコストが高いので、平らな面では通常のデカールを使ってください。

ゲームプレイエンティティパックに`infodecal`として入っています。[投影デカール](projected-decals.md)で、設定のしかたと置き方、注意点を説明しています。
