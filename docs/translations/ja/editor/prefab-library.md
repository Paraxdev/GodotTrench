# プレハブライブラリ { #prefab-library }

下部にある、マテリアルとモデルの隣の**プレハブ**タブには、マップに貼り付けられる既製の部品が入っています。階段、出入口、柱、小さな部屋、ディテールなどです。TrenchBroomのマッパーがコピーして使うプレハブ集のようなもので、それがエディターに組み込まれています。

![プレハブタブ。プレハブを検索、カテゴリ一覧、カードサイズのスライダー、組み込みの部品ごとのカードが並び、Switchback stairにカーソルを重ねてツールチップが出ている。Stairs/Switchback stair、192 × 128 × 352ユニット、組み込み](../assets/prefab-library/prefabs-panel.png)

各カードは、部品がいちばんよくわかる方向から描かれます。階段のような床の間取りは上から、出入口のような壁は正面からです。明るいほど手前にあります。

## 部品を貼り付ける { #pasting-a-piece }

1. 場所を指す

    ビューで部品を置きたい場所にカーソルを合わせます。それで3Dカーソルが決まります。

2. カードをクリックする

    *プレハブを検索*に入力するか、カテゴリを選んで探し、クリックします。部品はその場所を中心に、グリッドにスナップして貼り付けられます。Ctrl+Vと同じです。

    ![小さな部屋に貼り付けたSwitchback stair。段はグレーの開発用マテリアル](../assets/prefab-library/pasted-switchback-stair.png)

カーソルに合わせて動くのは、間取り上の位置だけです。高さは保存されたときのままなので、上の階では、貼り付けたあとで持ち上げてください。

貼り付けたものは、ライブラリへのリンクがない普通のコピーなので、形もテクスチャも自由に変えられます。組み込みの部品は、どのプロジェクトにもある`dev/`マテリアルを使っているので、マテリアルタブでテクスチャを変えてください。

カードを右クリックすると、*貼り付け*と*コピー*が出ます。コピーは部品をクリップボードに入れるので、別のマップに貼り付けたり、テキストとして共有したりできます。

ランダムに選んだ部品でエリア全体を覆いたいときは、[ランダム充填](random-fill.md)を使ってください。

> [!TIP]
> 貼り付けた部品は、ただのマップの内容です。窓枠を建物のあちこちに繰り返すときのように、使っているすべての場所で同期していてほしいものは、代わりに[プレハブインスタンス](organizing.md#prefabs)を作ってください。

## 自分の部品 { #your-own-pieces }

1. オブジェクトを選ぶ

    Godotプロジェクトを開いた状態で、部品にしたいものを選びます。

2. 選択範囲を追加する

    プレハブタブの上にある**選択範囲を追加**を開き、部品の名前とカテゴリを入力して、**追加**をクリックします。

    ![選択範囲を追加を開いたところ。名前はGrand stair、カテゴリはStairs、位置を維持はオフで、追加のツールチップに、選択範囲を.tdmとしてres://prefab_libraryに保存します。下面の中心が原点に来ます、と出ている](../assets/prefab-library/add-the-selection.png)

3. 新しいカードを見つける

    先頭に、青い枠付きで表示されます。右クリックすると、部品をマップとして開く*開いて編集*と、*ファイルマネージャーで表示*が出ます。組み込みの部品は編集できません。

    ![Grand stairのカードを右クリックしたメニュー。貼り付け、コピー、開いて編集にカーソルが重なり、ファイルマネージャーで表示が並んでいる](../assets/prefab-library/card-menu.png)

部品は`res://prefab_library/<category>/`に`.tdm`として保存され、選択範囲の下面の中心が原点に来るように動かされます。**位置を維持**にチェックを入れると、動かさずにそのままの位置になります。[ランダム充填](random-fill.md)のキットの部品のように、マップの原点のまわりにわざと作った部品に向いています。

そのフォルダにある`.tdm`はすべて部品です。*ファイル > 別名で保存…*で自分でマップをそこに保存すると、すぐにカードとして表示されます。手でコピーしたファイルや、プロジェクト間で共有する部品のフォルダは、⟳ボタンを押してください。

## TrenchBroomから貼り付ける { #pasting-from-trenchbroom }

TrenchDotは、TrenchBroomがクリップボードに入れたものも貼り付けられます。TrenchBroomでブラシをコピーするか、ウェブにあるTrenchBroomのプレハブ集からコピーして、マップでCtrl+Vを押してください。グループはグループとして、エンティティはエンティティとして入り、軸は[.mapのインポート](importing.md)のときと同じ向きに回されます。テクスチャ名は保たれ、ほかのゲームのツールテクスチャは、プロジェクトのものに置き換わります。

## MCP { #mcp }

`prefab_library`ツールは、部品の一覧（`op: list`）、`category/name`を指定した貼り付け（`op: paste`、`origin`か`offset`付き）、クリップボードのテキストの取得（`op: copy`）、オブジェクトのプロジェクトのライブラリへの追加（`op: add`、`ids`を指定しなければ選択範囲）を行います。`paste`を指定した`run_action`は、TrenchDotのテキストに加えて、TrenchBroomのクリップボードのテキストも受け付けます。
