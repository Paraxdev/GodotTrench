# 投影デカール { #projected-decals }

投影デカールは、箱の中にあるものすべてにマテリアルを照らし出すボックスです。平らな板である[通常のデカール](decals.md)と違って、当たったものの形に沿うので、しみが段差にこぼれたり、パイプに巻きついたり、でこぼこの地面に寝そべったりします。箱の中にあるプロップやモデルにも貼られます。

ビルドしたシーンではGodotの`Decal`ノードになり、通常のデカールより描画に手間がかかります。平らな板では足りない場所に使ってください。

> [!WARNING]
> 投影デカールは、[通常のデカール](decals.md)よりGPUに負担がかかります。Godotは、箱が画面上で覆うすべてのピクセルについてデカールを計算するので、箱が多かったり大きかったりするとゲームが重くなり、非力なグラフィックスカードでは特に目立ちます。平らな面には通常のデカールを使い、箱は用が足りる範囲でできるだけ小さくして、投影デカールは巻きつきが必要な場所にとっておいてください。

## プロジェクトに追加する { #adding-it-to-your-project }

投影デカールは、[ゲームプレイエンティティパック](../godot/project-setup.md#core-entities-and-the-gameplay-entities-pack)に`infodecal`として入っているので、パックをインストールすればそれで準備完了です。

1. パックをインストールまたは更新する

    *このプロジェクトを設定*ウィンドウで**ゲームプレイエンティティをインストール**をクリックします。パックがすでにプロジェクトに入っているときは、ゲームプレイメニューの**ゲームプレイエンティティを更新**をクリックします。手順は[パックのインストールと更新](../godot/project-setup.md#installing-and-updating-the-pack)にあります。

2. エディターから見えているか確かめる

    インスペクターの隣の**エンティティ**タブに、`infodecal`のカードが見えるはずです。タブの上にある検索ボックスに`infodecal`と入力すると、すぐ見つかります。

    ![infodecalで検索したエンティティタブ。カードにカーソルを重ねると、ツールチップに投影デカールと表示されている](../assets/projected-decals/entities-infodecal-card.png)

> [!NOTE]
> パックができる前に自分で`infodecal`の定義を作っていた場合は、更新したあとでFGDから取り除いてください。そのままだとクラスが二重に定義され、エディターが警告を出します。

> [!TIP]
> パックを使わないなら、定義の[`infodecal.tres`](https://github.com/Paraxdev/trenchdot_func/blob/main/gameplay_pack/definitions/infodecal.tres)を自分のプロジェクトにコピーして、自分のFGDファイルの*Entity Definitions*に加えてください。[カスタムエンティティ](../gameplay/custom-entities.md#making-it-placeable)を参照してください。*Node Class*は`Decal`のままにしておきます。スクリプトがそれを必要としていて、エディターもそれでこのエンティティをデカールとして扱うからです。

## 置く { #placing-one }

1. カードを面にドラッグする

    インスペクターの隣の**エンティティ**タブを開き、`infodecal`のカードをビューにドラッグします。ほかのエンティティを置くときと同じです（[エンティティを置く](../gameplay/placing.md#placing-entities)を参照）。ポインターが最初の固体の面に当たった場所に、その面へ投影されるような向きで置かれます。箱がカバーする空間を示していて、半分は面の手前に、半分は奥にあります。

    ![3Dビューにある、レンガの段差の縁のinfodecal。箱は上面から前面へと覆いかぶさり、中には看板のマテリアルがプレビューされている](../assets/projected-decals/decal-box-on-step.png)

2. マテリアルを選ぶ

    インスペクターで`material`にマテリアル名を入力します。面で使うのと同じ名前で、たとえば`base/stain`です。色、法線マップ、発光が引き継がれます。

    ![infodecalを選択したインスペクター。materialにnight/shop_sign、sizeに128 64 64が入っている](../assets/projected-decals/decal-inspector-material.png)

3. サイズを決める

    `size`にはマップユニットで3つの数値を入れます。幅、奥行き、高さの順です。幅と高さは面の上で覆うパッチの大きさで、奥行きは面の内側と外側に箱がどこまで届くかです。デフォルトは64 32 64で、2メートル四方、前後に半メートルずつ届きます。デフォルトのままにしておくと、マテリアルに[テクスチャサイズ](../godot/materials.md#texture-size)があればそれがパッチの大きさになります。エディターでもGodotでも同じです。

4. （任意）向きを決める

    ほかのエンティティと同じように回転できます。投影はいつも自分の下向きの軸、つまりローカルの-Yに沿って行われ、ドロップしたときにはそれが面の内側を向いています。

5. Godotでマップをビルドする

    Godotがマップをビルドすると、箱の中にあるすべての面にマテリアルが表示されます。[マップをビルドする](../godot/building.md)を参照してください。

    エディターが見せるのは、箱の中のマテリアルの平らなプレビューだけです。本物の投影を描くのはGodotで、看板は段差の縁で曲がり、前面へと下りていきます。

    ![実行中のGodotゲームの同じ看板。レンガの段差の縁で曲がり、前面に回り込んでいる](../assets/projected-decals/decal-in-game.png)

## キー { #keys }

| キー | 働き |
| --- | --- |
| `material` | 投影するマテリアルで、`base/stain`のような名前か`res://`パスです。アルベド、法線、ORM、発光の各テクスチャとアルベドの色が使われます |
| `texture` | 画像への`res://`パスで、`material`が空のときに投影されます |
| `normal_texture` | 法線マップへの`res://`パスで、`texture`と合わせて使います。マテリアル自身の法線マップがあればそちらが優先されます |
| `size` | 箱の幅、奥行き、高さをマップユニットで指定します。変えなければ64 32 64です |
| `modulate` | 投影される画像に掛け合わせる色です |

## 気をつけること { #things-to-watch-out-for }

| 状況 | 起こること |
| --- | --- |
| プロジェクトがCompatibilityレンダラーを使っている | Godotはデカールをまったく描きません。*Project Settings > Rendering > Renderer*の*Rendering Method*をForward+かMobileに切り替えてください |
| プロジェクトがMobileレンダラーを使っている | 1つのメッシュに表示されるデカールは8つまでで、残りは省かれます |
| 投影の方向に沿っている面 | テクスチャが筋状に引き伸ばされます。真下を向いたデカールの下にある、段差の前面がそうです。箱を傾けて、両方の面に斜めから当たるようにしてください |
| 箱の端に近い面 | デカールは箱の上端と下端に向かって薄れていくので、面は、ドロップで置かれる真ん中のあたりに保ってください |
| 箱の中を何かが通る | それにもデカールが貼られます。横を歩くプレイヤーも例外ではありません。箱の奥行きは、面に必要な分より深くしないでください |
| ガラスと切り抜き | 以前と同じ透け方のままです。デカールで透明な部分を埋めることはできません |
| 大きなデカールがたくさんある | 1つ1つが、覆うすべてのピクセルに処理を足すので、重なる場所ではゲームが重くなります |

## MCP { #mcp }

[MCPサーバー](../mcp.md)では、`run_action`に`action: "place_entities"`と`args: {"classnames": ["infodecal"], "at": [x, y, z], "normal": [x, y, z]}`を渡すと、ドラッグしたときと同じように、面に沿った向きで置かれます。キーはそのあとで`update_entity`の`properties`で設定します。
