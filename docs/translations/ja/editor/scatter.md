# 散布 { #scatter }

**散布**ツール（B）は、木、岩、草を、選んだ面にペイントします。モデルを1つずつ手で置かなくても、丘の斜面を数秒で覆えます。[海の島の散布チュートリアル](../tutorials/sea-island-scatter.md)で、セットアップの全体を順に見られます。

![散布ツールで島に森の帯をペイントしているところ](../assets/scatter/scatter-paint.gif)

## 散布セット { #scatter-sets }

散布したものはすべて、それぞれ専用のレイヤーにある**散布セット**に入ります。たとえば、木のセットと草のセットを別々に作ります。Bを押すと右に散布パネルが開き、いま有効なセットのモデルごとにカードが並びます。

![散布パネルで、bushesセットが有効なところ。セットのメニュー、+、プリセット、名前変更、モデルごとのカードが並んでいる](../assets/scatter/scatter-panel.png)

| やりたいこと | 方法 |
| --- | --- |
| 空のセットを始める | セットのメニューの隣にある**+** |
| プリセットから始める | **プリセット**を押して、10種類の組み込みセットから選びます |
| モデルを追加する | モデルパネルからドラッグするか、**モデルを追加…**を使います。**選択したプロップを追加**は、選択したエンティティのモデルを取り込みます |
| 1つのモデルのペイントをやめる | そのカードの**描画**のチェックを外します。すでに置かれたものはそのまま残ります |
| モデルを調整する | カードの右にある矢印をクリックします |

![プリセットメニューを開いたところ。forest、pines、mixed woodland、detailed forest、low-poly trees、bushes、undergrowth、rocks、boulders、grassが並び、rocksにカーソルが重なっている](../assets/scatter/preset-menu.png)

rocks、boulders、grass、undergrowth、low-poly treesのプリセットは、エディターに組み込まれたBlockbenchのモデルを使います。選ぶと、必要なモデルがオフラインで`res://trenchdot/nature`に追加されます。forest、pines、mixed woodland、detailed forest、bushesのプリセットは、自然パックのglTFの木と茂みを使い、約23MBのダウンロードです。パックがないプロジェクトでこれらを選ぶと、モデルが足りないセットを作る代わりに、自然モデルの*Godot > プロジェクトにコンテンツを追加…*が開きます。*地形 > 散布 > 自然モデルをインストール…*や、パネルの一番下の**自然モデルをインストール…**でも開けます。プロジェクトにすでにあるファイルが上書きされることはありません。

### モデルのカード { #model-cards }

カードの矢印で開くと、そのモデル1つを調整できます。

![bush_roundのカードを開いたところ。スケール、間隔、整列、傾き、沈み込み、ランダム回転、マテリアルが並んでいる](../assets/scatter/model-card.png)

| カードの設定 | 働き |
| --- | --- |
| 重み | セットの中のほかのモデルと比べて、このモデルがどれくらいの頻度で選ばれるかです |
| スケール | 2つの値のあいだのランダムな大きさです |
| 間隔 | 別のインスタンスとのあいだの最小の距離で、マップユニットです |
| 整列 | 0ならモデルがまっすぐ立ち、1なら面に沿って傾きます |
| 傾き | ランダムに傾く最大の角度で、度です |
| 沈み込み | モデルを地面にどれだけ押し込むかです。幹や岩の底を隠すのに使います |
| ランダム回転 | インスタンスごとに、ランダムな向きに回します |
| マテリアル | モデル自身のマテリアルの代わりに描かれます。空のままなら、セットのマテリアルがあればそれが適用されます |

## ターゲット { #targets }

セットは自分の**ターゲット**の上にしか置かれないので、地形にペイントした森が、その上の家を覆うことはありません。ビューでAlt+クリックするか、*ターゲット*の右にあるスポイトをクリックしてからビューでクリックすると、ターゲットを追加または削除できます。ターゲットのないセットは、最初のストロークが当たったものをターゲットにします。ほかのセットをターゲットにすることもでき、岩の上に草を生やすにはそうします。

![散布パネルのターゲットのセクション。地形がターゲットで、右上にスポイトがある](../assets/scatter/targets.png)

**カーソルに追従**にチェックを入れると、ターゲットを無視して、ブラシの下にあるどんな面にも、散布済みのプロップにもペイントします。

## ペイント { #painting }

手早く使う設定は、左上のツールオプションバーにあります。セット、**ペイント**か**消去**、半径、密度、最大傾斜、**カーソルに追従**、スポイト、**塗り潰し**です。パネルを閉じてしまったときは、**散布パネル**で戻せます。

![散布ツールのオプションバー。bushesセット、ペイント、半径512 u、密度1.00、最大傾斜40°](../assets/scatter/scatter-toolbar.png)

| 入力 | 操作 |
| --- | --- |
| 左ドラッグ | ペイント |
| Shift+左ドラッグ | 消去。有効なセットだけが対象です |
| Ctrl+ホイール | ブラシの大きさを変える |
| **ターゲットを充填** | 傾斜と高さの制限の範囲で、すべてのターゲットを一度に覆います |

残りの設定は、パネルの*ブラシ*セクションにあります。

![散布パネルのブラシセクション。半径、密度、勾配、高さ、フォールオフ、露出部のみ、消去量、シード、出力と、その下のチェックボックスが並んでいる](../assets/scatter/brush-settings.png)

**密度**は、64 x 64ユニットあたりにブラシが何回の配置を試みるかで、実際にいくつ収まるかは、各モデルの間隔で制限されます。**露出部のみ**は、上にジオメトリがある点を飛ばすので、バルコニーや屋根の下に草が生えません。**他のセットとの間隔を保つ**は、デフォルトでオンで、茂みが別のセットの幹を突き抜けて生えるのを防ぎます。

## Godotで { #in-godot }

セットの**種類**で、Godotが何を作るかが決まります。

| 種類 | 作られるもの |
| --- | --- |
| props | 当たり判定と影を持つMultiMeshです。シーンにスクリプトが付いているモデルは、スクリプトが動くように1つずつインスタンス化されます |
| foliage | 当たり判定も影もないMultiMeshで、デフォルトでは2400ユニットより遠くでは隠れます。草や小さな植物向けです |

アウトライナーでセットを選ぶと、インスペクターの**衝突**の行で、各インスタンスが何の形で衝突するかを選べます。新しいpropsのセットは凸形で、foliageのセットはなしで始まります。

| 衝突 | インスタンスごとの形 |
| --- | --- |
| なし | 当たり判定なし |
| ボックス | インスタンスを囲む1つの箱 |
| 凸形 | インスタンスを囲む1つの凸包 |
| 分解 | アーチのような凹んだモデルに沿った、複数の凸包です。作るのに時間がかかります |
| トライメッシュ | モデルのすべての面で、正確ですが最も負荷が高くなります |

プロップを1つずつ編集したいときは、散布パネルの一番下の**エンティティへ**か、選択したセットなら*地形 > 散布 > 散布セットをエンティティに*で、セットがインスタンスごとに1つの`prop_model`エンティティに置き換わります。

![散布パネルの下部。種類、ペイント、消去、ターゲットを充填、インスタンスを消去、エンティティへ、自然モデルをインストール…が並んでいる](../assets/scatter/panel-buttons.png)
