# Godotでのベイクしたライティング { #baked-lighting-in-godot }

[エディターでマップをベイクする](../editor/light-baking.md)と、ライトマップは`.tdm`の中に保存されます。Godot自身は何もベイクせず、ビルドのたびに、保存されたベイクをGodotのライトマップノードに変換するだけです。

## ビルドが追加するもの { #what-the-build-adds }

| 部品 | 追加されるもの |
| --- | --- |
| `baked_lighting`という名前の`LightmapGI` | `FuncGodotMap`の子で、ライトマップ、太陽のシャドウマスク、ライトプローブを持ちます |
| ベイクしたメッシュ | ライトマップ座標がUV2として設定され、GIモードはstaticになります。ストリーミングされるチャンクも含みます |
| ライトと太陽 | `bake_mode`または`sun_bake_mode`に応じたGodotのベイクモード。[ライトのキー](../editor/light-baking.md#light-keys)を参照してください |

太陽が`bounce`のときは、太陽はリアルタイムのままで、ベイクしたシャドウマスクが、影の距離より先にあるものに陰影をつけます。

ベイクのあとに変更した面は、マップの平均的な光に戻ります。そのため、もう一度ベイクするまでは、それらしく見えても平坦になります。

## ライトプローブ { #light-probes }

プレイヤー、プロップ、ドアのような動くオブジェクトは、周りのライトプローブから光を受け取ります。そのため、ベイクした回り込む光を拾って、周囲になじみます。

ベイクは、ベイクしたジオメトリを囲むボックスの上に、2メートルのグリッドでプローブを置き、ソリッドの内側のものは捨てます。細い廊下や階段のように、グリッドが粗すぎる場所では、`light_probe`エンティティを追加して、プローブをもう1つ増やします。ひとつのマップが持てるプローブは、手で置いたものを含めて最大でおよそ1000個なので、大きなマップではグリッドの間隔が広がります。

## プローブのエンティティ { #probe-entities }

| エンティティ | 種類 | Godotのノード | 用途 |
| --- | --- | --- | --- |
| `light_probe` | ポイント | `LightmapProbe` | ベイクのための追加のライトプローブ。上を参照してください |
| `env_reflection_probe` | ブラシボリューム | ブラシの大きさの`ReflectionProbe` | つやのある床や金属に、部屋に合った反射を映す |
| `env_voxel_gi` | ブラシボリューム | ブラシの大きさの`VoxelGI` | 動くライトやオブジェクトに追従する、リアルタイムの回り込む光 |

3つとも、エンティティタブにあります。`light_probe`はビューにドラッグします。2つのボリュームは、部屋を囲むボックスを描いてから、カードを右クリックして**選択したブラシをこれに変換**を選びます。

![env_で絞り込んだエンティティタブ。env_voxel_giのカードを右クリックして、選択したブラシをこれに変換が強調表示されている](../assets/baked-lighting/entities-turn-brushes-into.png)

ブラシが与えるのはボックスだけで、ビルドがそのブラシを取り除きます。3つのキーは、[プロップ、ライト、エフェクト](../gameplay/entities/effects.md#light_probe-env_reflection_probe-and-env_voxel_gi)に一覧があります。

`env_voxel_gi`は、マップがビルドされるたびに、Godotエディターでベイクされます。大きなボリュームでは、`bake_on_build`を0にして、代わりに`VoxelGI`ノードの**ベイク**ボタン(英語のGodotでは「Bake」)で手動でベイクしてください。ゲームの実行中にビルドされたマップは、そのベイクを行いません。

## 別のライトマッパーを使う { #using-another-lightmapper }

代わりにGodot自身の`LightmapGI`でベイクしたいですか。`FuncGodotMap`の**Use Baked Lighting**のチェックを外すと、保存されたベイクを使わなくなります。するとビルドは`baked_lighting`ノードを追加せず、ライトのベイクモードにも触れません。Godotでベイクするのに必要なUV2がメッシュに付くように、*Build Flags*の*Unwrap UV2*にチェックを付けてください。
