# 大きなマップをストリーミングする { #streaming-big-maps }

広い屋外マップでは、遠くにあるものを隠せるので、マップが持つものすべてではなく、プレイヤーに見えるものの分だけコストがかかります。ビルドはマップのメッシュをグリッド上のチャンクに振り分け、カメラの近くにあるチャンクだけを描画します。

## オンにする { #turning-it-on }

1. 何も選択しない

    Escapeを押して、何も選択されていない状態にします。すると、右のインスペクターに*マップ (worldspawn)*が表示されます。

2. `chunk_streaming`を追加する

    いちばん下の*キー*欄に`chunk_streaming`、*値*に`1`と入力して、**追加**をクリックします。(すでに一覧にあるときは、そこでオンにするだけです。)

    ![キー欄にchunk_streaming、値欄に1を入力し、追加ボタンにカーソルを乗せたworldspawnのインスペクター](../assets/streaming/worldspawn-add-key.png)

    他のworldspawnのキーと一緒に、一覧に表示されます。

    ![chunk_streamingにチェックが付いたworldspawnのインスペクター](../assets/streaming/worldspawn-chunk-streaming.png)

3. マップを保存する

    次のビルドで、マップに`TrenchDotStreamer`が追加されます。

(任意で)`chunk_size`と`load_radius`も同じように追加します。

| キー | デフォルト | 意味 |
| --- | --- | --- |
| `chunk_size` | 2048 | チャンクのサイズ。マップユニットで、64m。チャンクが小さいほど正確に隠せますが、判定のコストが増えます |
| `load_radius` | 8192 | カメラからどこまでのチャンクを表示したままにするか。マップユニットで、256m |

ストリーミングが隠すのはメッシュだけです。コリジョンとスクリプトはどこでも動き続けるので、減らせるのは描画のコストで、物理やロジックのコストではありません。オーバーレイ、実行時に生成されたコンテンツ、動いているドアやトレインに付いているものは、決して隠されません。

ストリーマーは、ビューポートの現在のカメラに追従します。カメラがないあいだは`info_player_start`に追従します。ひとつのカメラに固定したいときは、ビルドのあとにコードから`camera_path`を設定してください。再ビルドするとストリーマーが置き換わるためです。ストリーマーが動くのはゲームの中だけなので、Godotエディターには常にマップ全体が表示されます。

チャンクが出入りするたびに、ストリーマーは`area_loaded(key, bounds)`と`area_unloaded(key, bounds)`を発行します。これを使えば、自分のコンテンツも一緒にストリーミングできます。

```gdscript
streamer.area_loaded.connect(func(key, bounds): spawn_wildlife(bounds))
```

## セクションをストリーミングする { #streaming-sections }

複数のマップを、ローディング画面なしにひとつのワールドとして遊ばせたいですか。ワールドをセクションに分けて、コネクタールームでつなぎます。シーンツリーにあるセクションは常にひとつだけです。次のセクションは、プレイヤーが探索しているあいだにバックグラウンドで読み込まれ、プレイヤーがコネクターを通っているあいだに入れ替わります。位置が揃えてあるので、プレイヤーの周りの部屋はまったく同じままです。これには[ゲームプレイエンティティパック](../gameplay/entities/README.md#installing-and-customizing)が必要です。

1. コネクタールームを作る

    両側にそれぞれ曲がり角がある廊下にして、どちらの端も中央からは見えないようにします。中央に`info_landmark`を置き、半分ずつを覆い、中央で接する2つの`func_section_stream`ボリュームを置きます。コピーがすべて同じになるように、[プレハブライブラリ](../editor/prefab-library.md)に追加してください。

2. 2つのマップが接する場所に貼り付ける

    他のマップと接する各マップで、2つが接する場所にコネクターを貼り付け、そのランドマークに名前を付けます。たとえば`lm_hall_cellar`です。それぞれの半分の`section`には、その側のセクションを、`landmark`にはランドマークの名前を設定します。2つのマップには、同じ名前で、同じ向きに回した同じコピーを入れます。

3. すべてのセクションのマップでライティングをベイクする

    SDFGIは、入れ替えで入ってきたジオメトリに、カスケードがスクロールするまで気づきません。そのため、入れ替えたセクションは暗いままになってしまいます。ベイクしたライティングはセクションと一緒に付いてきます。

4. セクションごとにシーンを作る

    セクションごとに、ビルドしたマップを入れたシーンをひとつ、いつもの方法で作ります。

5. ストリーマーを追加する

    ワールドのシーンに`TDSectionStreamer`ノードを追加し、`first_section`とプレイヤーを設定します。[TDSectionStreamer](../gameplay/entities/sections.md#tdsectionstreamer)を参照してください。

> [!TIP]
> ランドマークの位置は、480マップユニットの倍数か、コネクターのすべてのテクスチャが繰り返されるサイズにしてください。そうすれば、2つのコピーでテクスチャが同じように揃います。
