# エンティティリファレンス { #entity-reference }

ゲームプレイエンティティパックのエンティティを、使い道ごとにまとめました。各項目では、そのエンティティが何のためのものかを説明したあと、インプット(ほかのエンティティにやらせられること)、アウトプット(先へ配線できるイベント)、キー(インスペクターの設定)を一覧にしています。アウトプットとインプットのつなぎ方は[インプットとアウトプット](../io.md)で説明しています。

## インストールとカスタマイズ { #installing-and-customizing }

パックはアドオン本体には含まれていません。*このプロジェクトを設定*ウィンドウの**ゲームプレイエンティティをインストール**を押すか、*ゲームプレイ > ゲームプレイエンティティをインストール*を選ぶと、定義とスクリプトが`res://trenchdot/entities`にコピーされます。それまでは、エンティティパネルに一覧されるのはコアだけです。worldspawn、`func_`系の補助、`light`、`light_spot`、ライトプローブとリフレクションプローブ、`info_player_start`です。

コピーはあなたのプロジェクトのものです。`scripts/`にあるエンティティのスクリプトや、`definitions/`にあるキーとデフォルト値を変えたり、使わないエンティティを削除したり、自作のものを追加したりできます。アドオンを更新すると新しいパックを提案されますが、編集したファイルは上書きされません。更新の扱いと、二つの定義が同じクラス名だったときの動作は、[プロジェクトのセットアップ](../../godot/project-setup.md#core-entities-and-the-gameplay-entities-pack)で説明しています。

## 項目の読み方 { #reading-the-entries }

* 角かっこの中の引数は、インプットが受け付けるものか、アウトプットが渡すものです。たとえば`trigger(activator)`は、連鎖を始めたボディかエンティティを受け取ります。
* インプットかアウトプットを持つエンティティには、`logic_auto`を除いてすべて`targetname`キーがあります。ほかのエンティティがそのエンティティを指すときの名前です。
* 設定しなかったキーには、一覧にあるデフォルト値が使われます。
* 距離はマップ単位で、1メートルが32です。速度はメートル毎秒で、`omni_range`、`spot_range`、`max_distance`はメートルです。
* インプットとアウトプットの一覧は、エディターのピッカーに出てくるものです。実行時には、エンティティのスクリプトにあるメソッドならどれでもインプットとして使えるので、ピッカーがすべてではありません。

自分のクラスを追加するには、[GDScriptでオリジナルエンティティを作る](../custom-entities.md)を参照してください。

## パックに含まれないもの { #not-in-the-pack }

**コア**はアドオンに付いていて、パックは要りません。Worldspawnには、太陽、環境光、空、フォグ、ストリーミングの設定があり、何も選択していないときにインスペクターに表示されます。FuncGodotのクラス`func_geo`、`func_detail`、`func_detail_illusionary`、`func_illusionary`は、ふつうのジオメトリを作ります。`info_player_start`はプレイヤーが出現する場所を示しますが、自分では何もスポーンしません。そこにプレイヤーを置くのはゲームコードの仕事です。[`light`と`light_spot`](effects.md)は、切り替えられるライトです。

ブラシエンティティとモデルエンティティは、デフォルトで衝突します。変更するキーは[コリジョン](collision.md)を参照してください。

**プレイヤー**はエンティティではなく、あなたのゲームのシーンです。パックは、プレイヤーが`player`グループにいて、トリガーが見るコリジョンレイヤー1にいること、そしてダメージを与えるトリガーや爆発が呼ぶ`take_damage(amount, source)`メソッドがあることを前提にしています。別のレイヤーにいるプレイヤーは、*Trigger Collision Mask*にそのレイヤーを入れる必要があります。[トリガー](triggers.md#shared-inputs-outputs-and-keys)を参照してください。完全な例は[`godot/demo/player.gd`](https://github.com/Paraxdev/TrenchDot/blob/main/godot/demo/player.gd)にあります。
