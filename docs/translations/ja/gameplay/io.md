# エンティティI/Oのしくみ { #how-entity-io-works }

エンティティI/Oは、コードを書かずにマップの中で物事を起こすしくみです。SourceのHammerと同じやり方で配線します。

どのエンティティにも**アウトプット**と**インプット**があります。アウトプットは、ボタンが押されたときのように、エンティティが知らせるイベントです。インプットは、ドアを開けるように、エンティティにやらせられることです。接続は「このアウトプットが起動したら、あのターゲットのインプットを呼ぶ」という意味になります。配線はマップに保存されるので、エディターでボタンとドアをつなげば、ゲームの中でドアが開きます。

## 接続 { #a-connection }

アウトプットには、接続をいくつでも持たせられます。接続には次のフィールドがあります。

| フィールド | 役割 |
| --- | --- |
| 出力 | 接続を始める、このエンティティのイベント。たとえばボタンの`pressed` |
| ターゲット | 呼び出しを受け取るエンティティ。ふつうはtargetnameです。[ターゲット](parameters.md#targets)を参照してください |
| 入力 | ターゲットにやらせること。たとえばドアの`open` |
| パラメーター | インプットに渡す任意の値。ダメージ量などです。[パラメーター](parameters.md#parameters)を参照してください |
| 遅延 | インプットを呼ぶまで待つ秒数。0なら即座に呼びます。ライトが順番に点くときのように、イベントの時間をずらすのに使います |
| 回数 | 接続が起動できる回数。-1なら毎回、1なら一度きりのイベントになります |

接続は、選択したエンティティのインスペクターの**出力**で編集するか、[ロジックグラフ](logic-graph.md)のワイヤーとして編集します。どちらも同じアウトプットを変更します。(インスペクターにあるのは*回数*用の**一度だけ起動**チェックボックスだけです。それ以外の回数にしたいときは、ロジックグラフの接続ボックスを使ってください。)

![ボタンのインスペクターの出力セクション。アウトプットはpressed、ターゲットはfront_door、インプットはopen、パラメーターは空、遅延は0.00秒で、一度だけ起動のチェックボックスがある](../assets/io/inspector-outputs.png)

Godotでは、アウトプットがシグナルで、インプットがメソッドです。`func_button`には`signal pressed(activator)`があり、`func_door`には`func open()`があります。自作のスクリプトも同じ形で参加できます。[オリジナルエンティティ](custom-entities.md)を参照してください。

## アウトプットが起動するとき { #when-an-output-fires }

*遅延*の秒数が経つと、ターゲットが見つけたすべてのノードでインプットが呼ばれます。何も見つからないターゲットは、何もしません。targetnameやノードパスの場合、ほとんどはタイプミスなので、最初に起動したときに警告を出力します。遅延つきの呼び出しは、その間にエンティティがツリーから外れていると(たとえば倒されたとき)、破棄されます。

遅延がなければ、チェーン全体がシグナルの`emit`の中で実行され、emitしたコードの続きより先に終わります。emitした直後にスクリプトが状態を読むときは、これが重要です。下流のドアやカウンターは、すでに反応しています。

## アクティベーター { #the-activator }

アクティベーターは、チェーンを始めた存在です。たいていは、ボタンを押したプレイヤーや、トリガーに踏み込んだプレイヤーです。チェーンの先で`!activator`と書くと、そのノードを指すので、トリガーに触れた相手だけにダメージを与えたり、テレポートさせたりできます。

アクティベーターは、起動したシグナルの最初の`Node`引数から取られます。そのため、チェーン内のすべてのシグナルがノードを引き渡しているあいだしか残りません。組み込みのシグナルの動きは次のとおりです。

| シグナル | アクティベーターの扱い |
| --- | --- |
| `triggered`、`pressed`、`entered`、`exited`、`hurt`、`teleported`、`pushed` | そのまま引き継ぎます。これらのシグナルは、きっかけになったノードを運んでいます |
| `arrived(corner)`、`spawned(node)`、`reached(train)` | 括弧内のノードに置き換わります。以降の`!activator`は、そのコーナー、スポーンされたノード、トレインを指します |
| `opened`、`timer`、`step_N`、`on_true`、`on_case_N`、`result`、`broken`、`switched`、`map_spawn` | 失われます。これらはノードを運ばないので、ここから先の`!activator`は何も見つけません |

> [!TIP]
> アクティベーターを失ったチェーンの何段も先で、プレイヤーが必要になったときは、代わりに`!player`をターゲットにしてください。チェーンに左右されません。
