# 配置と配線 { #placing-and-wiring }

## エンティティを置く { #placing-entities }

右側のインスペクターの隣にある**エンティティ**タブを開きます。プロジェクトが知っているクラスごとに、カテゴリ別にカードが並んでいます。カードにカーソルを重ねると、そのクラスが何をするのかが表示されます。

![エンティティパネルでfunc_doorのカードにカーソルを重ねた状態。ツールチップにはブラシエンティティ、スライドドアと書かれている](../assets/placing/entities-panel.png)

カードをどれかのビューにドラッグすると置けます。ダブルクリックすると、3Dカーソルの位置に置かれます。(CtrlキーかShiftキーを押しながらクリックすると複数のカードを選べます。まとめてドラッグすると、一列に並んで置かれます。)ブラシエンティティのカードには、ボックスが付いてきます。ブラシを選択しているときにダブルクリックすると、ボックスの代わりに、選んだブラシをそのエンティティで包みます。

エンティティは、ポインターの下にある最初のソリッドな面に置かれます。トリガーボリューム、ツールテクスチャだけでできたブラシ、ほかのエンティティは素通りします。ドラッグ中は、置かれる場所にシアンのマーカーが出ます。2Dビューでは奥行きを表示できないので、マーカーには置かれる高さ(または奥行き)のラベルが付きます。上面ビューでは部屋の屋根が邪魔になります。Altキーを押しながらドロップすると、エンティティは屋根を抜けて、中の床に置かれます。正面ビューと側面ビューでは、Altキーで手前の壁を抜けて、部屋の中ほどに置かれます。

### ブラシエンティティ { #brush-entities }

ドア、ボタン、トリガーはブラシエンティティで、自分で作ったブラシから形を取ります。

1. 形を作ります。たとえば、ドアを置きたい場所に薄いボックスを作って、選択します。
2. ビューで右クリックして、*ブラシエンティティを作成*の下からクラスを選びます。*ブラシ > ブラシエンティティ*にも同じ一覧があります。

![ビューの右クリックメニュー。ブラシエンティティを作成が開き、trigger_onceにカーソルが重なっている](../assets/placing/context-create-brush-entity.png)

よく使うものには、もっと手早い方法があります。

| ツールまたはメニュー | 作るもの |
| --- | --- |
| *ゲームプレイ > ドアと可動物* | 選択したブラシから、蝶番のドアやスライドドア(トリガー付き)、またはリフト |
| *ゲームプレイ > トリガー* | 選択範囲を囲む大きさのトリガーボリューム |
| **ボリューム**ツール(Shift+E) | あらかじめブラシを作らずに、好きなトリガーボリュームを一度にドラッグして作る |
| **パス**ツール(Shift+P) | クリックごとに`path_corner`エンティティの連なりを作り、トレインやウォーカーがそれをたどる。Enterで完了 |

![ゲームプレイメニューでドアと可動物が開いた状態。蝶番ドア、スライドドア、リフト・移動プラットフォームが並んでいる](../assets/placing/gameplay-doors-menu.png)

![ツールバーのボリュームツールにカーソルを重ねてツールチップが出ている。ボリュームツール(Shift+E)、トリガー、スポーン、ダメージ、テレポート、プッシュのボリュームをドラッグして作る](../assets/placing/toolbar-volume-tool.png)

### ハンドル { #handles }

ドア、ゲート、プラットフォーム、ボタン、プッシュトリガー、スポナー、爆発、物理プロップを選ぶと、ビューにハンドルが出ます。数値を入力する代わりに、ハンドルをドラッグして、蝶番、開く量や動く距離、半径、大きさを決められます。蝶番の角度は15度刻みでスナップします。Shiftキーを押すと1度刻みになります。

![上面ビューで蝶番ドアの角度ハンドルをドラッグしている。ラベルが95°から30°に変わる](../assets/placing/door-hinge-handle.gif)

## 配線 { #wiring }

接続は、それを起動するエンティティに属します。そのエンティティを選んで、インスペクターの下にある**出力**を見てください。**+ 出力を追加**で接続が1つ増えるので、出力、ターゲット、インプットを入力します。各フィールドの役割は、[エンティティI/Oのしくみ](io.md)にあります。

![ボタンのインスペクターの出力セクション。出力はpressed、ターゲットはfront_door、インプットはopen](../assets/io/inspector-outputs.png)

2つのエンティティをもっと手早くつなぐには、両方を選んで*ゲームプレイ > ロジック > 選択した2つのエンティティをリンク…*を選びます。ちょうど2つのエンティティを選んでいるあいだは、インスペクターにも**リンク…**ボタンが出ます。

![ゲームプレイメニューでロジックが開き、選択した2つのエンティティをリンク…にカーソルが重なっている](../assets/placing/menu-link-two-entities.png)

*エンティティをリンク*ウィンドウでは、左にソース、右にターゲットが表示されます。*条件*の下で出力を、*呼出*の下でインプットを選んで、**リンク**を押します。

![エンティティをリンクウィンドウ。左にfunc_button、右にlight、条件はpressed、呼出はturn_on、入れ替えのツールチップが出ている](../assets/placing/link-dialog.png)

> [!WARNING]
> ソースが、最初にクリックしたエンティティとは限りません。上に出ている2つの名前を確認して、順番が逆なら、間にある**入れ替え**ボタンを押してください。

[ロジックグラフ](logic-graph.md)では、すべての配線が一度に見えます。ピンからピンへドラッグして、エンティティをつなげます。

## Godotなしで配線を確認する { #checking-wiring-without-godot }

[ロジックグラフ](logic-graph.md#simulate)でエンティティを選び、**シミュレート**を押して、出力を選びます。グラフは、そのあとに続く`source.output → target.input`の各ステップをハイライトし、遅延つきで一覧にします。そのため、ゲームをビルドして動かさなくても、長いチェーンをたどれます。赤は存在しないターゲットで、たいていはtargetnameのタイプミスです。青は`!player`や`@enemies`のような実行時のターゲットで、ゲームの中にしか存在しないので、それ以上はたどりません。

## どのエンティティのコードも見る { #code-for-any-entity }

**リファレンス**パネルは、どのエンティティクラスについても、GDScriptとC#のコードを見せてくれます。ゲームのコードがマップのエンティティと話す必要があるとき、たとえばドアを開けたり、ボタンを待ち受けたりするときに便利です。開くには、*表示 > パネル > リファレンス*か、*ヘルプ > エンティティとコードのリファレンス*を使います。インスペクターの**コードリファレンス**なら、選択しているエンティティのクラスに直接ジャンプします。クラス一覧と詳細のあいだの仕切りをドラッグすると一覧の幅を変えられ、ダブルクリックすると名前に合わせた幅になります。

![リファレンスパネルでfunc_buttonを選んだ状態。インプットとアウトプット、GDScriptでの使い方が表示されている](../assets/placing/reference-panel.png)

左でクラスを選んで、タブを選びます。*GDScript での使い方*と*C# での使い方*は、エンティティの呼び出し方を示します。*GDScript クラス*、*C# クラス*、*FGD.tres*は、自分で書くときのひな形です。**コピー**を押すと、コードがクリップボードに入ります。ひな形のタブでは、**プロジェクトに作成**が`res://entities/`の下にファイルを書き出します。すでにあるファイルには手を付けません。
