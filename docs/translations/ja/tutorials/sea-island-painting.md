# 海の島 3: ペイント { #sea-island-3-painting }

**Shift+G**キーか、ツールバーでスカルプトの隣にあるブレンドボタンで、ブレンドツールに切り替えます。スカルプトと同じく、選択中の地形に働き、何も選択していなければすべてに働きます。設定は左上のツールオプションバーにあります。

![ツールバーでブレンドツールのボタンにカーソルを重ねてツールチップが出ている。ドラッグすると、地形レイヤー、ディスプレイスメント、ブレンドマテリアルを持つ面にブレンドを描く](../assets/sea-island/toolbar-blend.png)

**傾斜**モードと**高さ**モードは、地面の急さや高さが範囲に収まっている場所にだけ描きます。半径12000なら島全体を覆えるので、これらのモードでは1回クリックするだけで、すべての岸辺や崖が一度に塗られます。

## 砂と岩 { #sand-and-rock }

| 設定 | 砂 | 岩 |
| --- | --- | --- |
| モード | 高さ、`-3000`から`40` | 傾斜、`32`から`90` |
| フォールオフ | 一定、ブラシ全体で最大の強さ | 一定 |
| レイヤー | 3 | 1 |
| 半径、強さ | 12000、1 | 12000、1 |

設定したら、それぞれ島の真ん中を1回ずつクリックします。40より低い部分がすべて砂になり、急な斜面がすべて岩になるはずです。

![高さモード。40ユニットより低い部分がすべて砂になる](../assets/sea-island/sand-height.jpg)

![傾斜モード。32°より急な部分がすべて岩になる](../assets/sea-island/rock-slope.jpg)

浜辺を広げるには、**描画**モード、フォールオフはスムーズ、半径700、強さ0.7で、南岸に沿ってレイヤー3を塗ります。スムーズなフォールオフはブラシの縁に向かって薄くなるので、砂の縁がやわらかく残ります。

## 小道 { #paths }

モードは**描画**、フォールオフはスムーズ、レイヤー2、半径140、強さ0.8にして、ドラッグします。

1. 浜辺の上から、メインの丘まで、長いカーブで。
2. メインの丘の頂上から、尾根に沿って崖の上まで。
3. 浜辺の東端から、2つ目の丘まで。

![メインの丘へ上る小道を描いているところ](../assets/sea-island/paths.jpg)

![小道を近くから見たところ](../assets/sea-island/path-close.jpg)

## 繰り返しを崩す { #break-up-the-repeat }

遠くから見ると、繰り返すテクスチャは格子に見えます。アウトライナーで地形を選び(ビューをクリックすると、ブレンドツールでペイントされてしまいます)、インスペクターの各レイヤー行で**タイル解消**と**シャープ**を設定します。シャープは、タイル解消したテクスチャをぼやけさせず、くっきり保ちます。

| レイヤー | タイル解消 | シャープ |
| --- | --- | --- |
| 0 草 | 0.5 | 0.5 |
| 1 崖 | 0.7 | 0.4 |
| 2 土 | 0.5 | 0.5 |
| 3 砂 | 0.4 | 0.5 |

![4つのレイヤー行が並んだ地形のインスペクター。各行にマテリアル、タイル、タイル解消、シャープがある](../assets/sea-island/inspector-terrain-layers.png)
