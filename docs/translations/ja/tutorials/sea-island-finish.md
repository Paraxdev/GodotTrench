# 海の島 5: 桟橋とGodot { #sea-island-5-pier-and-godot }

## 桟橋 { #the-pier }

1. 専用のレイヤーを用意する

    アウトライナー上部の**レイヤーを追加**をクリックします。新しいレイヤーが現在のレイヤーになるので、桟橋はそこに入り、地形とは別に隠したりロックしたりできます。

    ![アウトライナーでレイヤーを追加にカーソルが重なってツールチップが出ている。新しいレイヤー、現在のレイヤーになり、新しいオブジェクトがその中に入る](../assets/sea-island/outliner-add-layer.png)

2. 作る

    **Q**キーで選択ツールにします。散布ツールのままだと、ドラッグでモデルがペイントされてしまうからです。そのうえで、浜辺の真ん中から海へ伸びる普通のブラシを、下の表の大きさで描きます。

3. プロップを足す

    *ファイル > インポート > モデルプロップ (.bbmodel, .glb)…*を開いて、デモプロジェクトの`models/polyhaven`フォルダからモデルを選びます。デッキの上に`containers/wooden_crate_01`を2つと`containers/wine_barrel_01`を1つ、柱のそばに`nautical/lifebuoy`、水の中に`nautical/ocean_buoy`です。どれも3Dカーソルの位置に置かれるので、そこから所定の場所へ動かします。

    ![ファイルメニューでインポートが開き、モデルプロップ (.bbmodel, .glb)…にカーソルが重なっている](../assets/sea-island/menu-import-model-prop.png)

| パーツ | 大きさ | マテリアル |
| --- | --- | --- |
| デッキ | 幅128、長さ1100、厚さ8、上面は水面から48上 | `showcase/planks` |
| 柱 | 1辺16ユニットの角柱。200ユニットごとに2列、水面下320からデッキまで | `showcase/beam` |
| 手すり | 先端に短い柱を2本、高さ40 | `showcase/beam` |

プロップは、モデルを`res://`パスで参照します。そのため、ファイルは開いているGodotプロジェクトの中になければなりません。ほかの場所から選ぶと、エディターが先に`res://models`へのコピーを提案します。

![海から見た桟橋](../assets/sea-island/pier.jpg)

## Godotで見る { #see-it-in-godot }

マップをGodotプロジェクトの中に保存し、`FuncGodotMap`でビルドします。[マップのビルド](../godot/building.md)を参照してください。マップの各部分は、それぞれ違う種類のノードになります。

| マップの部分 | Godotで得られるもの |
| --- | --- |
| 地形 | チャンクに分かれた`TrenchDotTerrain`。各チャンクは4つのレイヤーをブレンドするメッシュで、それぞれ独自のコリジョンを持つ |
| 海 | `func_illusionary`ブラシ。コリジョンなしで見える |
| 木、茂み、大岩のセット | MultiMesh。さらに、モデルごとに静的ボディが1つあり、インスタンスごとにコリジョンシェイプが付く。シェイプはすべて共有される |
| 草のセット | コリジョンなしのMultiMesh。距離とともに消えていく |
