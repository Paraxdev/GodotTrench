# 海の島 4: 散布 { #sea-island-4-scatter }

散布を使うと、木、茂み、岩、草を、1つずつではなくブラシでたくさん置けます。以下の植え込みの種類は、それぞれ独立した散布セットで、セットはそのターゲット、つまり自分で選んだ面の上にだけ育ちます。

## セットを用意する { #set-up-a-set }

このページのセットは、どれも同じ手順で始めます。

1. 散布ツールを選ぶ

    **B**キーを押すか、ツールバーの散布ボタンをクリックします。右側のインスペクターの隣で、散布タブが開きます。(閉じてしまったときは、ツールオプションバーの**散布パネル**で戻せます。)

    ![ツールバーで散布ツールのボタンにカーソルを重ねてツールチップが出ている。ドラッグすると、有効な散布セットのモデルをペイントする](../assets/sea-island/toolbar-scatter.png)

2. プリセットから始める

    散布パネルの上にある**プリセット**をクリックして、手順に書いてあるプリセットを選びます。

    ![散布パネルでプリセットメニューが開き、混交林にカーソルが重なっている](../assets/sea-island/scatter-preset-menu.png)

3. 地形をターゲットにする

    **ターゲット**の隣のスポイトをクリックして、3Dビューで地形をクリックします。ターゲットの下に`terrain #2`のような名前で並ぶはずです。

    ![散布パネルのターゲットの行。スポイトにカーソルが重なってツールチップが出ている](../assets/sea-island/scatter-eyedropper.png)

**カーソルに追従**はチェックを外したままにします。これは、ターゲットを無視してブラシの下にあるものすべてに描いてしまうからです。**他のセットとの間隔を保つ**はチェックを入れたままにします。セット同士が距離を保ち、幹を突き抜けて何かが生えることがなくなります。

## 森 { #woodland }

1. **プリセット** > *混交林*を選び、上の**名前変更**をクリックして`woodland`と付けます。地形をターゲットにします。
2. ブラシセクションで、**密度**を0.16、**勾配**を0から30にして、**高さ**にチェックを入れ、120から2000にします。勾配の範囲で木が崖に生えなくなり、高さの範囲で浜辺に生えなくなります。

    ![散布パネルの下のほう。ターゲットはterrain #2、カーソルに追従はチェックなし、密度0.16、勾配0から30、高さはチェックありで120から2000、他のセットとの間隔を保つにチェックがあり、ターゲットを充填ボタンにカーソルが重なっている](../assets/sea-island/scatter-woodland-settings.png)

3. パネル下の**ターゲットを充填**をクリックして、地形全体に一度に植えます。

密度は、64 x 64ユニットあたりの試行回数を数えます。0.16なら、おおよそ5 mに木が1本です。

![ターゲットを充填したあとの森](../assets/sea-island/scatter-woodland.jpg)

**Shift**キーを押しながら、半径260で各小道に沿ってドラッグすると、そこの木が消えます。メインの丘の頂上に空き地(半径約520)、浜辺の裏に草地(約700)を消して作ります。

![小道の木を消しているところ](../assets/sea-island/scatter-erase-paths.jpg)

## 目玉の木、茂み、大岩 { #hero-trees-bushes-and-boulders }

各行は、名前のあるプリセットから作る新しいセットで、森と同じように地形をターゲットにします。目玉の木は、プレイヤーが近くでじっくり見る場所に置く、大きくて細部まで作り込んだ木を数本置くものです。

| セット | プリセット | 置き方 | 半径 | 密度 | 勾配 | 高さ |
| --- | --- | --- | --- | --- | --- | --- |
| 目玉の木 | 精細な森 | 小道が浜辺を離れるあたりと、頂上の空き地の周りを、単発のクリックで | 260 | 0.08 | 0から30 | オフ |
| 茂み | 茂み | **ターゲットを充填**してから、半径190で小道に沿って消す | | 0.35 | 0から32 | 45から200 |
| 大岩 | 大岩 | 崖の上に沿って1ストローク | 1100 | 0.035 | 12から50 | 20から2000 |

![小道のふもとの目玉の木](../assets/sea-island/scatter-hero-trees.jpg)

![砂の上に帯状に並んだ茂み](../assets/sea-island/scatter-bushes.jpg)

![崖に沿った大岩](../assets/sea-island/scatter-boulders.jpg)

## 草 { #grass }

1. *草*プリセットからセットを始めます。草はフォリッジで、コリジョンも影もなしで描画されるので、ゲームを重くせずに密に生やせます。
2. 開けた草地を、半径650、密度2.5、勾配0から28、高さ45から2000でペイントします。小道の上は半径170で消します。

    ![浜辺の裏の草地の草](../assets/sea-island/scatter-meadow.jpg)

3. 大岩の上にも草を生やすには、もう1つ*草*セットを始めます。スポイトで、地形ではなく大岩をクリックすると、大岩のセットがそのターゲットになります。ターゲットの下に、名前のあとに`(set)`が付いて並ぶはずです。そのうえで、密度6、勾配0から45で**ターゲットを充填**します。

    ![ターゲットの行に、ターゲットとしてcliff boulders (set)が並んでいる](../assets/sea-island/scatter-target-boulders.png)

> [!NOTE]
> 充填は、その時点の大岩の上に草を置きます。先に大岩を仕上げてください。

![大岩の上に生えた草](../assets/sea-island/scatter-boulder-grass.jpg)
