# 海の島 1: 地形 { #sea-island-1-terrain }

2つの丘、崖、浜辺、小道、森、桟橋のある大きな島を、5つのパートに分けて作ります。数値は画像に使ったもので、マップユニット(1メートルが32)で表しています。

![南から見た完成した島](../assets/sea-island/island-finished.jpg)

## 地形を作る { #create-the-terrain }

メニューバーの*地形 > 地形を作成…*を開きます。

![地形メニューで地形を作成…にカーソルが重なっている](../assets/sea-island/menu-create-terrain.png)

ダイアログを次のように埋めます。

| 設定 | 値とその理由 |
| --- | --- |
| **解像度**、**セルサイズ** | 257 x 257ポイント、間隔64ユニット。下の**サイズ**の行に、できあがる大きさが16384ユニット(512 m)と出ます |
| **形状** | 島、**高さ** 1600、**地形の大きさ** 3000、**侵食** 20、**シード** 1。島は中央が盛り上がり、端に向かって下がります。地形の大きさは一番大きな起伏の幅で、侵食は急な斜面を崩して風化したように見せます |
| **ベースレイヤー**、**斜面レイヤー**、**山頂レイヤー**、**低地レイヤー** | `showcase/grass`、`showcase/cliff`、`showcase/dirt`、`showcase/sand`。タイルは最初の2つが256、残りが192。ベースはペイントしなかった部分すべてを覆い、ほかの3つは急斜面、高地、低地のためのものです |
| **中央** | **3Dカーソル**のチェックを外して、`0 -576 0`にします |
| **傾斜と高さでレイヤーをペイント** | チェックを外します。パート3で手でペイントします |

(タイルの値は、テクスチャ1回分の繰り返しが何ユニットをカバーするかです。)

![入力済みの地形を作成ダイアログ。257 x 257、セルサイズ64、島、高さ1600、地形の大きさ3000、侵食20、シード1、4つのshowcaseレイヤー、中央0 -576 0、傾斜と高さでレイヤーをペイントはチェックなし](../assets/sea-island/create-terrain-dialog.png)

下にある**作成**をクリックします。緑色の島が、選択された状態で現れ、エディターは自動でスカルプトツールに切り替わります。

海は高さ0に置くので、地形を576下げると外側のリングは水没し、中央は乾いたまま残ります。後のパートでは、レイヤーをスロット番号で呼びます。0が草、1が崖、2が土、3が砂です。

## 海を足す { #add-the-sea }

海は、プレイヤーが入っていける平らなブラシ1つです。

1. 巨大なボックスを描く

    **Q**キーで選択ツールにして、**Escape**キーで地形の選択を外します。外さないと、ドラッグで地形がスカルプトされたり動いたりします。次に、上面ビューでドラッグして、地形より何倍も大きなボックスを描きます。小さいと、水平線に縁が見えてしまいます。

2. 平らにする

    正面ビューで、厚さを32ユニットにして、上面を高さ0に合わせます。

3. 水にする

    ボックスを選んだ状態で、マテリアルタブの`showcase/water`をクリックします。続けて、3Dビューで水をShiftクリックして上面だけを選び、インスペクターの*アライメント*セクションで*スケール*を8と8にします。こうすると、水のテクスチャが数メートルおきに繰り返されません。

    ![面が1つ選択されたインスペクター。マテリアルはshowcase/water、アライメントのスケールは8.00と8.00](../assets/sea-island/inspector-alignment-scale.png)

4. プレイヤーが歩いて入れるようにする

    島から離れた場所で水を一度クリックして、上面だけではなくボックス全体を選び直します。それから右クリックして、*ブラシエンティティを作成 > func_illusionary*を選びます。コリジョンなしで描画されるので、プレイヤーは水の中に歩いて入れます。

これで、スカルプトの準備ができた、海に浮かぶ島ができました。

![スカルプト前の、海の中に生成された島](../assets/sea-island/fresh-island.jpg)
