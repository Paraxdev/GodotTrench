# 海の島 2: スカルプト { #sea-island-2-sculpting }

スカルプトで、生成された地面を狙いどおりの形に押し出していきます。

1. スカルプトツールを選ぶ

    先に**Escape**キーを押してください。前のパートで作った海がまだ選択されたままだと、スカルプトは何もしません。スカルプトは、選択中の地形に対して働き、何も選択していなければすべての地形に対して働きます。そのあと**G**キーを押すか、ツールバーのスカルプトボタンをクリックします。

    ![ツールバーでスカルプトツールのボタンにカーソルを重ねてツールチップが出ている。選んだモードで、地形やディスプレイスメントの上をドラッグして形を整える](../assets/sea-island/toolbar-sculpt.png)

2. 設定を探す

    モード、半径、強さは、ツールバーのすぐ下の左上にあるツールオプションバーにあります。ドラッグしながら**Ctrl**キーを押すと、どのモードでもスムーズになります。

    ![スカルプトツールのオプション。半径2800、強さ32で、モードの一覧が開き、上げる、下げる、スムーズ、平坦化、ノイズ、段丘、アルファを描くが並んでいる](../assets/sea-island/sculpt-mode-list.png)

3. 高さを見ておく

    右下のステータスバーには、ポインターの下の点が表示され、真ん中の数字が高さです。どこまで上げたか、下げたかを判断するのに便利です。

    ![ステータスバーの座標、-2200.0、1549.2、-600.0。真ん中が高さ](../assets/sea-island/status-bar-height.png)

## 丘 { #hills }

1. **上げる**、半径2800、強さ32。中央より西で、マウスボタンを4秒ほど押し続けます。ステータスバーに、丘の高さが約1500ユニットと出るまで続けます。

    ![スカルプトツールが上げるモード、半径2800、強さ32。ボタンを押している間、ブラシのリングの下で丘が育っていく](../assets/sea-island/sculpt-raise.gif)

2. 同じ場所で半径を1300にすると、頂上が急になります。小さなブラシは狭い範囲を持ち上げるので、頂上が尖ります。
3. 半径を1900にして、南東に低い2つ目の丘を作ります。

## 崖 { #cliffs }

1. **上げる**、半径1800。北東の海岸線に沿って、少し内陸側をドラッグし、岬を作ります。次に、とても大きなブラシで島全体を一度**スムーズ**にして、でこぼこを取ります。
2. **下げる**、半径1000。その海岸の前の海をドラッグして深くします。崖が浅い棚ではなく、深い水に落ち込むようにするためです。
3. **段丘**、ステップ300、半径1000。段丘は、高さを指定した大きさの段に揃えます。海岸線に沿ってドラッグして、棚と急な面に分けたら、軽い**スムーズ**を一度かけます。

![海岸沿いに300ユニット刻みで段丘をかけたところ](../assets/sea-island/terrace-cliffs.jpg)

## 浜辺 { #beach }

1. **平坦化**、半径900。平坦化は、ストロークを始めた高さを保ちます。南岸の水際からちょうど始めて、海岸に沿ってドラッグしてください。
2. 少し大きめのブラシで**スムーズ**をかけると、浜辺が段差なく陸へつながります。

![南岸に平坦化をかけたところ](../assets/sea-island/beach-flatten.jpg)
