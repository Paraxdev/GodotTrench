# TrenchDot { #trenchdot }

![TrenchDot, un editor de niveles para Godot](assets/brand/itch-banner-960x300.png)

TrenchDot es un editor de niveles para Godot basado en brushes, en el espíritu de TrenchBroom y Hammer.
Admite I/O, mallas propias (Hammer, Quake, Blockbench) y más.

TrenchDot se inspira mucho en TrenchBroom y sigue su propio camino alrededor de Godot. No tiene ninguna relación con el
proyecto TrenchBroom.

![El editor TrenchDot](screenshots/editor.png)

## Descarga { #download }

TrenchDot tiene una [beta continua en GitHub](https://github.com/Paraxdev/TrenchDot/releases/tag/beta), es decir, siempre
es la versión más nueva que puedes conseguir.
Como el proyecto está en una fase muy temprana, ahora mismo no hay prevista ninguna versión LTS. Cuando se vuelva un
software útil, se publicará una versión completa.

También está disponible en [itch.io](https://paraxdev.itch.io/trenchdot).

Para compilarlo desde el código fuente, consulta [Desarrollo](development.md).
