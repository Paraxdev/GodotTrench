# TrenchDot { #trenchdot }

![TrenchDot, un éditeur de niveaux pour Godot](assets/brand/itch-banner-960x300.png)

TrenchDot est un éditeur de niveaux à base de brushes pour Godot, dans l'esprit de TrenchBroom et de Hammer.
Il gère les E/S, les meshes personnalisés (Hammer, Quake, Blockbench) et bien plus encore !

TrenchDot s'inspire beaucoup de TrenchBroom et trace sa propre route autour de Godot. Il n'est pas affilié au projet
TrenchBroom.

## Télécharger { #download }

TrenchDot a une [bêta continue sur GitHub](https://github.com/Paraxdev/TrenchDot/releases/tag/beta), c'est-à-dire que
c'est toujours la version la plus récente que vous pouvez obtenir.
Le projet en est à un stade très précoce, aucune version LTS n'est donc prévue pour le moment. Quand il aura fait ses
preuves comme logiciel utile, une version complète sortira.

Il est aussi disponible sur [itch.io](https://paraxdev.itch.io/trenchdot).

Pour le compiler depuis les sources, rendez-vous sur [Développement](development.md).
