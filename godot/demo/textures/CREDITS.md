# Demo texture credits

Every photo texture here comes from [Poly Haven](https://polyhaven.com) or [ambientCG](https://ambientcg.com) and is
released under [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/). No attribution is required, it is
given here anyway. The files are rebuilt by `python tools/fetch_demo_textures.py`, which holds the same table.

The world size is what one repeat of the texture covers in the map, stored in each material as
`metadata/texture_size` and taken from the real size of the scan where the source publishes one.
